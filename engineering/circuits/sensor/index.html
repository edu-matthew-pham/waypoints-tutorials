Sensors that vary

Analog read turns the voltage on a pin, 0 to 3.3 V, into a number from 0 to 1023. A knob or a light sensor in a divider changes that voltage, so the number changes. A program compares the number with a threshold to decide, as a night light does.

A button is on or off. But a room isn't just light or dark, and a volume knob isn't just loud or silent. How does a micro:bit measure something in between?

A digital input is 0 or 1. An analog input can be anything in between. Analog read pin P0 gives a number from 0 to 1023. A knob (a potentiometer) is a resistor with a slider: turning it moves the slider between 3V and GND, so the voltage on pin 0 changes.

Explain it to me

Analog read turns the voltage on a pin, 0 to 3.3 V, into a number from 0 to 1023: halfway (1.65 V) reads about 512. A knob or a light sensor in a divider changes the voltage, so the number changes. The number is a scale, not the volts. A program compares it with a threshold to decide, such as switching lights on below 300.

For teachers

Students turn a knob on pin 0 and see analog read give 0 to 1023, convert between position, reading and volts, swap in a light sensor in a divider, and set a threshold for a night light. About 45 minutes.

Open the teacher guide: answers, solutions, slides and a worksheet.

Students will be able to

  • I can explain what analog read gives.
  • I can convert between a reading and volts.
  • I can choose a threshold so a program decides at the right moment.

Before class

Model: analog read is 0–1023 for 0–3.3 V (the micro:bit's 10-bit reading); the knob and the light sensor give a voltage in proportion to the position or the light. Real light sensors (photoresistors) are far from linear, which Tinkercad will show.

Links: Digital systems › binary (10 bits make 1024 patterns, 0 to 1023).

Running the lesson

  1. Predict: ask those who chose 1.65 what unit analog read gives.
  2. Worked example: draw the three scales one above the other.
  3. Vary, swap them: draw both dividers and ask which end the sensor is on.
  4. Make: compare thresholds. Who picked one close to 205, and what could go wrong?

The hard part (on purpose)

Three scales at once (percent, reading, volts) blur together. Keep a number line on the board with all three marked.

When students get stuck

  • A student reports volts as the reading. Ask: What is the biggest number analog read can give? Fix: 1023, for 3.3 V.
  • A student's threshold works backwards. Ask: Does darker make the reading bigger or smaller, in this circuit? Fix: Smaller here: lights on below the threshold.

Stretch and support

Stretch: Why 1023? How many bits does the micro:bit use for an analog reading?

Support: A printed number line with 0, 512 and 1023 above 0 V, 1.65 V and 3.3 V.

What each step is for

  • halfway: Committing to the reading at halfway tests the new move: analog read maps 0–3.3 V onto 0–1023. Each wrong option is a real slip: the volts, a percentage, a digital 1.
  • Try: turn the knob: Turning the knob settles the prediction and shows both ends of the scale.
  • Worked example: number and volts: Converting between position, reading and volts models the move; Sam's 'the number is volts' is planted after the method.
  • Vary: a light sensor: Swapping the knob for a light sensor in a divider shows the same move with a real-world input: light changes the voltage, so the number.
  • Build it in Tinkercad: Tinkercad's photoresistor and potentiometer, read with analog read and shown on the micro:bit, check the idea in a fuller simulator.
  • readings: Readings, volts and percentages both ways, and a threshold decision.
  • a night light: Setting a threshold so the lights switch on at the right darkness reverses the process: from a behaviour to a number.
