Counting and measuring

Numerical data is discrete when it is counted (siblings: 0, 1, 2, …) and continuous when it is measured (a 100 m time can be any value, such as 14.37 s). Measured values are always rounded to some precision.

How many siblings do you have? How long does it take you to run 100 m? Both answers are numbers, but they behave differently. How?

Statistics starts with data: values collected to answer a question. Before you work with some numbers, it helps to ask what values they could take.

Explain it to me

Discrete data is counted: it takes separate values, such as 0, 1, 2 siblings. Continuous data is measured: it can be any value in a range, such as a 100 m time of 14.37 s.

Measured values are always rounded: 152 cm to the nearest centimetre means from 151.5 cm up to 152.5 cm. Decimals alone do not make data continuous: shoe sizes (7, 7.5, 8) are discrete.

Numerical data comes in two kinds:

  • Discrete data is counted: number of siblings, goals scored, cars in a car park. It takes separate values, usually whole numbers.
  • Continuous data is measured: height, time, mass, temperature. It can take any value in a range; we round it when we record it.

The kind of data changes how you collect it, and how you display it later in this unit.

  2. Waiting time: measured, so any value in a range, such as 94.3 s: continuous a stopwatch gives a value rounded to some precision

For teachers

Students sort numerical variables into discrete (counted) and continuous (measured), place a measured value between whole numbers on a dot plot, and see that measurements are always rounded to some precision (AC9M7ST01, node 1). About 35 minutes.

  • I can explain why a measurement is always rounded, and choose a sensible precision.

Before class

Try the Run board first. This short lesson opens the Data unit; the next lesson calculates mean, median, mode and range.

The one idea: counted data takes separate values (discrete); measured data can be any value in a range (continuous). The common mistake is treating any decimal as continuous (shoe sizes, prices); it is planted in Ava's reasoning.

Age and money are worth discussing rather than ruling on: age is measured time recorded in whole years; money is counted in cents but has so many values that it is often treated as continuous.

Running the lesson

  1. Predict: take a show of hands; ask each group how they decided.
  2. Run: ask whether a 14.35 s time is possible and what would measure it.
  3. Investigate: build a two-column list on the board (counted / measured) from students' own examples.
  4. Modify: let the age question be a short debate.
  5. Make: ask what happens to the six times if rounded to whole seconds.
  6. Paper: the canteen line is worked in books; the page marks the reason the wait is continuous. Books out, and look for a measured value written with its rounding.

The hard part (on purpose)

Treating any decimal as continuous. Ask: could there be a value between these two? Was it counted or measured?

When students get stuck

  • A student calls any decimal data continuous (Ava's mistake). Ask: What values are possible between 7 and 7.5 for a shoe size? Fix: Fixed steps with nothing in between: discrete.
  • A student calls large counts continuous. Ask: Is it counted or measured? Fix: Counted, however big: discrete.

Stretch and support

Stretch: Find a variable that could be recorded either way, depending on how you collect it (time in whole minutes, or measured with a stopwatch).

Support: Ask 'Could you have half of one?' and 'Is it counted or measured?' for every variable.

What each step is for

  • which can be 152.5?: Committing to which variable can take the value 152.5 shows whether they think in terms of counting versus measuring.
  • add a time: Placing a value between whole numbers on a measured scale shows that continuous data can fall anywhere, limited only by how precisely it is measured.
  • counted or measured: Counted gives discrete data, measured gives continuous; and measured values are always rounded. Ava's mistake thinks any decimal means continuous.
  • one change at a time: One change at a time: the same topic counted or measured, money, a rating scale, then the edge case of age, which is measured but usually recorded as a count of years.
  • kinds of data: Classifying variables from contexts, choosing a precision, and spotting rounding, mixed; the review keeps decimals fresh.
  • your own measured data: Building a data set whose values all lie between two whole numbers shows that continuous data needs decimals, and that more precision separates values that rounding would merge.
  • the canteen line on paper: Counting a line and timing a wait shows both kinds of numbers in one place; the paper task asks them to sort and choose the reason for continuous.
