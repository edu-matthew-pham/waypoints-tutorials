Solving by backtracking

Undo what was done to x, last step first, to find the number you started with.

Retracing your steps to find a lost key is backtracking: you undo your route, most recent first. Equations work the same way.

What you should already know:
  • Undo it · Adding and taking away undo each other, and so do multiplying and dividing.
  • Equations as a balance · An equation says two things are equal.

An equation like 2x+3=112x + 3 = 112x+3=11 is a machine: xxx goes in, gets multiplied by 2, then 3 is added, and 11 comes out. If you only see what comes out, how could you find xxx?

How this lesson works: Predict, Try, Investigate, Modify, Practise, Make

  • Try: Try it on the board and compare the result with your prediction.
  • Investigate: Work out why it happens, one step at a time.
  • Modify: Change the problem on purpose and see what happens.
  • Practise: A few on your own, to check you have it.
  • Make: Make your own problem using what you have learned. Expect a few tries; that is normal.

Explain it to me

Backtracking means running an equation backwards. In 2x+3=112x + 3 = 112x+3=11, xxx is multiplied by 2, then 3 is added, and the answer is 11.

To find xxx, undo each step with its opposite, starting with the last one: take away 3 (11−3=811 - 3 = 811−3=8), then divide by 2 (8÷2=48 \div 2 = 48÷2=4).

Then check by running forwards: 2×4+3=112 \times 4 + 3 = 112×4+3=11. If it matches, you have the solution.

Do this one in your book. The prices are made up, but trip organisers work out head counts from a bill like this. Write the machine, undo it, check it, then type the number of students and choose the reason for the first step.

For teachers

Students solve one- and two-step equations by backtracking, undoing each step of a function machine in reverse order and checking forwards (AC9M7A03, node 2). About 45 minutes.

Open the teacher guide: answers, solutions, slides and a worksheet.

Students will be able to

  • I can solve a two-step equation by backtracking.
  • I can name the step that undoes another (the inverse operation).
  • I can undo steps in the right order, last step first, and check my answer forwards.

Before class

This is a hinge lesson: the next lesson's balance method needs the same idea of order. Students who undo steps in the wrong order here will set up every later equation wrongly, so watch for it.

Try the last Modify machine yourself (3(x+4)=273(x + 4) = 273(x+4)=27). It adds first and multiplies last, so the first undo is ÷ 3\div\,3÷3. That surprises students who always "take away the number first".

Running the lesson

  1. Predict: take a few answers and ask how each student got there. Someone will describe undoing; name it 'backtracking'.
  2. Run: the machine only accepts the step that undoes the last arrow. Wrong steps get a nudge, not the answer.
  3. Investigate: before the worked example, ask the class for the opposite of each step (the matching task). Then reveal the example one line at a time.
  4. Mia's mistake is the most common error. Ask: what did the machine do last? That is the first thing to undo.
  5. Modify: the brackets task is the point. Ask students to say the machine's order aloud before undoing anything.
  6. Practise: insist on the forwards check every time. It catches the order mistake on its own.
  7. Paper: the excursion bus is worked in books (equation, undo the fee, divide, check). The page marks 28 and the reason for taking the fee away first. Books out, then look at the page for the model.

The hard part (on purpose)

Undoing in the wrong order. The number in front of x looks like the one to deal with first, so students divide before they take the extra number away. Ask 'what did the machine do last?' every time, and make the forwards check automatic.

When students get stuck

  • A student divides first in 2x + 3 = 11 and gets 2.5. Ask: What did the machine do last? What undoes that? Fix: Undo the + 3 first (11 − 3 = 8), then the × 2 (8 ÷ 2 = 4). Check forwards.
  • A student undoes − 5 by taking away 5 again. Ask: If I take 5 away and want it back, what do I do? Fix: The opposite of taking away is adding: 9 + 5 = 14.
  • A student stops after one step on a two-step equation. Ask: Is that the number that went in, or a number partway through the machine? Fix: Draw the machine with a box between the steps; keep undoing until you reach x.

Stretch and support

Stretch: Make a three-step machine, such as × 2, + 5, × 3, and write its equation with brackets. Swap with a partner and backtrack each other's.

Support: Write the machine as arrows on paper (x → × 2 → + 3 → 11), then draw the backwards arrows underneath with the opposite steps before calculating.

Where it leads

Next: the balance method, which does the same undoing to both sides of an equation, and still works when xxx is on both sides (where backtracking cannot).

Where it leads in class: "think of a number" puzzles, and working back from a total, such as the price before a fee was added.

What each step is for

  • what number went in?: Students can already reverse a two-step calculation in their heads; naming that as undoing is the bridge to backtracking.
  • run the machine backwards: Undoing has an order: the last thing the machine did is the first thing to undo.
  • undo in reverse: Each operation has an opposite (inverse), and the steps are undone in reverse order.
  • new machines: The order of the machine decides the order of undoing, including when the machine adds before it multiplies (brackets).
  • backtrack these: Fluent backtracking needs the order and the inverse right every time, checked forwards.
  • your own machine: Building a machine from its input shows that backtracking and running forwards are the same steps in reverse.
  • the excursion bus on paper: Counting students from a bus bill uses the whole lesson in one place: build the machine, undo the last step first, check forwards.
