# AC9M7A01 — Variables and formulas

**Year 7**
**Strand:** Algebra
**Planning mode:** A — Concept-certifying

## ACARA Descriptor

recognise and use variables to represent everyday formulas algebraically and substitute values into formulas to determine an unknown

## ACARA Elaborations

- linking variables to attributes and measures being modelled when using formulas, such as area of a rectangle as A = l × w
- interpreting and using formulas obtained from other sources; for example, maximum heart rates and target heart rates for moderate exercise
- substituting numerical values for variables when using formulas and calculating the value of an unknown in practical situations; for example, calculating weekly wage W = b + 1.5 × h × r
- using everyday formulas and their application to contexts on Country/Place, investigating the relationships between variables

## Prior Knowledge

Students can find unknown values in equations involving brackets and combinations of operations, and recognise rules in growing patterns (from AC9M6A01, AC9M6A02). Students understand that a letter can represent an unknown.

## Progression Endpoint

Students recognise variables as quantities that can change, represent everyday formulas algebraically, and substitute values to determine unknowns.

## Width Tiers

**Width varies by:** phenomena and contexts

**Minimum width:** Identify variables in a given formula, describe what each represents, and substitute given values to evaluate the formula.

**Typical width:** Recognise and use variables to represent everyday formulas; substitute values to find the result; determine an unknown by substituting known values and solving; verify by substitution back.

**Wider:**
- Interpret and use formulas from other subject areas: maximum heart rate, density, distance-speed-time — substitute values and interpret results in context.
- Apply formulas in Country/Place contexts: investigate formulas relevant to First Nations Australian land management or traditional ecological knowledge.
- Explore formulas with multiple unknowns where all but one value are given — systematically find the unknown across a range of practical contexts.

## Waypoint Sequence (3 waypoints, 1 hinge, 1 width opportunity)

#### 1. Variables as generalised quantities

Students recognise that variables represent quantities that can change, and distinguish a variable from an unknown constant.

**Response modes:**
- ↔ Widen contexts — more examples resolve misconceptions here: Students entering Y7 typically treat all letters as 'the unknown x to solve for'. The variable-as-generalised-quantity concept requires multiple formula contexts to become stable.

**Minimum width:** Identify the variables in a given formula and describe what each represents in context.

**Typical width:** Link variables to the attributes they model; explain the difference between a variable (can take many values) and a specific unknown (one value to find).

**Wider:**
- Investigate how the same letter variable is used differently in different formulas (e.g. A for area in one, for amplitude in another) — variables are context-specific labels.
- Explore formulas from other subjects: distance = speed × time; explore what each variable represents.

**Success criteria:**
- Correctly identifies what each variable represents in a given formula.
- Explains the difference between a variable that can take many values and a specific unknown.
- Does not treat all variables as things to 'solve for'.

**Related standards:**
- AC9M7A02 — Algebraic expressions

#### 2. Substituting values into formulas ⚑

Students substitute given numerical values into a formula and calculate the result.

**⚑ Hinge — ◆ Practise here — fluency matters more than breadth:** Arithmetic errors during substitution propagate directly into Node 3 — students who cannot substitute correctly cannot find unknowns, since the finding-unknown step builds on a correctly evaluated substitution.

**Response modes:**
- ◆ Practise here — fluency matters more than breadth: Substitution is a mechanical skill that requires fluency before finding unknowns. Errors here are typically arithmetic (not algebraic) but propagate into node 3.

**Minimum width:** Given a formula and values for all but one variable, substitute and evaluate.

**Typical width:** Substitute values into formulas from practical contexts (area, perimeter, wage, density); evaluate correctly including with fractions and decimals.

**Wider:**
- Substitute values into formulas from science and everyday life (e.g. heart rate formula, body mass index) and interpret the result in context.
- Investigate Country/Place formulas: investigate formulas used in Indigenous land management or navigation contexts.

**Success criteria:**
- Correctly substitutes values into a formula and evaluates.
- Applies correct order of operations during substitution.
- Does not multiply the coefficient by the variable label (e.g. does not treat 3A as 3×'the letter A' rather than 3 times the value of A).

**Related standards:**
- AC9M7A06 — Manipulate formulas

#### 3. Finding an unknown by substitution and backtracking ★

Students determine the value of an unknown variable in a formula by substituting known values and solving.

**★ Width opportunity:** Advancing students can explore both substitution/backtracking and formal rearrangement as equivalent methods, and apply to a range of real formulas — connecting algebra to science and everyday contexts.

**Response modes:**
- ⊕ Integration point — components come together here: Finding an unknown brings together variable understanding, substitution, and arithmetic operations simultaneously. The coordinated application is the learning.

**Minimum width:** Given a formula with one unknown and all other values provided, find the unknown by substituting and solving.

**Typical width:** Find unknowns in formulas in practical contexts (e.g. find the base wage given total wage and overtime details); verify by substituting back.

**Wider:**
- Compare finding unknowns using substitution + backtracking vs formal algebraic rearrangement — note both methods are valid.
- Apply to a range of real formulas: perimeter to find a missing side, density formula to find mass or volume.

**Success criteria:**
- Correctly finds an unknown in a formula given all other values.
- Verifies the solution by substituting back into the formula.
- Interprets the result in context (with units and meaning).

**Related standards:**
- AC9M7A03 — Solve linear equations
- AC9M7A06 — Manipulate formulas
