# AC9M7N07 — Add and subtract integers

**Year 7**
**Strand:** Number Concepts (Number)
**Planning mode:** A — Concept-certifying

## ACARA Descriptor

compare, order and solve problems involving addition and subtraction of integers

## ACARA Elaborations

- using less-than and greater-than notation in expressions when comparing and ordering integers; for example, negative 5 is less than positive 2 and is represented as -5 < 2
- discussing language such as 'addition', 'subtraction', 'magnitude', 'difference', 'sign' and synonyms of these terms
- ordering, adding and subtracting integers using a number line

## Prior Knowledge

Students can locate integers on a number line and recognise negative integers in context (from AC9M6N01). Students understand magnitude and direction in simple contexts (above/below zero, gain/loss).

## Progression Endpoint

Students compare and order integers using inequality notation and solve problems involving addition and subtraction of integers.

## Width Tiers

**Width varies by:** phenomena and contexts

**Minimum width:** Compare and order integers including negatives using < and > notation; add and subtract integers using a number line.

**Typical width:** Apply < and > notation in expressions; add and subtract integers without a number line; solve practical problems involving addition and subtraction of integers in real contexts (temperature, gain/loss, floors).

**Wider:**
- Investigate the pattern that subtracting a negative equals adding a positive — explain through number line movement and verify with multiple examples.
- Explore integer operations in financial contexts: running balance problems involving credits and debits over a series of transactions.
- Apply integer reasoning to temperature change problems that chain multiple additions and subtractions across a daily record.

## Waypoint Sequence (2 waypoints, 2 hinges, 1 width opportunity)

#### 1. Comparing and ordering integers ⚑

Students compare and order integers using less-than and greater-than notation, including negative integers.

**⚑ Hinge — ↔ Widen contexts — more examples resolve misconceptions here:** The magnitude-vs-direction confusion (believing −7 > −2) produces systematic errors in Node 2 addition and subtraction — students who cannot correctly order integers cannot set up or check integer calculations.

**Response modes:**
- ↔ Widen contexts — more examples resolve misconceptions here: Students commonly believe −7 > −2 because 7 > 2. Multiple real-world contexts (temperature, floors below ground, financial loss) help resolve the magnitude vs direction confusion.

**Minimum width:** Order a given set of integers (including negatives) from least to greatest and use <, > notation to compare pairs.

**Typical width:** Place a mixed set of integers on a number line; use inequality notation in expressions; explain why −7 < −2.

**Wider:**
- Investigate absolute value informally: distance from zero on a number line. Compare |−7| and |2| without formal notation.
- Connect ordering to real contexts: temperature below zero, sea level, financial debt.

**Success criteria:**
- Correctly orders a set of integers including negatives.
- Uses < and > notation correctly between integers.
- Does not confuse the magnitude of a negative with its value (e.g. understands −10 < −1).

**Related standards:**
- AC9M7N04 — Rational numbers on a number line

#### 2. Addition and subtraction of integers ⚑ ★

Students add and subtract integers using a number line and understand the effect of adding or subtracting a negative number.

**⚑ Hinge — ↔ Widen contexts — more examples resolve misconceptions here · ◎ Scaffold reasoning — unpack the logic explicitly:** The operation-sign/number-sign confusion produces persistent errors in AC9M7N06 rational number operations and AC9M7N09 modelling contexts — students who cannot confidently add and subtract integers cannot handle any signed number computation downstream.

**★ Width opportunity:** The pattern that subtracting a negative equals adding a positive, explained through number line movement, is a rich structural insight — advancing students can use this to reason about multi-step integer expressions.

**Response modes:**
- ↔ Widen contexts — more examples resolve misconceptions here: Integer addition and subtraction is a major misconception site. Students confuse the sign of the number with the operation sign. Number line contexts, thermometer contexts, and financial contexts each address different facets of the misconception.
- ◎ Scaffold reasoning — unpack the logic explicitly: The rule 'subtract a negative = add a positive' requires explicit reasoning: movement on a number line combined with meaning of the operation. Without scaffolding, students apply rules inconsistently.

**Minimum width:** Calculate simple integer additions and subtractions using a number line (e.g. −3 + 5, 4 − 7, −2 − 3).

**Typical width:** Calculate integer sums and differences without a number line; interpret addition of a negative and subtraction of a negative; apply in context.

**Wider:**
- Investigate the pattern: subtracting a negative equals adding a positive — explain using number line movement.
- Explore temperature change problems requiring chaining multiple integer additions and subtractions.

**Success criteria:**
- Correctly adds and subtracts integers including cases with negative operands.
- Interprets adding a negative number as movement in the negative direction.
- Does not treat subtraction of a negative as subtraction (e.g. 5 − (−3) = 8, not 2).

**Related standards:**
- AC9M7N09 — Model with rational numbers
