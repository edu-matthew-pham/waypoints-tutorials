# AC9M8SP03 — 3d coordinate systems

**Year 8**
**Strand:** Space

## ACARA Descriptor

describe the position and location of objects in 3 dimensions in different ways, including using a three-dimensional coordinate system with the use of dynamic geometric software and other digital tools

## Prior Knowledge

Students can plot and describe positions on the Cartesian plane (from AC9M7SP03). Students understand transformations in 2D using coordinates.

## Progression Endpoint

Students describe positions in 3D using latitude/longitude/altitude, three-dimensional coordinates, and other spatial reference systems.

## Waypoint Sequence (2 waypoints, 1 hinge)

#### 1. Extending the coordinate system to three dimensions ⚑

Students extend the 2D Cartesian plane to three dimensions by adding a third axis (z), and plot and read coordinates in the first octant.

**⚑ Hinge:** Node 2 requires interpreting practical 3D reference systems including latitude/longitude/altitude — students who have not built spatial intuition for the third axis cannot map between the abstract coordinate system and these real-world applications.

**Response modes:**
- ↔ Widen contexts: The extension from 2D to 3D coordinates is conceptually demanding — multiple representations (software, verbal description, diagrams) and real-world contexts help students build spatial intuition for the third axis.

**Minimum width:** Plot and read coordinates (x, y, z) for simple positions in the first octant using dynamic geometry software.

**Typical width:** Describe and locate objects using 3D coordinates; compare 2D and 3D coordinate systems identifying what is the same and what differs.

**Wider:**
- Construct 3D shapes using 3D design software that uses a three-dimensional coordinate system — connect the coordinates to the vertices of the shape.
- Explore geospatial technologies used by First Nations Australian communities to describe position and transformation on Country.

**Success criteria:**
- Plots a point given 3D coordinates in the first octant.
- Reads the coordinates of a plotted point.
- Identifies which axis extends the 2D plane to 3D.

**Related standards:**
- AC9M7SP03

#### 2. Describing positions in real-world 3D systems ★

Students describe positions in practical 3D reference systems including latitude/longitude/altitude and multi-storey coordinate systems.

**Response modes:**
- ↔ Widen contexts: 3D spatial reasoning develops through varied practical contexts — aircraft, buildings, games, and printing all use the same underlying coordinate structure but present it very differently.

**Minimum width:** Describe the position of an object using latitude, longitude and altitude; interpret a 3D coordinate location in a practical context.

**Typical width:** Apply 3D coordinate systems to aircraft/drone location, multi-storey buildings, and map-based systems; connect the abstract system to familiar real-world applications.

**Wider:**
- Investigate how 3D printers use a three-dimensional coordinate system to build objects layer by layer — describe the relationship between the coordinate path and the physical object.
- Explore games based on 3D coordinate systems — describe how player position and movement are represented.

**Success criteria:**
- Correctly describes a position using a practical 3D reference system.
- Interprets a 3D coordinate in a real-world context.
- Connects the three coordinates to three independent dimensions of location.
