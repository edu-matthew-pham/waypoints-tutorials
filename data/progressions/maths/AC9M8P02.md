# AC9M8P02 — Combinations for two events

**Year 8**
**Strand:** Probability

## ACARA Descriptor

determine all possible combinations for 2 events, using two-way tables, tree diagrams and Venn diagrams, and use these to determine probabilities of specific outcomes in practical situations

## Prior Knowledge

Students can list sample spaces and assign probabilities for single-stage events (from AC9M7P01). Students understand complementary events (from AC9M8P01).

## Progression Endpoint

Students represent all combinations for two events using two-way tables, tree diagrams and Venn diagrams, and calculate probabilities of compound events.

## Waypoint Sequence (2 waypoints, 1 hinge)

#### 1. Representing two-event combinations ⚑ ★

Students represent all possible combinations for two events using two-way tables, tree diagrams and Venn diagrams.

**⚑ Hinge:** Students who cannot select an appropriate representation for a given probability question cannot access Node 2 — calculating compound event probabilities requires first constructing a valid representation of the sample space.

**Response modes:**
- ↔ Widen contexts: Each representation (table, tree, Venn) makes different probability questions easy or hard. Students need experience with all three to develop judgment about which to use for a given question.

**Minimum width:** Represent all combinations for two events using one of: two-way table, tree diagram, or Venn diagram.

**Typical width:** Represent the same two-event situation using all three methods; identify which representation is most useful for different probability questions.

**Wider:**
- Explore First Nations Australian children's instructive games with two-event outcomes — e.g. Battendi from the Ngarrindjeri Peoples — represent combinations and discuss fairness.
- Investigate mutually exclusive events using Venn diagrams: show that the circles don't overlap and explain what this means.

**Success criteria:**
- Correctly lists all combinations for a two-event situation.
- Represents combinations accurately using at least one method.
- Identifies the advantage of each representation for different questions.

**Related standards:**
- AC9M7P01

#### 2. Calculating compound event probabilities

Students use representations to calculate probabilities of compound events using 'and', 'or' (inclusive and exclusive), and 'at least' language.

**Response modes:**
- ◎ Scaffold reasoning: Compound probability calculation requires careful interpretation of event language before selecting a calculation method. Students who skip the interpretation step frequently calculate the wrong compound event.

**Minimum width:** Calculate P(A and B) and P(A or B) from a two-way table or Venn diagram.

**Typical width:** Calculate probabilities using all event language types (and, or, at least, not); distinguish inclusive and exclusive or; apply to practical situations.

**Wider:**
- Investigate the addition rule P(A or B) = P(A) + P(B) − P(A and B) informally — verify using a two-way table.
- Apply compound probability to real situations: the probability of a randomly selected student studying both maths and music, or either subject.

**Success criteria:**
- Correctly calculates P(A and B) and P(A or B) from a representation.
- Distinguishes inclusive and exclusive 'or' in context.
- Uses the representation systematically rather than guessing.

**Related standards:**
- AC9M8P01
- AC9M8P03
