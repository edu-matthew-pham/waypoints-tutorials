# AC9M7A02 — Algebraic expressions

**Year 7**
**Strand:** Algebra
**Planning mode:** A — Concept-certifying

## ACARA Descriptor

formulate algebraic expressions using constants, variables, operations and brackets

## ACARA Elaborations

- generalising arithmetic expressions to algebraic expressions involving constants, variables, operations and brackets; for example, 7 + 7 + 7 = 3 × 7, x + x + x = 3 × x
- formulating algebraic expressions that represent mathematical relationships; for example, translating from words to symbols, 'think of a number' problems
- recognising and applying the concept of variable as something that can change in value, investigating the relationships between variables, and the application of formulas

## Prior Knowledge

Students can recognise variables in formulas and understand that letters represent quantities (from AC9M7A01). Students can write rules for patterns using words (from AC9M6A01).

## Progression Endpoint

Students formulate algebraic expressions using constants, variables, operations and brackets to represent mathematical relationships.

## Width Tiers

**Width varies by:** phenomena and contexts

**Minimum width:** Translate a verbal description of a mathematical relationship into an algebraic expression using constants, variables and operations.

**Typical width:** Formulate algebraic expressions involving brackets and multiple operations; translate in both directions (words to algebra, algebra to words); generalise arithmetic patterns to algebraic expressions.

**Wider:**
- Investigate common translation ambiguities: 'five less than x' versus 'x less five' — use substitution to verify which expression is correct.
- Create word problems that match given algebraic expressions, then exchange with peers for verification — building fluency in both translation directions.
- Explore how the same relationship can be expressed in multiple equivalent algebraic forms — compare 2(x + 3) and 2x + 6 and discuss what each form makes visible.

## Waypoint Sequence (3 waypoints, 2 hinges, 1 width opportunity)

#### 1. Translating words to algebraic expressions ⚑

Students translate verbal descriptions of mathematical relationships into algebraic expressions using constants, variables and operations.

**⚑ Hinge — ↔ Widen contexts — more examples resolve misconceptions here:** Translation errors (especially 'five less than x' vs 'x minus five') propagate directly into Node 2 bracket formulation and AC9M7A03 equation solving — students who mis-translate a verbal problem cannot set up correct equations.

**Response modes:**
- ↔ Widen contexts — more examples resolve misconceptions here: Translation between verbal and algebraic forms is error-prone and context-sensitive. Students who only translate simple phrases fail with relational descriptions ('five less than x'). Multiple verbal structures across varied contexts are required.

**Minimum width:** Write an algebraic expression for a simple verbal description (e.g. 'three more than x', 'twice n').

**Typical width:** Translate multi-step verbal descriptions; identify the correct order of operations; translate in both directions (words → algebra, algebra → words).

**Wider:**
- Investigate common translation errors: 'five less than x' vs 'x less five' — use substitution to check which is correct.
- Create word problems that match given algebraic expressions, building translation fluency in both directions.

**Success criteria:**
- Correctly translates a verbal description into an algebraic expression.
- Correctly translates an algebraic expression into a verbal description.
- Does not confuse 'n less than 5' (5 − n) with 'n minus 5' (n − 5).

**Related standards:**
- AC9M7A01 — Variables and formulas

#### 2. Expressions with brackets and multiple operations ⚑

Students formulate algebraic expressions involving brackets, including those where brackets are required to preserve intended meaning.

**⚑ Hinge — ◎ Scaffold reasoning — unpack the logic explicitly:** Students who omit necessary brackets formulate expressions with different meanings than intended — this error cascades into AC9M7A03 equation solving where setting up the equation incorrectly means the solution is always wrong regardless of solving skill.

**Response modes:**
- ◎ Scaffold reasoning — unpack the logic explicitly: Deciding when brackets are required demands explicit reasoning about order of operations and meaning. Students routinely omit necessary brackets or add unnecessary ones without a clear reasoning process.

**Minimum width:** Write an algebraic expression that requires brackets (e.g. 'the sum of x and 3, multiplied by 4').

**Typical width:** Formulate expressions from multi-step descriptions; explain when brackets are necessary; evaluate expressions for given values.

**Wider:**
- Compare equivalent expressions with and without brackets: 2(x + 3) vs 2x + 6. Verify equivalence by substitution.
- Apply distributive property to expand and factorise simple expressions — preview of Y8 algebra.

**Success criteria:**
- Correctly writes expressions requiring brackets to preserve intended meaning.
- Can explain why brackets are necessary in a given expression.
- Evaluates expressions with brackets correctly applying order of operations.

**Related standards:**
- AC9M7A03 — Solve linear equations

#### 3. Generalising arithmetic to algebraic expressions ★

Students recognise that algebraic expressions generalise arithmetic relationships, and can identify what an expression represents across multiple cases.

**★ Width opportunity:** Algebraic generalisation is a threshold concept — advancing students who can express the same relationship multiple ways and evaluate which form is most transparent are building genuine algebraic fluency.

**Response modes:**
- ↔ Widen contexts — more examples resolve misconceptions here: The shift from arithmetic to algebraic generalisation is a conceptual threshold. Students need multiple examples where the same arithmetic pattern is generalised before the generalising move feels natural.

**Minimum width:** Given an arithmetic pattern (e.g. 7+7+7 = 3×7), write the algebraic generalisation (x+x+x = 3x).

**Typical width:** Formulate algebraic expressions that represent general mathematical relationships; test with multiple values to verify the generalisation.

**Wider:**
- Investigate how the same relationship can be expressed in multiple equivalent algebraic forms — which is simplest? Which shows structure best?
- Apply to pattern generalisation: write an expression for the nth term of a visual growing pattern.

**Success criteria:**
- Writes an algebraic expression that correctly generalises a given arithmetic pattern.
- Verifies the expression by substituting specific values.
- Does not confuse the generalised expression with a specific equation to solve.

**Related standards:**
- AC9M7A05 — Tables and graphs from patterns
- AC9M7A01 — Variables and formulas
