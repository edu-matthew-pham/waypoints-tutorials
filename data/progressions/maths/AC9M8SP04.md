# AC9M8SP04 — Algorithms for congruence and similarity

**Year 8**
**Strand:** Space

## ACARA Descriptor

design, create and test algorithms involving a sequence of steps and decisions that identify congruency or similarity of shapes, and describe how the algorithm works

## Prior Knowledge

Students have designed classification algorithms for shapes (from AC9M7SP04). Students know the conditions for congruence and similarity (from AC9M8SP01).

## Progression Endpoint

Students design, test and describe algorithms (flowcharts or pseudocode) that classify triangles as congruent, similar, or neither, based on given measurements.

## Waypoint Sequence (2 waypoints, 1 hinge)

#### 1. Designing a congruence/similarity classification algorithm ⚑

Students design a step-by-step algorithm that correctly classifies two triangles as congruent, similar, or neither, using the appropriate conditions.

**⚑ Hinge:** Node 2 requires tracing and evaluating an algorithm — students who have not designed one themselves lack the understanding of decision branching and condition ordering needed to identify errors or describe logic in Node 2.

**Response modes:**
- ◎ Scaffold reasoning: Algorithm design requires systematic reasoning about decision order — which condition to test first, what information is needed, and how to handle each branch. Without explicit structure students produce incomplete or ambiguous algorithms.

**Minimum width:** Design a flowchart that correctly classifies two triangles as congruent or not using at least two conditions (SSS and SAS).

**Typical width:** Design and test an algorithm covering all congruence and similarity conditions; handle edge cases (e.g. insufficient information); describe how the algorithm works.

**Wider:**
- Evaluate two different algorithms for the same classification task — compare their efficiency and edge case handling.
- Extend the algorithm to classify quadrilaterals as congruent or similar — identify what additional conditions are needed.

**Success criteria:**
- Designs an algorithm that correctly classifies triangles using at least two conditions.
- Includes clear decision points with yes/no branches.
- Tests the algorithm with at least two examples and corrects any errors.

**Related standards:**
- AC9M8SP01
- AC9M7SP04

#### 2. Evaluating and describing algorithms ★

Students trace through a given algorithm with test cases, identify errors or limitations, and describe in plain language how it works.

**Response modes:**
- ⊕ Integration point: Evaluating an algorithm requires simultaneously applying geometric knowledge, logical reasoning, and computational thinking — an integration of the space and digital strands.

**Minimum width:** Trace a given congruence/similarity algorithm with two test inputs; identify whether the algorithm is correct.

**Typical width:** Evaluate a given algorithm for completeness and accuracy; fix identified errors; describe the algorithm's decision logic in plain language.

**Wider:**
- Implement a classification algorithm in a simple programming language — test it with generated sets of triangle measurements.
- Investigate: what is the minimum number of decision steps needed to distinguish all five outcomes (SSS congruent, SAS congruent, AAS congruent, RHS congruent, similar, neither)?

**Success criteria:**
- Correctly traces an algorithm with given inputs.
- Identifies at least one error or limitation in a given algorithm.
- Describes the algorithm's logic in plain language.
