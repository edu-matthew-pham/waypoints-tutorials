# AC9M7A06 — Manipulate formulas

**Year 7**
**Strand:** Algebra
**Planning mode:** A — Concept-certifying

## ACARA Descriptor

manipulate formulas involving several variables using digital tools, and describe the effect of systematic variation in the values of the variables

## ACARA Elaborations

- experimenting with different sets of tables of values from formulas; for example, using volume of a rectangular prism = length × width × height
- using spreadsheets and the formula function to recognise the effect of changing parameters on the entries in cells
- analysing distance travelled for different combinations of average speed and time of travel using a table of values and the distance formula
- exploring how deep learning models used for training artificial intelligence agents can involve the manipulation of mathematical functions with multiple variables
- understanding that the relationship between variables in an artificial intelligence model assists with explainability and interpretability

## Prior Knowledge

Students can substitute values into formulas and generate tables of values (from AC9M7A01, AC9M7A05). Students have used digital tools for calculation.

## Progression Endpoint

Students use digital tools to systematically vary values in multi-variable formulas, and describe the effect of each variable's change on the output.

## Width Tiers

**Width varies by:** phenomena and contexts

**Minimum width:** Using a digital tool (spreadsheet or table), vary one variable in a multi-variable formula while holding others constant and describe the effect on the output.

**Typical width:** Systematically vary each variable in a multi-variable formula in turn; describe the effect of each variable; compare which variable produces the largest change in output for an equal proportional variation.

**Wider:**
- Analyse distance = speed × time using a table — investigate different combinations of speed and time that produce the same distance, and describe the pattern.
- Explore how deep learning models involve multi-variable function manipulation — describe informally what 'parameter tuning' means in this context.
- Investigate how spreadsheet formula functions encode systematic variation: use cell references to automate the variation and compare outputs across a large range.

## Waypoint Sequence (2 waypoints, 1 hinge, 1 width opportunity)

#### 1. Systematic variation of one variable ⚑

Students vary one variable in a formula while holding others constant, and describe the effect on the output.

**⚑ Hinge — ◎ Scaffold reasoning — unpack the logic explicitly:** Students who vary multiple variables simultaneously in Node 1 cannot describe the effect of any single variable — this blocks Node 2, where comparing the effect of different variables requires having isolated each one first.

**Response modes:**
- ◎ Scaffold reasoning — unpack the logic explicitly: Systematic variation requires the explicit strategy of holding all variables constant except one. Students without this scaffold vary multiple things simultaneously and cannot isolate the effect of each variable.

**Minimum width:** Using a spreadsheet or table, vary one variable in a simple formula (e.g. V = l × w × h, vary h) and describe the effect on V.

**Typical width:** Systematically vary each variable in turn in a multi-variable formula; describe the relationship between each variable and the output.

**Wider:**
- Investigate formulas where the output changes non-linearly with one variable (e.g. area of a square vs side length) — describe the difference.
- Use spreadsheet formula functions to automate systematic variation across a range of values.

**Success criteria:**
- Correctly varies one variable while holding others constant.
- Describes the effect of the variation on the output in words.
- Uses a table or digital tool to organise the systematic variation.

**Related standards:**
- AC9M7A01 — Variables and formulas
- AC9M7A05 — Tables and graphs from patterns

#### 2. Describing effects of variation across multiple variables ★

Students describe how changing each variable in a multi-variable formula affects the output, and identify which variables have the greatest effect.

**★ Width opportunity:** Parameter variation in multi-variable formulas is the conceptual foundation for modelling and AI — advancing students can investigate compound variation and connect to proportional reasoning in ways that go well beyond the minimum.

**Response modes:**
- ↔ Widen contexts — more examples resolve misconceptions here: Comparing the effect of variables requires varied formula contexts to develop generalised understanding. Students who only explore one formula see the pattern as context-specific rather than a feature of multi-variable relationships.

**Minimum width:** Compare the effect of equal proportional changes in two different variables on the output of a formula.

**Typical width:** Analyse a real formula (e.g. distance = speed × time; volume of a prism) and describe which variable has the most/least impact on the output for a given change.

**Wider:**
- Explore parameter variation in formulas used in machine learning or AI contexts (as described in elaborations) — model the concept of tuning parameters.
- Investigate the formula for compound scenarios: if both speed and time double, what happens to distance? Connect to proportional reasoning.

**Success criteria:**
- Correctly describes the effect of changing each variable on the output.
- Identifies which variable produces the largest change in output for an equal proportional variation.
- Uses digital tool output systematically rather than performing isolated calculations.

**Related standards:**
- AC9M7A04 — Graphs of functions
- AC9M7A01 — Variables and formulas
