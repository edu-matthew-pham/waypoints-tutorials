# AC9M7A05 — Tables and graphs from patterns

**Year 7**
**Strand:** Algebra
**Planning mode:** A — Concept-certifying

## ACARA Descriptor

generate tables of values from visually growing patterns or the rule of a function; describe and plot these relationships on the Cartesian plane

## ACARA Elaborations

- plotting points from a table of values generated using simple linear functions and recognising patterns, such as the points lie on a straight line
- discussing and using variables to create a general rule and determine the value of the dependent variable for any given value of the independent variable
- using function machines to generate a table of ordered pairs using input and output values, plotting the relationships on a Cartesian plane
- using diagrams and manipulatives to form linear growth patterns, representing these patterns in tables and describing the relationship
- using a simple general-purpose programming language to create and use algorithms that generate growing patterns and graphing the relationships

## Prior Knowledge

Students can plot points in all four quadrants of the Cartesian plane (from AC9M6SP02). Students can write rules for growing patterns (from AC9M6A01, AC9M6A03).

## Progression Endpoint

Students generate tables of values from growing patterns or function rules, plot the relationships on the Cartesian plane, and describe the resulting graph.

## Width Tiers

**Width varies by:** phenomena and contexts

**Minimum width:** Generate a table of values from a simple linear function rule and plot the ordered pairs on the Cartesian plane.

**Typical width:** Generate tables from growing patterns and function rules; describe the pattern in output values; plot linear relationships on the Cartesian plane; describe the resulting graph and identify that linear rules produce straight lines.

**Wider:**
- Use a programming language or spreadsheet to generate tables from growing patterns and graph the relationships — connect the code/formula to the algebraic rule.
- Compare two linear functions plotted on the same axes — identify what differs in the graph (steepness, intercept) and connect to differences in the rule.
- Explore a non-linear function (e.g. y = x²) from a table — generate values, plot, and contrast the curved result with linear functions.

## Waypoint Sequence (3 waypoints, 1 hinge, 1 width opportunity)

#### 1. Generating tables of values from patterns

Students identify the rule in a visually growing pattern and use it to generate a table of values.

**Response modes:**
- ↔ Widen contexts — more examples resolve misconceptions here: Students who only see numerical patterns without visual context often generate tables mechanically without understanding the rule. Visual pattern contexts anchor the algebraic structure.

**Minimum width:** Given a visual growing pattern, complete a table of values for the first 5 terms.

**Typical width:** Identify the rule in words and algebraic notation; use the rule to generate values including for non-consecutive terms.

**Wider:**
- Investigate growing patterns using physical materials (tiles, blocks) and connect the physical growth to the algebraic rule.
- Compare two growing patterns — which grows faster? How can you tell from the table?

**Success criteria:**
- Correctly generates a table of values from a growing pattern.
- Identifies the rule that generates the values.
- Can find the value for a term not shown in the original pattern.

**Related standards:**
- AC9M7A02 — Algebraic expressions

#### 2. Generating tables from function rules ⚑

Students generate a table of ordered pairs from a given function rule and identify the relationship between input and output values.

**⚑ Hinge — ◆ Practise here — fluency matters more than breadth:** Errors in the table of ordered pairs cascade directly into Node 3 — incorrectly generated pairs produce a graph that doesn't represent the function rule, meaning students cannot see or describe the relationship they were supposed to plot.

**Response modes:**
- ◆ Practise here — fluency matters more than breadth: Systematic generation of ordered pairs requires procedural care that students need to practise before plotting. Errors in the table cascade into errors in the graph.

**Minimum width:** Given a simple function rule (e.g. y = 2x + 1), generate a table of at least 5 ordered pairs.

**Typical width:** Generate tables from various linear function rules; describe the pattern in the output values; identify the effect of changing the rule.

**Wider:**
- Use a function machine or spreadsheet to generate tables for multiple rules and compare outputs side by side.
- Investigate what happens to the table when the rule changes: how does doubling the coefficient change the values?

**Success criteria:**
- Correctly generates a table of ordered pairs from a given function rule.
- Labels the table with input (x) and output (y) columns.
- Does not substitute the same value for both x and y.

**Related standards:**
- AC9M7A06 — Manipulate formulas

#### 3. Plotting and describing relationships on the Cartesian plane ★

Students plot ordered pairs from a table of values on the Cartesian plane and describe the resulting relationship.

**★ Width opportunity:** Comparing two functions on the same axes and connecting visual differences to rule differences (steepness, intercept) is genuinely rich — advancing students can begin to reason about what the rule parameters control.

**Response modes:**
- ⊕ Integration point — components come together here: Plotting connects the table of values, the function rule, and the Cartesian plane simultaneously. Describing the resulting graph requires coordinating all three representations.

**Minimum width:** Plot a set of ordered pairs from a table and connect them; describe whether the relationship is linear.

**Typical width:** Plot and describe relationships for several linear rules; identify that linear functions produce straight lines; describe slope informally.

**Wider:**
- Compare two functions plotted on the same axes — identify what differs (steepness, y-intercept) and connect to the rule.
- Investigate the graphical representation of a non-linear function (e.g. y = x²) from a table — contrast with linear.

**Success criteria:**
- Correctly plots ordered pairs from a table on the Cartesian plane.
- Draws a line through plotted points for a linear relationship.
- Describes the relationship shown in the graph using appropriate language.

**Related standards:**
- AC9M7SP03 — Transformations on Cartesian plane
- AC9M7A04 — Graphs of functions
