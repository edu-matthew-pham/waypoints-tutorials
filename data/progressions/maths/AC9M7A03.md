# AC9M7A03 — Solve linear equations

**Year 7**
**Strand:** Algebra
**Planning mode:** A — Concept-certifying

## ACARA Descriptor

solve one-variable linear equations with natural number solutions; verify the solution by substitution

## ACARA Elaborations

- recognising that solving an equation is a process of determining a value that makes the equation true; using substitution to determine whether a given value is a solution
- solving equations using concrete materials, the balance model, and backtracking, explaining the process
- solving linear equations such as 3x + 7 = 19 algebraically, and verifying the solution by substitution

## Prior Knowledge

Students can find unknown values in equations using backtracking and balance (from AC9M6A02). Students can formulate algebraic expressions (from AC9M7A02).

## Progression Endpoint

Students solve one-variable linear equations with natural number solutions using algebraic methods and verify solutions by substitution.

## Width Tiers

**Width varies by:** phenomena and contexts

**Minimum width:** Solve a two-step one-variable linear equation using backtracking or algebraic method; verify the solution by substitution.

**Typical width:** Solve one-variable linear equations with natural number solutions using algebraic methods; explain each step; always verify by substitution; apply to equations arising from practical word problems.

**Wider:**
- Compare backtracking and algebraic (balance) methods for the same equations — articulate when each is more efficient.
- Create and solve equations from contextual problems: 'I think of a number' scenarios, perimeter problems, simple fare/cost problems.
- Investigate equations where the solution must be interpreted in context: when must the answer be a whole number? What does a non-integer solution mean?

## Waypoint Sequence (3 waypoints, 2 hinges)

#### 1. Equation as a balance statement

Students understand that an equation is a statement of equality and that the solution is the value that makes it true.

**Response modes:**
- ↔ Widen contexts — more examples resolve misconceptions here: Students often confuse solving an equation with simplifying an expression. Multiple contexts and the explicit distinction between 'expression' and 'equation' help establish this foundational understanding.

**Minimum width:** Use substitution to check whether a given value is the solution to a simple equation.

**Typical width:** Explain what it means to 'solve' an equation; test multiple candidates for a solution; distinguish between expressions and equations.

**Wider:**
- Investigate equations that have no natural number solution vs those that do — develop the habit of verifying.
- Use a balance model to demonstrate what 'maintaining equality' means concretely.

**Success criteria:**
- Correctly identifies whether a given value satisfies an equation by substitution.
- Distinguishes between an expression and an equation.
- Understands that a solution must make both sides equal.

**Related standards:**
- AC9M7A02 — Algebraic expressions

#### 2. Solving by backtracking ⚑

Students solve one-step and two-step linear equations by backtracking (undoing operations in reverse order).

**⚑ Hinge — ◎ Scaffold reasoning — unpack the logic explicitly:** Students who cannot execute the backtracking scaffold cannot transition to the algebraic balance method in Node 3 — both methods require identifying the order of operations, and the backtracking scaffold makes this explicit before the abstract method is introduced.

**Response modes:**
- ◎ Scaffold reasoning — unpack the logic explicitly: Backtracking requires students to map the order of operations forward then reverse it. An explicit scaffold (draw the 'machine', identify steps, reverse) is needed before students apply this fluently.

**Minimum width:** Solve equations of the form ax = b and x + a = b by backtracking; show the inverse operations used.

**Typical width:** Solve two-step equations (e.g. 3x + 7 = 19) using backtracking; explain the process at each step.

**Wider:**
- Compare backtracking and the balance/algebraic method for the same equation — note they produce the same result.
- Apply to contextual problems: write and solve an equation from a word problem.

**Success criteria:**
- Correctly solves a two-step linear equation using backtracking.
- Identifies the inverse operations used.
- Applies backtracking to multi-operation equations in the correct order.

#### 3. Solving algebraically and verifying ⚑

Students solve one-variable linear equations algebraically, using the balance model, and verify the solution by substitution.

**⚑ Hinge — ◆ Practise here — fluency matters more than breadth:** Students who lack automatic algebraic solving and the verification habit cannot apply equations to modelling problems in AC9M7N09 and AC9M7M06 — the modelling contexts require fluent solving, and missing verification means errors go undetected.

**Response modes:**
- ◆ Practise here — fluency matters more than breadth: Algebraic solving and verification together form the method students need to have automatic before applying equations to modelling contexts. The verification habit specifically needs consolidation.

**Minimum width:** Solve a two-step linear equation algebraically (performing the same operation to both sides) and verify by substitution.

**Typical width:** Solve a range of one-variable linear equations; choose between backtracking and algebraic methods; always verify.

**Wider:**
- Create and solve equations from contextual problems (e.g. 'I think of a number, double it and add 5 to get 19').
- Investigate equations where the unknown appears in a context requiring interpretation of the solution (e.g. 'x must be a whole number of people').

**Success criteria:**
- Solves a one-variable linear equation algebraically with correct steps shown.
- Verifies the solution by substituting back into the original equation.
- Does not skip verification.

**Related standards:**

- AC9M7A06 — Manipulate formulas
