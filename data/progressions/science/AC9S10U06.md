# AC9S10U06 — Periodic Table and Atomic Structure

**Year 10**
**Strand:** Chemical Sciences
**Planning mode:** A — Concept-certifying

## ACARA Descriptor

explain how the structure and properties of atoms relate to the organisation of the elements in the periodic table

## ACARA Elaborations

- examining how elements are organised in the periodic table and analysing patterns
- investigating physical properties of some metals and non-metals
- using the Bohr model to describe atom structure in terms of electron shells
- deducing that repeating periodic patterns reflect outer electron shell patterns
- conducting flame tests and examining emission spectra
- examining how the spectroscope led to further development of the atomic model

## Prior Knowledge

Students can classify matter as elements, compounds or mixtures and use symbols, formulas and models to represent them (AC9S8U06). They can explain how atomic theory developed through the discovery of subatomic particles and describe how radioactive decay produces stable atoms (AC9S9U06). They have the Bohr model of the atom as prior knowledge — protons, neutrons and electrons in shells — but have not yet examined how electron shell configuration determines an element's chemical properties, or how repeating patterns in electron configuration are the basis for periodic table organisation.

## Progression Endpoint

Students explain how the structure of atoms — particularly outer electron shell configuration — determines the physical and chemical properties of elements and accounts for the organisation and repeating patterns of the periodic table.

## Width Tiers

**Width varies by:** phenomena and contexts

**Minimum width:** Draw Bohr models for at least three elements and identify their group from outer electron count; explain why same-group elements have similar properties; identify at least two periodic table patterns.

**Typical width:** Use the Bohr model to describe electron shell structure for elements across periods; explain how outer electron number determines reactivity and bonding; identify group patterns (similar properties) and period trends (progressive shell filling); deduce that periodic patterns reflect outer electron shell patterns; investigate physical properties of metals and non-metals.

**Wider:**
- Conduct flame tests for selected elements and examine emission spectra — connecting spectral evidence to the Bohr model of discrete electron energy levels
- Examine how the spectroscope's development led to refinement of the atomic model (AC9S10H01, AC9S9U06)
- Analyse periodic table patterns to predict properties of elements based on position — using the table predictively
- Compare merits and limitations of periodic table representation vs graphical representations of patterns such as melting point

## Waypoint Sequence (4 waypoints, 2 hinges, 1 width opportunity)

#### 1. Electron shell configuration and the Bohr model ⚑

Students can draw or describe the electron shell configuration of elements 1–20 using the Bohr model and explain the shell-filling rules.

**⚑ Hinge — ◆ Practise here — fluency matters more than breadth:** Outer electron shell configuration is the structural variable the entire periodic table organisation depends on. Students who cannot correctly assign outer electrons for a given element cannot explain why elements in the same group share properties (N2), cannot interpret periodic trends (N3), and cannot use the table predictively (N4).

**Response modes:**
- ◆ Practise here — fluency matters more than breadth: Electron shell assignment requires procedural precision — filling shells in order, knowing capacities, correctly identifying outer-shell electrons. Students need practice and error-checking at the diagram level before the pattern-recognition work of N2 is meaningful.

**Minimum width:** Students correctly assign electrons to shells for at least five elements and state the maximum electron capacity of the first three shells.

**Typical width:** Students draw Bohr diagrams for elements 1–20; state shell capacities (2, 8, 8); identify the number of outer-shell electrons for any element 1–20; explain that the number of outer-shell electrons is the key variable for chemical behaviour; connect to the prior atomic model from AC9S9U06.

**Wider:**
- Investigate emission spectra from flame tests and explain how spectral lines relate to electron energy levels — connecting the visible pattern to the Bohr model
- Examine how the development of the spectroscope enabled scientists to probe atomic structure — what did spectral lines reveal that earlier atomic models could not explain?

**Success criteria:**
- Draws a correct Bohr diagram for any element 1–20
- States the maximum electron capacity of the first three shells (2, 8, 8)
- Identifies the number of outer-shell electrons for any element 1–20

**Terms introduced:**
- **Bohr model**: A model of atomic structure in which electrons occupy concentric shells around the nucleus at fixed energy levels. The first shell holds a maximum of 2 electrons, the second holds 8, and the third holds 8 (for elements 1–20). At Year 10, the Bohr model is the representational tool students use to determine outer-shell electron count, which is the key variable linking atomic structure to periodic table organisation and chemical properties. (Electron shell, Shell capacity)
- **Outer-shell electrons**: The electrons in the outermost occupied shell of an atom. The number of outer-shell electrons determines an element's chemical properties, reactivity, and bonding behaviour. Elements with the same number of outer-shell electrons are in the same group and share similar chemical properties. The outer-shell electron count is the single most important variable linking atomic structure to periodic table organisation. (Valence)
- **Emission spectrum**: The pattern of specific wavelengths of light emitted by an element when its electrons are excited (given energy) and then return to lower energy levels. Each element produces a unique emission spectrum — a 'fingerprint' — because its electron energy levels are unique. Emission spectra are observable evidence for the Bohr model's claim that electrons occupy discrete energy levels. (Flame test, Electron energy transition)

#### 2. Outer electrons and group properties — why elements in a group behave similarly ⚑ ★

Students can explain why elements in the same group of the periodic table have similar chemical properties by reference to their outer electron shell configuration.

**⚑ Hinge — ◎ Scaffold reasoning — unpack the logic explicitly:** The outer-electron-determines-group-property connection is the conceptual bridge between atomic structure and periodic table organisation. Students who cannot explain group properties by electron configuration cannot understand why the table is organised as it is (N3), cannot predict element behaviour from position (N4), or explain periodic trends as patterns rather than arbitrary facts.

**★ Width opportunity:** Group property comparisons — alkali metals, halogens, noble gases — are genuinely rich investigative contexts. Physical property investigation, reactivity trends, and the connection between electron loss/gain and reactivity all offer depth without accelerating beyond Year 10.

**Response modes:**
- ◎ Scaffold reasoning — unpack the logic explicitly: Students commonly learn group properties as lists (alkali metals are reactive, noble gases are inert) without connecting them to electron configuration. Making the explanatory link explicit — the same outer electron count produces the same chemical behaviour — is the conceptual move that makes the periodic table a predictive tool rather than a lookup table.
- ↔ Widen contexts — more examples resolve misconceptions here: Comparing multiple groups (1, 2, 17, 18) and investigating both physical and chemical properties builds genuine pattern-recognition across the table. Each group is a different application of the same principle.

**Minimum width:** Students explain that elements in the same group have the same number of outer-shell electrons and use this to explain at least one shared property of a named group (e.g. Group 1 all react with water).

**Typical width:** Students compare outer electron counts across groups 1, 2, 17 and 18; explain why noble gases are unreactive (full outer shell); explain why alkali metals are highly reactive (one outer electron, easily lost); describe group trends as evidence that outer electrons determine reactivity; connect to the concept of valence.

**Wider:**
- Investigate the physical properties of metals and non-metals in groups 1 and 17 — how do their electron configurations predict their physical as well as chemical properties?
- Compare the reactivity of Group 1 elements (Li, Na, K) with water and explain the trend using outer electron configuration and atomic radius

**Success criteria:**
- Explains that elements in the same group have the same number of outer-shell electrons
- Uses outer electron configuration to explain the shared chemical properties of at least one group
- Contrasts a reactive group (e.g. Group 1) with noble gases using outer electron configuration

**Terms introduced:**
- **Group**: A vertical column in the periodic table containing elements with the same number of outer-shell electrons. Because outer-shell electrons determine chemical behaviour, elements in the same group share similar chemical properties. Group 1 (alkali metals) have 1 outer electron and are highly reactive; Group 18 (noble gases) have a full outer shell and are unreactive.
- **Noble gases**: Group 18 elements (He, Ne, Ar, Kr, Xe) with a full outer electron shell. Their full shell means they have no tendency to lose, gain or share electrons, making them extremely unreactive — they exist as single atoms rather than forming compounds. Noble gases are the reference case for understanding why full outer shells confer stability, which in turn explains why other groups are reactive.
- **Alkali metals**: Group 1 elements (Li, Na, K, Rb, Cs) with one outer-shell electron. Their single outer electron is easily lost, making them the most reactive metals — they react vigorously with water and oxygen. Reactivity increases down the group because the outer electron is further from the nucleus and more easily removed in heavier alkali metals.
- **Halogens**: Group 17 elements (F, Cl, Br, I) with seven outer-shell electrons — one short of a full shell. Their strong tendency to gain one electron makes them highly reactive non-metals, especially with alkali metals (which readily lose one electron). Halogens are the reactive non-metal counterpart to alkali metals: one group loses an electron easily, the other gains one easily.
- **Reactivity**: The tendency of an element to undergo chemical reactions, determined by how readily its atoms lose, gain or share outer-shell electrons to achieve a stable (full outer shell) configuration. Highly reactive elements have outer-shell configurations that are easily changed (1 outer electron lost easily, or 7 outer electrons needing only 1 more); unreactive elements already have stable configurations (full outer shell).
- **Periodic table**: The systematic arrangement of elements by atomic number into groups (columns) and periods (rows) that reveals repeating patterns of properties. At Year 10, the periodic table is reframed from a reference chart (what are this element's properties?) to a predictive tool (given an element's position, what must its electron configuration and properties be?). The organisation of the table is not arbitrary — it is a direct map of electron shell configuration.

#### 3. Periodic trends — why properties repeat across periods

Students can describe repeating patterns of properties across the periodic table and explain them as a consequence of repeating outer electron shell configurations.

**Response modes:**
- ◎ Scaffold reasoning — unpack the logic explicitly: The periodicity of the table — why it has the structure it does, with periods and groups — is not obvious to students who learned the table as a given organisational chart. Making the electron-shell-reset the explicit explanation for period structure completes the descriptor's 'relate structure of atoms to organisation' demand.

**Minimum width:** Students identify that a new period begins when a new electron shell starts filling and explain that properties repeat because outer electron counts repeat.

**Typical width:** Students describe how atomic number increases across a period while outer electrons increase from 1 to 8 before resetting; explain metallic character decreasing across a period; describe trends in reactivity within groups; explain that the period number indicates the number of occupied electron shells; interpret the table's structure as a map of electron configuration.

**Wider:**
- Analyse the historical development of the periodic table — why did Mendeleev's table work before electron theory was established, and what does this suggest about the relationship between pattern and explanation?
- Examine an extended periodic table section (transition metals) and explain why their properties are more similar across periods than main group elements

**Success criteria:**
- Explains that a new period begins when electrons start filling a new shell
- Describes that properties repeat across periods because outer electron configurations repeat
- Interprets the position of an element in the table in terms of its electron shell configuration

**Terms introduced:**
- **Period**: A horizontal row in the periodic table. Each period corresponds to the filling of a new electron shell — Period 1 fills shell 1 (2 elements), Period 2 fills shell 2 (8 elements), Period 3 fills shell 3 (8 elements). Properties repeat from period to period because the outer electron configuration resets from 1 to 8 each time a new shell begins filling. The period number tells you how many electron shells the element has. (Atomic number, Metallic character)

**Related standards:**
- AC9S9U06 — Atomic Model and Radioactive Decay

#### 4. Using atomic structure to predict and explain element properties

Students can use the position of an element in the periodic table to predict its electron configuration and properties, and explain those properties in terms of atomic structure.

**Response modes:**
- ⊕ Integration point — components come together here: This node is the descriptor's full demand — using atomic structure (electron configuration) to explain both properties and organisation. Students apply everything from N1–N3 to treat the table as a predictive model, not a lookup. The flame test and emission spectra elaborations are best placed here as application contexts.

**Minimum width:** Students predict the number of outer-shell electrons and describe the likely reactivity of an unnamed element given only its position in the periodic table.

**Typical width:** Students predict whether an element is a metal or non-metal, its likely reactivity, and its likely bonding behaviour from table position; explain flame test results using electron energy transitions; evaluate how atomic structure knowledge enabled development of the modern periodic table; use the table as a predictive tool rather than a reference list.

**Wider:**
- Investigate Mendeleev's prediction of undiscovered elements — how did electron-configuration logic (before it was understood) allow gaps to be correctly identified?
- Examine how the spectroscope's role in identifying elemental composition (flame tests, emission spectra) connected atomic structure evidence to table organisation

**Success criteria:**
- Predicts the outer electron configuration and likely properties of an element from its table position
- Explains at least two element properties in terms of atomic structure
- Uses the periodic table as a predictive tool — not just a reference — for an unfamiliar element

**Related standards:**
- AC9S9U06 — Atomic Model and Radioactive Decay
- AC9S8U06 — Elements, Compounds and Mixtures
