# AC9TDI6K03 — Data represented as numbers

**Year 5-6**
**Strand:** Knowledge and Understanding

## ACARA Descriptor

Explain how digital systems represent all data using numbers

## Prior Knowledge

Students can recognise different types of data and explore how the same data can be represented differently depending on context (AC9TDI4K03). They understand that data exists in different forms (text, images, numbers). They have not yet connected the idea that digital systems ultimately represent all these different data types as numbers.

## Progression Endpoint

Students explain how digital systems represent all types of data — text, images, sound — as numbers, and understand that the data type determines what operations can be performed.

## Waypoint Sequence (2 waypoints, 1 hinge)

#### 1. Text as numbers ⚑ ★

Students can explain how text characters are represented as numbers in a digital system

**⚑ Hinge:** Students who have not grasped that data is represented as numbers cannot engage with N2's data type reasoning — if a student does not accept that 'A' and 65 are the same stored value in different interpretations, the concept that type determines operations has no foundation.

**Response modes:**
- ↔ Widen contexts: Students readily accept that the number '5' is stored as a number, but resist the idea that the letter 'A' is also stored as a number — it seems like a category error. Multiple encoding contexts (letters, emoji, non-Latin scripts) help students generalise: all characters, regardless of type, are ultimately numbers.

**Minimum width:** Convert letters in a short message to numbers using a positional scheme (e.g. A=1, B=2) and explain that digital systems use similar numeric encoding for text

**Typical width:** Explain that each character in a digital system is assigned a number (like ASCII or Unicode); demonstrate with examples how text characters — letters, numbers, symbols — each map to a unique number that the system stores and processes

**Wider:**
- Investigate how Unicode allows characters from non-English scripts (e.g. Chinese, Arabic, First Nations language characters) to be encoded numerically — why a single scheme matters for global communication
- Explore how emoji are also assigned numeric codes — explaining that an emoji is stored as a number just like the letter 'A' is

**Success criteria:**
- Explains that text characters are stored as numbers in a digital system
- Can demonstrate a simple letter-to-number conversion

**Related standards:**
- AC9TDI4K03
- AC9TDI6K04

#### 2. Data type determines what you can do ★

Students can explain how the data type used to represent data changes what operations can be performed on it

**Response modes:**
- ↔ Widen contexts: Students often treat data types as arbitrary naming conventions rather than a meaningful distinction. Concrete cases where the type matters (phone number as number vs string, pixel values as arithmetic) help students see that the type determines what operations make sense — not just what the value looks like.
- ◎ Scaffold reasoning: The reasoning pattern here (identify data → identify operation → check if type supports operation → predict outcome) is the key skill. Scaffolding this as an explicit reasoning chain prevents students from guessing rather than reasoning.

**Minimum width:** Give one example showing that the same value behaves differently depending on its data type — e.g. adding '3' + '4' gives 7 when they are numbers but '34' when they are strings

**Typical width:** Explain that numbers support arithmetic operations (addition, subtraction) while text supports string operations (joining, searching); demonstrate both with examples; explain why digital systems need to know which type they are working with

**Wider:**
- Investigate how treating a phone number as a number versus a string causes real problems — adding phone numbers is meaningless, but searching within them (e.g. all numbers starting with 04) requires string operations
- Explore how images are also represented as numbers (each pixel has a numeric colour value) and what kinds of operations this enables — adjusting brightness by changing pixel values mathematically

**Success criteria:**
- Gives a correct example where the same value behaves differently based on data type
- Explains in plain language why data type affects what operations are possible

**Related standards:**
- AC9TDI6K04
- AC9TDI6P05
