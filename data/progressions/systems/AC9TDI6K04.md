# AC9TDI6K04 — Binary representation

**Year 5-6**
**Strand:** Knowledge and Understanding

## ACARA Descriptor

Explore how data can be represented by off and on states (zeros and ones in binary)

## Prior Knowledge

Students can explain how digital systems represent all data using numbers (AC9TDI6K03). They understand that text and other data types are stored as numbers. They have not yet explored how numbers themselves are represented in a digital system — the binary (on/off) basis of all digital data.

## Progression Endpoint

Students explore how on/off states in digital circuits can represent zeros and ones, and how binary is the fundamental representation underlying all digital data.

## Waypoint Sequence (2 waypoints, 1 hinge)

#### 1. On/off states represent zero and one ⚑ ★

Students can explain that an on/off state in a digital circuit represents the digits one and zero

**⚑ Hinge:** The on/off state = 0/1 concept is definitionally required for N2 — without it, the integration of numeric representation (K03) with physical storage cannot proceed. N2's chain (data → number → binary → physical state) collapses at the last step.

**Response modes:**
- ↔ Widen contexts: Students often struggle to see that binary is an abstract principle, not a specific technology. Seeing the same on/off structure in circuits, Morse code, beads, and yes/no questions helps students abstract the principle: any two distinguishable states can encode 0 and 1.

**Minimum width:** Demonstrate or explain that a two-state system (on/off, yes/no, long/short) can represent 1 and 0; connect this to how digital systems store data at the physical level

**Typical width:** Demonstrate that an on/off state in a circuit represents 1 and 0; recognise that yes/no questions, Morse code dashes and dots, and circuit states all use the same two-state principle; explain that digital systems use billions of these switches to store complex data

**Wider:**
- Create a binary representation of a word or phrase (e.g. the name of a local Country/Place in a First Nations language) using beads, switches or symbols — demonstrating that any two-state medium can encode binary data
- Investigate how punch cards or early telegraph systems used physical two-state mechanisms to encode information before electronic computers existed

**Success criteria:**
- Explains that an on/off state represents 1 and 0 in a digital system
- Gives at least one example of a two-state system representing binary data

**Related standards:**
- AC9TDI6K03

#### 2. Binary connects numeric representation to physical storage

Students can explain how binary connects the numeric representation of data (from AC9TDI6K03) to the physical on/off states in a digital system

**Response modes:**
- ⊕ Integration point: This node integrates the data-as-numbers understanding from K03 with the binary/on-off understanding from K04 node 1. Tracing the full chain (data → number → binary → physical state) is the integration act — students who cannot connect these steps have two disconnected facts rather than a system understanding.

**Minimum width:** Explain that numbers stored in a digital system are ultimately represented as sequences of on/off states — each digit (0 or 1) corresponds to one switch state

**Typical width:** Trace the connection from data (e.g. the letter 'A') → number (65 in ASCII) → binary sequence (01000001) → physical on/off states; explain each step in the chain

**Wider:**
- Represent a short word in binary using a provided encoding table; explain that the digital system performs this translation billions of times per second
- Investigate how the number of binary digits (bits) limits how many different values can be stored — 1 bit = 2 values, 2 bits = 4 values, 8 bits = 256 values

**Success criteria:**
- Connects the idea that data is stored as numbers to the idea that numbers are stored as binary sequences
- Can describe the on/off state interpretation of at least one binary digit

**Related standards:**
- AC9TDI6K03
