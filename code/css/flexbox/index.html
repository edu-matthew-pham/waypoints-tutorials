A row with Flexbox

Put boxes side by side in a row with Flexbox, and find out that it goes on the box that holds them.

Almost every menu bar, toolbar and row of cards on the web is a Flexbox row.

So far, boxes stack down the page. Flexbox lines them up in a row.

Explain it to me

The video and the picture show the same steps:

  1. A list stacks its items, one under another.
  2. display: flex; goes on the box that holds the items: here the ul (the parent).
  3. Its children, the li items, now sit side by side in a row.
  4. On each li instead, it does nothing for the row: the items need a parent to line them up.

The rule to remember: Flexbox goes on the parent, and the children line up.

Code What it does Why
ul { display: flex; } Puts the ul's children in a row The box that holds the items is the parent, and its boxes inside are its children. Flex goes on the parent, and the children line up
the three li Sit side by side They are the parent's children. Without display: flex they are block boxes, and block boxes start a new line
list-style: none; Removes the bullets Not Flexbox: real menus have no bullets, so it is a tidy-up on the list
li { margin-right: 24px; } Keeps the words apart A margin on each item. Items in a row touch otherwise

          For teachers

          Students put boxes in a row with display flex, and find out that it goes on the box that holds them, not on the items. About 45 minutes.

          Open the teacher guide: answers, solutions, slides and a worksheet.

          Students will be able to

          • I can put a box's children in a row with display flex on the parent.
          • I can say which box is the parent and which are its children.
          • I can explain why display flex on the items does nothing.

          Before class

          Read the unit primer "Layout and components in 5 minutes", then do the Make task yourself.

          The one idea of the lesson: display: flex; goes on the parent (the box that holds the items), and its children line up in a row. Only the direct children line up. Spacing, centring and wrapping are the next lessons, so here the space between items is a margin on each item. list-style: none; is not Flexbox: it removes a list's bullets, which every real menu does.

          Running the lesson

          1. Predict: most students do not expect one line on the `ul` to rearrange its items. It does, because the items are its children. Ask one pair from each answer to say why. Listen for who says bullets: list-style is not Flexbox.
          2. Run: delete and restore `display: flex;` to see the switch.
          3. Investigate: ask which box is the parent before every rule. The menu that will not line up has `display: flex` on each `li`: each item lines up its own insides, so nothing visible changes and there is no error.
          4. Mix it up: both rules are from earlier lessons. Ask which links `nav a` picks, and where padding goes.
          5. Modify: menu first, then the cards (a new rule on the div that holds them), then the tidy-up.
          6. Make: several answers are fine. The check wants the nav parts and `display: flex`.

          The hard part (on purpose)

          display: flex goes on the parent, not the items. When the row doesn't appear, ask which box holds the items before saying anything else.

          When students get stuck

          • The items still stack after adding display flex. Ask: Which box did you put display flex on? Is it the box that holds the items? Fix: Move display flex to the parent's rule (the ul, or the div that holds the cards).
          • The words in the row touch each other. Ask: What puts space outside each item? Fix: Add a margin to the li items, such as margin-right 24px. The next lesson has a better tool for the space between items.
          • Bullets sit oddly beside the menu items. Ask: What removes a list's bullets? Fix: Add list-style none; to the ul's rule.

          Stretch and support

          Stretch: Make the cards a row too, with a picture in each, and predict what happens if a card has display flex as well.

          Support: Give students the Modify starter and do the first task together, saying out loud: the menu is the parent, so display flex goes in .menu.

          Where it leads

          Next lesson spaces the row out: gap, justify-content and align-items, so the club name sits left and the menu right. Class idea: find three websites and sketch which parts are Flexbox rows (menus, toolbars, rows of cards).

          What each step is for

          • Predict: Students rarely guess that one property on the list rearranges all its items; seeing the row appear makes the parent-child idea concrete.
          • Run: display: flex goes on the box that holds the items; its children line up in a row.
          • Investigate: Flexbox goes on the parent, the box that holds the items, and only its children line up.
          • Modify: Building a menu row and a row of cards, always putting display: flex on the parent.
          • Mix it up: A selector with a space picks the links inside the menu, and padding gives the header room inside its edge.

          • Say which box is the parent and which are its children.
