# Mixing text types

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A letter asking for donations starts: 'Last July, floodwater filled Jun's house in the night.' Is it a story, or something else?


:::teacher-note

**In one sentence:** Students learn that writers mix text types on purpose, and that a hybrid works when each borrowed part serves the main purpose and links back to the point. They label a charity letter that opens with a story, catch Nib's story that never connects to the argument, match hybrids to the types they combine, order a story told as diary entries, label a museum web page that mixes four types, and write an argument that opens with a story.

**Students should be able to say:** I can find the borrowed parts of a hybrid text and the job each does. I can say why a writer might adapt or mix a text type. I can check that a borrowed story links back to the main point. I can write an argument that opens with a story.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Worked example: why mix?


:::keep-together

### Borrowing for a purpose

1. $\text{Find the main purpose}$ — What is the whole text trying to do?
2. $\text{Find the borrowed part}$ — Which part comes from another text type?
3. $\text{Ask what job it does}$ — Does it hook, make the reader care, or make the steps easier to follow?
4. $\text{Check the link}$ — Does the borrowed part connect back to the main point?

Now: why start an argument with a story?

**Why might an argument start with a short true story?**

☐ So the writer doesn't need to give any reasons

☐ Because every argument has to start with a story

☐ So the reader cares before the reasons arrive

☐ To fill space before the real argument begins

:::


:::teacher-note

**Answer:** So the reader cares before the reasons arrive

A story makes the issue real. The reasons and the call to act then have someone to be about.

:::


:::keep-together

### Find Nib's slip

**Here is Nib's argument, one sentence per line. Nib opens with a story. Click the first line where the reader finds out the story has nothing to do with the argument.**

```
 1  Last Friday, my friend Ava found a baby bird under the slide.
 2  We put it in a shoebox, and Ms Lin called the wildlife rescue.
 3  Our school should make lunch half an hour longer.
 4  Longer lunches would give students more time to eat and play.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: the argument is about longer lunches, but the baby bird story never connects to it. Nib needs to link it ('We missed lunch helping the bird. With a longer break...') or cut it.

:::
