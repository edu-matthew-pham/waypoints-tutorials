# Challenge: repair the report

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A report has all the right facts, but readers keep getting lost. Can you fix it without changing a single fact?


:::teacher-note

**In one sentence:** The course challenge: students repair a report on a school rubbish audit that has the right facts but is hard to follow. They fix unclear pointing words, choose joining words, put the paragraphs in the order the overview promises, and add a missing explanation, then run the same four checks on their own writing.

**Students should be able to say:** I can find and fix the parts of a text that make it hard to follow. I can choose the right move for each problem. I can run the same checks on my own writing.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::
