> **Key question:** Your phone has "256 GB" and "8 GB" on its box. Which one decides how many apps stay open?


:::teacher-note

**In one sentence:** Students open what each row of a spec sheet measures (processor, RAM, storage, network, graphics), compare a phone, a laptop and a server, and set a spec sheet to match an advert (AC9TDI8K01 node 1).

## Worked example: reading a spec sheet


:::keep-together

### One line at a time

1. $\text{8-core 3.0 GHz processor}$ — 8 cores work on 8 things at once; each takes 3 billion steps a second.
2. $\text{16 GB RAM}$ — The working space: running apps and open files. It empties when the power goes off.
3. $\text{512 GB SSD}$ — Storage: keeps 512 GB with the power off. SSD is the fast type; HDD is slower.
4. $\text{Wi-Fi, 300 Mb/s}$ — Network bandwidth: 300 million bits can arrive each second.
5. $\text{built-in graphics}$ — No separate graphics card: the processor's own graphics.

Now name the spec on a phone box.

**A phone box says **256 GB**. Which spec is that, most likely?**

☐ Storage: how much it can keep

☐ Network speed

☐ RAM: how much it can work on at once

☐ Processor speed

:::


:::teacher-note

**Answer:** Storage: how much it can keep

Storage. Phone RAM is much smaller, usually 4 to 16 GB.

:::


:::keep-together

### Find the mistake

**Sam reads a phone's spec sheet. Click the line where it first goes wrong.**

```
 1  The phone's spec sheet says 8 GB RAM and 256 GB storage.
 2  RAM and storage are both memory, so the phone has 264 GB of memory.
 3  So it can have 264 GB of apps running at once.
 4  That is why it never slows down.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: RAM and storage are different parts that measure different things. 8 GB of RAM is the working space; 256 GB of storage is what it keeps.

:::


:::keep-together

## Sort the specs


:::keep-together

### Sort

**Which part does each spec describe?**

Groups: Processor, RAM, Storage, Network

- 3.2 GHz: {{field-15}}
- 6 cores: {{field-15}}
- 16 GB, empties when switched off: {{field-15}}
- 1 TB SSD: {{field-15}}
- 2 TB hard disk (HDD): {{field-15}}
- Wi-Fi 6, up to 600 Mb/s: {{field-15}}

:::


:::teacher-note

**Answer:** 3.2 GHz → Processor; 6 cores → Processor; 16 GB, empties when switched off → RAM; 1 TB SSD → Storage; 2 TB hard disk (HDD) → Storage; Wi-Fi 6, up to 600 Mb/s → Network

GHz and cores: processor. Working space: RAM. SSD and HDD: storage. Mb/s: network.

:::


:::keep-together
