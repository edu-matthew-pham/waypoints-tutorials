## Today

**We are learning to** a spec sheet lists a computer's parts and how much of each it has: processor cores and speed, RAM, storage size and type, network bandwidth and graphics. Each one measures something different, on a phone, a laptop or a server.

- I can name the main specs on a spec sheet.
- I can say what each spec measures, in plain words.
- I can explain why a phone, a laptop and a server have different specs.

## One line at a time

Now name the spec on a phone box.

$$\text{8-core 3.0 GHz processor}$$

1) $\text{16 GB RAM}$ — The working space: running apps and open files. It empties when the power goes off.
2) $\text{512 GB SSD}$ — Storage: keeps 512 GB with the power off. SSD is the fast type; HDD is slower.
3) $\text{Wi-Fi, 300 Mb/s}$ — Network bandwidth: 300 million bits can arrive each second.
4) $\text{built-in graphics}$ — No separate graphics card: the processor's own graphics.

## Find the mistake

**Sam reads a phone's spec sheet. Click the line where it first goes wrong.**

```
 1  The phone's spec sheet says 8 GB RAM and 256 GB storage.
 2  RAM and storage are both memory, so the phone has 264 GB of memory.
 3  So it can have 264 GB of apps running at once.
 4  That is why it never slows down.
```

* Answer: line 2

<!-- Speaker note: Line 2: RAM and storage are different parts that measure different things. 8 GB of RAM is the working space; 256 GB of storage is what it keeps. -->

* Answer: Mb/s (megabits a second)

## Sort

**Which part does each spec describe?**

Groups: Processor · RAM · Storage · Network

3.2 GHz · 6 cores · 16 GB, empties when switched off · 1 TB SSD · 2 TB hard disk (HDD) · Wi-Fi 6, up to 600 Mb/s

* Answer: 3.2 GHz → Processor; 6 cores → Processor; 16 GB, empties when switched off → RAM; 1 TB SSD → Storage; 2 TB hard disk (HDD) → Storage; Wi-Fi 6, up to 600 Mb/s → Network

<!-- Speaker note: GHz and cores: processor. Working space: RAM. SSD and HDD: storage. Mb/s: network. -->
