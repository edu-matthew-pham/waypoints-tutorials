## Explain: what you found has names

1. $\text{1. a site leaks}$ — A **breach**. You can't stop other sites being breached; you can limit the damage.
2. $\text{2. reuse spreads it}$ — The leaked password is tried on every other site. One password everywhere means one leak opens everything.
3. $\text{3. guessable falls first}$ — Common passwords, symbol swaps and personal details (names, birthdays, pets) are on the lists tried first.
4. $\text{fix: long, random, different}$ — Four random words for each site.

:::keep-together

Answer: {{field-15}}

:::teacher-note

**Answer:** The game site's list leaked, with Ava's password on it. (the site kept it and lost it); Whoever had the list tried that password on her other accounts. (people often use one password everywhere, so it's the first thing to try); Every account with the same password fell. (the password matched); Accounts with a popular or personal password fell even with no match. (those are on the lists people try first, leak or not); A different long, random password on each account stopped it. (the leaked one opens nothing else, and the rest aren't on any list)

One leaked password is tried everywhere, so a shared password falls with it; a common or personal one falls with no leak at all.
