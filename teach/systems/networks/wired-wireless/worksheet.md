## Worked example: three properties


:::keep-together

### Time to send a file

1. $50 \text{ MB} \times 8 = 400 \text{ megabits}$ — Speeds are in megabits a second, so change bytes to bits.
2. $400 \div 1000 = 0.4 \text{ s}$ — Over a cable at 1000 Mb/s.
3. $400 \div 100 = 4 \text{ s}$ — Over Wi-Fi at 100 Mb/s: ten times as long.
4. $\text{latency} \to \text{games, video calls}$ — Jobs that go back and forth need a short delay.
5. $\text{bandwidth} \to \text{streaming, downloads}$ — Jobs that move a lot of data need a high speed.
6. $\text{reliability} \to \text{every job}$ — Lost packets must be sent again, which costs time.

Now work out a file's time at 100 Mb/s.

**A link carries 100 Mb/s. How many seconds does a 50 MB file take? (A byte is 8 bits, so 50 MB is 400 megabits.)**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 4

400 megabits ÷ 100 Mb/s = 4 seconds (a little more if packets are lost).

:::


:::keep-together

### Find the mistake

**Sam plans to fix a laggy game. Click the line where the reasoning first goes wrong.**

```
 1  My online game lags: my moves show up late.
 2  Lag is the delay (latency) before each packet arrives.
 3  More bandwidth means each packet arrives sooner.
 4  So a faster internet plan will fix the lag.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: bandwidth is how much data a second, not how soon each packet arrives. Lag is latency; a cable, or being closer to the router, cuts the delay. A bigger plan mostly helps big downloads.

:::


:::keep-together

### Why Wi-Fi loses packets

**Why does Wi-Fi lose more packets than a cable?**

☐ The signal travels through the air, where walls, distance and other devices weaken or interfere with it

☐ Wi-Fi is newer, so it has more bugs

☐ Wi-Fi packets are bigger

☐ Cables send each packet twice

:::


:::teacher-note

**Answer:** The signal travels through the air, where walls, distance and other devices weaken or interfere with it

A radio signal spreads out, is blocked by walls and shares the air with other devices, so some packets are damaged or lost.
