# Text or number?

Starting out · Numbers and switches

## Today

- I can say what a computer does with numbers and with text.
- I can explain why 12 and 3 can make 15 or 123.
- I can choose whether a form should store something as a number or as text.

<!-- Speaker note: Before class: Do the Try board yourself: type 12, then 123. The one idea: the type of data (number or text) decides what the computer can do with it. Numbers add; text joins. Simplification: in programs this is "string" and "integer"; spreadsheets show it as a number lined up on the right and text on the left. Neither word is needed here. Year 7–8 catch-up: Text as numbers (8K03 n2) assumes students know a digit in text is a character; this lesson is that idea. Teacher: Try: ask why 12 needs two numbers here but would need one as a number. Teacher: Worked example: ask what goes wrong if a phone number loses its 0. -->

## Why it matters

> 12 and 3 make 15. But a computer can also turn 12 and 3 into 123. How does it know which to do?

<!-- Speaker note: When you type 12, the computer has to decide: is it the number twelve, or the two characters 1 and 2? -->

## 12 and 3, two ways

Now: which can be added?

$$12 + 3 = 15$$

1) $\text{12 joined to 3} = \text{123}$ — Stored as text: the computer puts one after the other.
2) $\text{"12"} \to 49,\ 50$ — As text, 12 is two characters, each with its own code.
3) $\text{the type decides}$ — Number or text: the computer stores which one it is, and that decides what it can do.

## Find the mistake

**Sam joins two text boxes. Click the line where it first goes wrong.**

```
 1  Sam types 12 in one text box and 3 in another, then joins them.
 2  Inside the computer, text is stored as numbers.
 3  So the computer adds them up: 12 + 3.
 4  The answer box shows 15.
```

* Answer: line 3

<!-- Speaker note: Line 3: text is stored as codes, but the computer doesn't add text. It joins it, so the box shows 123. -->

## Phone numbers

**Why is a phone number like 0412 345 678 stored as text?**

- Phone numbers are too big to be numbers
- Text is faster
- It isn't: it's a number
- You never add phone numbers, and the 0 at the front must stay

* Answer: You never add phone numbers, and the 0 at the front must stay

<!-- Speaker note: As a number, 0412 would lose its 0 and become 412. As text, every character stays. -->
