# The parts inside

Starting out · The parts inside

<!-- Speaker note: Students match the five parts of a games console to their jobs, follow a game through them, see memory empty and storage keep a save when the console is turned off and on, and take out the one part that stops saving but not playing (AC9TDI6K01 node 1). ## Today

- I can name the five kinds of parts in a computer and their jobs.
- I can explain the difference between memory and storage.
- I can find the same parts in a laptop or a phone.

<!-- Speaker note: Before class: Do the boards yourself first: press A, save, turn off and on, load. The one idea: five kinds of parts, one job each, and memory (empties without power) is not storage (keeps without power). Simplifications (say so if asked): one processor, one memory and one storage; no operating system; the game itself also sits in storage and is loaded into memory to run. Year 7–8 catch-up: Inside a computer (8K01) starts at specifications. A student who can say which part keeps a saved game and which empties can start there. Unplugged: five students as the parts, passing a card that says "score" between them. Teacher: Try: ask pairs to test one guess on the console before they match it. Teacher: Vary: before Turn off and on, ask what will be left in memory and in storage. -->

## Think, pair, share

**Memory and storage both remember things. Why would a computer need both?**

- What happens to each when the power goes off?
- Which one would you want your saved game in? Which one is the game using right now?

## Five parts, five jobs

Now: which part works out what happens?

$$\text{Buttons (input)}$$

1) $\text{Processor}$ — Works out what happens: the score goes up by one.
2) $\text{Memory}$ — Holds the score while you play. It empties when the power goes off.
3) $\text{Storage}$ — Keeps the saved game when the power is off.
4) $\text{Screen (output)}$ — Shows the result: the new score.
