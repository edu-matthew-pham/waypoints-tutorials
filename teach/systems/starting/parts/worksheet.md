# The parts inside

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A games console, a laptop and a phone look different, but inside they have the same five kinds of parts.


:::teacher-note

**In one sentence:** Students match the five parts of a games console to their jobs, follow a game through them, see memory empty and storage keep a save when the console is turned off and on, and take out the one part that stops saving but not playing (AC9TDI6K01 node 1).

**Students should be able to say:** I can name the five kinds of parts in a computer and their jobs. I can explain the difference between memory and storage. I can find the same parts in a laptop or a phone.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Worked example: one game, five parts


:::keep-together

### Five parts, five jobs

1. $\text{Buttons (input)}$ — Take in what you do: press A.
2. $\text{Processor}$ — Works out what happens: the score goes up by one.
3. $\text{Memory}$ — Holds the score while you play. It empties when the power goes off.
4. $\text{Storage}$ — Keeps the saved game when the power is off.
5. $\text{Screen (output)}$ — Shows the result: the new score.

Now: which part works out what happens?

**You press A. Which part works out that the score should go up?**

☐ The screen

☐ The processor

☐ The buttons

☐ Storage

:::


:::teacher-note

**Answer:** The processor

The processor follows the game's instructions: press A, add one to the score.

:::


:::keep-together

### Find the mistake

**Sam explains memory and storage. Click the line where it first goes wrong.**

```
 1  Sam's console has memory and storage.
 2  Both of them remember things.
 3  So memory and storage are the same part.
 4  So the score in memory is still there after turning off.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: they are different parts. Memory holds what's being used right now and empties when the power goes off. Storage keeps things with the power off.
