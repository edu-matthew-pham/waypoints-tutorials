# Organise what you found

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** You have five numbers, one for each day. In a paragraph, which day was busiest? In a table?


:::teacher-note

**In one sentence:** Students organise what they kept so the answer is visible: a table with a row for each item, themes across sources, a graph for change over time. Economics uses a digital tool on the required path.

**Students should be able to say:** I can pick a table or a graph to suit my information. I can name columns so I can compare. I can say why a shape fits my question.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## The idea: put like with like


:::keep-together

### Find Nib's mistake

**Click the line where Nib's plan goes wrong.**

```
 1  Nib has notes: Monday 212, Tuesday 198, Wednesday 230, Thursday 205, Friday 190.
 2  Nib says: "I will keep my notes in the order I found them, written as sentences."
 3  Nib writes each fact in a paragraph and tries to see which day was busiest.
 4  Nib cannot tell at a glance. Nib decides the notes are fine.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: keeping notes in the order found, as sentences, hides the pattern. Put like with like in a table so the busiest day shows.

## Check: before you move on

Tables and graphs can both show numerical data. Choose a table to retrieve exact values or a graph to inspect a pattern; label the measure, units, dates and sources. A graph of river level needs comparable readings from the same location. Neither format proves a cause.

:::keep-together

**You need to compare what C1 and N1 say about access and participation. Which layout helps most?**

☐ A graph counting words in each source

☐ Only notes that agree with the closure

☐ All of C1, then all of N1, in the order copied

☐ One row per theme, with each source's notes alongside it

:::


:::teacher-note

**Answer:** One row per theme, with each source's notes alongside it

Theme rows make similarities and differences visible without losing the sources.

:::
