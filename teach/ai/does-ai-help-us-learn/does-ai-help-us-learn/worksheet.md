# Does AI help us learn?

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Compare the same task done for different goals, and start an inquiry that may not have one final answer.


:::teacher-note

**In one sentence:** Students start the course inquiry by comparing one task done for two different goals, and separate getting a task done from learning to do it.

**Students should be able to say:** I can explain why the same help can suit one goal and not another. I can say what a finished product shows, and what it does not show, about learning. I can give the best reason for a view I disagree with.

**Width:** the unmarked parts are the floor every student does (Engage, Explore, Explain, Evaluate). Typical and Wider sections add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::


## Engage

Two students hand in equally good games. One wrote the code in a beginner game maker. The other told an AI what to build. Did they learn the same things? Does it matter what each one was trying to do?

**Inquiry record:** answer *Does AI help us learn?* in two or three sentences. Add one reason, one thing you are unsure about, and how sure you are (low, medium or high). Keep this first answer.

:::keep-together

## Explain: the goal changes the judgement

Getting a task done is one thing. Being able to do it yourself is another. Help from a person, a tool or an AI can get the task done, and that can be valuable. But it doesn't tell us everything about what you learned.

Ari and Bea both made a maze game with help. Ari wanted to learn to code. Bea wanted to find out what players enjoy.

:::keep-together

### Ari's game

**Ari's goal was to learn to code movement. He asked AI to write the whole maze game. What did he skip?**

☐ Nothing: the game works, so he met his goal

☐ Testing whether players like the game

☐ Writing the movement code, the part he wanted to learn

:::


:::teacher-note

**Answer:** Writing the movement code, the part he wanted to learn

:::


:::keep-together

### Bea's game

**Bea's goal was to find out whether players like a time limit. She used a ready-made template so the maze took five minutes to build. Was that a good choice for her goal?**

☐ No: using any shortcut means she learned nothing

☐ Yes: her goal was about players, so building quickly left time to test

☐ No: she should have written every line herself

:::


:::teacher-note

**Answer:** Yes: her goal was about players, so building quickly left time to test

:::


:::typical

## Make: Elaborate: two claims

Discuss these two claims with a partner.

- **Claim A:** "AI helps people learn, because it lets them do things they couldn't do alone."
- **Claim B:** "Doing a task with AI doesn't show you learned how to do it."

First give the best reason for each claim. Then ask:

- Can both be true?
- Do they mean the same thing by *learn*?
- Would your answer change if the task were learning fractions, not making a game?

**Inquiry record:** add a reason against your first answer. You can keep your answer, change it, or add "it depends on…". Write one question to take into the next lesson.

Work in the tutorial. Plan first: what will you change, and how will you test it?

## Evaluate: what was the goal?

Before you judge any use of AI, name the goal. Then ask what the result shows about that goal.

**Next lesson:** if someone does better with help, what would show they really learned?
