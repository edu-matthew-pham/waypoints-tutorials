# Two data sets, one scale

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Two battery brands: which lasts longer? Plot them so you can see.


:::teacher-note

**In one sentence:** To compare two data sets fairly, draw them on the same scale, one above the other. Then the centre, the spread and the shape can be read side by side.

**Students should be able to say:** I can draw or read two sets on a shared scale. I can find and compare their ranges. I can say why the scale must match.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Compare fairly


:::keep-together

### Why share a scale

1. $A:\ 8\text{ to }12,\ \text{range }4$ — Read the lowest and highest.
2. $B:\ 5\text{ to }15,\ \text{range }10$ — Same scale, so it is clearly wider.
3. $\text{both medians} = 10$ — The centres agree, the spreads do not.

**Why must two plots being compared use the same scale?**

☐ So both have the same number of dots

☐ So the same distance means the same number on both

☐ So they are the same colour

☐ So they look neat

:::


:::teacher-note

**Answer:** So the same distance means the same number on both

With the same scale, a gap or a spread of the same length means the same amount on both.

:::


:::keep-together

## Ranges and medians


:::keep-together

### Range difference

**Set A: 12, 14, 15, 17, 18. Set B: 9, 13, 15, 18, 24. What is B's range minus A's range?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 9

B: 24 − 9 = 15. A: 18 − 12 = 6. 15 − 6 = 9.

:::


:::keep-together

### Median

**What is the median of set B (9, 13, 15, 18, 24)?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 15

The middle (3rd) value.

:::


:::keep-together

### Review

**Review: the mean is 30 and the median 24. What shape is it likely?**

☐ Symmetric

☐ Skewed left

☐ Skewed right

☐ Uniform

:::


:::teacher-note

**Answer:** Skewed right

Mean above median means a tail to the right.
