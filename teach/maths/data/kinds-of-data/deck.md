## Today

**We are learning to** numerical data is discrete when it is counted (siblings: 0, 1, 2, …) and continuous when it is measured (a 100 m time can be any value, such as 14.37 s). Measured values are always rounded to some precision.

- I can say whether numerical data is discrete (counted) or continuous (measured).
- I can explain why a measurement is always rounded, and choose a sensible precision.

<!-- Speaker note: Before class: Try the Run board first. This short lesson opens the Data unit; the next lesson calculates mean, median, mode and range. ## Why it matters

> How many siblings do you have? How long does it take you to run 100 m? One answer is always a whole number; the other could be anything in between.

<!-- Speaker note: Statistics starts with **data**: values collected to answer a question. Numerical data comes in two kinds: - **Discrete** data is **counted**: number of siblings, goals scored, cars in a car park. It takes separate values, usually whole numbers. - **Continuous** data is **measured**: height, time, mass, temperature. It can take any value in a range; we round it when we record it. The kind of data changes how you collect it, and how you display it later in this unit. -->

## Counted or measured

Here is how to tell the kinds apart.

Sort each one: discrete or continuous?

$$\text{siblings: } 0, 1, 2, 3$$

1) $\text{height: } 152.5\text{ cm}$ — Measured: any value in a range. **Continuous.**
2) $152.5 \approx 152.47\ldots$ — A measurement is rounded to the precision of the instrument (here 0.1 cm).
3) $\text{shoe size: } 7, 7.5, 8$ — Fixed steps with nothing in between: discrete, even with halves.

## Rounded measurements

**A height is recorded as $152$ cm, to the nearest centimetre. What could the real height be?**

- Exactly 152 cm
- Anything from 151.5 cm up to (but not including) 152.5 cm
- Anything from 152 cm to 153 cm

* Answer: Anything from 151.5 cm up to (but not including) 152.5 cm

<!-- Speaker note: Measured values are rounded: 152 cm to the nearest cm means from 151.5 cm up to 152.5 cm. -->
