## Today

**We are learning to** describe a data set by its shape (symmetrical or skewed, with clusters, gaps or outliers), its centre and its spread. Compare two sets on centre and spread, with numbers and in context, not by one value.

- I can describe the shape of a data set (symmetrical, skewed, clusters, gaps, outliers).
- I can compare two data sets using a measure of centre and a measure of spread.
- I can write a comparison with numbers and in context.

<!-- Speaker note: Before class: Do the Run and Make boards first. Students need Mean, median, mode and range, and Stem-and-leaf plots. The one idea: a data set has a shape, a centre and a spread; comparing two needs both centre and spread. The common mistake is comparing single values (the highest score); it is planted in Mia's reasoning and again in Practise. The board draws the second set above the first, each with its own median line and range arrow; only the first set can be changed. -->

## Why it matters

> Two classes sit the same quiz. One has the top score; the other has nobody below 12. Which class did better? It depends on what you compare.

<!-- Speaker note: To describe a data set, look at three things: - **Shape**: is it **symmetrical** (balanced about the middle) or **skewed** (bunched at one end with a tail at the other)? Are there **clusters**, **gaps** or **outliers**? - **Centre**: the median (or mean): a typical value. - **Spread**: the range: how varied the values are. To **compare** two data sets, compare their centres **and** their spreads, using the numbers and saying what they mean in context. -->

## Shape, centre, spread

Here is how to describe and compare.

Now describe the shape of the books data.

$$\text{Shape}$$

1) $\text{Centre: medians } 15 \text{ and } 16$ — Close: a typical score is about the same.
2) $\text{Spread: ranges } 6 \text{ and } 16$ — Very different: Class B's scores vary much more.
3) $\text{Compare both}$ — "Similar centres, but A is more consistent (range 6, not 16)."

**Mia compares the two classes. Click the line where her reasoning goes wrong.**

```
 1  Class A: 12, 14, 15, 15, 16, 17, 18. Class B: 6, 10, 13, 16, 19, 20, 22.
 2  The best score in Class B is 22; in Class A it is 18.
 3  So Class B did better.
```

* Answer: line 3

## A good comparison

**Which is the best comparison of Class A and Class B?**

- Class B is better because it has a 22.
- Class A is better because 15 + 14 is more than 6 + 10.
- The classes have similar medians (15 and 16), but Class A's scores are much less spread (range 6 against 16), so A was more consistent.

* Answer: The classes have similar medians (15 and 16), but Class A's scores are much less spread (range 6 against 16), so A was more consistent.

## Centre and spread

**Two bakeries' delivery times (min). Bakery X: median 25, range 10. Bakery Y: median 22, range 30. Which statement is right?**

- Y is slower and more reliable
- Y is usually a bit faster, but X is more reliable
- X is faster and more reliable

* Answer: Y is usually a bit faster, but X is more reliable

<!-- Speaker note: Lower median: Y is faster typically. Smaller range: X is more reliable. -->

## A fair comparison

**Which is NOT a fair comparison of two netball teams' goals?**

- Team 1 scored the single highest game, so Team 1 is better
- Team 1's median was 3 goals higher
- Team 2's goals varied less (smaller range)

* Answer: Team 1 scored the single highest game, so Team 1 is better

## Exit ticket

**Group 1 reaction times (s): median 0.32, range 0.10. Group 2: median 0.28, range 0.35. Compare the groups in one sentence.**

* Group 2 was faster on a typical try (median 0.28 s against 0.32 s), but much less consistent (range 0.35 s against 0.10 s).
