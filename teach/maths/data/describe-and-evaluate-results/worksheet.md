# Why real results differ

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** The simulation says she scores all five about a third of the time. In real shootouts she did it 3 times in 10. Is the simulation wrong?


:::teacher-note

**In one sentence:** Small groups of trials vary a lot, a simulation leaves things out, and a real season is only a short run; describe the results, compare with the theory and explain the gap.

**Students should be able to say:** I can describe how simulated results vary. I can compare results with the theory. I can give reasons for a gap.

## Variation and models


:::keep-together

### The spread

1. $0.58,\ 0.66,\ 0.70,\ 0.62,\ 0.64$ — Group results vary by chance.
2. $\tfrac{160}{250} = 0.64$ — Pool them: more trials, steadier.
3. $\text{real season: } 3 \text{ in } 10 = 0.3$ — A short run, so it varies a lot.

**The five groups' relative frequencies ranged from 29/50 = 0.58 to 35/50 = 0.70. What is the range (a decimal)?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 0.12

0.70 − 0.58 = 0.12.

:::


:::keep-together

### Reasons for a gap

**Which is NOT a good reason for a real season to differ from the simulation?**

☐ Pressure may change how well the striker plays

☐ The simulation is always wrong

☐ A real season is a short run of trials, so chance varies

☐ The scoring rate used might be a bit off

:::


:::teacher-note

**Answer:** The simulation is always wrong

A simulation is not always wrong: it is a model. Differences come from chance, from what the model leaves out and from the numbers fed into it.

:::


:::keep-together

```
 3  That is not 0.64, so the theory is wrong.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: 29/50 = 0.58 is within the normal spread of 50 trials. One group can't show the model is wrong. Pool the groups: 160/250 = 0.64.
