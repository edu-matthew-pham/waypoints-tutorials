## Mean

$$\text{mean} = \tfrac{671}{10} = 67.1$$

1) $\text{range} = 81 - 55 = 26$ — Highest minus lowest.
2) $\text{median} = 67$ — Middle of the ordered values.

```

 3  So the recycling is working well.
```
