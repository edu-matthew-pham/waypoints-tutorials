## List, then count


:::keep-together

### List, then count

Here is how to find a probability.

1. $\{1, 2, 3, 4, 5, 6\}$ — List the sample space: every possible outcome of rolling a dice.
2. $\text{equally likely?} \;\checkmark$ — A fair dice: each face has the same chance.
3. $\text{even} = \{2, 4, 6\}$ — The favourable outcomes for the event.
4. $P(\text{even}) = \tfrac{3}{6} = \tfrac{1}{2} = 0.5 = 50\%$ — Favourable ÷ total, in any form.
5. $P(\text{red}) = \tfrac{1}{2},\ P(\text{blue}) = P(\text{green}) = \tfrac{1}{4}$ — Not equally likely: use the sizes. Check: they add to 1.

Now work out P(even) on a dice.

**Roll a fair dice. What is the probability of an even number? Give a fraction in simplest form.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 1/2

Sample space {1, 2, 3, 4, 5, 6}; even: 2, 4, 6. P = 3/6 = 1/2.

:::


:::keep-together

### Find the mistake

**Kai works out probabilities for the half-red spinner. Click the line where his reasoning goes wrong.**

```
 1  The spinner has three colours: red, blue and green.
 2  So the sample space is {red, blue, green}.
 3  There are 3 outcomes, so each has probability 1/3.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: favourable ÷ total only works when the outcomes are equally likely. Red is half the spinner: P(red) = 1/2, P(blue) = P(green) = 1/4.
