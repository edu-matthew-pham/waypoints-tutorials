# Listing every outcome of two choices

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** The canteen meal deal is a main and a drink. How many different deals can you order?


:::teacher-note

**In one sentence:** A meal deal is a main and a drink. Listing the deals in an order (every main with every drink) shows that two-step outcomes multiply, and stops you missing one.

**Students should be able to say:** I can list every outcome of two choices without missing one. I can count them by multiplying. I can explain why two choices multiply rather than add.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Count and list


:::keep-together

### Count the pairs

1. $\text{4 mains, 3 drinks}$ — Two choices, one after the other.
2. $\text{burger} \to \text{water, juice, milk}$ — Take one main and pair it with every drink.
3. $4 \times 3 = 12$ — Every main has 3 deals, so multiply.

**A pizza has 5 toppings to choose from and 4 sauces. How many top-and-sauce pairs?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 20

5 × 4 = 20 pairs.

:::


:::keep-together

### Find the mistake

**Sam counts the deals for 4 mains and 3 drinks. Click the line where he goes wrong.**

```
 1  There are 4 mains and 3 drinks.
 2  A deal is a main and a drink, so 4 + 3 = 7 deals.
 3  So there are 7 different meal deals.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: each main goes with each drink, so the deals are 4 × 3 = 12, not 4 + 3.

:::


:::keep-together

### List without missing any

**What is the safest way to list every meal deal?**

☐ List the drinks only

☐ Count the mains, then count the drinks and add

☐ Write deals as they come to mind

☐ Take one main at a time and pair it with each drink

:::


:::teacher-note

**Answer:** Take one main at a time and pair it with each drink

Go main by main: burger with water, juice, milk; then wrap with water, juice, milk; and so on. Each main gets a row, so none is missed or repeated.

:::
