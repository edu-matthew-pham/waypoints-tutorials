# Stem-and-leaf plots

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Thirty homework times in a list tell you very little. Sort them into a stem-and-leaf plot and the shape jumps out, and you can still read every value.


:::teacher-note

**In one sentence:** Students build ordered stem-and-leaf plots (tens as stems, units as leaves, every stem included, with a key) and read values, the median, mode and range from them (AC9M7ST02, node 1).

**Students should be able to say:** I can build an ordered stem-and-leaf plot with a key. I can read values, the median, the mode and the range from a stem-and-leaf plot.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

## Build and read


:::keep-together

### Build, then read

Here is how to build one, and read from it.

1. $23, 31, 35, 35, 38, 42, 47, 51$ — Sort the values first (or sort the leaves at the end).
2. $\text{stems: } 2, 3, 4, 5$ — The tens digits, from smallest to largest, none missed out.
3. $3 \mid 1\ 5\ 5\ 8$ — Each value's units digit goes on its stem's row, in order.
4. $\text{Key: } 3 \mid 5 = 35$ — A key says how to read the plot.
5. $\text{median} = \tfrac{35 + 38}{2} = 36.5$ — 8 values: count in to the 4th and 5th leaves.

Now read the median of the plot in the picture.

**What is the median of the data in this plot?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 27

11 values, so the median is the 6th: 14, 18, 21, 23, 23, 27.
