## Build and read


:::keep-together

### Build, then read

Here is how to build one, and read from it.

1. $23, 31, 35, 35, 38, 42, 47, 51$ — Sort the values first (or sort the leaves at the end).
2. $\text{stems: } 2, 3, 4, 5$ — The tens digits, from smallest to largest, none missed out.
3. $3 \mid 1\ 5\ 5\ 8$ — Each value's units digit goes on its stem's row, in order.
4. $\text{Key: } 3 \mid 5 = 35$ — A key says how to read the plot.
5. $\text{median} = \tfrac{35 + 38}{2} = 36.5$ — 8 values: count in to the 4th and 5th leaves.

Now read the median of the plot in the picture.

**What is the median of the data in this plot?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 27

11 values, so the median is the 6th: 14, 18, 21, 23, 23, 27.

Line: {{field-15}}

**Answer:** line 3

Line 3: every stem from the smallest to the largest goes in, even with no leaves: 1, 2, 3, 4. The empty 3 row shows the gap between the 20s and the 40s.
