# Stem-and-leaf plots

Data and chance · Data

## Today

**We are learning to** a stem-and-leaf plot keeps every value and shows the shape: the tens are the stems, the units are the leaves, written in order. Include every stem, even with no leaves, and add a key.

- I can build an ordered stem-and-leaf plot with a key.
- I can read values, the median, the mode and the range from a stem-and-leaf plot.

<!-- Speaker note: Before class: Do the Run board first. Students need Mean, median, mode and range. This is a hinge: describing and comparing distributions (next lesson) reads shape from these plots. The common mistake is leaving out a stem with no leaves, which hides gaps; it is planted in Jo's working. Others: unordered leaves, and reading a leaf as a value on its own (the board's key helps). The board shows the dot plot and the stem-and-leaf plot together in Run and Make, so students can see they show the same data. -->

## Why it matters

> Thirty homework times in a list tell you very little. Sort them into a stem-and-leaf plot and the shape jumps out, and you can still read every value.

<!-- Speaker note: A **stem-and-leaf plot** is a display that keeps every value. For two-digit numbers: - the **stem** is the tens digit, written once down the left; - the **leaves** are the units digits, written in order along each stem's row; - a **key** says how to read it: $3 \mid 5$ means $35$. Turned on its side, it looks like a bar graph, so you can see the shape of the data and still read every value. -->

## Build, then read

Here is how to build one, and read from it.

Now read the median of the plot in the picture.

$$23, 31, 35, 35, 38, 42, 47, 51$$

1) $\text{stems: } 2, 3, 4, 5$ — The tens digits, from smallest to largest, none missed out.
2) $3 \mid 1\ 5\ 5\ 8$ — Each value's units digit goes on its stem's row, in order.
3) $\text{Key: } 3 \mid 5 = 35$ — A key says how to read the plot.
4) $\text{median} = \tfrac{35 + 38}{2} = 36.5$ — 8 values: count in to the 4th and 5th leaves.
