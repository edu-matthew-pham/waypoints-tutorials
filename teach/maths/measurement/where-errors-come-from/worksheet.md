# Where errors come from

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Two inspectors measure the same bolt hole with the same calipers and write down different numbers. Whose is right?


:::teacher-note

**In one sentence:** Students name where a measurement error comes from (the instrument, the method or the person) and tell an error that pushes every reading one way (systematic) from one that goes both ways (random). Averaging helps the second kind only (AC9M10M04, node 1).

**Students should be able to say:** I can say whether an error comes from the instrument, the method or the person. I can tell a systematic error from a random one. I can say why readings that agree are not necessarily right.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Close together, or right?


:::keep-together

### Systematic or random

A **systematic** error pushes every reading the same way (the stretched tape, the scale that is not zeroed). A **random** error goes high or low from reading to reading.

1. $1.60 - 1.52 = 0.08$ — Compare each reading with a trusted value. They are all about 0.08 m low.
2. $\text{all low, by about the same} \Rightarrow \text{systematic}$ — Same direction, same size.
3. $\text{averaging will not fix it}$ — The average is low by 0.08 too.
4. $\text{tape stretched?} \to \text{instrument}$ — Name where it comes from.
5. $\text{test the guess with a different tape}$ — A fix that checks the diagnosis.

Now try one on paper: a tape reads 1.52 m for a table that a laser says is 1.60 m. Work out by how much the tape is out, then say what kind of error it is and where it comes from.

**A cloth tape reads 1.52 m for a table that a laser says is 1.60 m. By how much is the tape out? (m)**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** $1.60 - 1.52$ (compare with the trusted value); $= 0.08$ (work it out); every reading is low, so the error is systematic, from the instrument (same direction every time, and it comes from the tape)

1.60 − 1.52 = 0.08 m. Every reading is low by about that much, so it is a systematic error from the tape.

:::


:::keep-together

### Find the mistake

**Dev's group measures a table six times and wants to know if their tape is accurate. Click the line where the reasoning goes wrong.**

```
 1  Dev's group measures a table six times with a cloth tape: 1.52, 1.53, 1.51, 1.52, 1.53, 1.52 m.
 2  The teacher's laser says the table is 1.60 m long.
 3  The readings are all within 0.02 m of each other.
 4  So the readings agree, which means the tape must be accurate.
 5  We will report the table as 1.52 m.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 4

Line 4: the readings agree with each other, but they are all about 0.08 m below the laser's 1.60 m. They are close together and still wrong in the same way, so the tape (or the way it was used) has a systematic error.

:::


:::keep-together

### Blame

**Mia's group finds all their masses read 3 g too high. Click the line where the group blames the wrong thing.**

```
 1  Mia's group finds every mass they weigh comes out 3 g too high.
 2  The scale shows 3 g with nothing on it.
 3  They write: this is human error, we should read the scale more carefully.
 4  Next time everyone will be more careful.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: the scale reads 3 g with nothing on it, so the error is in the instrument. Being more careful will not help; zeroing the scale will.

:::

### Averaging

**A group measures a pencil ten times and the readings scatter: some a little high, some a little low. What does averaging the ten do?**

☐ It removes the error, because the average is exact

☐ It makes the error bigger

☐ It reduces the error, because the highs and lows partly cancel

☐ It does nothing, because every reading is wrong

:::


:::teacher-note

**Answer:** It reduces the error, because the highs and lows partly cancel

A random error goes both ways, so the average is better than one reading. A systematic error goes one way and survives the average.

## Name the source


:::keep-together

### A falling ball

**A group measures how long a ball takes to fall by starting the stopwatch when they let go and stopping it when they hear it land, from the top of a tall building. What is the main source of error?**

☐ None: the time is exact

☐ The person: they are not careful

☐ The instrument: the stopwatch is broken

☐ The method: sound takes time to travel, so the time is too long

:::


:::teacher-note

**Answer:** The method: sound takes time to travel, so the time is too long

Waiting for the sound adds a delay to every drop, a systematic error from the method. Watching the ball land instead would remove it.

:::


:::keep-together

### Which direction

**Five readings of a length are $12.3$, $12.1$, $12.4$, $12.2$ and $12.0$ cm; the true length is $11.0$ cm. Which kind of error is the main one?**

☐ Both are equal

☐ None: the readings are close together

☐ Random: the readings differ

☐ Systematic: every reading is too big

:::


:::teacher-note

**Answer:** Systematic: every reading is too big

All five are over the true value by 1 to 1.4 cm, so the main error is systematic. The 0.4 cm scatter is the smaller, random part.

:::


:::keep-together

### Review

**Review: a length of $80$ cm is measured with an error of $2$ cm. What is the percentage error? (%)**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 2.5

2 ÷ 80 = 0.025, × 100 = 2.5%.
