## Three parts, three tools


:::keep-together

### Three parts

1. $\text{run} = 0.45 \times 14 = 6.3$ — The gradient: 14 along for every 1 up.
2. $\text{ramp} = \sqrt{0.45^2 + 6.3^2} \approx 6.32$ — Pythagoras: the ramp is the hypotenuse.
3. $\theta = \tan^{-1}\left(\dfrac{0.45}{6.3}\right) = 4.1°$ — Rise is opposite, run is adjacent.

**Rise $0.45$ m, run $6.3$ m. How long is the ramp surface, to 2 decimal places?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 6.32

√(0.45² + 6.3²) = √39.8925 = 6.316, about 6.32 m.

:::


:::keep-together

### Which tool

**Which tool gives the angle of the ramp from the rise and the run?**

☐ tan⁻¹(rise ÷ run)

☐ The scale factor

☐ Pythagoras

☐ Adding the rise and run

:::


:::teacher-note

**Answer:** tan⁻¹(rise ÷ run)

Rise is opposite and run is adjacent, so the angle is tan⁻¹(0.45 ÷ 6.3).

:::


:::keep-together

### Find the mistake

**Ali finds the ramp's angle. Click the line where his working goes wrong.**

```
 1  The gradient is 1 in 14, so rise ÷ run = 1 ÷ 14.
 2  That means the angle is 14°.
 3  So the ramp is 14° to the ground.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: 1 in 14 is a ratio (rise ÷ run). The angle is tan⁻¹(1 ÷ 14) = 4.1°, not 14°.
