## Size matters


:::keep-together

### Absolute and relative

1. $\text{absolute error} = |\text{measured} - \text{true}|$ — How far out, in the same unit.
2. $|20.04 - 20| = 0.04 \text{ mm}$ — The hole.
3. $\text{relative error} = \dfrac{\text{absolute error}}{\text{true value}}$ — How big compared with the thing.
4. $0.04 \div 20 = 0.002$ — The hole's relative error.
5. $1 \div 2000 = 0.0005$ — The beam's relative error.

**The hole's absolute error is $0.04$ mm and its true size is $20$ mm. What is the relative error? (3 decimal places)**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 0.002

0.04 ÷ 20 = 0.002.

:::


:::keep-together

### Divide by the true value

**A $2000$ mm beam is out by $1$ mm. What is the relative error? (4 decimal places)**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 0.0005

1 ÷ 2000 = 0.0005.

:::


:::keep-together

### Find the mistake

**Una finds the relative error of a hole that is 0.04 mm out. Click the line where her working goes wrong.**

```
 1  The hole should be 20 mm and is 20.04 mm.
 2  Absolute error = 0.04 mm.
 3  Relative error = 0.04 × 20 = 0.8.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: relative error divides the absolute error by the true value. Multiplying gives a number that grows when it should shrink.

Answer: {{field-15}}

:::

**Answer:** 1

### Relative

**What is the relative error of that measurement? (2 decimal places)**

Answer: {{field-15}}

:::
