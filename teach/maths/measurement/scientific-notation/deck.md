Area, volume, circles and Pythagoras · Scientific notation

## Today

- I can write a big number in scientific notation.
- I can write a small number in scientific notation with a negative power.
- I can turn scientific notation back into a decimal.

## How far

Here's converting both ways.

Now try one on paper: $0.000\,038$ in scientific notation. Then type the power.

$$45\,000$$

1) $4.5 \times 10^{4}$ — The point moves 4 places left to sit after the 4: a positive power.
2) $0.00072$ — A small number.
3) $7.2 \times 10^{-4}$ — The point moves 4 places right, to sit after the 7: a negative power.
4) $3.6 \times 10^{5} = 360\,000$ — Back again: move the point 5 places right.

## Find the mistake

**Ravi writes 0.0004 in scientific notation. Click the line where his working goes wrong.**

```
 1  Write 0.0004 in scientific notation.
 2  The first digit is 4, so the number part is 4.
 3  The point moves 4 places, so the power is 4.
 4  So 0.0004 = 4 × 10⁴.
```

* Answer: line 3

<!-- Speaker note: Line 3: the point moves 4 places to the left, and a small number has a negative power: 4 × 10⁻⁴. -->

## Which is scientific notation?

**Which one is in scientific notation?**

- $1.2 \times 10^{4}$
- $12 \times 10^{3}$
- $120 \times 10^{2}$
- $0.12 \times 10^{5}$

* Answer: $1.2 \times 10^{4}$

<!-- Speaker note: All four are 12 000. Only 1.2 × 10⁴ has a number from 1 up to 10. -->
