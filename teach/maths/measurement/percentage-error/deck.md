- No: the timer might be wrong
- No: 0.01 s is too small to notice

## Percentage error

$$\text{percentage error} = \dfrac{\text{absolute error}}{\text{true value}} \times 100\%$$

1) $0.04 \div 20 = 0.002$ — The relative error.
2) $0.002 \times 100 = 0.2\%$ — The percentage error.
3) $\text{gap} > \text{combined error} \Rightarrow \text{result is real}$ — Compare the difference with what the measurements could be out by.

```

 3  So the percentage error is 0.002%.
```
