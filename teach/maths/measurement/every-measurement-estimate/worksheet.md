## Half the precision


:::keep-together

### Bounds

1. $\text{reading } 24 \text{ mm, to the nearest } 1 \text{ mm}$ — The smallest mark is 1 mm.
2. $1 \div 2 = 0.5$ — Half the smallest mark.
3. $24 - 0.5 = 23.5$ — Lower bound.
4. $24 + 0.5 = 24.5$ — Upper bound.
5. $23.5 \le \text{true length} < 24.5$ — The true value is in this range.

**A tape reads $156$ cm to the nearest cm. What is the upper bound? (cm)**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 156.5

156 + 0.5 = 156.5 cm.

:::


:::keep-together

### Half the mark

**A scale reads $3.2$ kg to the nearest $0.1$ kg. What is the upper bound? (kg)**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 3.25

Half of 0.1 is 0.05, so 3.2 + 0.05 = 3.25 kg.
