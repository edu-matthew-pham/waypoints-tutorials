## Neighbours

Here is the routine.

$$\angle K = 72^\circ \text{ in parallelogram } KLMN$$

1) $\angle K + \angle L = 180^\circ$ — Co-interior angles: KN is parallel to LM.
2) $\angle L = 180^\circ - 72^\circ = 108^\circ$ — Work it out.
3) $\angle M = 72^\circ,\ \angle N = 108^\circ$ — Opposite angles are equal. Check: they add to 360°.

## Find the mistake

**Jo works out the angles of a parallelogram. Click the line where she goes wrong.**

```
 1  ABCD is a parallelogram with angle A = 65°.
 2  Opposite angles add to 180°, so angle C = 180° − 65° = 115°.
 3  Angles A and B are co-interior, so angle B = 180° − 65° = 115°.
 4  So the angles are A = 65°, B = 115°, C = 115° and D = 65°.
```

* Answer: line 2

<!-- Speaker note: Line 2: opposite angles are equal, so C = 65°. Neighbouring angles add to 180°. Then D = 115°. -->

## A kite

**Kite ABCD has AB = AD and CB = CD, and angle B = 100°. Which other angle must be 100°, and why?**

- Angle C: it is next to B
- Angle A: it is opposite
- Angle D: triangles ABC and ADC are congruent (SSS)
- None of them

* Answer: Angle D: triangles ABC and ADC are congruent (SSS)

<!-- Speaker note: AB = AD, CB = CD and AC is shared, so the triangles are congruent and angle B = angle D. -->
