## Find the angles


:::keep-together

### Neighbours

Here is the routine.

1. $\angle K = 72^\circ \text{ in parallelogram } KLMN$ — What is given?
2. $\angle K + \angle L = 180^\circ$ — Co-interior angles: KN is parallel to LM.
3. $\angle L = 180^\circ - 72^\circ = 108^\circ$ — Work it out.
4. $\angle M = 72^\circ,\ \angle N = 108^\circ$ — Opposite angles are equal. Check: they add to 360°.

**In parallelogram PQRS, angle P = 65°. What is angle Q, in degrees?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 115

P and Q are co-interior angles between the parallel sides PS and QR: 180 − 65 = 115°.

:::


:::keep-together

### Find the mistake

**Jo works out the angles of a parallelogram. Click the line where she goes wrong.**

```
 1  ABCD is a parallelogram with angle A = 65°.
 2  Opposite angles add to 180°, so angle C = 180° − 65° = 115°.
 3  Angles A and B are co-interior, so angle B = 180° − 65° = 115°.
 4  So the angles are A = 65°, B = 115°, C = 115° and D = 65°.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: opposite angles are equal, so C = 65°. Neighbouring angles add to 180°. Then D = 115°.

:::


:::keep-together

### A kite

**Kite ABCD has AB = AD and CB = CD, and angle B = 100°. Which other angle must be 100°, and why?**

☐ Angle C: it is next to B

☐ Angle A: it is opposite

☐ Angle D: triangles ABC and ADC are congruent (SSS)

☐ None of them

:::


:::teacher-note

**Answer:** Angle D: triangles ABC and ADC are congruent (SSS)

AB = AD, CB = CD and AC is shared, so the triangles are congruent and angle B = angle D.

:::

## Quadrilateral problems


:::keep-together

### Angles with x

**Two neighbouring angles of a parallelogram are x° and 2x°. What is x?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 60

x + 2x = 180, so 3x = 180 and x = 60. The angles are 60° and 120°.

:::


:::keep-together

### Rhombus sides

**A rhombus has diagonals of 6 cm and 8 cm. How long is each side, in cm?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 5

The diagonals cut each other in half at 90°, making right-angled triangles with legs 3 and 4: the side is 5 cm.

:::


:::keep-together

### Opposite angles

**In parallelogram ABCD, angle A = 52°. What is angle C, in degrees?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 52

Opposite angles of a parallelogram are equal: 52°.

:::


:::keep-together

### Review: similar shapes

**Review: a 2 cm by 3 cm rectangle is enlarged with scale factor 4. What is the longer side now, in cm?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 12

3 × 4 = 12 cm.

:::

## Make: a linkage tray, on paper

Do this one in your book, not on the screen. The angle is made up for the task; real trays have arms that stop at a set angle. Write the reason for each line, check with 360°, and type angle B.

**Also used in**

- **Desk lamps and barriers.** Lamp arms and car-park barriers use the same parallelogram linkage, so the lamp head or the barrier arm keeps its direction as it moves.
- **Garden beds.** Setting out a parallelogram-shaped bed means knowing which sides and angles must match.
- **Frames.** A carpenter measures a frame's two diagonals: equal ones show a parallelogram frame is a rectangle.

**In parallelogram ABCD, angle B = 3 × angle A. Find all four angles.**

{{lines-3}}

:::


:::teacher-note

**Answer:** A + 3A = 180, so A = 45°. B = 135°, C = 45°, D = 135°.
