# Algorithms

> The words and methods from this unit, with an example of each.

:::keep-together

**algorithm**: A set of steps and decisions that gives the right result every time. Test it on one shape of every class.

$$\text{ask the most specific question first}$$

:::

:::keep-together

**congruence algorithm**: Ask the congruence tests first, then the similarity conditions, and end with a catch-all. Test on one pair of each kind, including SSA.

$$\text{congruent?} \to \text{similar?} \to \text{not enough to tell}$$

:::
