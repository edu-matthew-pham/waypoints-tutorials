# Same amount, different fraction

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** You eat 2 of 4 slices, your friend eats 1 of 2 slices of the same pizza. Who ate more?


:::teacher-note

**In one sentence:** Students see that different fractions can name the same amount, and drop the idea that bigger numbers mean a bigger fraction.

**Students should be able to say:** I can say two fractions are the same amount. I can find a fraction equivalent to one I am given. I can say why the amount does not change.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## The idea

Fractions are **equivalent** when they show the same amount. Cut every part into the same number of smaller parts: the top and bottom are multiplied by the same number, and the amount stays the same.

:::keep-together

### Same as a half?

**Is it the same amount as 1/2?**

Groups: Same as 1/2, Not the same

- 2/4: {{field-15}}
- 3/6: {{field-15}}
- 1/3: {{field-15}}
- 5/10: {{field-15}}
- 2/3: {{field-15}}

:::


:::teacher-note

**Answer:** 2/4 → Same as 1/2; 3/6 → Same as 1/2; 1/3 → Not the same; 5/10 → Same as 1/2; 2/3 → Not the same

:::


:::keep-together

### The missing number

**2/3 is the same as ?/12. What is the missing number?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 8

3 × 4 = 12, so 2 × 4 = 8. 2/3 = 8/12.

:::


:::keep-together

### Why it works

**Why does 2/4 show the same amount as 1/2?**

☐ It only works for 1/2

☐ Each half is cut into 2 parts, so there are twice as many parts and twice as many shaded

☐ 4 is bigger than 2, so it is a bigger fraction

☐ You add 2 to the top and the bottom

:::


:::teacher-note

**Answer:** Each half is cut into 2 parts, so there are twice as many parts and twice as many shaded

Cutting every part into 2 gives twice as many parts, and twice as many shaded. The amount does not change.

:::

### Not the same

**Which is NOT the same amount as 3/4?**

☐ 6/8

☐ 9/12

☐ 12/16

☐ 4/5

:::


:::teacher-note

**Answer:** 4/5

3/4 = 6/8 = 9/12 = 12/16. 4/5 is a different amount.

:::


:::keep-together

### Tenths

**3/5 is the same as ?/10. What is the missing number?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 6

5 × 2 = 10, so 3 × 2 = 6.

:::
