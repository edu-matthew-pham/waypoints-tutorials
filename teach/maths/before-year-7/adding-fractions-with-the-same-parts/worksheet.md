# Adding fractions with the same parts

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** You eat 2 fifths of a block of chocolate and your friend eats 1 fifth. How much is gone?


:::teacher-note

**In one sentence:** Students add fractions with the same bottom by adding the tops, and drop the idea that the bottoms are added too.

**Students should be able to say:** I can say what the bottom number tells me. I can add fractions with the same bottom. I can say what to do when the sum is more than 1.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## The idea

$\tfrac{2}{5} + \tfrac{1}{5} = \tfrac{3}{5}$. The bottom number names the part, like a unit, so it stays the same. Add the tops. When the tops add to more than the bottom, the sum is more than one whole: $\tfrac{6}{5} = 1\tfrac{1}{5}$.

:::keep-together

### Why the bottom stays

**Why does the bottom stay the same when you add?**

☐ You add the bottoms but leave one out

☐ The bottom is not important

☐ It only stays the same when the answer is under 1

☐ The bottom is the size of the parts, and you are still counting the same size of part

:::


:::teacher-note

**Answer:** The bottom is the size of the parts, and you are still counting the same size of part

The bottom names the part. 2 fifths + 1 fifth is 3 fifths, as 2 apples + 1 apple is 3 apples.

:::
