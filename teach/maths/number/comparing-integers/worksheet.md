# Comparing integers

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Thredbo at −9 °C, Canberra at −3 °C: which is colder? Below zero, the number that looks bigger is the smaller one.


:::teacher-note

**In one sentence:** Students place integers on a number line, find that further left is less (so −7 < −2), and compare and order integers with < and > (AC9M7N07, node 1).

**Students should be able to say:** I can put a set of integers, including negatives, in order from least to greatest. I can write a comparison between two integers with &lt; or &gt;. I can explain why −10 is less than −1, even though 10 is more than 1.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Further left is less


:::keep-together

### Ordering on the line

Here is how to put integers in order, using where each one sits on the number line.

1. $-2, \; -8, \; 3, \; 0$ — Put these in order from least to greatest.
2. $\text{place each on the line}$ — Negatives go left of zero: $-2$ is 2 left, $-8$ is 8 left.
3. $-8 \text{ is furthest left}$ — Furthest left is least, so $-8$ comes first.
4. $-8, \; -2, \; 0, \; 3$ — Read the line from left to right.
5. $-8 < -2$ — Between two negatives, the one further from zero is less.

**Which is true?**

☐ $-5 = -1$

☐ $-5 &lt; -1$

☐ $-5 &gt; -1$

:::


:::teacher-note

**Answer:** $-5 &lt; -1$

−5 is further left than −1, so −5 &lt; −1.

:::


:::keep-together


Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: 8 is bigger than 2, but −8 is further below zero than −2, so −8 is less. The order is −8, −2, 0, 3.

## Compare and order

### Which sign?

**Which sign goes in the gap? $-6 \;\square\; -9$**

☐ $&lt;$

☐ $&gt;$

:::


:::teacher-note

**Answer:** $&gt;$

−6 &gt; −9: −6 is to the right of −9.

:::

### In order

**Which list is in order from least to greatest?**

☐ $-9, -4, 0, 2, 5$

☐ $0, -4, -9, 2, 5$

☐ $-4, -9, 0, 2, 5$

:::


:::teacher-note

**Answer:** $-9, -4, 0, 2, 5$

Left to right on the line: −9, −4, 0, 2, 5.

:::
