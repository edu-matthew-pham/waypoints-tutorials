# Adding and subtracting integers

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A temperature that rises 9 degrees from −4 °C, a lift that goes down 5 floors from level 2, a bank balance below zero: all of them are moves along a number line.


:::teacher-note

**In one sentence:** Students add and subtract integers as moves on a number line, find that adding a negative moves left and that subtracting moves the opposite way to adding, so 5 − (−3) = 8 (AC9M7N07, node 2).

**Students should be able to say:** I can add and subtract integers by moving along a number line. I can explain why adding a negative number moves left. I can explain why 5 − (−3) is 8, not 2.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Which way to move


:::keep-together

### Moves on the line

Here is how to use the line for each kind of sum.

1. $-2 + 5$ — Start at the first number, $-2$.
2. $-2 + 5 = 3$ — Adding a positive moves right: 5 to the right lands on 3.
3. $4 + (-6) = -2$ — Adding a negative moves left: from 4, left 6 lands on $-2$.
4. $5 - (-3)$ — Subtracting moves the opposite way to adding.
5. $\text{adding } {-3} \text{ is left 3, so subtracting it is right 3}$ — Find the way adding would go, then turn round.
6. $5 - (-3) = 8$ — From 5, right 3 lands on 8. Subtracting $-3$ is the same as adding 3.

**Work out $4 + (-6)$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** -2

Start at 4. Adding −6 moves left 6: 3, 2, 1, 0, −1, −2.

:::


:::keep-together
