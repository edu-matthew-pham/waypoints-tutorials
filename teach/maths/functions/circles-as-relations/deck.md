## What happened?

* (3, 4). The distance from (0, 0) is found with Pythagoras: 3² + 4² = 9 + 16 = 25, and 5² = 25. For (4, 4) it is 32, which is more than 25, so that point is past the end of the arm. For (2, 3) it is 13, which is less.

## Write the equation

Here's how to write the equation of a circle from its centre and radius.

Now try one on paper: centre $(-1, 4)$, radius 3. Work out the number on the right side and type it.

$$\text{centre } (2, -3),\; r = 5$$

1) $(x - 2)^2$ — The centre's x is 2, so the bracket is x minus 2.
2) $(y + 3)^2$ — The centre's y is −3, so the bracket is y minus −3, which is y plus 3.
3) $r^2 = 25$ — The right side is the radius squared.
4) $(x - 2)^2 + (y + 3)^2 = 25$ — Put the two brackets and the right side together.

## Why not a function?

**On the circle $x^2 + y^2 = 25$, the points $(3, 4)$ and $(3, -4)$ are both on it. What does that say about a circle?**

- It isn't a function: the input x = 3 has two outputs, 4 and −4
- It is a function: it's a smooth curve
- It is a function: every point has an x and a y
- It isn't a function: the radius is 5

* Answer: It isn't a function: the input x = 3 has two outputs, 4 and −4

<!-- Speaker note: A vertical line at x = 3 meets the circle twice. A function has only one y for each x, so a circle is a relation but not a function. -->

## Moving the circle

**The circle $x^2 + y^2 = 25$ moves 2 right and 1 up. The radius stays 5. What is its new equation?**

- $x^2 + y^2 = 28$
- $(x - 2)^2 + (y - 1)^2 = 25$
- $(x - 2)^2 + (y - 1)^2 = 5$
- $(x + 2)^2 + (y + 1)^2 = 25$

* Answer: $(x - 2)^2 + (y - 1)^2 = 25$

<!-- Speaker note: The centre is now (2, 1): the brackets are (x − 2) and (y − 1). The radius is still 5, so the right side is 25. -->
