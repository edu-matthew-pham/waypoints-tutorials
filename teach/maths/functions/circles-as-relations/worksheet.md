## Centre, radius and not a function


:::keep-together

### Write the equation

Here's how to write the equation of a circle from its centre and radius.

1. $\text{centre } (2, -3),\; r = 5$ — Write the equation of the circle.
2. $(x - 2)^2$ — The centre's x is 2, so the bracket is x minus 2.
3. $(y + 3)^2$ — The centre's y is −3, so the bracket is y minus −3, which is y plus 3.
4. $r^2 = 25$ — The right side is the radius squared.
5. $(x - 2)^2 + (y + 3)^2 = 25$ — Put the two brackets and the right side together.

Now try one on paper: centre $(-1, 4)$, radius 3. Work out the number on the right side and type it.

**A circle has centre $(-1, 4)$ and radius 3. What number is on the right side of its equation?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 9

The equation is (x + 1)² + (y − 4)² = 9. The right side is r² = 3² = 9.

:::


:::keep-together

### Find the mistake

**Alex reads the centre and radius from an equation. Click the line where his working goes wrong.**

```
 1  Find the centre and radius of (x - 3)^2 + (y + 1)^2 = 16.
 2  Copy the numbers from the brackets with their signs, so the centre is (-3, 1).
 3  The right side is r^2, so r^2 = 16 and the radius is 4.
 4  Centre (-3, 1), radius 4.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: the brackets are (x − 3) and (y + 1), and the centre is where each bracket is zero: x = 3 and y = −1. The centre is (3, −1), not (−3, 1).

:::


:::keep-together

### Why not a function?

**On the circle $x^2 + y^2 = 25$, the points $(3, 4)$ and $(3, -4)$ are both on it. What does that say about a circle?**

☐ It isn't a function: the input x = 3 has two outputs, 4 and −4

☐ It is a function: it's a smooth curve

☐ It is a function: every point has an x and a y

☐ It isn't a function: the radius is 5

:::


:::teacher-note

**Answer:** It isn't a function: the input x = 3 has two outputs, 4 and −4

A vertical line at x = 3 meets the circle twice. A function has only one y for each x, so a circle is a relation but not a function.

:::


:::keep-together

### Moving the circle

**The circle $x^2 + y^2 = 25$ moves 2 right and 1 up. The radius stays 5. What is its new equation?**

☐ $x^2 + y^2 = 28$

☐ $(x - 2)^2 + (y - 1)^2 = 25$

☐ $(x - 2)^2 + (y - 1)^2 = 5$

☐ $(x + 2)^2 + (y + 1)^2 = 25$

:::


:::teacher-note

**Answer:** $(x - 2)^2 + (y - 1)^2 = 25$

The centre is now (2, 1): the brackets are (x − 2) and (y − 1). The radius is still 5, so the right side is 25.

:::

## Circles


:::keep-together

### Inside, on or outside

**Is $(6, 8)$ inside, on or outside the circle $x^2 + y^2 = 100$?**

☐ On it: 6² + 8² = 100

☐ Inside: 6² + 8² is less than 100

☐ Outside: 6² + 8² is more than 100

☐ Can't tell

:::


:::teacher-note

**Answer:** On it: 6² + 8² = 100

36 + 64 = 100, which is 10². The point is on the circle.

:::


:::keep-together

### Radius

**A circle is $(x - 4)^2 + (y + 2)^2 = 49$. What is its radius?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 7

r² = 49, so r = 7.

:::


:::keep-together

### Centre

**What is the centre of the circle $(x + 3)^2 + (y - 5)^2 = 9$?**

☐ $(3, 5)$

☐ $(-3, 5)$

☐ $(3, -5)$

☐ $(-3, -5)$

:::


:::teacher-note

**Answer:** $(-3, 5)$

x + 3 = 0 gives x = −3, and y − 5 = 0 gives y = 5.
