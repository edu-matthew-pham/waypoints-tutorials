# Which model?

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Used cars get cheaper every year. How cheap, by how old?


:::teacher-note

**In one sentence:** Students test tables for a line, a quadratic and an exponential using differences, second differences and ratios, and say which pattern they found. The hinge node: classify, then justify (AC9M10A04, node 1).

**Students should be able to say:** I can tell a line, a quadratic and an exponential apart from a table. I can show the pattern that proves my choice. I can say what a model leaves out.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Differences or ratios


:::keep-together

### Multiply by what?

There are three tests, and you try them in order.

1. $10,\; 12,\; 14.4,\; 17.28$ — Which model fits this table?
2. $2,\; 2.4,\; 2.88$ — First differences. They aren't equal, so it isn't a line.
3. $0.4,\; 0.48$ — Second differences. They aren't equal either, so it isn't a quadratic.
4. $12 \div 10,\; 14.4 \div 12,\; 17.28 \div 14.4$ — Ratios.
5. $1.2,\; 1.2,\; 1.2$ — The same every time.
6. $\text{exponential, ratio } 1.2$ — Equal ratios mean exponential. Each value is 1.2 times the one before.

Now try one on paper: $64, 48, 36, 27$. Find the ratio, then type it.

**Look at $64, 48, 36, 27$. What do you multiply by to get from each value to the next?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 0.75

48 ÷ 64 = 0.75, 36 ÷ 48 = 0.75 and 27 ÷ 36 = 0.75. Each value is 0.75 times the one before.

:::


:::keep-together

### Find the mistake

**Dev looks at the car prices. Click the line where his working goes wrong.**

```
 1  The prices are 30000, 24000, 19200, 15360. Is it linear or exponential?
 2  The price goes down every year, so it's a straight line going down.
 3  The line is y = 30000 - 6000x.
 4  At 3 years that gives 12000, but the table says 15360. The table must be wrong.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: falling every year doesn't make a table linear. A line drops the same dollars each time. These drops are 6,000, 4,800 and 3,840, so they aren't the same. The ratio is 0.8 every time, so it's exponential, and the table was right.

:::

## Choose the model


:::keep-together

### A multiplying table

**A table gives $6, 9, 13.5, 20.25$. Which model fits?**

☐ Quadratic: the second differences are equal

☐ Exponential: each value is 1.5 times the one before

☐ Linear: the differences are equal

☐ None of them

:::


:::teacher-note

**Answer:** Exponential: each value is 1.5 times the one before

9 ÷ 6 = 1.5, 13.5 ÷ 9 = 1.5 and 20.25 ÷ 13.5 = 1.5.

:::


:::keep-together

### A second difference

**A table gives $3, 7, 13, 21$. Which model fits?**

☐ Exponential: the ratios are equal

☐ Quadratic: the second differences are both 2

☐ Linear: the differences are equal

☐ None of them

:::


:::teacher-note

**Answer:** Quadratic: the second differences are both 2

First differences 4, 6, 8. Second differences 2, 2.

:::


:::keep-together

### A falling line

**A table gives $50, 45, 40, 35$. Which model fits?**

☐ Quadratic: it falls every time

☐ Exponential: it falls every time

☐ Linear: it takes off 5 every time

☐ None of them

:::


:::teacher-note

**Answer:** Linear: it takes off 5 every time

The differences are −5, −5, −5. Equal differences mean a line.

:::


:::keep-together

### Review

**Review: solve $2^x = 32$. What is $x$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 5

32 = 2⁵, so the bases match and x = 5.

## Make: back to the car


**How far out?.** Back to the car. Work it out on paper first, then type your answer.

**What else changes the price?.** The prices here are made up, and so is the 20% a year. Real listings differ in kilometres and condition. Your class can pick a model on a car-sales site, write down the prices at five ages and test them in the same three ways.

Sources: all prices and the 20% a year are made up for this lesson.

**Also used in**

- **Money.** Phones, laptops and bikes lose value by a share each year, not by the same dollars.
- **Science.** A table of measurements can be tested the same way: equal differences, equal second differences or an equal ratio.
