:::teacher-note

**In one sentence:** Students find where y = 2ˣ meets a horizontal line on a graph board, then solve equations with x in the power by writing both sides as powers of the same base and matching the indices, using the doubling sandwich from lesson 1 (AC9M10A03, node 4).

**Students should be able to say:** I can solve 2ˣ = 64 by writing both sides as powers of 2. I can rewrite a base like 4 or 8 as a power of 2 to match the other side. I can explain why I can't divide by the base to solve for x.

## Same base


:::keep-together

### Same base

Here's how to solve one when the two sides aren't powers of each other.

1. $8^x = 32$ — Solve for x. Neither side is a power of the other, but both are powers of 2.
2. $8 = 2^3,\; 32 = 2^5$ — Write each side with the same base, 2.
3. $(2^3)^x = 2^5$ — Put them in the equation.
4. $2^{3x} = 2^5$ — A power of a power: multiply the indices.
5. $3x = 5$ — The bases match, so the indices must match.
6. $x = \tfrac{5}{3}$ — Divide both sides by 3.
7. $8^1 = 8 \text{ and } 8^2 = 64$ — Check it's sensible: 32 is between 8 and 64, so x should be between 1 and 2. 5/3 is about 1.67. ✓

Now try one on paper like the example: $4^x = 32$. Write both sides as powers of 2, then type $x$.

**Solve $4^x = 32$. Write both sides as powers of 2.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 2.5

4 = 2², so 4^x = (2²)^x = 2^(2x). And 32 = 2⁵. So 2x = 5 and x = 2.5. Check: 4² = 16 and 4³ = 64, and 32 is between them.

:::


:::keep-together

### Find the mistake

**Eli solves $3^x = 81$. Click the line where his working goes wrong.**

```
 1  Solve 3^x = 81.
 2  I'll undo the 3 like in an equation, so I divide both sides by 3.
 3  x = 81 ÷ 3 = 27.
 4  So x = 27.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: in 3^x the 3 isn't multiplying x, so dividing by 3 doesn't undo anything. Write 81 as a power of 3: 81 = 3⁴, so 3^x = 3⁴ and x = 4. (3²⁷ would be a huge number.)

:::


:::keep-together

### Which base?

**To solve $25^x = 125$, you write both sides as powers of which number?**

☐ $5$, because $25 = 5^2$ and $125 = 5^3$

☐ $25$, because 25 is in the equation

☐ $125$, because it's the biggest

☐ No number works

:::


:::teacher-note

**Answer:** $5$, because $25 = 5^2$ and $125 = 5^3$

25 = 5² and 125 = 5³, so (5²)^x = 5³, 5^(2x) = 5³, 2x = 3 and x = 1.5.

### Rewrite 4

**Solve $4^x = 128$. Write both sides as powers of 2.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 3.5

4 = 2², so 4^x = 2^(2x) and 128 = 2⁷. So 2x = 7 and x = 3.5.

### A number in front

**Solve $5(2^x) = 80$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 4

Divide both sides by 5: 2^x = 16. And 16 = 2⁴, so x = 4.
