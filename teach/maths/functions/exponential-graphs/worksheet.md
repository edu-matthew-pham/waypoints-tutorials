## Reading the graph


:::keep-together

### Where it starts

Here is a decay graph worked out.

1. $y = 80(0.5^x)$ — What does this graph do?
2. $x = 0:\; y = 80(0.5^0) = 80$ — Put 0 in. Any number to the power 0 is 1, so y is just a. It crosses the y-axis at 80.
3. $b = 0.5 < 1$ — The base is less than 1: each step multiplies by a half, so the graph decays.
4. $80,\; 40,\; 20,\; 10,\; 5,\; 2.5$ — Keep halving for x = 0, 1, 2, 3, 4, 5.
5. $y > 0 \text{ always}$ — Halving never gives 0, so y never touches the x-axis.
6. $y = 0$ — The graph gets closer and closer to y = 0 but never reaches it. A line it gets close to like this is called an asymptote.

Now try one on paper like the example: $y = 3(2^x)$. Where does it cross the $y$-axis, and does it grow or decay? Then type the $y$-axis value.

**Where does $y = 3(2^x)$ cross the $y$-axis? Give the value of $y$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 3

3. When x = 0, 2 to the power 0 is 1, so y = 3 × 1 = 3. That's a.

:::


:::keep-together

### Find the mistake

**Kim sketches $y = 4(0.5^x)$. Click the line where her reasoning goes wrong.**

```
 1  Sketch y = 4 × 0.5^x.
 2  When x = 0, y = 4, so the graph starts at 4.
 3  0.5 is less than 1, so y gets smaller as x grows: 4, 2, 1, 0.5, ...
 4  Keep halving and y reaches 0, so the graph crosses the x-axis.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 4

Line 4: halving never gets to 0. 4, 2, 1, 0.5, 0.25, 0.125... there is always half left. The graph gets closer and closer to the x-axis but never touches it.

:::


:::keep-together

### Growth or decay

**Which of these is a decay graph?**

☐ $y = 5(1.2^x)$

☐ $y = 5(0.8^x)$

☐ $y = 0.8(5^x)$

:::


:::teacher-note

**Answer:** $y = 5(0.8^x)$

y = 5(0.8^x) multiplies by 0.8 each step, so it gets smaller: decay. The base, the number with the x in its power, decides.

## Read the rule

### Start

**Where does $y = 7(3^x)$ cross the $y$-axis? Give the value of $y$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 7

7. At x = 0, 3⁰ = 1 and y = 7 × 1 = 7.

:::


:::keep-together

### Growth or decay

**Is $y = 100(0.9^x)$ growth or decay?**

☐ Decay: 0.9 is less than 1

☐ Growth: 0.9 is positive

☐ Growth: 100 is a big number

:::


:::teacher-note

**Answer:** Decay: 0.9 is less than 1

The base 0.9 is between 0 and 1, so each step makes y smaller: decay.

:::


:::keep-together

### Never reaches

**The graph of $y = 6(0.5^x)$ gets closer and closer to a horizontal line but never reaches it. What is $y$ on that line?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 0

0. Halving 6, 3, 1.5, 0.75... gets closer and closer to 0 and never reaches it. The line y = 0 is the asymptote.

:::


:::keep-together

### Review

**Review: the table goes $7, 14, 28, 56$. What do you multiply by each time?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 2

14 ÷ 7 = 2 and 28 ÷ 14 = 2. Each value is 2 times the one before.
