> **Key question:** Leave a sandwich out and the germs on it multiply. Why does the food rule change at 2 hours, and bin it at 4?


:::teacher-note

**In one sentence:** Students compare a table that adds with one that multiplies on a graph board, find the constant ratio, tell the two kinds of table apart, and use the doubling model to see why the last hours of a food-safety rule matter most (AC9M10A03, node 1).

## Ratio, not difference


:::keep-together

### Multiply by what?

Here's how to tell the two kinds of table apart.

1. $2,\; 6,\; 18,\; 54$ — Is this table linear or exponential?
2. $6 - 2 = 4,\; 18 - 6 = 12,\; 54 - 18 = 36$ — The differences are 4, 12, 36. They aren't the same, so it isn't linear.
3. $6 \div 2 = 3,\; 18 \div 6 = 3,\; 54 \div 18 = 3$ — Divide each value by the one before. Every time, it's 3.
4. $\text{ratio} = 3$ — A constant ratio means exponential: each value is 3 times the one before.
5. $54 \times 3 = 162$ — So the next value is 162.

Now try one on paper like the example: $5, 15, 45, 135$. Find the ratio, then type it.

**A table goes $5, 15, 45, 135$. What do you multiply by to get from each value to the next?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 3

15 ÷ 5 = 3, 45 ÷ 15 = 3 and 135 ÷ 45 = 3. Each value is 3 times the one before.

:::


:::keep-together

### Find the mistake

**Priya tests the table $3, 6, 12, 24$. Click the line where her working goes wrong.**

```
 1  Is the table 3, 6, 12, 24 exponential?
 2  Exponential means it goes up by the same amount each step, so I'll check the differences.
 3  6 − 3 = 3, 12 − 6 = 6, 24 − 12 = 12. The differences aren't the same.
 4  So the table isn't exponential.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: exponential doesn't mean 'goes up by the same amount'. That's a linear table. Exponential means multiplying by the same number: 6 ÷ 3 = 2, 12 ÷ 6 = 2 and 24 ÷ 12 = 2, so this table is exponential.

:::


:::keep-together

**Answer:** 486

**The table goes $80, 40, 20, 10$. What do you multiply by each time?**

40 ÷ 80 = 0.5, and 20 ÷ 40 = 0.5. Each value is half the one before.

## Make: back to the sandwich


**4 hours against 2.** Back to the picnic. Work this out on paper first, then type your answer.

**Twice as risky?.** The rule's numbers come from food scientists, and the model here is made up. But the shape is the point: with multiplying, the last hours add far more than the first.

Sources: the 2-hour/4-hour rule is from [NSW Food Authority](https://www.foodauthority.nsw.gov.au/sites/default/files/2021-07/2_hour_4_hour_rule.pdf). The 100 germs and the doubling every half hour are made up for this lesson.

**Also used in**

- **Money.** Savings that earn the same percentage each year multiply, so the last years add the most.
- **Sharing.** A post that everyone who sees it sends to 3 friends: each round multiplies.
- **Next lessons.** The graph of a multiplying table, then its rule, then solving for when it reaches a number.
