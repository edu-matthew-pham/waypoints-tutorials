## Today

- I can state a conjecture as a claim that could be wrong.
- I can test it by changing one number at a time, including a case that might break it.
- I can say whether the cases support it or reject it, and fix it if it fails.

<!-- Speaker note: Before class: Do the Run board yourself first. The graph draws the height of a ball dropped from a 20 m cliff, h = 20 − at², and marks where it meets the ground. The dashed line is the ground. The slider is a, how strong gravity is on a made-up planet. The one idea: a conjecture is a claim about every case in a family ("if a is bigger, the ball lands sooner"), not a note about one graph. Cases that agree support it and can never prove it. One case that disagrees rejects it, and the useful next move is to refine the claim and test it again. Students have used a board to vary a and b in a line, and a, h and k in a curve (Year 9). Here the new move is writing the claim down first and then choosing tests, rather than playing with the slider. The conjecture holds for a above 0 and has no landing time at a = 0 (the ball hangs at 20 m) or below (it climbs). The worked example uses y = ax² for a conjecture that fails: with negative a, a bigger a gives a wider curve. Everything is made up: the cliff, the planets and the values of a. A class option: on Earth, a is a little under 5, so a = 5 is close to a real drop from 20 m (about 2 s). Let students look the number up for themselves if they ask; the lesson does not depend on it. Teacher: Paper: the try-one after the worked example and the Make question are worked on paper first. -->

## What counts as a conjecture

**Which of these is a conjecture about the ball's rule, a claim a new case could prove wrong?**

- If $a$ is bigger, then the ball lands sooner
- The cliff is 20 m high
- The graph is a curve
- When $a = 2$, the ball lands at about 3.2 s

* Answer: If $a$ is bigger, then the ball lands sooner

## Test one on paper

Here's how to test a conjecture on a different family, $y = ax^2$.

Now try one on paper. The claim is: "In $y = x^2 + c$, if $c$ is bigger, the curve crosses the $x$-axis in more places." For $c = -4$ the curve crosses at $x = 2$ and $x = -2$, so two places. Test $c = 4$. How many places does it cross?

$$\text{Conjecture: if } a \text{ is bigger, the curve is narrower.}$$

1) $a = 1,\; 2,\; 3$ — Try some positive values. At x = 1 the heights are 1, 2 and 3, and the curve is steeper each time.
2) $\text{Positive cases agree}$ — These support the conjecture. They are not enough, so choose a case that might break it.
3) $a = -1 \text{ and } a = -3$ — Try negatives. Here -1 is bigger than -3.
4) $y = -1 \text{ and } y = -3 \text{ at } x = 1$ — The a = -3 curve is lower at x = 1, so it is the narrower one.
5) $\text{A bigger } a \text{ gave the wider curve}$ — One case that disagrees rejects the conjecture as it is written.
6) $\text{If } a \text{ is further from } 0 \text{, the curve is narrower.}$ — Refine it, then test it on new values.

## Test one on paper

**The claim: 'In $y = x^2 + c$, if $c$ is bigger, the curve crosses the $x$-axis in more places.' For $c = -4$ it crosses in 2 places. Test $c = 4$. In how many places does $y = x^2 + 4$ cross the $x$-axis?**

* Answer: $x^2 + 4 = 0$ (the curve crosses the axis where y is 0); $x^2 = -4$ (subtract 4 from both sides); no number squared is negative, so there are 0 places (the curve stays above the axis); 0 is fewer than 2, so the claim is rejected (a bigger c gave fewer places)

<!-- Speaker note: x² + 4 = 0 has no solution, because x² is never negative. The curve crosses in 0 places, fewer than the 2 at c = -4, so the claim is rejected. -->
