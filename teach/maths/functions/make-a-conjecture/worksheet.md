# Make a conjecture

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Three planets, one 20 m cliff, one ball dropped on each. The rule for the ball's height has one number that changes from planet to planet. How would you find out what that number does?


:::teacher-note

**In one sentence:** Students vary one number in a rule on a graphing board, state a conjecture as an if-then claim, test it on cases chosen to break it, and refine it when one case disagrees (AC9M10A05, node 1).

**Students should be able to say:** I can state a conjecture as a claim that could be wrong. I can test it by changing one number at a time, including a case that might break it. I can say whether the cases support it or reject it, and fix it if it fails.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## What makes a conjecture


:::keep-together

### What counts as a conjecture

**Which of these is a conjecture about the ball's rule, a claim a new case could prove wrong?**

☐ If $a$ is bigger, then the ball lands sooner

☐ The cliff is 20 m high

☐ The graph is a curve

☐ When $a = 2$, the ball lands at about 3.2 s

:::


:::teacher-note

**Answer:** If $a$ is bigger, then the ball lands sooner

A conjecture says what happens for every $a$ in the family, so a value you haven't tried yet could show it wrong. 'If $a$ is bigger, then the ball lands sooner' does that.

:::


:::keep-together

### Find the mistake

**Ivy tests her conjecture. Click the line where her reasoning goes wrong.**

```
 1  Conjecture: if a is bigger, the ball lands sooner.
 2  Tests: a = 1 lands at about 4.5 s. a = 2 lands at about 3.2 s.
 3  The landing time went down both times, so the conjecture is proved.
 4  So it is true for every value of a.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: two tests that agree support the conjecture, but they don't prove it. A third value, one she hasn't tried, could still disagree.

:::


:::keep-together

### Supported or proved

**Zara tests $a = 1, 2, 4$ and $5$. The ball lands sooner every time. What can she say?**

☐ The conjecture is proved, because four cases is plenty

☐ The conjecture is supported, but one case that disagrees would still reject it

☐ The conjecture is rejected, since she hasn't tried every value

☐ Nothing, because four cases is too few to say anything

:::


:::teacher-note

**Answer:** The conjecture is supported, but one case that disagrees would still reject it

Cases that agree make the conjecture more believable. Only a case that disagrees can reject it, and only a reason that covers every case can prove it.

:::


:::keep-together

### Test one on paper

Here's how to test a conjecture on a different family, $y = ax^2$.

1. $\text{Conjecture: if } a \text{ is bigger, the curve is narrower.}$ — Write the claim as an if-then about the whole family, so a new value of a could show it wrong.
2. $a = 1,\; 2,\; 3$ — Try some positive values. At x = 1 the heights are 1, 2 and 3, and the curve is steeper each time.
3. $\text{Positive cases agree}$ — These support the conjecture. They are not enough, so choose a case that might break it.
4. $a = -1 \text{ and } a = -3$ — Try negatives. Here -1 is bigger than -3.
5. $y = -1 \text{ and } y = -3 \text{ at } x = 1$ — The a = -3 curve is lower at x = 1, so it is the narrower one.
6. $\text{A bigger } a \text{ gave the wider curve}$ — One case that disagrees rejects the conjecture as it is written.
7. $\text{If } a \text{ is further from } 0 \text{, the curve is narrower.}$ — Refine it, then test it on new values.

Now try one on paper. The claim is: "In $y = x^2 + c$, if $c$ is bigger, the curve crosses the $x$-axis in more places." For $c = -4$ the curve crosses at $x = 2$ and $x = -2$, so two places. Test $c = 4$. How many places does it cross?

**The claim: 'In $y = x^2 + c$, if $c$ is bigger, the curve crosses the $x$-axis in more places.' For $c = -4$ it crosses in 2 places. Test $c = 4$. In how many places does $y = x^2 + 4$ cross the $x$-axis?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** $x^2 + 4 = 0$ (the curve crosses the axis where y is 0); $x^2 = -4$ (subtract 4 from both sides); no number squared is negative, so there are 0 places (the curve stays above the axis); 0 is fewer than 2, so the claim is rejected (a bigger c gave fewer places)

x² + 4 = 0 has no solution, because x² is never negative. The curve crosses in 0 places, fewer than the 2 at c = -4, so the claim is rejected.

:::

## Conjectures


:::keep-together

### Testable or not

**Which of these is a conjecture you could test on $y = ax^2$?**

☐ If $a$ is positive, then the curve opens upward

☐ When $a = 2$, $y = 8$ at $x = 2$

☐ The curve $y = 3x^2$ passes through $(1, 3)$

☐ Graphs of curves are interesting

:::


:::teacher-note

**Answer:** If $a$ is positive, then the curve opens upward

It says what happens for every positive $a$, so a new value could show it wrong.

:::


:::keep-together

### A test with numbers

**A student's conjecture: 'In $y = ax^2$, doubling $a$ doubles $y$ at $x = 3$.' Test it. For $a = 2$, $y = 18$ at $x = 3$. What is $y$ at $x = 3$ for $a = 4$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 36

4 × 3² = 4 × 9 = 36, which is twice 18. This case agrees, so the conjecture is supported.

:::


:::keep-together

### The case that breaks it

**Which pair of values rejects the claim 'if $a$ is bigger, the curve $y = ax^2$ is narrower'?**

☐ $a = 0.5$ and $a = 1$

☐ $a = 2$ and $a = 5$

☐ $a = 1$ and $a = 2$

☐ $a = -1$ and $a = -3$

:::


:::teacher-note

**Answer:** $a = -1$ and $a = -3$

-1 is bigger than -3, but the a = -3 curve is the narrower one. One case that disagrees rejects the claim.

:::


:::keep-together

### Review

**Review: solve $x^2 + 4x = 0$. What is the negative solution?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** -4

x(x + 4) = 0, so x = 0 or x = -4.

:::
