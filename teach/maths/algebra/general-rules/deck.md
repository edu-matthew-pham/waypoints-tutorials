# An expression for any case

Algebra Foundations · Expressions

<!-- Speaker note: Students say what a letter stands for, write an expression for a situation with a fee and a rate, test it with a case they can check, and use it for any number (AC9M7A02, node 3). About 45 minutes (Predict and Run 8 min · Investigate 15 min · Modify 12 min · Practise and Make 10 min). -->

---

## Today

**We are learning to** say what the letter stands for, write an expression for the situation, then test it with a number you can check. One expression then gives the answer for every case.

- I can say what the letter in an expression stands for, a number that changes.
- I can write an expression for a situation with a once-only amount and an amount for each one.
- I can test my expression with a case I can check in words, then use it for a big case.

<!-- Speaker note: Before class: Do the Modify boards yourself first. The mystery boards follow the situation, so students check their expression against them before they answer. The new move is saying what the letter stands for before writing anything. Two common errors: letting the letter be the thing worked out ("Let n be the cost"), and reading the letter as the object (Pia's mistake: 3a means 3 apples). Insist on the sentence "Let ___ be the number of ___". The once-only amount is a constant added on; the amount for each one is multiplied by the letter. This is the same structure as y = mx + c in Linear relations, so say so, but do not name it yet. -->

---

## Why it matters

> A party for 5 people, 50 people or 500: one expression gives the cost for all of them, if you say clearly what the letter stands for.

<!-- Speaker note: So far each expression was written from one sentence about a number. A real situation has parts: a fee, a price for each one, a number of people. To write one expression for all of it, first say **what the letter stands for**, then build the expression, then **test** it with a case you can check in words. After that one expression gives the answer for any number. -->

## A hall

Here is how to build an expression for a situation.

$$\text{Hall: 60 dollars, plus 5 dollars per guest}$$

1) $\text{Let } g = \text{number of guests}$ — Say what the letter stands for. The number of guests changes, so $g$ stands for that.
2) $5g$ — Each guest costs 5 dollars, so $g$ guests cost $5 \times g$.
3) $5g + 60$ — Add the hire, which is paid once.
4) $g = 10: \; 5(10) + 60 = 110$ — Test with a case you can check in words: 10 guests cost 50 + 60 = 110 dollars.
5) $g = 40: \; 5(40) + 60 = 260$ — Now the same expression gives any case, with no counting.

**Zoe starts with "Let $n$ be the cost" for tickets that cost 9 dollars each. Why is that not a good start?**

- 9 should be the letter
- The cost changes with the number of tickets, so the letter should stand for the number of tickets
- A letter can never stand for a cost

* Answer: The cost changes with the number of tickets, so the letter should stand for the number of tickets

## Exit ticket

**A gym costs 30 dollars to join plus 15 dollars a week. Write what your letter stands for, an expression for the total, and the cost after 8 weeks.**

* Let w be the number of weeks. Total = 15w + 30. After 8 weeks: 15 × 8 + 30 = 150 dollars.
