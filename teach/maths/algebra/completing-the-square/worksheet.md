# Completing the square

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A ball is thrown, and a formula gives its height. How high does it get, and when, without a table or a graph?


:::teacher-note

**In one sentence:** Students fill the corner of an x² and x-tile square, take away the ones they did not have, and read the lowest (or highest) point from the result: x² + 6x + 5 = (x + 3)² − 4, then the ball's highest point (AC9M10A01, node 4).

**Students should be able to say:** I can write x² + bx + c as (x + b/2)² + k by filling the corner and taking away what I did not have. I can read the lowest point of y = x² + bx + c from the completed square. I can use it to find the highest point of a ball's path.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## The bracket and the number


:::keep-together

### Fill the corner

Here's one worked out, piece by piece.

1. $x^2 + 6x + 5$ — One x², 6 x-tiles and 5 ones.
2. $6 \div 2 = 3$ — Half the x-tiles go down each side: 3 and 3.
3. $3 \times 3 = 9$ — The corner is 3 by 3, so it needs 9 ones.
4. $x^2 + 6x + 9 = (x + 3)^2$ — With 9 ones it is a perfect square.
5. $5 - 9 = -4$ — We only have 5, so 4 are missing: take 4 away.
6. $x^2 + 6x + 5 = (x + 3)^2 - 4$ — The completed square.

Now try one on paper, piece by piece like the example: $x^2 + 10x + 7$. Then type $k$.

**Write $x^2 + 10x + 7$ as $(x + 5)^2 + k$. What is $k$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** -18

Half of 10 is 5, and the corner needs 5 × 5 = 25. You have 7, so k = 7 − 25 = −18: x² + 10x + 7 = (x + 5)² − 18.

:::


:::keep-together

### Find the mistake

**Rin writes $x^2 + 8x + 3$ in the form $(x + 4)^2 + k$. Click the line where her working goes wrong.**

```
 1  Write x² + 8x + 3 as (x + 4)² + k.
 2  Half of 8 is 4, so the bracket is (x + 4)².
 3  So x² + 8x + 3 = (x + 4)² + 3.
 4  Check with x = 0: the left side is 3, the right side is 16 + 3 = 19.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: Rin copied the 3 after the bracket. But (x + 4)² already has a corner of 16, so she needs 3 − 16 = −13. Her check on line 4 is the clue: 3 and 19 don't match.

:::


:::keep-together

### The lowest point

**What is the lowest value of $(x + 3)^2 - 4$, and when does it happen?**

☐ −4, when $x = -3$

☐ 0, when $x = -3$

☐ 4, when $x = -3$

☐ −4, when $x = 3$

:::


:::teacher-note

**Answer:** −4, when $x = -3$

A number squared is never below 0, and it is 0 when x + 3 = 0, which is x = −3. There the whole thing is 0 − 4 = −4. So the lowest point of y = (x + 3)² − 4 is (−3, −4).

## Complete and read


:::keep-together

### A plus

**$x^2 + 12x + 20 = (x + 6)^2 + k$. What is $k$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** -16

Half of 12 is 6, and the corner needs 36. 20 − 36 = −16.

:::


:::keep-together

### A minus

**$x^2 - 10x + 3 = (x - 5)^2 + k$. What is $k$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** -22

Half of −10 is −5, the corner is 25, and 3 − 25 = −22.

:::


:::keep-together

### Write the form

**Which is $x^2 + 4x - 1$ with the square completed?**

☐ $(x + 4)^2 - 17$

☐ $(x + 2)^2 + 3$

☐ $(x + 2)^2 - 1$

☐ $(x + 2)^2 - 5$

:::


:::teacher-note

**Answer:** $(x + 2)^2 - 5$

Half of 4 is 2, the corner is 4, and −1 − 4 = −5.

:::


:::keep-together

### Read the point

**What is the lowest point of $y = x^2 + 8x + 19$?**

☐ $(4, 3)$

☐ $(-4, -3)$

☐ $(-4, 3)$

☐ $(-4, 19)$

:::


:::teacher-note

**Answer:** $(-4, 3)$

x² + 8x + 19 = (x + 4)² + 3. The square is zero at x = −4, so the lowest point is (−4, 3).

:::


:::keep-together

### Review

**Review: expand and simplify $(x - 4)^2 + 6$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** x^2 - 8x + 22

(x − 4)² = x² − 8x + 16. Add 6: x² − 8x + 22. This is completing the square run backwards.
