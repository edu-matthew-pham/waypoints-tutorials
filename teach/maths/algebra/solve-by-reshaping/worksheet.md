# Solving by reshaping

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A framer says a frame will double the area of your photo. How wide does the border have to be?


:::teacher-note

**In one sentence:** Students set up (30 + 2x)(20 + 2x) = 1200 for a framed photo, expand it, move everything to one side, factorise, throw out the negative width and check; the same reshaping solves equations with the unknown in a power (AC9M10A01, node 5).

**Students should be able to say:** I can set up a quadratic equation from a picture, reshape it so one side is 0, and factorise to solve it. I can put my answers back into the picture and throw out the one that doesn't fit. I can solve an equation with the unknown in a power by writing both sides with the same base.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Reshape, factorise, reject


:::keep-together

### Reshape and solve

Here's the frame from the start, worked out step by step.

1. $(30 + 2x)(20 + 2x) = 1200$ — The framed picture is 30 + 2x by 20 + 2x: the border goes on both ends of each side.
2. $4x^2 + 100x + 600 = 1200$ — Expand: 600 + 60x + 40x + 4x².
3. $4x^2 + 100x - 600 = 0$ — Move 1200 across, so one side is 0.
4. $x^2 + 25x - 150 = 0$ — Divide by 4.
5. $(x + 30)(x - 5) = 0$ — Two numbers that multiply to −150 and add to 25: 30 and −5.
6. $x = -30 \text{ or } x = 5$ — One bracket has to be 0.
7. $x = 5$ — A border can't be −30 cm wide.
8. $40 \times 30 = 1200$ — Check by putting x = 5 back in.

Now try one on paper, step by step like the example: a 20 cm by 10 cm photo with a framed area of 336 cm². Then type the border width.

**A 20 cm by 10 cm photo has a frame of width $x$ and a framed area of 336 cm². Solve $(20 + 2x)(10 + 2x) = 336$ and type the border width in cm.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 2

Expand: 4x² + 60x + 200 = 336, so 4x² + 60x − 136 = 0 and x² + 15x − 34 = 0. (x + 17)(x − 2) = 0, so x = −17 or x = 2. A border can't be negative: 2 cm. Check: 24 × 14 = 336.

:::


:::keep-together

### Find the mistake

**Taz solves $(x + 5)(x - 3) = 20$. Click the line where his working goes wrong.**

```
 1  Solve (x + 5)(x − 3) = 20.
 2  (x + 5)(x − 3) = 20 means x + 5 = 20 or x − 3 = 20.
 3  So x = 15 or x = 23.
 4  Check x = 15: (20)(12) = 240, which is not 20.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: a bracket can only be set equal to 0 when the product is 0. (x + 5)(x − 3) = 20 can be made by many pairs. Move 20 across first: x² + 2x − 35 = 0, which is (x + 7)(x − 5) = 0. His check on line 4 is the clue.

:::


:::keep-together

### Which answer fits?

**$x = -30$ solves $(30 + 2x)(20 + 2x) = 1200$. Why isn't it the border?**

☐ Only the first answer counts

☐ Negative answers are always thrown out

☐ A border can't be −30 cm wide

☐ −30 doesn't make the equation true

:::


:::teacher-note

**Answer:** A border can't be −30 cm wide

−30 satisfies the equation, but x is a width. Always put your answers back into the picture and ask if they make sense.

## Set up, solve, check


:::keep-together

### Reshape

**Solve $x^2 + 2x = 24$. Give the positive solution.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 4

x² + 2x − 24 = 0, so (x + 6)(x − 4) = 0: x = −6 or x = 4. The positive one is 4.

:::


:::keep-together

### A power

**Solve $2^x = 64$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 6

64 = 2⁶, so x = 6.

:::


:::keep-together

### Another power

**Solve $5^{x - 1} = 25$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 3

25 = 5², so x − 1 = 2 and x = 3. Check: 5² = 25.

:::


:::keep-together

### A word problem

**A garden is 4 m longer than it is wide, and its area is 60 m². How wide is it, in m?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 6

w(w + 4) = 60, so w² + 4w − 60 = 0 and (w + 10)(w − 6) = 0. w = 6. The garden is 6 m by 10 m.

:::


:::keep-together

### Review

**Review: $x^2 + 6x + 1 = (x + 3)^2 + k$. What is $k$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** -8

Half of 6 is 3, the corner needs 9, and 1 − 9 = −8.

:::keep-together

**A rectangle's length is 2 m more than its width, and its area is 15 m². Find the width.**

{{lines-3}}

:::


:::teacher-note

**Answer:** 3 m: w(w + 2) = 15, so (w + 5)(w − 3) = 0 and w = 3 (w = −5 is thrown out).
