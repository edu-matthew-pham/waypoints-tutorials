# Solving by reshaping

Algebra Foundations · Year 10: solving

<!-- Speaker note: Students set up (30 + 2x)(20 + 2x) = 1200 for a framed photo, expand it, move everything to one side, factorise, throw out the negative width and check; the same reshaping solves equations with the unknown in a power (AC9M10A01, node 5). ## Today

- I can set up a quadratic equation from a picture, reshape it so one side is 0, and factorise to solve it.
- I can put my answers back into the picture and throw out the one that doesn't fit.
- I can solve an equation with the unknown in a power by writing both sides with the same base.

## Reshape and solve

Here's the frame from the start, worked out step by step.

Now try one on paper, step by step like the example: a 20 cm by 10 cm photo with a framed area of 336 cm². Then type the border width.

$$(30 + 2x)(20 + 2x) = 1200$$

1) $4x^2 + 100x + 600 = 1200$ — Expand: 600 + 60x + 40x + 4x².
2) $4x^2 + 100x - 600 = 0$ — Move 1200 across, so one side is 0.
3) $x^2 + 25x - 150 = 0$ — Divide by 4.
4) $(x + 30)(x - 5) = 0$ — Two numbers that multiply to −150 and add to 25: 30 and −5.
5) $x = -30 \text{ or } x = 5$ — One bracket has to be 0.
6) $x = 5$ — A border can't be −30 cm wide.
7) $40 \times 30 = 1200$ — Check by putting x = 5 back in.

## Find the mistake

**Taz solves $(x + 5)(x - 3) = 20$. Click the line where his working goes wrong.**

```
 1  Solve (x + 5)(x − 3) = 20.
 2  (x + 5)(x − 3) = 20 means x + 5 = 20 or x − 3 = 20.
 3  So x = 15 or x = 23.
 4  Check x = 15: (20)(12) = 240, which is not 20.
```

* Answer: line 2

<!-- Speaker note: Line 2: a bracket can only be set equal to 0 when the product is 0. (x + 5)(x − 3) = 20 can be made by many pairs. Move 20 across first: x² + 2x − 35 = 0, which is (x + 7)(x − 5) = 0. His check on line 4 is the clue. -->

## Which answer fits?

**$x = -30$ solves $(30 + 2x)(20 + 2x) = 1200$. Why isn't it the border?**

- Only the first answer counts
- Negative answers are always thrown out
- A border can't be −30 cm wide
- −30 doesn't make the equation true

* Answer: A border can't be −30 cm wide

## Exit ticket

**A rectangle's length is 2 m more than its width, and its area is 15 m². Find the width.**

* 3 m: w(w + 2) = 15, so (w + 5)(w − 3) = 0 and w = 3 (w = −5 is thrown out).
