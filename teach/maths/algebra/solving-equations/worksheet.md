## Same to both sides


:::keep-together

### Solve, then check

Here is how to solve with $x$ on both sides.

1. $3x + 7 = 5x - 9$ — $x$ is on both sides.
2. $7 = 2x - 9$ — Take $3x$ from both sides (the smaller $x$ term, so $2x$ stays positive).
3. $16 = 2x$ — Add 9 to both sides: this undoes $- 9$.
4. $x = 8$ — Divide both sides by 2.
5. $3(8) + 7 = 31,\; 5(8) - 9 = 31$ — Check in the first equation: both sides are 31.

Now solve it yourself, one step per line. The checker marks the first line that does not follow.

**Solve $3x + 7 = 5x - 9$. Write one step per line.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 3x + 7 = 5x - 9 → 7 = 2x - 9 → 16 = 2x → x = 8

Take 3x from both sides: 7 = 2x − 9. Add 9: 16 = 2x. Halve: x = 8.

:::


:::keep-together

## Solve and check


:::keep-together

### x on both sides

**Solve $5x - 4 = 2x + 11$. One step per line.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 5x - 4 = 2x + 11 → 3x - 4 = 11 → 3x = 15 → x = 5

Take 2x: 3x − 4 = 11. Add 4: 3x = 15. x = 5. Check: 21 = 21.

:::


:::keep-together

### Negative x

**Solve $6 - x = 2x - 9$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 5

Add x: 6 = 3x − 9. Add 9: 15 = 3x. x = 5. Check: 1 = 1.

:::


:::keep-together

### Angles

**Angles on a straight line are $3x$ and $x + 20$ degrees. Find $x$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 40

3x + x + 20 = 180, so 4x = 160 and x = 40. The angles are 120° and 60°.

:::
