## Add and multiply

Here's the pattern, worked out.

Now try one on paper: $(x + 3)(x + 8)$. Then type your answer.

$$(x + 5)(x + 2)$$

1) $5 + 2 = 7$ — The middle: the two strips together.
2) $5 \times 2 = 10$ — The end: the corner.
3) $x^2 + 7x + 10$ — Put it together.

## Find the mistake

**Sam uses the pattern on $(x + 3)(x + 5)$. Click the line where his working goes wrong.**

```
 1  Expand (x + 3)(x + 5).
 2  The two numbers are 3 and 5.
 3  The middle number is 3 times 5, which is 15.
 4  The last number is 3 plus 5, which is 8.
 5  So (x + 3)(x + 5) = x² + 15x + 8.
```

* Answer: line 3

<!-- Speaker note: Line 3: the middle number is the sum, 3 + 5 = 8, and the last is the product, 3 × 5 = 15: x² + 8x + 15. -->
