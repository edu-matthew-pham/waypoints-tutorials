# Finding an unknown

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** You know how much fence you have and how long the garden bed must be. How wide can it be?


:::teacher-note

**In one sentence:** Students substitute the known values into a formula, solve the equation that is left for the unknown, and check by substituting back (AC9M7A01, node 3).

**Students should be able to say:** I can substitute the values I know into a formula to make an equation. I can solve the equation by undoing each operation, last first. I can check my answer by substituting it back into the formula.

## Substitute, then solve


:::keep-together

### Area

Here is how to find an unknown in a formula.

1. $P = 2l + 2w$ — Write the formula.
2. $P = 20, \; l = 6$ — Write what you know. The unknown is $w$.
3. $20 = 2 \times 6 + 2w$ — Substitute. Now it is an equation with one unknown.
4. $20 = 12 + 2w$ — Work out what you can.
5. $8 = 2w$ — Undo the + 12: take 12 from both sides.
6. $w = 4$ — Undo the × 2: divide both sides by 2.
7. $2 \times 6 + 2 \times 4 = 20 \;\checkmark$ — Check by substituting back into the formula.

**A rectangle has area $A = 24$ cm² and length $l = 6$ cm. Using $A = lw$, find its width $w$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 4

24 = 6w, so w = 24 ÷ 6 = 4. Check: 6 × 4 = 24.

:::


:::keep-together

### A plumber

**A plumber charges $C = 5h + 20$ dollars. A job cost 45 dollars. How many hours, $h$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 5

45 = 5h + 20, so 5h = 25 and h = 5. Check: 5 × 5 + 20 = 45.

:::

## Find the unknown


:::keep-together

### Tickets

**Concert tickets cost $T = 12n + 6$ dollars. An order cost 66 dollars. How many tickets?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 5

66 = 12n + 6, so 12n = 60 and n = 5.

:::


:::keep-together

### Substitute or solve?

**Using $T = 12n + 6$, what do 3 tickets cost?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 42

T = 12 × 3 + 6 = 42 dollars. Here you know n, so you just substitute.

:::


:::keep-together

### A bike ride

**Average speed is $s = d / t$. A cyclist rides at 20 km/h for $t = 3$ hours. How far, $d$, in km?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 60

20 = d ÷ 3, so d = 20 × 3 = 60 km.

:::
