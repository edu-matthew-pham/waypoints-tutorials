# Expand or factorise?

Algebra Foundations · Two brackets

<!-- Speaker note: Students see expanding and factorising as undoing each other, match a curve y = (x − p)(x − q) to an expanded one on a graph, and use each form for what it shows: meeting points or start value (AC9M9A02, node 4). ## Today

- I can expand and factorise to move between the two forms.
- I can read where a curve meets the x-axis from the factorised form.
- I can find where it starts from the expanded form.

## What happened?

* (x − 1)(x − 5). The curve meets the ground line where h = 0. A product is zero when one bracket is zero: x = 1 or x = 5. The expanded form shows h = 5 at x = 0 instead.

## Undo it

Here's moving from expanded to factorised, and what each form shows.

Now try one on paper: $x^2 - 8x + 12$. Where does the curve meet the axis, and where does it start? Then type the smaller meeting point.

$$x^2 - 6x + 5$$

1) $-1 \times -5 = 5, \; -1 + -5 = -6$ — Two numbers: multiply to 5, add to −6.
2) $(x - 1)(x - 5)$ — Factorised.
3) $x - 1 = 0 \text{ or } x - 5 = 0$ — A product is zero when a bracket is zero.
4) $x = 1 \text{ or } x = 5$ — Where the curve meets the axis.
5) $\text{start: } 0^2 - 6 \times 0 + 5 = 5$ — From the expanded form: where it meets the y-axis.

## Find the mistake

**Leo factorises $x^2 + x - 6$ and checks by expanding. Click the line where his working goes wrong.**

```
 1  Factorise x² + x − 6.
 2  Two numbers that multiply to −6: 2 and −3.
 3  So x² + x − 6 = (x + 2)(x − 3).
 4  Check: (x + 2)(x − 3) = x² − 3x + 2x − 6 = x² − x − 6.
 5  That matches, so it's right.
```

* Answer: line 5

<!-- Speaker note: Line 5: the expansion gives x² − x − 6, not x² + x − 6. The middle terms differ, so it isn't a match. The numbers should add to +1: −2 and 3, so (x − 2)(x + 3). -->
