# Expand or factorise?

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** The same curve, written two ways. Each way answers a different question.


:::teacher-note

**In one sentence:** Students see expanding and factorising as undoing each other, match a curve y = (x − p)(x − q) to an expanded one on a graph, and use each form for what it shows: meeting points or start value (AC9M9A02, node 4).

**Students should be able to say:** I can expand and factorise to move between the two forms. I can read where a curve meets the x-axis from the factorised form. I can find where it starts from the expanded form.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Two forms, two questions


:::keep-together

### Undo it

Here's moving from expanded to factorised, and what each form shows.

1. $x^2 - 6x + 5$ — Start: expanded.
2. $-1 \times -5 = 5, \; -1 + -5 = -6$ — Two numbers: multiply to 5, add to −6.
3. $(x - 1)(x - 5)$ — Factorised.
4. $x - 1 = 0 \text{ or } x - 5 = 0$ — A product is zero when a bracket is zero.
5. $x = 1 \text{ or } x = 5$ — Where the curve meets the axis.
6. $\text{start: } 0^2 - 6 \times 0 + 5 = 5$ — From the expanded form: where it meets the y-axis.

Now try one on paper: $x^2 - 8x + 12$. Where does the curve meet the axis, and where does it start? Then type the smaller meeting point.

**Factorise $x^2 - 7x + 10$. Type $x^2$ as x^2.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** (x - 2)(x - 5)

−2 and −5 multiply to 10 and add to −7.

:::


:::keep-together

### Find the mistake

**Leo factorises $x^2 + x - 6$ and checks by expanding. Click the line where his working goes wrong.**

```
 1  Factorise x² + x − 6.
 2  Two numbers that multiply to −6: 2 and −3.
 3  So x² + x − 6 = (x + 2)(x − 3).
 4  Check: (x + 2)(x − 3) = x² − 3x + 2x − 6 = x² − x − 6.
 5  That matches, so it's right.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 5

Line 5: the expansion gives x² − x − 6, not x² + x − 6. The middle terms differ, so it isn't a match. The numbers should add to +1: −2 and 3, so (x − 2)(x + 3).

:::


:::keep-together

x − 2 = 0 at x = 2 and x − 5 = 0 at x = 5.

## Move between the forms


:::keep-together

### Expand

**Expand $(x - 4)(x + 9)$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** x^2 + 5x - 36

−4 + 9 = 5 and −4 × 9 = −36.

:::


:::keep-together

### Factorise

**Factorise $x^2 + 4x - 21$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** (x - 3)(x + 7)

−3 and 7 multiply to −21 and add to 4.

:::


:::keep-together

### Choose a form

**You want to know where the curve $y = x^2 - 3x - 10$ meets the x-axis. What do you do first?**

☐ Expand it

☐ Factorise it to (x − 5)(x + 2)

☐ Put x = 0 into it

:::


:::teacher-note

**Answer:** Factorise it to (x − 5)(x + 2)

Factorised form shows where each bracket is zero: x = 5 and x = −2.

:::


:::keep-together

### Review

**Review: expand $(x - 6)(x - 6)$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** x^2 - 12x + 36

−6 + (−6) = −12 and (−6)(−6) = 36.
