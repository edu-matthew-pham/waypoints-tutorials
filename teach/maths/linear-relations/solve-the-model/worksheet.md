## Solve and choose


:::keep-together

### Solve it

1. $x^2 + x + 7 = 67$ — The stopping distance we aim for is 67 m.
2. $x^2 + x - 60 = 0$ — Take 67 from both sides.
3. $(x + 8)(x - 7) = 0$ — Two numbers that multiply to −60 and add to 1.
4. $x = -8 \text{ or } x = 7$ — Both solve the equation.
5. $x = 7$ — Keep the one that makes sense: 70 km/h.

**Rearrange $x^2 + x + 7 = 67$ to $x^2 + x - 60 = 0$ and factorise as $(x + 8)(x - 7) = 0$. What is the positive solution for $x$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 7

x + 8 = 0 gives x = −8. x − 7 = 0 gives x = 7.

:::


:::keep-together

### Keep one

**The solutions are $x = 7$ and $x = -8$. Which do you report as the speed?**

☐ −80 km/h: it's a solution

☐ Both, they are both answers

☐ 70 km/h: a speed can't be negative

☐ Neither

:::


:::teacher-note

**Answer:** 70 km/h: a speed can't be negative

x = 7 means 70 km/h. The negative solution solves the equation but not the problem.

:::


:::keep-together

## Solve and decide


:::keep-together

### Positive solution

**Solve $x^2 + x + 7 = 13$. What is the positive solution?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 2

x² + x − 6 = 0, so (x + 3)(x − 2) = 0. x = 2.

:::


:::keep-together

### Both fit

**A ball's height is $h = 20t - 5t^2$ metres. Solving $h = 15$ gives $t = 1$ and $t = 3$. How do you report this?**

☐ Only t = 3

☐ Both are real: the ball is at 15 m going up and coming down

☐ Only t = 1

☐ Neither

:::


:::teacher-note

**Answer:** Both are real: the ball is at 15 m going up and coming down

Here both answers fit the situation. The check is whether each makes sense, not always to throw one out.
