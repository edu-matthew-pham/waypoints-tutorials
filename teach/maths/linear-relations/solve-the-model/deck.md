- Two: and only one of them can be a real speed
- One: the speed is 50 km/h
- None

## Solve it

$$x^2 + x + 7 = 67$$

1) $x^2 + x - 60 = 0$ — Take 67 from both sides.
2) $(x + 8)(x - 7) = 0$ — Two numbers that multiply to −60 and add to 1.
3) $x = -8 \text{ or } x = 7$ — Both solve the equation.
4) $x = 7$ — Keep the one that makes sense: 70 km/h.

## Solve it

**Rearrange $x^2 + x + 7 = 67$ to $x^2 + x - 60 = 0$ and factorise as $(x + 8)(x - 7) = 0$. What is the positive solution for $x$?**

* Answer: 7

<!-- Speaker note: x + 8 = 0 gives x = −8. x − 7 = 0 gives x = 7. -->

## Keep one

**The solutions are $x = 7$ and $x = -8$. Which do you report as the speed?**

- −80 km/h: it's a solution
- Both, they are both answers
- 70 km/h: a speed can't be negative
- Neither

* Answer: 70 km/h: a speed can't be negative

<!-- Speaker note: x = 7 means 70 km/h. The negative solution solves the equation but not the problem. -->

## Find the mistake

**Sam solves the model for a stopping distance of 37 m. Click the line where his working goes wrong.**

```
 1  Solve x² + x + 7 = 37 for the speed x (tens of km/h).
 2  x² + x - 30 = 0, so (x + 6)(x - 5) = 0.
 3  x = -6 or x = 5.
 4  The speeds are 5 and -6, so 50 km/h and -60 km/h.
```

* Answer: line 4

<!-- Speaker note: Line 4: he reports both solutions. A speed of −60 km/h can't happen, so the answer is only 50 km/h. -->

## Both fit
