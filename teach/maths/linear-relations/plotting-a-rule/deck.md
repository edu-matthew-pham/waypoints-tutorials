# Plotting a rule

Linear relations · Rules, tables and graphs

<!-- Speaker note: Students plot ordered pairs from a rule's table, across then up, see that rules adding the same amount each step give straight lines, and describe the line (AC9M7A05, node 3). ## Today

**We are learning to** plot each ordered pair from a rule's table as a point, across first and then up. For a rule like y = 2x + 1, the points lie on a straight line.

- I can plot ordered pairs from a table, across first and then up.
- I can describe a straight-line graph by which way it goes and how much for each step.
- I can tell from a table whether its points will lie on a straight line.

<!-- Speaker note: Before class: Do the Run and Modify boards yourself first. Points start in a row at the bottom of the board and snap to the grid; students drag each to its pair. Students should be able to plot points in all four quadrants (Year 6). ## Why it matters

> A table of numbers hides its pattern; a graph shows it at a glance. Plotting the pairs turns a rule into a picture you can read.

<!-- Speaker note: In the last lesson you made tables of ordered pairs from rules. Now you **plot** them. To plot the point $(x, y)$, start at $(0, 0)$, go **across** $x$, then **up** $y$. Then look at the shape the points make. -->

## Plotting a rule

Here is how to plot a rule and describe its graph.

$$y = 2x + 1: \; (0, 1), (1, 3), (2, 5), (3, 7)$$

1) $(0, 1): \text{ across } 0, \text{ up } 1$ — Plot each pair from $(0, 0)$: across first, then up.
2) $(1, 3), (2, 5), (3, 7)$ — Plot the rest the same way.
3) $\text{up } 2 \text{ for each step right}$ — Each step of 1 across, $y$ goes up 2: the same step every time.
4) $\text{a straight line}$ — So the points lie on a straight line. Join them with a ruler.
5) $\text{going up, starting at } 1$ — Describe it: it goes up 2 for each step right and crosses the $y$-axis at 1.

## Describing a graph

**The table for $y = 10 - x$ is $(0, 10)$, $(1, 9)$, $(2, 8)$, $(3, 7)$. Which describes its graph?**

- A curve going down
- A straight line going up 1 for each step right
- A straight line going down 1 for each step right

* Answer: A straight line going down 1 for each step right

<!-- Speaker note: y goes down by 1 each time x goes up by 1: the same step each time, so a straight line, going down. -->
