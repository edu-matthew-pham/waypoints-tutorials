Linear relations · Rules, tables and graphs

## Today

**We are learning to** a rule turns each input x into an output y. Choose inputs, work out each output, and write them as a table of ordered pairs (x, y), input first.

- I can make a table of values from a rule by putting in inputs and working out outputs.
- I can write ordered pairs with the input first, (x, y).
- I can find the input that gives a chosen output.

## Why it matters

> A spreadsheet column, a recipe scaled for more people, a taxi meter: each one takes a number in and gives a number out by the same rule, every time.

## A table of values

Here is how to make a table from a rule.

| $x$ (input) | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| $y$ (output) | −1 | 2 | 5 | 8 |

$$y = 3x - 1$$

1) $x = 0: \; y = 3(0) - 1 = -1$ — Choose an input and put it in place of $x$.
2) $x = 1: \; y = 3(1) - 1 = 2$ — Each input gives its own output. Do not use the same number for both.
3) $x = 2: \; y = 5, \quad x = 3: \; y = 8$ — Work out the rest the same way.
4) $(0, -1), (1, 2), (2, 5), (3, 8)$ — Write each as an ordered pair: input first, output second.
