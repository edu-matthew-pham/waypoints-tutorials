# What c does to a line

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Two phone plans with the same price per gigabyte but different monthly fees never meet: their graphs are parallel. The fee is c.


:::teacher-note

**In one sentence:** Students vary c in y = 2x + c on a graph board, find that c moves the line up or down and is where it crosses the y-axis, and that lines with the same m are parallel (AC9M8A04, node 2).

**Students should be able to say:** I can describe what happens to the line y = mx + c when c changes. I can read where a line crosses the y-axis from its rule. I can tell from their rules whether two lines are parallel.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Reading c


:::keep-together

### Where it crosses

Here is how to read $c$ from a rule.

1. $y = 2x + 4$ — Where does this line cross the $y$-axis, and how does it compare with $y = 2x + 1$?
2. $x = 0: \; y = 2(0) + 4 = 4$ — The $y$-axis is where $x = 0$. Put 0 in place of $x$.
3. $c = 4$ — $2x$ is 0 there, so $y$ is just $c$: the line crosses at 4.
4. $x = 1: \; 2(1) + 4 = 6, \; 2(1) + 1 = 3$ — Compare the two rules at $x = 1$.
5. $6 - 3 = 3$ — $y$ is 3 more, and it is 3 more at every $x$, because only $c$ changed.
6. $\text{same } m \Rightarrow \text{parallel}$ — The line moved up 3 without turning: lines with the same $m$ are parallel.

**Where does the line $y = 3x - 5$ cross the $y$-axis? Give the value of $y$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** -5

−5. When x = 0, y = 3 × 0 − 5 = −5, which is c.

:::


:::keep-together

```

 2  Both rules use a 2 and a 5.
 3  So they have the same numbers.
 4  So the lines are parallel.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 4

Line 4: parallel lines need the same m, the number in front of x. Here m is 2 and 5, so one is steeper than the other: they are not parallel.

### Parallel

**Which line is parallel to $y = 3x + 1$?**

☐ $y = x + 3$

☐ $y = 3x - 4$

☐ $y = -3x + 1$

:::


:::teacher-note

**Answer:** $y = 3x - 4$

y = 3x − 4 has the same m, 3, so it is just as steep: it is y = 3x + 1 moved down 5.

### From the rule

**Where does $y = 5x + 7$ cross the $y$-axis? Give the value of $y$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 7

7: when x = 0, y = 5 × 0 + 7 = 7.

:::

### Parallel

**Which two lines are parallel?**

☐ $y = 4x + 1$ and $y = 4x - 3$

☐ $y = 4x + 1$ and $y = x + 4$

☐ $y = 4x + 1$ and $y = 2x + 1$

:::


:::teacher-note

**Answer:** $y = 4x + 1$ and $y = 4x - 3$

Both have m = 4, so they are equally steep. y = 4x + 1 and y = x + 4 use the same numbers but in different places; y = 4x + 1 and y = 2x + 1 cross at (0, 1).

:::


:::keep-together

### From a point

**The line $y = 2x + c$ passes through $(3, 10)$. What is $c$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 4

At x = 3, 2x = 6. 6 + c = 10, so c = 4.

:::
