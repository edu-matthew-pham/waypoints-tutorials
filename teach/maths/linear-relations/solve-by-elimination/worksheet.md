# Solving by elimination

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Nobody has told you the prices, but two receipts together can.


:::teacher-note

**In one sentence:** Students solve two equations in two letters by elimination: add or subtract the equations so one letter cancels, multiplying one or both first if no coefficients match, then find the other letter (AC9M10A02, node 3, second of two lessons on the hinge). Edge cases: a false result (no solution) and a true result (infinitely many). The gym prices are made up.

**Students should be able to say:** I can subtract or add two equations so one letter cancels. I can multiply an equation so two coefficients match, then cancel. I can find the second letter and check it in the other equation.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Take one receipt from the other


:::keep-together

### Compare the receipts

**Let $v$ be the price of a visit and $k$ the price of a class. Ava: $4v + 2k = 44$. Ben: $4v + 5k = 62$. Subtract Ava's equation from Ben's. What is left?**

☐ $3k = 18$

☐ $7k = 106$

☐ $8v + 7k = 106$

☐ $k = 18$

:::


:::teacher-note

**Answer:** $3k = 18$

4v − 4v = 0, 5k − 2k = 3k and 62 − 44 = 18: 3k = 18.

:::


:::keep-together

### Solving for both prices

**Solve $3k = 18$, then use $k$ to find $v$ from $4v + 2k = 44$. What is $v$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 8

k = 6. Then 4v + 12 = 44, so 4v = 32 and v = 8.

:::


:::keep-together

### Find the mistake

**Sam solves $5p + 3q = 29$ and $2p + 3q = 17$ by subtracting. Click the line where his working goes wrong.**

```
 1  Solve 5p + 3q = 29 and 2p + 3q = 17.
 2  Subtract the second equation from the first: (5p − 2p) + (3q + 3q) = 29 − 17.
 3  So 3p + 6q = 12.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: he subtracted the p terms but added the q terms. Subtracting means every term of the second equation is taken away: 3q − 3q = 0. Then 3p = 12, p = 4 and q = 3.

:::


:::keep-together

### Try one on paper

Here is the routine with the first two receipts.

1. $4v + 2k = 44,\; 4v + 5k = 62$ — Both equations have $4v$. Subtract so it cancels.
2. $(4v + 5k) - (4v + 2k) = 62 - 44$ — Take away every term of the first equation from the second.
3. $3k = 18$ — The $v$ terms cancel. $5k - 2k = 3k$.
4. $k = 6$ — Divide by 3.
5. $4v + 2 \times 6 = 44$ — Put $k$ into one equation to find $v$.
6. $v = 8$ — $4v = 32$, so $v = 8$.
7. $4 \times 8 + 5 \times 6 = 62$ — Check in the other equation.

Now try one on paper with the example beside you: Cara and Dan. Find the price of one class, then type it.

**At the same gym, Cara paid 29 dollars for 3 visits and 2 classes and Dan paid 41 dollars for 3 visits and 5 classes. Solve $3v + 2k = 29$ and $3v + 5k = 41$ on paper. What does one class cost?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** $3v + 5k - (3v + 2k) = 41 - 29$ (subtract Cara's equation from Dan's); $3k = 12$ (the 3v cancels; 5k − 2k and 41 − 29); $k = 4$ (divide by 3)

Dan minus Cara: 3k = 12, so k = 4. Then 3v + 8 = 29, so v = 7. Check Dan: 21 + 20 = 41.

:::

## Pairs of equations


:::keep-together

### Subtract

**Solve $3a + 2b = 27$ and $3a + 5b = 45$. What is $b$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 6

Subtract: 3b = 18, so b = 6. Then 3a + 12 = 27, so a = 5.

:::


:::keep-together

### Add

**Solve $4x + 3y = 26$ and $2x - 3y = 4$. What is $x$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 5

Add: 6x = 30, so x = 5. Then 20 + 3y = 26, so y = 2.

:::


:::keep-together

### Which first step?

**Which is the best first step for $x + 2y = 11$ and $3x + 2y = 17$?**

☐ Subtract the first from the second: the $2y$ cancels

☐ Add them: the $2y$ cancels

☐ Multiply the first by 3 and add

:::


:::teacher-note

**Answer:** Subtract the first from the second: the $2y$ cancels

Both have +2y, so subtract: 2x = 6, x = 3. Then 3 + 2y = 11, so y = 4.

:::


:::keep-together

### Review

**Review (substitution): solve $y = 3x$ and $x + y = 20$. What is $x$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 5

x + 3x = 20, so 4x = 20 and x = 5. Then y = 15.

:::
