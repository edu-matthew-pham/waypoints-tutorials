## The null factor law


:::keep-together

### The null factor law

Here's solving the garden equation.

1. $x(x + 3) = 40$ — The garden: width times length is the area.
2. $x^2 + 3x - 40 = 0$ — Expand and make one side 0.
3. $(x + 8)(x - 5) = 0$ — Factorise: 8 × −5 = −40 and 8 + (−5) = 3.
4. $x + 8 = 0 \text{ or } x - 5 = 0$ — If a product is 0, a factor is 0.
5. $x = -8 \text{ or } x = 5$ — Both solve the equation.
6. $x = 5 \text{ (a width can't be negative)}$ — The situation picks one.

Now try one on paper: $x^2 + x - 12 = 0$. Factorise, find both solutions, then type the positive one.

**$(x + 8)(x - 5) = 0$. What are the solutions?**

☐ $x = 8$ or $x = 5$

☐ $x = 8$ or $x = -5$

☐ $x = -3$

☐ $x = -8$ or $x = 5$

:::


:::teacher-note

**Answer:** $x = -8$ or $x = 5$

x + 8 = 0 gives x = −8, and x − 5 = 0 gives x = 5.
