## Rise over run

Here's finding a gradient from two points.

Now try one on paper: the points $(2, 7)$ and $(6, 3)$. Work out the rise, the run and the gradient, then type the gradient.

$$A(1, 2),\; B(5, 10)$$

1) $\text{rise} = 10 - 2 = 8$ — Up from A to B: the y values.
2) $\text{run} = 5 - 1 = 4$ — Across from A to B: the x values, in the same order.
3) $\text{gradient} = \frac{8}{4} = 2$ — Rise over run: up 2 for each 1 across.

## Find the mistake

**Zoe finds the gradient between $(1, 7)$ and $(4, 1)$. Click the line where her working goes wrong.**

```
 1  Find the gradient between (1, 7) and (4, 1).
 2  Rise: 1 - 7 = -6
 3  Run: 1 - 4 = -3
 4  Gradient: -6 / -3 = 2
```

* Answer: line 3

<!-- Speaker note: Line 3: she did 1 − 7 for the rise but 1 − 4 for the run, starting from different points. Both must start from the same point: (1 − 7) ÷ (4 − 1) = −6 ÷ 3 = −2. -->
