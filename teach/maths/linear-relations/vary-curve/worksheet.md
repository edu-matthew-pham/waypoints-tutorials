## What each number does


:::keep-together

### Reading the turning point

1. $y = (x - 3)^2 + 2$ — h = 3, k = 2.
2. $(x - 3) = 0 \Rightarrow x = 3$ — The bracket is zero at the turning point.
3. $(3, 2)$ — The turning point.
4. $y = (x + 3)^2 + 2$ — The bracket is x + 3.
5. $(x + 3) = 0 \Rightarrow x = -3$ — The sign flips.
6. $(-3, 2)$ — The turning point.

**For $y = (x - 4)^2 + 1$, what is the $x$-coordinate of the turning point?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 4

x − 4 = 0 at x = 4.

:::


:::keep-together

### Up or down

**What does a negative $a$ do, as in $y = -(x - 4)^2 + 1$?**

☐ Makes the curve narrower

☐ Moves the curve left

☐ Flips the curve: the turning point is a peak

☐ Moves the curve down 1

:::


:::teacher-note

**Answer:** Flips the curve: the turning point is a peak

A negative a turns the curve upside down: a peak instead of a valley, like a thrown ball.

:::


:::keep-together

### Find the mistake

**Lee finds the turning point of y = (x + 3)² + 2. Click the line where his working goes wrong.**

```
 1  y = (x + 3)^2 + 2
 2  Compare with y = a(x - h)^2 + k.
 3  The bracket has +3, so h = 3.
 4  The turning point is (3, 2).
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: x + 3 = 0 at x = −3, so the turning point is (−3, 2). The sign flips because the bracket must be zero.
