# Regions from a budget

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A fixed budget never gives one answer. It gives a whole set of plans, and some of them are better than others.


:::teacher-note

**In one sentence:** Students turn a spending limit with two kinds of item into an inequality in two letters, find where its boundary meets each axis, and read the shaded region as the set of plans that fit (AC9M10A02, node 2). The prices are made up.

**Students should be able to say:** I can write a budget as an inequality such as 24p + 12d ≤ 120. I can find where the boundary meets each axis by putting the other letter equal to 0. I can tell which plans fit by reading the shaded region.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## From the budget to the line


:::keep-together

### Where the line crosses the d-axis

**Buy no pizzas ($p = 0$). How many packs of drinks does $24p + 12d = 120$ allow? This is where the line crosses the $d$-axis.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 10

With p = 0: 12d = 120, so d = 10. Ten packs spend the whole budget.

:::


:::keep-together

### Find the mistake

**Mia graphs $24p + 12d \le 120$. Click the line where her working goes wrong.**

```
 1  Graph 24p + 12d <= 120 (pizzas $24, packs $12, budget $120).
 2  Where does the boundary cross the p-axis? Put d = 0: 24p = 120, so p = 5.
 3  Where does it cross the d-axis? Put p = 0: 24d = 120, so d = 5.
 4  Draw a solid line through (5, 0) and (0, 5), test (0, 0) and shade the side with it.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: with p = 0 the equation is 12d = 120, not 24d = 120. Packs cost 12 dollars, so d = 10. Mia used the pizza price on the d-axis.

:::


:::keep-together

### Which side?

**The boundary of $24p + 12d \le 120$ crosses the axes at $(5, 0)$ and $(0, 10)$. Which side is shaded?**

☐ The side without the origin, because the line is solid

☐ Neither: solid boundaries have no shading

☐ The side with the origin $(0, 0)$, because $0 \le 120$ is true

:::


:::teacher-note

**Answer:** The side with the origin $(0, 0)$, because $0 \le 120$ is true

Test the origin: 24 × 0 + 12 × 0 = 0, and 0 ≤ 120 is true, so shade the side with (0, 0): the plans that cost less.

:::


:::keep-together

### Try it on paper

Here is the whole routine, from the budget to the region.

1. $24p + 12d \le 120$ — Pizzas cost 24 dollars each, packs 12 dollars each, and the total can be at most 120 dollars.
2. $p = 0:\; 12d = 120,\; d = 10$ — Where the boundary meets the $d$-axis: no pizzas, so divide by the pack price.
3. $d = 0:\; 24p = 120,\; p = 5$ — Where it meets the $p$-axis: no packs, so divide by the pizza price.
4. $\text{solid line through } (5, 0) \text{ and } (0, 10)$ — $\le$ includes the line: plans that spend exactly $120$ are allowed.
5. $(0, 0):\; 0 \le 120$ — Test a point not on the line. True, so shade the side with the origin.

Now try one on paper: the class has 96 dollars instead, so the boundary is $24p + 12d = 96$. Find where it crosses the $p$-axis, with the example beside you, and then type the number.

**The class has 96 dollars instead. The boundary of $24p + 12d \le 96$ crosses the $p$-axis where $d = 0$. What is $p$ there?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** $d = 0$: $24p = 96$ (no packs, so only the pizza price is left); $p = 96 \div 24$ (divide by the pizza price); $p = 4$ (four pizzas spend all 96 dollars)

With d = 0: 24p = 96, so p = 4. (With p = 0: 12d = 96, d = 8, so the line joins (4, 0) and (0, 8).)

:::

## Budgets and regions


:::keep-together

### The d-axis

**Pizzas cost 30 dollars, packs cost 15 dollars and the budget is 90 dollars. Where does the boundary of $30p + 15d \le 90$ cross the $d$-axis?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 6

With p = 0: 15d = 90, so d = 6.

:::


:::keep-together

### Is the plan in?

**Is the plan $(3, 4)$ inside $24p + 12d \le 120$?**

☐ Yes: it costs 72 + 48 = 120, exactly on the solid line

☐ No: it is on the line, so it does not count

☐ No: it costs more than 120

:::


:::teacher-note

**Answer:** Yes: it costs 72 + 48 = 120, exactly on the solid line

72 + 48 = 120. The limit is at most 120, so a plan that costs exactly 120 is allowed.

:::


:::keep-together

### More than

**Which inequality means 'the total is more than 60 dollars'?**

☐ $24p + 12d \ge 60$, with a dashed boundary

☐ $24p + 12d &lt; 60$, with a solid boundary

☐ $24p + 12d &gt; 60$, with a dashed boundary

:::


:::teacher-note

**Answer:** $24p + 12d &gt; 60$, with a dashed boundary

'More than' is &gt;: the boundary is dashed, because exactly 60 dollars is not more than 60 dollars.

:::


:::keep-together

### Review

**Review: solve $24x = 120$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 5

x = 120 ÷ 24 = 5.

:::


## Make: your own party budget


**Pick a plan.** Work it out on paper first, then type the number of packs.

**Check a plan.** The prices and the budget are made up, so only the method carries over. A real party also has other costs, such as plates and a place to hold it.

**Also used in**

- **Everyday life.** Any spending limit with two kinds of thing to buy, such as tickets and snacks, or two sizes of boxes in a delivery.
- **Next lessons.** Setting up equations from a situation, and solving two equations at once by substitution and elimination.
