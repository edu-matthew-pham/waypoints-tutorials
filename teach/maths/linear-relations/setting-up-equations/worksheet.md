# Setting up equations

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** The cheaper electricity plan depends on a number that only your own bill knows.


:::teacher-note

**In one sentence:** Students turn a rate card into a rule with named letters and one unit, set two plans equal, solve, and say the answer in the words of the situation, checking it makes sense (AC9M10A02, node 4). The electricity plans and the sample bill are made up; students can repeat the Make task with a real bill from home.

**Students should be able to say:** I can name the letters, with units, and write a rule from a rate card. I can keep every quantity in the same unit before I set up an equation. I can say a solution in the words of the situation and check it makes sense.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## From a rate card to a rule


:::keep-together

### Write the rule

**Let $k$ be the kWh used in a day and $c$ the cost for the day in cents. Plan A charges 120 cents a day plus 24 cents per kWh. Which rule is Plan A?**

☐ $c = 144k$

☐ $c = 120 + 24 + k$

☐ $c = 120 + 24k$

☐ $c = 120k + 24$

:::


:::teacher-note

**Answer:** $c = 120 + 24k$

The fixed part is 120 cents a day. The rate part is 24 cents times the kWh used: c = 120 + 24k.

:::


:::keep-together

### Same units

**A bill covers 90 days. Plan A's daily charge is 120 cents. How many dollars is the daily charge for the whole bill?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 108

90 × 120 = 10,800 cents, which is 108 dollars.

:::


:::keep-together

### Find the mistake

**Tess writes Plan A as a rule. Click the line where her working goes wrong.**

```
 1  Plan A: the daily charge is 1.20 dollars and the rate is 24 cents per kWh.
 2  Let k be the kWh used in a day and c the cost for the day in dollars.
 3  So c = 1.20 + 24k.
 4  For k = 10 that gives c = 241.20 dollars for the day.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: the 1.20 is in dollars but the 24 is in cents, so the rule mixes units. Write both in cents: c = 120 + 24k. Then 10 kWh costs 360 cents, which is 3.60 dollars.

:::


:::keep-together

### Try one on paper

Here is the whole routine on a different pair of plans: letters, rules, solve, then say it in words.

1. $c = 100 + 30k,\; c = 80 + 35k$ — Let $k$ be the kWh in a day and $c$ the cost for the day in cents. Plan C is a daily charge plus a rate for each kWh. Plan D likewise.
2. $100 + 30k = 80 + 35k$ — Both rules give $c$, so set them equal.
3. $20 = 5k$ — Take $30k$ and $80$ from both sides.
4. $k = 4$ — Divide by 5.
5. $c = 100 + 30 \times 4 = 220$ — Put $k$ into one rule for the cost.
6. $\text{Both cost 220 cents a day at 4 kWh a day.}$ — Say it in the words of the situation, with its units. Below 4 kWh Plan D is cheaper; above it, Plan C.

Now try one on paper with the example beside you: Plans A and B. Find the $k$ where they cost the same, then type it.

**Plan A is $c = 120 + 24k$ and Plan B is $c = 72 + 28k$ (cents for a day, with $k$ kWh in the day). Find $k$ where the two plans cost the same, on paper, with the example beside you. Then type $k$.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** $120 + 24k = 72 + 28k$ (both rules give c, so set them equal); $48 = 4k$ (take 24k and 72 from both sides); $k = 12$ (divide by 4; then $c = 120 + 24 \times 12 = 408$ cents)

120 + 24k = 72 + 28k gives 48 = 4k, so k = 12 and c = 408 cents. Below 12 kWh a day Plan B is cheaper; above it Plan A is.

:::

## Rules and bills


:::keep-together

### Write a rule

**A taxi charges 4 dollars to start plus 3 dollars for each kilometre. Write the cost $c$ dollars for $d$ kilometres as $c = \dots$**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** c = 4 + 3d

4 dollars once, plus 3 dollars for each of d kilometres: c = 4 + 3d.

:::


:::keep-together

### Units

**A plan charges 90 cents a day plus 30 cents per kWh. A household uses 20 kWh in a day. How many dollars is the cost for the day?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 6.9

90 + 20 × 30 = 90 + 600 = 690 cents, which is 6.90 dollars.

:::


:::keep-together

### Does it make sense?

**Solving a pair for a school trip gives $b = -3$ buses. What should you conclude?**

☐ The trip needs no buses

☐ The answer cannot be right: a number of buses cannot be negative

☐ Three buses are needed

:::


:::teacher-note

**Answer:** The answer cannot be right: a number of buses cannot be negative

A negative number of buses is impossible, so check the setup and the arithmetic before using the answer.

:::


:::keep-together

### Review

**Review (elimination): solve $x + y = 10$ and $x - y = 2$. What is $x$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 6

Add: 2x = 12, so x = 6. Then y = 4.

:::


## Make: your own bill


**The bill.** Work it out on paper first, then type the difference in dollars.

- **Everyday life.** Phone plans, hire charges, taxi fares and gym fees: any cost made of a fixed part and a rate.
