> **Key question:** A delivery zone, a speed limit, a budget: often the answer is not one point but a whole region of points that work.


:::teacher-note

**In one sentence:** Students graph vertical and horizontal lines and linear inequalities as regions, choosing a dashed or solid boundary and testing a point to decide which side to shade (AC9M8A02, node 1).

**Students should be able to say:** I can graph lines such as x = 3 and y = −2. I can graph an inequality such as y &lt; 2x + 1 as a region, with the right boundary (dashed or solid). I can test a point to decide whether it is in a region.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Boundary, then test


:::keep-together

### Boundary and test

Here is how to graph an inequality.

1. $y < 2x + 1$ — The boundary is the line $y = 2x + 1$.
2. $\text{dashed}$ — $<$ does not include the line's points (for $\le$ or $\ge$, draw it solid).
3. $(0, 0):\; 0 < 2 \times 0 + 1$ — Test a point not on the line. $0 < 1$ is true.
4. $\text{shade the side with } (0, 0)$ — True: shade the test point's side. (False: shade the other side.)
5. $x = 3,\; y = -2$ — One letter: $x = 3$ is vertical (every point has $x$ = 3); $y = -2$ is horizontal.

Solid or dashed for $y \ge x - 2$?

**For $y \ge x - 2$, is the boundary line solid or dashed?**

☐ Solid: ≥ includes the points on the line

☐ Dashed: points on the line are not included

☐ There is no boundary

:::


:::teacher-note

**Answer:** Solid: ≥ includes the points on the line

≤ and ≥ include the boundary (solid); &lt; and &gt; do not (dashed).

:::


:::keep-together

## Regions


:::keep-together

### Test a point

**Which point is in $y \le 3x - 2$?**

☐ $(1, 3)$

☐ $(2, 1)$

☐ $(0, 1)$

:::


:::teacher-note

**Answer:** $(2, 1)$

(2, 1): 1 ≤ 3 × 2 − 2 = 4. True.

:::


:::keep-together

### Solid or dashed

**Which has a dashed boundary?**

☐ $x &lt; -1$

☐ $y \ge 2x$

☐ $x \le -1$

:::


:::teacher-note

**Answer:** $x &lt; -1$

&lt; and &gt; leave the line out: dashed.

:::


:::keep-together

### Vertical

**Which line is vertical?**

☐ $x = 4$

☐ $y = 4x$

☐ $y = 4$

:::


:::teacher-note

**Answer:** $x = 4$

x = 4: every point has x = 4, so the points stack straight up: a vertical line.

:::


:::keep-together

### Review: m and c

**Review: what are the gradient and y-intercept of $y = 3x - 2$?**

☐ Gradient −2, y-intercept 3

☐ Gradient 3, y-intercept 2

☐ Gradient 3, y-intercept −2

:::


:::teacher-note

**Answer:** Gradient 3, y-intercept −2

y = mx + c with m = 3 and c = −2.

:::
