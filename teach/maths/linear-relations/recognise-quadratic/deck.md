# Recognising a quadratic

Linear relations · Quadratic relationships

<!-- Speaker note: Students recognise a quadratic from the constant second differences of a table or from an x² in the equation (AC9M9A04, node 1). About 40 minutes (Predict and Run 8 min · Investigate 12 min · Modify 8 min · Practise and Make 12 min). -->

---

## Today

- I can find first and second differences of a table.
- I can tell a linear table from a quadratic one.
- I can use the second differences to carry on a quadratic pattern.

## Why it matters

> Everyone in a group shakes hands with everyone else once. How many handshakes for 6 people? Does the count go up at a steady rate?

<!-- Speaker note: Some patterns grow at a steady rate, and those make straight lines. Others grow faster each time. One kind of speeding-up pattern is called quadratic. -->

- 12
- 13
- 14
- 15

## Second differences

Here's testing a table.

Now try one on paper: $y = 0, 2, 8, 18, 32$ for $x = 0, 1, 2, 3, 4$. Work out the first differences, then type the second difference.

$$y = 3, 6, 11, 18, 27$$

1) $\text{first differences: } 3, 5, 7, 9$ — Subtract each value from the next.
2) $\text{second differences: } 2, 2, 2$ — Subtract again.
3) $\text{constant, so the table is quadratic}$ — The second differences are all equal.

## Second differences

**The handshake counts for 1, 2, 3, 4, 5 people are $0, 1, 3, 6, 10$. The first differences are $1, 2, 3, 4$. What is the second difference (the change in the first differences)?**

* Answer: 1

<!-- Speaker note: 1, 2, 3, 4 goes up by 1 each time, so the second difference is 1. -->

## Which table?

**Which table of $y$ values (for $x = 1, 2, 3, 4$) is quadratic?**

- $3, 6, 11, 18$
- $3, 7, 11, 15$
- $3, 6, 9, 12$
- $3, 6, 12, 24$

* Answer: $3, 6, 11, 18$

<!-- Speaker note: 3, 6, 11, 18 has first differences 3, 5, 7 and constant second differences 2, 2. -->

## Which equation?

**Which equation gives a quadratic relationship?**

- $y = 2x - x$
- $y = \dfrac{5}{x}$
- $y = x^2 - 4$
- $y = 3x + 2$

* Answer: $y = x^2 - 4$

<!-- Speaker note: A quadratic has $x^2$ as its highest power. -->

## Find the mistake

**Sam looks at the table $y = 2, 5, 10, 17$ for $x = 1, 2, 3, 4$. Click the line where his working goes wrong.**

```
 1  The table is y = 2, 5, 10, 17.
 2  First differences: 3, 5, 7
 3  3, 5 and 7 are not equal, so it isn't quadratic.
 4  It must be something else.
```

* Answer: line 3

<!-- Speaker note: Line 3: unequal first differences don't rule out a quadratic. Equal first differences mean a straight line. A quadratic has equal second differences: 2, 2. -->

## Linear or quadratic

**A table gives $y = 4, 7, 10, 13$ for $x = 1, 2, 3, 4$. What kind of relationship is it?**

- Quadratic: it keeps going up
- Linear: the first differences are all 3
- Neither
- You can't tell from four values

* Answer: Linear: the first differences are all 3

<!-- Speaker note: 7 − 4 = 3, 10 − 7 = 3, 13 − 10 = 3: linear. -->

**A table gives y = 2, 6, 12, 20 for x = 1, 2, 3, 4. Linear, quadratic or neither?**
