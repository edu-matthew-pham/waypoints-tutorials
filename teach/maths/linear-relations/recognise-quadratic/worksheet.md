# Recognising a quadratic

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Everyone in a group shakes hands with everyone else once. How many handshakes for 6 people? Does the count go up at a steady rate?


:::teacher-note

**In one sentence:** Students recognise a quadratic from the constant second differences of a table or from an x² in the equation (AC9M9A04, node 1).

**Students should be able to say:** I can find first and second differences of a table. I can tell a linear table from a quadratic one. I can use the second differences to carry on a quadratic pattern.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

**In a group, everyone shakes hands with everyone else once. 2 people make 1 handshake, 3 make 3, 4 make 6 and 5 make 10. How many handshakes for 6 people?**

☐ 12

☐ 13

☐ 14

☐ 15

My prediction, and why:

{{lines-3}}

:::


:::teacher-note

**What happens:** 15. The count goes up by 2, then 3, then 4. The next step goes up by 5, so 10 + 5 = 15. A new person shakes hands with everyone already there, so each person adds one more handshake than the last.

## Differences


:::keep-together

### Second differences

Here's testing a table.

1. $y = 3, 6, 11, 18, 27$ — The table for x = 1, 2, 3, 4, 5.
2. $\text{first differences: } 3, 5, 7, 9$ — Subtract each value from the next.
3. $\text{second differences: } 2, 2, 2$ — Subtract again.
4. $\text{constant, so the table is quadratic}$ — The second differences are all equal.

Now try one on paper: $y = 0, 2, 8, 18, 32$ for $x = 0, 1, 2, 3, 4$. Work out the first differences, then type the second difference.

**The handshake counts for 1, 2, 3, 4, 5 people are $0, 1, 3, 6, 10$. The first differences are $1, 2, 3, 4$. What is the second difference (the change in the first differences)?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 1

1, 2, 3, 4 goes up by 1 each time, so the second difference is 1.

:::


:::keep-together

### Which table?

**Which table of $y$ values (for $x = 1, 2, 3, 4$) is quadratic?**

☐ $3, 6, 11, 18$

☐ $3, 7, 11, 15$

☐ $3, 6, 9, 12$

☐ $3, 6, 12, 24$

:::


:::teacher-note

**Answer:** $3, 6, 11, 18$

3, 6, 11, 18 has first differences 3, 5, 7 and constant second differences 2, 2.

:::


:::keep-together

### Which equation?

**Which equation gives a quadratic relationship?**

☐ $y = 2x - x$

☐ $y = \dfrac{5}{x}$

☐ $y = x^2 - 4$

☐ $y = 3x + 2$

:::


:::teacher-note

**Answer:** $y = x^2 - 4$

A quadratic has $x^2$ as its highest power.

:::


:::keep-together

### Find the mistake

**Sam looks at the table $y = 2, 5, 10, 17$ for $x = 1, 2, 3, 4$. Click the line where his working goes wrong.**

```
 1  The table is y = 2, 5, 10, 17.
 2  First differences: 3, 5, 7
 3  3, 5 and 7 are not equal, so it isn't quadratic.
 4  It must be something else.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: unequal first differences don't rule out a quadratic. Equal first differences mean a straight line. A quadratic has equal second differences: 2, 2.

:::

## Quadratic or not?


:::keep-together

### The second difference

**For $x = 0, 1, 2, 3, 4$ a table gives $y = 1, 2, 5, 10, 17$. What is the second difference?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 2

First differences 1, 3, 5, 7. Second differences 2, 2, 2.

:::


:::keep-together

### Linear or quadratic

**A table gives $y = 4, 7, 10, 13$ for $x = 1, 2, 3, 4$. What kind of relationship is it?**

☐ Quadratic: it keeps going up

☐ Linear: the first differences are all 3

☐ Neither

☐ You can't tell from four values

:::


:::teacher-note

**Answer:** Linear: the first differences are all 3

7 − 4 = 3, 10 − 7 = 3, 13 − 10 = 3: linear.

:::


:::keep-together

### The next value

**A quadratic table has $y = 3, 5, 9, 15$. The second differences are 2. What is the next $y$ value?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 23

First differences 2, 4, 6. The next is 8, so the next value is 15 + 8 = 23.

:::


:::keep-together

### Review

**Review: what is the gradient of the line through $(1, 3)$ and $(3, 9)$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 3

Rise 6, run 2: 6 ÷ 2 = 3.

:::
