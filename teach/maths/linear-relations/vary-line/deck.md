# Change a and b in a line

Linear relations · Changing the rule

## What b does

$$y = 3x + 7$$

1) $x = 0 \Rightarrow y = 7$ — Where the line starts.
2) $x = 1 \Rightarrow y = 10$ — 3 more for each gigabyte.
3) $y = 3x + 12$ — Raise b by 5.
4) $x = 0 \Rightarrow y = 12$ — The start moves up 5, every point moves up 5.
5) $y = 5x + 7$ — Raise a by 2 instead.
6) $x = 0 \Rightarrow y = 7$ — The start stays; the line is steeper.

## What b does

**For $y = 3x + 7$, what is $y$ when $x = 0$ (no gigabytes used)?**

* Answer: 7

## What a does

**In $y = 3x + 7$, what does the $3$ tell you about the graph?**

- The line crosses the x-axis at 3
- y is always 3
- y rises by 3 for every 1 across: the steepness
- The line crosses the y-axis at 3

* Answer: y rises by 3 for every 1 across: the steepness

<!-- Speaker note: The number multiplying x is the gradient: how much y goes up for each 1 across. -->

## Find the mistake

**Jo describes what happens when a changes. Click the line where her working goes wrong.**

```
 1  The rule is y = ax + b.
 2  Changing b moves the line up or down.
 3  Changing a moves where the line starts.
 4  So to move the start, I change a.
```

* Answer: line 3

<!-- Speaker note: Line 3: it is b, not a, that moves where the line starts. Changing a tilts the line. -->
