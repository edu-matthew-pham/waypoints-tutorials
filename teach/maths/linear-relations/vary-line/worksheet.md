☐ The line gets steeper

☐ The line gets flatter

## What each number does


:::keep-together

### What b does

1. $y = 3x + 7$ — The rule: price per gigabyte 3, fee 7.
2. $x = 0 \Rightarrow y = 7$ — Where the line starts.
3. $x = 1 \Rightarrow y = 10$ — 3 more for each gigabyte.
4. $y = 3x + 12$ — Raise b by 5.
5. $x = 0 \Rightarrow y = 12$ — The start moves up 5, every point moves up 5.
6. $y = 5x + 7$ — Raise a by 2 instead.
7. $x = 0 \Rightarrow y = 7$ — The start stays; the line is steeper.

**For $y = 3x + 7$, what is $y$ when $x = 0$ (no gigabytes used)?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 7

3 × 0 + 7 = 7 dollars: the monthly fee, where the line starts.

:::


:::keep-together

### What a does

**In $y = 3x + 7$, what does the $3$ tell you about the graph?**

☐ The line crosses the x-axis at 3

☐ y is always 3

☐ y rises by 3 for every 1 across: the steepness

☐ The line crosses the y-axis at 3

:::


:::teacher-note

**Answer:** y rises by 3 for every 1 across: the steepness

The number multiplying x is the gradient: how much y goes up for each 1 across.

:::


:::keep-together

### Find the mistake

**Jo describes what happens when a changes. Click the line where her working goes wrong.**

```
 1  The rule is y = ax + b.
 2  Changing b moves the line up or down.
 3  Changing a moves where the line starts.
 4  So to move the start, I change a.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: it is b, not a, that moves where the line starts. Changing a tilts the line.
