**The graph of $y = x^2 + 4x - 45$ crosses the $x$-axis at $x = -9$ and $x = 5$. Which is the factorised form?**

## Same numbers

Here's one equation solved three ways.

Now try one on paper: $x^2 - x - 6 = 0$. Solve it by factorising and check one solution in a table. Type the smaller solution.

$$x^2 - 2x - 8 = 0$$

1) $(x + 2)(x - 4) = 0,\; x = -2 \text{ or } x = 4$ — Algebra: factorise, then each bracket.
2) $\text{crosses the x-axis at } -2 \text{ and } 4$ — Graph: the x-intercepts.
3) $y = 7, 0, -5, -8, -9, -8, -5, 0, 7 \text{ for } x = -3, -2, \ldots, 5$ — Table: y is 0 at x = −2 and x = 4.
4) $-2 \text{ and } 4$ — All three methods give the same numbers.

## Graph to brackets

**The graph of $y = x^2 - 2x - 8$ crosses the $x$-axis at $x = -2$ and $x = 4$. Which is its factorised form?**

- $(x - 2)(x - 4)$
- $(x - 2)(x + 4)$
- $(x + 2)(x - 4)$
- $(x + 2)(x + 4)$

* Answer: $(x + 2)(x - 4)$

<!-- Speaker note: x = −2 comes from (x + 2) = 0 and x = 4 from (x − 4) = 0. -->

**Mei solves $x^2 + 4x - 45 = 0$ from a table of $x = 0$ to $10$. Click the line where her working goes wrong.**

```
 1  Table of x^2 + 4x - 45 for x = 0, 1, 2, ... 10.
 2  y = 0 when x = 5.
 3  So the only solution is x = 5.
 4  Check: 5 x 5 + 4 x 5 - 45 = 0.
```

* Answer: line 3

## From table to brackets

**The table for $y = x^2 - 5x + 4$ shows $y = 0$ at $x = 1$ and $x = 4$. Which equation does that solve?**

- $(x + 1)(x - 4) = 0$

* Answer: $(x - 1)(x - 4) = 0$
