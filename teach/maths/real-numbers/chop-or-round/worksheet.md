# Chop or round?

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A till drops the extra digits off every price instead of rounding them. Would anyone notice?


:::teacher-note

**In one sentence:** Students chop and round four sale prices, see that chopping always goes down so the errors pile up while rounding errors go both ways and cancel, and work out what a chopping till loses over a week (AC9M10N01, node 2).

**Students should be able to say:** I can chop and round a price to the cent and get the right answers. I can say which of chopping and rounding is biased, and why. I can work out what a bias adds up to over many sales.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Which way do the errors go?


:::keep-together

### Round it properly

Here's one price chopped and rounded, and how far each one is from the exact price.

1. $\$3.3490$ — A sale price with extra digits.
2. $\text{chop} \to \$3.34$ — Cut after the cent. $0.0090 below the exact price.
3. $\text{round} \to \$3.35$ — The next digit is 9, so go up. $0.0010 above.
4. $\$1.5555$ — Another price.
5. $\text{chop} \to \$1.55$ — $0.0055 below.
6. $\text{round} \to \$1.56$ — The next digit is 5, so go up. $0.0045 above.

Now try one on paper: round $5.3380 to the nearest cent, and see how far from the exact price it is. Then type the rounded price.

**Round $5.3380 to the nearest cent.**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 5.34

The digit after the cent is 8, which is 5 or more, so the 3 goes up to 4: $5.34. Chopping would give $5.33.

:::


:::keep-together

### Find the mistake

**Rosa rounds $1.5555 to the nearest cent. Click the line where her working goes wrong.**

```
 1  Round $1.5555 to the nearest cent.
 2  The cents are 1.55, and 55 is left over after them.
 3  Drop the left over digits, so the rounded price is $1.55.
 4  Rounded to the nearest cent: $1.55.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: dropping the left over digits is chopping, not rounding. The next digit is 5, so round up: $1.56.

:::


:::keep-together

### Which way does it drift?

**A till handles thousands of prices with digits all over the place. Which method keeps drifting in the same direction?**

☐ Rounding, because it always goes up

☐ Chopping, because it always goes down

☐ Neither: they both come out even

☐ Both drift the same amount

:::


:::teacher-note

**Answer:** Chopping, because it always goes down

Every chop removes something, so the errors all add. Rounding's errors point up or down about equally, so they mostly cancel.
