## Every integer

The nesting, step by step.

Now try one on paper: for each of $\sqrt{4}$, $\tfrac{1}{2}$, $-3$, $\sqrt{3}$ and $5$, write whether it's rational. Then type how many are.

$$5$$

1) $-5$ — Not natural. Integer.
2) $-5 = \tfrac{-5}{1}$ — So it's also rational.
3) $\tfrac{1}{2}$ — Rational, not an integer.
4) $\sqrt{2}$ — Not a fraction: irrational.
5) $\text{rational} + \text{irrational} = \text{real}$ — Every number on the number line is real.

<!-- Speaker note: Model this live on the board before revealing anything: write each line and say why, pausing to ask the class what comes next. Then click to reveal the lines and compare. Script. Line 3: write 1 ÷ 2 and say "Rational, not an integer." Line 4: write 2 and say "Not a fraction: irrational." Line 5: write rational + irrational = real and say "Every number on the number line is real." -->
