# Number families

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Each kind of number was invented because the old ones couldn't answer a question. Which question did each one answer?


:::teacher-note

**In one sentence:** Students sort numbers into natural, integer, rational and irrational, see why the families nest inside each other, and learn that a root sign alone doesn't make a number irrational (AC9M9N01, node 1).

**Students should be able to say:** I can say which families a number belongs to. I can explain why every integer is rational. I can tell √16 from √7.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

## The nesting


:::keep-together

### Every integer

The nesting, step by step.

1. $5$ — Natural: a counting number.
2. $-5$ — Not natural. Integer.
3. $-5 = \tfrac{-5}{1}$ — So it's also rational.
4. $\tfrac{1}{2}$ — Rational, not an integer.
5. $\sqrt{2}$ — Not a fraction: irrational.
6. $\text{rational} + \text{irrational} = \text{real}$ — Every number on the number line is real.

Now try one on paper: for each of $\sqrt{4}$, $\tfrac{1}{2}$, $-3$, $\sqrt{3}$ and $5$, write whether it's rational. Then type how many are.

**True or false: every integer is a rational number.**

☐ False: integers aren't fractions

☐ False: only positive integers are

☐ True: 5 = 5/1

☐ It depends on the integer

:::


:::teacher-note

**Answer:** True: 5 = 5/1

Any integer n is the fraction n/1, so every integer is rational.

:::


:::keep-together
