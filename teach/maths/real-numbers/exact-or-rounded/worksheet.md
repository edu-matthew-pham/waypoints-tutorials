## When rounding matters


:::keep-together

### Exact first

Here's the difference rounding early makes.

1. $\sqrt{2} \times \sqrt{2} \times \sqrt{2} \times \sqrt{2}$ — Exact: (√2)² = 2, so (√2)⁴ = 4.
2. $1.4 \times 1.4 \times 1.4 \times 1.4$ — Rounded to 1 decimal place first.
3. $= 3.8416$ — Not 4.
4. $\sqrt{2} \approx 1.41421356 \text{, so } 1.41421356^4 \approx 4.0000$ — Keep more digits and it's closer.

Now try one on paper: use $\sqrt{2} \approx 1.4$ to work out $(\sqrt{2})^4$ by multiplying four 1.4s. Then type the value you get.

**Which one keeps the exact value of the side?**

☐ $7.071$

☐ $\sqrt{50}$

☐ $7.07$

☐ $7.1$

:::


:::teacher-note

**Answer:** $\sqrt{50}$

√50 is exact. Each decimal version is rounded.

:::


:::keep-together

### Find the mistake

**Lee works out the cable along 2 diagonals of a 1 m square. Click the line where his working goes wrong.**

```
 1  A 1 m square has a diagonal of √2 m. Find the length of a cable that goes along 2 diagonals.
 2  √2 is about 1.4.
 3  2 diagonals: 2 × 1.4 = 2.8.
 4  So the cable is exactly 2.8 m.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 4

Line 4: 2 × 1.4 = 2.8 is an approximation, because √2 was rounded. The exact length is 2√2 m, which is about 2.83 m.

:::

### Which is exact?

√50 × √50 = 50 exactly: a square root times itself gives the number back.
