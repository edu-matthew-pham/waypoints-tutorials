# Exact or approximate?

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Two people work out the same path across the same patch and get different answers.


:::teacher-note

**In one sentence:** Students find that multiplying exact roots gives √50 × √2 = 10 while rounded decimals give 9.9687, and learn that an approximation swaps an exact number for a nearby different one (AC9M10N01, node 1).

**Students should be able to say:** I can say which of two numbers is exact and which is an approximation. I can say what is lost when a root is replaced by a decimal. I can work a two-step calculation exactly, then with rounded values, and find the gap.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## What rounding changes


:::keep-together

### Exact first

Here's the builder's way, and what rounding does to it.

1. $\sqrt{50} \times \sqrt{2}$ — The side times the corner-to-corner factor, both exact.
2. $= \sqrt{50 \times 2}$ — Two roots multiply into one root.
3. $= \sqrt{100}$ — Multiply under the root.
4. $= 10$ — A whole number. Nothing was rounded, so nothing was lost.
5. $7.07 \times 1.41 = 9.9687$ — Round each root first and the 10 is gone: close, not exact.

Now try one on paper: a patch of 18 m² has a path of $\sqrt{18} \times \sqrt{2}$. Work it out exactly, then type it.

**A second patch has an area of 18 m². Its path is $\sqrt{18} \times \sqrt{2}$. Work it out exactly. What is it?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 6

√18 × √2 = √36 = 6.

:::


:::keep-together

### Find the mistake

**Mia works out the path with rounded numbers. Click the line where her working goes wrong.**

```
 1  A square patch has an area of 50 m². Find the path from corner to corner.
 2  The side is √50, which is about 7.07 m.
 3  The path is the side times √2, which is about 7.07 × 1.41 = 9.9687 m.
 4  So the path is exactly 9.9687 m.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 4

Line 4: 7.07 × 1.41 = 9.9687 is the product of two rounded numbers, so it's close but not exact. The path is exactly √50 × √2 = 10 m.

:::


:::keep-together

### What did rounding change?

**What changes when $\sqrt{50}$ is replaced by 7.07?**

☐ Nothing: they are the same number

☐ It becomes a bit smaller, by exactly 0.01

☐ It becomes a negative number

☐ It becomes a different number, one that stops after 2 places

:::


:::teacher-note

**Answer:** It becomes a different number, one that stops after 2 places

7.07 is the fraction 707/100. It stops, but √50 never does, so no decimal is exactly √50.

## Exact, then approximate


:::keep-together

### Exactly

**A square patch has an area of 72 m². Its path from corner to corner is $\sqrt{72} \times \sqrt{2}$. How long is it, exactly?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 12

√72 × √2 = √144 = 12.

:::


:::keep-together

### Rounded

**Someone rounds the side to 8.49 and $\sqrt{2}$ to 1.41. What path length do they get, to 2 decimal places?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 11.97

8.49 × 1.41 = 11.9709, so 11.97.

:::


:::keep-together

### The gap

**How much shorter than the exact path is that, to 2 decimal places?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 0.03

12 − 11.97 = 0.03 m, or 3 cm.

:::


:::keep-together
