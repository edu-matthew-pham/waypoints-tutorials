> **Key question:** A hole has to be 20 mm, give or take a tiny bit. Where's the line between a part that fits and one that doesn't?


:::teacher-note

**In one sentence:** Students turn a tolerance into a range on the number line, use ≤ and < to keep or leave out the ends, and check measurements against it (AC9M9N01, node 3).

**Students should be able to say:** I can write a tolerance as a range with its limits. I can show a range on the number line with open and closed ends. I can decide if a measurement is in a range.

## Closed and open ends


:::keep-together

### Both limits

Here's turning a tolerance into a range on the line.

1. $20 \pm 0.05$ — The drawing: 20 mm, give or take 0.05.
2. $20 - 0.05 = 19.95$ — The lower limit.
3. $20 + 0.05 = 20.05$ — The upper limit.
4. $19.95 \le x \le 20.05$ — Both ends count: closed circles.
5. $20.04 \text{ is between } 19.95 \text{ and } 20.05$ — So it passes.

Now try one on paper: a shaft of 12 mm ± 0.02 mm. Write the range, then type the upper limit.

**Which inequality describes every hole that passes, from 19.95 mm to 20.05 mm, including both limits?**

☐ $19.95 &lt; x &lt; 20.05$

☐ $19.95 \le x \le 20.05$

☐ $x \le 20.05$

☐ $x = 20$

:::


:::teacher-note

**Answer:** $19.95 \le x \le 20.05$

≤ keeps the end points: a closed circle at each limit.

:::


:::keep-together

### Find the mistake

**Ben writes the passing range. Click the line where his working goes wrong.**

```
 1  A hole passes if it is from 19.95 mm up to 20.05 mm, including both limits.
 2  So 19.95 < x < 20.05.
 3  A hole of exactly 20.05 mm passes.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: &lt; leaves the ends out, but a hole of exactly 19.95 or 20.05 passes. It should be 19.95 ≤ x ≤ 20.05.

:::


:::keep-together

## Read and write ranges


:::keep-together

### Tolerance

**A part must be $50$ mm ± $0.1$ mm. What's the upper limit?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 50.1

50 + 0.1 = 50.1 mm.

:::


:::keep-together

### Which signs

**Which means 'at least 5, but less than 9'?**

☐ $5 &lt; x &lt; 9$

☐ $5 \le x &lt; 9$

☐ $5 \le x \le 9$

☐ $5 &lt; x \le 9$

:::


:::teacher-note

**Answer:** $5 \le x &lt; 9$

At least 5 includes 5 (≤). Less than 9 leaves out 9 (&lt;).

:::


:::keep-together

### How many pass

**Three holes are measured: $19.94$, $20.03$ and $20.05$ mm. How many pass the range $19.95 \le x \le 20.05$?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 2

19.94 is below 19.95: fails. 20.03 and 20.05 pass.

:::
