← AC9M1M02 Measure length with informal units

Iterate units end-to-end

AC9M1M02 n1 · waypoint 1 of 3 · Year 1 Maths · Measurement · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can measure the length of an object by placing informal units end-to-end and counting them, producing a numerical measurement.

Lessons on this site

None yet.

Success criteria

  • Places informal units end-to-end without gaps or overlaps to measure a length.
  • Counts and records the number of units correctly.

Prior knowledge

Students can compare objects directly by length (AC9MFM01) and order objects by length using direct comparison (AC9M1M01). They have not yet iterated a unit along a length to produce a numerical measure, or reasoned about why units must be uniform and placed end-to-end.

Width

Minimum
Measure one object using a chosen informal unit placed end-to-end; count the units and record the measurement.
Typical
Measure several objects using an informal unit (blocks, pop sticks) placed end-to-end; count and record each measurement; compare measurements to determine which object is longer; explain what end-to-end placement means.
Wider
  • Measure the same object multiple times using the same unit, investigating whether the result is always the same and discussing what could cause variation.
  • Measure classroom features (door frame, table, corridor) using body-based units (footsteps, handspans) and record results, discussing how this connects to historical measurement practices.

Hinge

Placement errors (gaps or overlaps) produce invalid measurements that undermine Node 2 — students who cannot iterate units accurately cannot meaningfully compare measurements or reason about why units must be uniform, because their measurements are not trustworthy to begin with.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsCorrectly placing units end-to-end without gaps or overlaps requires practice and physical care — it is a procedural skill that needs to become reliable before students can reason about unit consistency. Errors in placement directly undermine the validity of the measurement.
