← AC9M1SP01 Compare and classify shapes

Classify by shared properties

AC9M1SP01 n1 · waypoint 1 of 3 · Year 1 Maths · Space

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can sort a collection of shapes into groups based on shared properties and explain what is the same within a group and different between groups.

Lessons on this site

None yet.

Success criteria

  • Sorts a mixed collection of shapes into groups and names a shared property for each group.
  • Explains at least one difference between two groups.

Prior knowledge

Students can sort, name and create familiar shapes and recognise them in the environment (AC9MFSP01). They have not yet classified shapes by comparing multiple properties simultaneously, nor distinguished between regular and irregular instances of the same shape type.

Width

Minimum
Sort a collection of shapes into at least two groups; state one property shared by shapes in each group and one difference between the groups.
Typical
Classify a collection including circles, ovals, triangles, quadrilaterals and irregular shapes into groups; explain the shared properties within each group; distinguish regular from irregular instances of the same type (e.g. equilateral vs scalene triangles); identify overlapping properties and decide how to handle shapes that could belong to multiple groups.
Wider
  • Explore string games from First Nations Australians (e.g. Karda from the Yandruwandha Peoples), recognising and classifying the shapes made by the string in terms of familiar shape properties.
  • Investigate shapes found in architecture and design across different cultures, classifying and comparing properties and noting how different traditions use shape differently.
  • Use dynamic geometry software to manipulate shapes, exploring which properties remain the same and which change as a shape is stretched or rotated.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents who only sort with clearly regular shapes often overgeneralise (all triangles must have equal sides, all rectangles must be upright). Including irregular instances and shapes in non-standard orientations gives the contexts needed to build a property-based concept of shape type rather than a prototype-based one.
