Comparing and ordering duration

AC9M1M01 n3 · waypoint 3 of 3 · Year 1 Maths · Measurement

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can compare the duration of events using informal timers and order events by duration, communicating reasoning using correct temporal comparative language.

Success criteria

  • Orders three or more events or activities by duration using an informal timer.
  • Uses correct comparative language to communicate the duration order and explains how the comparison was made.

Prior knowledge

Waypoint 2: Indirect comparison.

Width

Minimum
Compare the duration of two events using an informal timer (sand timer, counting); state which takes longer.
Typical
Compare and order the duration of three or more events using informal timers; create or select appropriate timers for comparison; use correct comparative language (faster, slower, shorter duration, longer duration); connect duration comparison to the time units studied in AC9M1M03.
Wider
  • Investigate First Nations Australians' seasonal calendars as representations of duration — discussing how the duration of seasons is described and compared across different language groups.
  • Create and compare a set of sand timers using everyday materials, ordering them by duration and designing a timing challenge for peers.
