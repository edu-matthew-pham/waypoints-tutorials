Order by length, mass, capacity, duration

AC9M1M01 · Year 1 Maths · Measurement

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Descriptor

Compare directly and indirectly and order objects and events using attributes of length, mass, capacity and duration, communicating reasoning

Prior knowledge

Students can identify and compare length, capacity, mass and duration using direct comparisons (AC9MFM01). They can sequence days of the week and times of day (AC9MFM02). They have not yet compared indirectly using a mediating object, or ordered three or more objects using a single attribute and communicated the reasoning systematically.

By the end

Students compare directly and indirectly and order objects and events using attributes of length, mass, capacity and duration, communicating reasoning.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • using a piece of string to indirectly compare the length of several objects, deciding which will fit within a space; using comparative language to describe the order: shortest, short, longer, longest
  • ordering the mass of 3 or more objects such as rocks, using hefting and balance scales; using comparative language to explain the order: lightest, light, heavier, heaviest
  • pouring sand/rice/water from one container to another to compare and order the capacity of 3 or more containers
  • creating sand timers from everyday items or recycled material and comparing them to order the duration of time
  • investigating situations where First Nations Australians estimate, compare and communicate measurements; for example, the duration of seasons; understanding animal behaviour using the length of animal tracks; investigating capacity through water management techniques

Waypoints

  • 1. Direct comparison and orderingStudents can directly compare and order three or more objects using a single attribute, using correct comparative language to communicate the order.
  • 2. Indirect comparisonStudents can compare the length (or capacity) of two objects that cannot be placed directly side-by-side, using a mediating object or material.
  • 3. Comparing and ordering durationStudents can compare the duration of events using informal timers and order events by duration, communicating reasoning using correct temporal comparative language.
