← AC9M4N08 Mathematical modelling — additive and multiplicative

Formulate — represent the situation

AC9M4N08 n1 · waypoint 1 of 3 · Year 4 Maths · Number · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can represent a practical problem using a diagram (part-part-whole, bar model, array) and write a number sentence that matches the structure.

Success criteria

  • Students can represent a practical problem using a diagram and write a matching number sentence
  • Students can identify what is known and what is unknown in the problem structure

Prior knowledge

Students can use mathematical modelling to solve additive and multiplicative problems including financial contexts (AC9M3N06). They have not yet formulated multi-step problems requiring selection between operations, or interpreted solutions in complex financial contexts.

Width

Minimum
Represent one additive or multiplicative practical problem using a bar model or array; write the corresponding number sentence; identify what is known and what is unknown.
Typical
Represent a range of additive and multiplicative problems using appropriate diagrams; write number sentences that reflect the problem structure (not just the calculation); identify the operation from the structure (additive: part or whole missing; multiplicative: groups or per-group missing); explain how each number in the sentence connects to the situation.
Wider
  • Compare two different representations of the same problem (e.g. bar model vs array) and discuss how each makes different aspects of the structure visible
  • Analyse word problems by identifying the structural type before selecting a representation — building the habit of problem analysis before calculation

Hinge

Incorrect formulation propagates through all subsequent modelling phases — an incorrect number sentence produces a correct calculation of the wrong thing. Students who cannot identify problem structure from context cannot meaningfully engage in Nodes 2 or 3.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents who encounter only additive problems may default to addition for all problems. Exposure to a wide range of problem types — missing part, missing whole, equal groups (number of groups missing), equal groups (per-group missing), comparison — is needed to develop appropriate operation selection. Phase collapse if this node is thin: students formulate incorrectly in all downstream modelling phases.
