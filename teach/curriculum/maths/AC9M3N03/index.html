Addition and subtraction with place value

AC9M3N03 · Year 3 Maths · Number

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Descriptor

add and subtract two- and three-digit numbers using place value to partition, rearrange and regroup numbers to assist in calculations without a calculator

Prior knowledge

Students can add and subtract one- and two-digit numbers using part-part-whole reasoning and a variety of calculation strategies (AC9M2N04). They have not yet applied place value partitioning and regrouping to three-digit calculations without a calculator.

By the end

Students add and subtract two- and three-digit numbers, applying place value partitioning, rearranging and regrouping strategies to calculate without a calculator.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • using place value to partition numbers and add or subtract, for example 245 + 132 = 200 + 100 + 40 + 30 + 5 + 2
  • applying partitioning strategies to solve addition and subtraction problems, including regrouping
  • using number lines or empty number lines to record and communicate thinking

Waypoints

  • 1. Partitioning for additionStudents can partition two- and three-digit numbers to add by place value (e.g. 245 + 132 = 200+100 + 40+30 + 5+2).
  • 2. Regrouping in additionHingeStudents can recognise when regrouping (carrying) is needed in addition and apply it correctly across hundreds, tens and ones.
  • 3. Subtraction using place valueHingeStudents can subtract two- and three-digit numbers using place value partitioning, including cases requiring decomposition.
