← AC9M1ST02 Represent and compare categorical data

Create one-to-one displays

AC9M1ST02 n1 · waypoint 1 of 3 · Year 1 Maths · Statistics · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can represent categorical data in a one-to-one display (pictograph or object display) where each item represents exactly one data value.

Success criteria

  • Creates a one-to-one display with each data value represented by exactly one object or symbol.
  • Arranges symbols clearly into categories.

Prior knowledge

Students can collect, sort and compare data represented by objects and images (AC9MFST01). They can acquire and record data using lists, tallies and symbols (AC9M1ST01). They have not yet represented data in formal one-to-one displays, used frequency counts to compare categories, or discussed findings in terms of most/least frequent categories.

Width

Minimum
Create one pictograph or object display for a categorical data set; ensure one object or drawing represents one data value.
Typical
Create pictographs with objects or drawings; discuss category choice; arrange items clearly into categories; reflect on whether the chosen categories were helpful; understand that one symbol represents one data value (one-to-one principle).
Wider
  • Explore First Nations Australian children's instructive games (e.g. Kolap from Mer Island), recording outcomes, creating a one-to-one display and discussing what patterns the display shows.
  • Create digital one-to-one displays using available classroom tools, comparing the digital representation with a hand-drawn pictograph of the same data.

Hinge

Displays that violate the one-to-one principle cannot be reliably read for frequency comparison in Node 3 — students who use differently-sized symbols or misaligned rows produce displays from which frequency comparisons are invalid.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsThe one-to-one principle (each symbol/object represents exactly one data value) requires careful physical practice to establish. Students who use different-sized symbols or place symbols in non-aligned rows produce displays that cannot be read reliably — precise construction needs explicit reinforcement.
