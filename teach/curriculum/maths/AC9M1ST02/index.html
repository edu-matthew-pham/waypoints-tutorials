Represent and compare categorical data

AC9M1ST02 · Year 1 Maths · Statistics

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Descriptor

Represent collected data for a categorical variable using one-to-one displays and digital tools where appropriate; compare the data using frequencies and discuss the findings

Prior knowledge

Students can collect, sort and compare data represented by objects and images (AC9MFST01). They can acquire and record data using lists, tallies and symbols (AC9M1ST01). They have not yet represented data in formal one-to-one displays, used frequency counts to compare categories, or discussed findings in terms of most/least frequent categories.

By the end

Students represent collected data for a categorical variable using one-to-one displays and digital tools where appropriate; compare the data using frequencies and discuss the findings.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • creating a pictograph with objects or drawings; discussing the possible categories, arranging the objects or drawings, then reflecting on whether the chosen categories were helpful
  • translating data from a list or pictorial display into a tally chart to make counting easier; using skip counting by fives to compare the numbers within each category
  • recognising that when there is no data for a particular category you may choose whether or not to include it
  • representing data with objects and drawings where one object or drawing represents one data value; describing the displays and explaining patterns using counting strategies
  • discussing what data frequency means in terms of the total count for a particular category
  • exploring First Nations Australian children's instructive games; for example, Kolap from Mer Island, recording the outcomes, representing and discussing the results

Waypoints

  • 1. Create one-to-one displaysHingeStudents can represent categorical data in a one-to-one display (pictograph or object display) where each item represents exactly one data value.
  • 2. Translate between display formatsStudents can translate data between a list or tally and a pictograph, and between a pictograph and a tally, recognising that the same data can be represented in multiple ways.
  • 3. Compare frequencies and discuss findingsStudents can compare the frequencies of categories in a data display, identify the most and least frequent categories, and discuss what the data shows.
