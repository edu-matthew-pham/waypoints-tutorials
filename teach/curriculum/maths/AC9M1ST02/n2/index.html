← AC9M1ST02 Represent and compare categorical data

Translate between display formats

AC9M1ST02 n2 · waypoint 2 of 3 · Year 1 Maths · Statistics

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can translate data between a list or tally and a pictograph, and between a pictograph and a tally, recognising that the same data can be represented in multiple ways.

Success criteria

  • Converts a tally chart to a pictograph (or vice versa) with matching totals for each category.
  • Uses skip counting by fives to read tally marks.

Prior knowledge

Waypoint 1: Create one-to-one displays.

Width

Minimum
Convert a tally chart into a pictograph (or vice versa) for the same data set; confirm the total count is preserved.
Typical
Translate between lists, tally charts and pictographs; use skip counting by fives to count tally marks efficiently; explain what each format shows and when each is useful; recognise that all formats represent the same underlying data.
Wider
  • Compare three representations of the same data (list, tally, pictograph) and evaluate which is most useful for answering specific questions about the data.
  • Represent the same data using both paper-based and digital formats, discussing what is easier and harder to communicate in each.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkTranslating between formats requires students to track data integrity — the count in each format must match. Scaffolding the translation with a checking step (do the totals match?) builds data discipline and reinforces the idea that the format is a representation of the same underlying information.
