Equivalent fractions — same quantity, different names

AC9M4N03 n1 · waypoint 1 of 2 · Year 4 Maths · Number · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can find at least two equivalent fractions for a given fraction using related denominators, and explain what makes them equivalent.

Success criteria

  • Students can find at least two fractions equivalent to a given fraction using materials or diagrams
  • Students can explain that equivalent fractions name the same quantity using a model

Prior knowledge

Students can recognise unit fractions (1/2, 1/3, 1/4, 1/5, 1/10) and their multiples (AC9M3N02) and can recognise halves, quarters and eighths through repeated halving (AC9M2N03). They have not yet found equivalent fractions using related denominators or connected fractions to decimal notation.

Width

Minimum
Use paper folding or materials to show that 1/2 = 2/4; identify one other equivalent pair (e.g. 2/4 = 4/8); explain that the fractions name the same quantity.
Typical
Use folding, area models and collections to find and verify equivalent fractions within families (halves/quarters/eighths, thirds/sixths, fifths/tenths); extend fraction families (e.g. 3/4 = 6/8 = 9/12); explain equivalence using the idea of 'same portion of the whole'.
Wider
  • Generate complete fraction families for halves/quarters/eighths and thirds/sixths using paper folding, and represent the full family on a number line to show all names for the same position
  • Explore capacity subdivisions (half cup = two-quarter cups = four-eighth cups) to ground equivalence in measurement and cooking contexts

Hinge

Students who retain the larger-denominator misconception cannot meaningfully engage with Node 2 — the fraction–decimal connection requires understanding that 1/4 and 2/8 name the same quantity, and that the decimal equivalent belongs to the quantity, not to one particular fraction name.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepMisconception: students believe a fraction with a larger denominator is always a larger fraction. Experiencing equivalent fractions across multiple representations (area, length, set models) builds the understanding that the denominator names the size of each part, not the value of the fraction.
