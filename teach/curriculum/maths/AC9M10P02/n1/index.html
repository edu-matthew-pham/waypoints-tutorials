Designing simulations for conditional probability

AC9M10P02 n1 · waypoint 1 of 3 · Year 10 Maths · Probability

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can design a simulation to model a conditional probability situation, specifying how the conditioning will be implemented in the digital tool.

Lessons on this site

  • Simulate it

Success criteria

  • Student describes a simulation design that correctly encodes the conditional structure of the problem
  • Student implements the simulation in a digital tool and runs it for a sufficient number of trials

Prior knowledge

Students can describe and interpret situations involving conditional probability using language, tables and diagrams (AC9M10P01). They have not yet designed and conducted simulations specifically for conditional probability or dependent event scenarios using digital tools.

Width

Minimum
Describe the steps needed to simulate a conditional probability scenario (e.g. drawing without replacement); implement the simulation using a digital tool.
Typical
Design simulations for dependent event scenarios (with and without replacement); implement using digital tools; identify how the conditioning condition is built into the simulation design; distinguish simulation design for dependent vs independent events.
Wider
  • Investigate simulations for counter-intuitive problems (Monty Hall three-door problem, birthday problem) — design the simulation, run it, and use the results to explain why the intuitive answer is wrong
  • Design a simulation for a sampling-with-replacement vs without-replacement scenario at different sample sizes, investigating at what population-to-sample ratio the difference becomes negligible

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkDesigning a simulation for conditional probability requires explicit reasoning about how dependency is encoded in the simulation steps. Students who design simulations mechanically without thinking through the dependency structure produce invalid results.
