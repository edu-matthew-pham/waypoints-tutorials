← AC9M4SP02 Grid reference systems

Creating and describing with grid references

AC9M4SP02 n2 · waypoint 2 of 2 · Year 4 Maths · Space

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can write directions using grid references and directional language to guide someone from one location to another.

Success criteria

  • Students can write clear directions using grid references to guide movement from one location to another
  • Students can create a grid reference map of a familiar space with at least four labelled locations

Prior knowledge

Waypoint 1: Reading grid references.

Width

Minimum
Write a set of directions using grid references to guide someone from one location to another on a familiar map.
Typical
Interpret and create grid reference maps; write directions combining grid references and directional language; use grids to enlarge images proportionally; use grid references to describe positions and pathways in different contexts.
Wider
  • Simulate a robotic or autonomous vehicle moving through a grid environment using grid references and directional instructions — connecting grid navigation to real automation applications
  • Use a grid overlay to enlarge a piece of artwork, systematically applying the grid reference to transfer each section proportionally
