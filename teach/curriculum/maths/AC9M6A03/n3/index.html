← AC9M6A03 Algorithms for number patterns

Identifying and explaining emerging patterns

AC9M6A03 n3 · waypoint 3 of 3 · Year 6 Maths · Algebra

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use an algorithm to generate a set of numbers, identify patterns that emerge in the set, and explain why those patterns arise from the algorithm's rules.

Lessons on this site

Success criteria

  • Student identifies a pattern in a number set generated by an algorithm.
  • Student explains why the pattern arises by referring to the rule in the algorithm.

Prior knowledge

Waypoint 2: Creating algorithms to generate number sets.

Width

Minimum
Run an algorithm to generate a number set; identify at least one pattern in the output; offer a reason why that pattern emerges from the rule.
Typical
Generate number sets from algorithms and identify multiple patterns; distinguish patterns that are always true from those that appear in the generated sample; explain the connection between the algorithm's rule and the patterns in the output; use digital tools to test conjectures about large sets.
Wider
  • Investigate what happens to patterns when the algorithm's rule is slightly modified — systematic variation to understand the rule-pattern connection
  • Explore the Collatz conjecture at an accessible level: the algorithm always seems to reach 1 — test with many starting values using a spreadsheet and describe what you observe

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierExplaining emerging patterns requires students to connect their algorithm (the rule) to its output (the number set) and articulate the causal relationship. This integrates algorithm literacy, pattern recognition, and mathematical reasoning into the kind of explanation that is the endpoint of this descriptor.
