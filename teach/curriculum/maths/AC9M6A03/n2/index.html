← AC9M6A03 Algorithms for number patterns

Creating algorithms to generate number sets

AC9M6A03 n2 · waypoint 2 of 3 · Year 6 Maths · Algebra

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can create an algorithm (as written steps or a flowchart) that uses a rule to generate a set of numbers, and use it to produce the set.

Success criteria

  • Student creates an algorithm with at least three steps and one decision point that generates a number set.
  • Student traces through the algorithm to verify it produces the correct set.

Prior knowledge

Waypoint 1: What an algorithm is — steps and decisions.

Width

Minimum
Write a step-by-step algorithm that generates a specific number sequence (e.g. all multiples of 3 to 100, or all numbers satisfying two conditions); run the algorithm to produce the set.
Typical
Create algorithms that generate number sets using arithmetic rules, divisibility conditions, and combinations of criteria; represent algorithms in written and flowchart form; test algorithms by tracing through them manually and with digital tools.
Wider
  • Create an algorithm to generate Fibonacci-like sequences starting from different seed values and compare the resulting patterns
  • Design an algorithm that generates all numbers satisfying two separate conditions (e.g. prime AND between 50 and 100) and explain why the decision order matters

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkCreating an algorithm requires students to externalise and order their reasoning. Students frequently write steps that are implicit or assume background knowledge. Scaffolding the 'write it so a computer (or a classmate who doesn't know the pattern) could follow it' standard helps develop the precision needed.
