Graph and solve linear equations

AC9M8A02 · Year 8 Maths · Algebra

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Descriptor

graph linear relations on the Cartesian plane using digital tools where appropriate; solve linear equations and one-variable inequalities using graphical and algebraic techniques; verify solutions by substitution

Prior knowledge

Students can plot ordered pairs and describe linear relationships on the Cartesian plane (from AC9M7A05). Students can solve one-variable linear equations (from AC9M7A03).

By the end

Students graph linear relations including inequalities, solve linear equations algebraically and graphically, and verify solutions by substitution.

Waypoints

  • 1. Graphing linear relations including inequalitiesHingeStudents graph linear relations of the form y = mx + b and one-variable inequalities on the Cartesian plane, identifying key features.
  • 2. Solving linear equations algebraicallyHingeStudents solve linear equations of the form ax + b = cx + d algebraically, including equations requiring expansion, and verify by substitution.
  • 3. Solving inequalities and using graphical methodsStudents solve one-variable inequalities algebraically and verify using graphical methods; represent solutions on a number line.
