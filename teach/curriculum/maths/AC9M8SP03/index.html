3D coordinate systems

AC9M8SP03 · Year 8 Maths · Space

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Descriptor

describe the position and location of objects in 3 dimensions in different ways, including using a three-dimensional coordinate system with the use of dynamic geometric software and other digital tools

Prior knowledge

Students can plot and describe positions on the Cartesian plane (from AC9M7SP03). Students understand transformations in 2D using coordinates.

By the end

Students describe positions in 3D using latitude/longitude/altitude, three-dimensional coordinates, and other spatial reference systems.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • locating aircraft/drones using latitude, longitude and altitude as a three-dimensional coordinate system
  • constructing three-dimensional objects using 3D printers or designing software that uses a three-dimensional coordinate system
  • comparing and contrasting two-dimensional and three-dimensional coordinate systems
  • using dynamic geometry software to construct shapes and objects within the first octant of a three-dimensional coordinate system
  • interpreting three-dimensional coordinate locations for objects in multi-storey car parks; playing games based on three-dimensional coordinate systems
  • exploring position and transformation through geospatial technologies used by First Nations Australians' communities

Waypoints

  • 1. Extending the coordinate system to three dimensionsHingeStudents extend the 2D Cartesian plane to three dimensions by adding a third axis (z), and plot and read coordinates in the first octant.
  • 2. Describing positions in real-world 3D systemsStudents describe positions in practical 3D reference systems including latitude/longitude/altitude and multi-storey coordinate systems.
