← AC9M8SP03 3D coordinate systems

Describing positions in real-world 3D systems

AC9M8SP03 n2 · waypoint 2 of 2 · Year 8 Maths · Space

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students describe positions in practical 3D reference systems including latitude/longitude/altitude and multi-storey coordinate systems.

Lessons on this site

  • Coordinates in 3D

Success criteria

  • Correctly describes a position using a practical 3D reference system.
  • Interprets a 3D coordinate in a real-world context.
  • Connects the three coordinates to three independent dimensions of location.

Prior knowledge

Waypoint 1: Extending the coordinate system to three dimensions.

Width

Minimum
Describe the position of an object using latitude, longitude and altitude; interpret a 3D coordinate location in a practical context.
Typical
Apply 3D coordinate systems to aircraft/drone location, multi-storey buildings, and map-based systems; connect the abstract system to familiar real-world applications.
Wider
  • Investigate how 3D printers use a three-dimensional coordinate system to build objects layer by layer — describe the relationship between the coordinate path and the physical object.
  • Explore games based on 3D coordinate systems — describe how player position and movement are represented.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify step3D spatial reasoning develops through varied practical contexts — aircraft, buildings, games, and printing all use the same underlying coordinate structure but present it very differently.
