Comparative data distributions

AC9M9ST03 · Year 9 Maths · Statistics

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Descriptor

represent the distribution of multiple data sets for numerical variables using comparative representations; compare data distributions with consideration of centre, spread and shape, and the effect of outliers on these measures

Prior knowledge

Students can analyse how sampling methods affect survey results and how representation choices support a point of view (AC9M9ST02). They have not yet formally described and compared distributions across multiple data sets using shape, centre, spread and outlier effects simultaneously.

By the end

Students represent and compare multiple data distributions considering centre, spread, shape and the effect of outliers.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • describing the shape of data distributions using terms: positive skew, negative skew, symmetric, bi-modal
  • using stem-and-leaf plots to compare 2 like sets of data; e.g. heights of girls and boys
  • constructing grouped histograms showing trends in health issues and using them to justify, verify or invalidate claims
  • exploring comparative data from the National Indigenous Australians Agency 'Closing the Gap' reports; discussing comparative distributions in context

Waypoints

  • 1. Describing distribution shapeHingeStudents can describe the shape of a data distribution using appropriate terminology (symmetric, positively skewed, negatively skewed, bimodal).
  • 2. Comparative representationsStudents can represent two or more data sets using the same comparative display type to allow direct comparison.
  • 3. Comparing distributions — centre, spread, shape, outliersStudents can compare two or more distributions considering centre, spread, shape and the effect of outliers on each measure.
