Gradient from two points

AC9M9A03 n1 · waypoint 1 of 5 · Year 9 Maths · Algebra · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can calculate the gradient of a line segment between two given points and explain why gradient is independent of which two points on the line are chosen.

Lessons on this site

  • Gradient between two points

Success criteria

  • Correctly calculates gradient (including sign) between two coordinate pairs
  • Verifies with a third point that gradient is constant along a line
  • Correctly identifies whether a gradient is positive, negative, zero or undefined from the coordinates

Prior knowledge

Students can graph linear relations on the Cartesian plane and solve linear equations (AC9M8A02). They have not yet formally derived gradient from two coordinate pairs, calculated midpoints algebraically, or applied Pythagoras' theorem to find distance between points.

Width

Minimum
Calculate the gradient of a line segment between two given coordinate pairs using rise/run; verify using a third point on the same line that the gradient is the same.
Typical
Calculate the gradient of line segments from coordinate pairs using the formula (y₂−y₁)/(x₂−x₁); verify that gradient is independent of point choice using multiple pairs; interpret gradient as a constant rate of change; identify positive, negative, zero and undefined gradients.
Wider
  • Investigate gradients in real-world contexts using superimposed images (e.g. ramps, escalators, playground equipment) — read gradient from images and connect to the linear function rule
  • Explore how gradient is used in machine learning to describe linear relationships in data (e.g. linear regression) at a conceptual level
  • Investigate how the gradient of a road or railway is expressed as a percentage or ratio and connect to the mathematical definition

Hinge

Signed gradient errors (wrong subtraction order) propagate into N2 parallel/perpendicular identification, N3 distance calculation setup, and all linear modelling in N5. Every subsequent node uses gradient as an input.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsStudents commonly confuse the sign of gradient (reading Δy/Δx in the wrong order) or treat it as always positive. Fluency with correct signed gradient across positive, negative, zero and undefined cases requires practice before gradient is used in more complex applications.
