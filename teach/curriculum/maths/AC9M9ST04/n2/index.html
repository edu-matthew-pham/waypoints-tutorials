← AC9M9ST04 Choosing data displays

Justifying and interpreting displays in context

AC9M9ST04 n2 · waypoint 2 of 2 · Year 9 Maths · Statistics

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can justify a display choice with reference to purpose and audience, and interpret key features of a display in context.

Success criteria

  • Justifies a display choice with reference to both data type and purpose/audience
  • Correctly interprets at least two features of the display in the language of the context
  • Evaluates whether the display communicates the key message clearly and fairly

Prior knowledge

Waypoint 1: Matching display type to data type.

Width

Minimum
Choose a display for a given data set and purpose; justify the choice with reference to both the data type and the audience; interpret one key feature of the display in context.
Typical
Choose and justify display types for a range of contexts, considering data type, audience and purpose; interpret displays by identifying and explaining key features (trend, centre, spread, proportion) in context; compare and interpret stacked bar charts, area charts and line graphs for part-whole and trend data.
Wider
  • Evaluate a non-standard visualisation (e.g. infographic from a news source) — assess purpose, audience and how well it communicates the statistical question
  • Use generative AI to produce display options for a data set, then critically evaluate which form is most appropriate for the intended purpose and audience
  • Investigate how stacked bar charts and area charts represent part-whole relationships and when line graphs are more appropriate for trend data

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierJustifying display choices requires integrating data type knowledge, audience awareness and purpose — not just selecting a graph type in isolation. Students who can classify data but cannot articulate why a display works for a specific audience and purpose have not reached the descriptor's full demand.
