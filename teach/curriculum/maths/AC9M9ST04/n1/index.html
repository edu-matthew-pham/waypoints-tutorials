Matching display type to data type

AC9M9ST04 n1 · waypoint 1 of 2 · Year 9 Maths · Statistics · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify the data type (categorical nominal/ordinal, numerical discrete/continuous) and select an appropriate display type.

Lessons on this site

  • The right graph for the data

Success criteria

  • Correctly classifies the data type as categorical (nominal/ordinal) or numerical (discrete/continuous)
  • Selects an appropriate display type and names it
  • Justifies the selection with reference to the data type

Prior knowledge

Students can represent and compare multiple data distributions using comparative representations (AC9M9ST03). They have not yet systematically matched display type to data type and purpose, or justified visualisation choices for a given audience and context.

Width

Minimum
Classify one data set as categorical or numerical, discrete or continuous; select and justify an appropriate display type for it.
Typical
Classify a range of data sets by type; match display types to data types (bar chart for categorical nominal, histogram for numerical continuous, dot plot or stem-and-leaf for small discrete numerical data sets); justify choices based on data type.
Wider
  • Investigate non-standard display types such as infographics and assess what data type and purpose they are suited for — evaluate one real infographic
  • Compare the same data displayed in two different but plausible formats and evaluate which communicates more effectively for the intended audience
  • Use digital tools including generative AI to produce multiple display options for the same data set and critically evaluate each

Hinge

Students who cannot classify data type (categorical vs numerical, discrete vs continuous) cannot make justified display choices in N2 — justification requires naming the data type as the reason.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents commonly apply bar charts to all categorical data and histograms to all numerical data, without distinguishing discrete vs continuous or nominal vs ordinal. Working across a range of data types — including ordinal categorical (survey scales), numerical discrete (count data) and numerical continuous (measurement data) — builds accurate discrimination.
