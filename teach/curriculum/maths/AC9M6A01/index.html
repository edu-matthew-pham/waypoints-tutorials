Growing patterns with rational numbers

AC9M6A01 · Year 6 Maths · Algebra

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Descriptor

Recognise and use rules that generate visually growing patterns and number patterns involving rational numbers

Prior knowledge

Students can recognise and explain the connection between multiplication and division as inverse operations and use this to develop families of number facts (AC9M5A01). They can find unknown values in multiplication and division equations (AC9M5A02). They have not yet described rules for growing patterns or applied pattern rules to rational number sequences.

By the end

Students can recognise and use rules that generate visually growing patterns and number patterns involving rational numbers.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • investigating patterns such as the number of tiles in a geometric pattern, or the number of dots or other shapes in successive repeats of a strip or border pattern
  • using a calculator or spreadsheet to experiment with number patterns from multiplying or dividing
  • creating extended number sequences representing additive patterns using decimals
  • investigating the number of regions created by successive folds of a sheet of paper
  • creating a pattern sequence with materials, writing the associated number sequence and describing the rule

Waypoints

  • 1. Identifying rules in number patternsHingeStudents can identify the rule governing a number pattern involving rational numbers and use it to extend the pattern.
  • 2. Visually growing patterns and their rulesStudents can describe the rule for a visually growing pattern using numbers, identify the connection between the visual structure and the number sequence, and use the rule to predict future terms.
  • 3. Generating and representing patternsStudents can create a number pattern from a given rule involving rational numbers and represent it in multiple forms (table of values, number sequence, visual pattern where applicable).
