← AC9M6A01 Growing patterns with rational numbers

Visually growing patterns and their rules

AC9M6A01 n2 · waypoint 2 of 3 · Year 6 Maths · Algebra

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can describe the rule for a visually growing pattern using numbers, identify the connection between the visual structure and the number sequence, and use the rule to predict future terms.

Success criteria

  • Student describes the rule for a visually growing pattern as a number sequence.
  • Student uses the rule to predict the number of elements in a non-adjacent term.

Prior knowledge

Waypoint 1: Identifying rules in number patterns.

Width

Minimum
Describe the growth rule for a visual pattern (e.g. tiles, dots) as a number sequence; identify how many tiles/elements are in a given term; predict the number in a later term using the rule.
Typical
Connect the visual structure of a growing pattern to the arithmetic rule generating it; express the rule in words; use the rule to predict non-adjacent terms without drawing all intermediate stages; identify both the starting value and the step size.
Wider
  • Investigate growing patterns from real contexts: number of tiles to border a square of increasing size, number of handshakes in growing groups
  • Explore patterns where the visual and numerical rules feel different but are equivalent — justify why they produce the same sequence

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkStudents often can describe what changes term-to-term but cannot articulate the underlying rule as a generalisable statement. Scaffolding the reasoning — 'what stays the same? what changes? by how much?' — bridges the gap between pattern observation and rule articulation.
