← AC9M7A05 Tables and graphs from patterns

Plotting and describing relationships on the Cartesian plane

AC9M7A05 n3 · waypoint 3 of 3 · Year 7 Maths · Algebra

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students plot ordered pairs from a table of values on the Cartesian plane and describe the resulting relationship.

Lessons on this site

  • Plotting a rule

Success criteria

  • Correctly plots ordered pairs from a table on the Cartesian plane.
  • Draws a line through plotted points for a linear relationship.
  • Describes the relationship shown in the graph using appropriate language.

Prior knowledge

Waypoint 2: Generating tables from function rules.

Width

Minimum
Plot a set of ordered pairs from a table and connect them; describe whether the relationship is linear.
Typical
Plot and describe relationships for several linear rules; identify that linear functions produce straight lines; describe slope informally.
Wider
  • Compare two functions plotted on the same axes — identify what differs (steepness, y-intercept) and connect to the rule.
  • Investigate the graphical representation of a non-linear function (e.g. y = x²) from a table — contrast with linear.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierPlotting connects the table of values, the function rule, and the Cartesian plane simultaneously. Describing the resulting graph requires coordinating all three representations.
