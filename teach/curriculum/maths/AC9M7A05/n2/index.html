Generating tables from function rules

AC9M7A05 n2 · waypoint 2 of 3 · Year 7 Maths · Algebra · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students generate a table of ordered pairs from a given function rule and identify the relationship between input and output values.

Lessons on this site

  • Tables from rules

Success criteria

  • Correctly generates a table of ordered pairs from a given function rule.
  • Labels the table with input (x) and output (y) columns.
  • Does not substitute the same value for both x and y.

Prior knowledge

Waypoint 1: Generating tables of values from patterns.

Width

Minimum
Given a simple function rule (e.g. y = 2x + 1), generate a table of at least 5 ordered pairs.
Typical
Generate tables from various linear function rules; describe the pattern in the output values; identify the effect of changing the rule.
Wider
  • Use a function machine or spreadsheet to generate tables for multiple rules and compare outputs side by side.
  • Investigate what happens to the table when the rule changes: how does doubling the coefficient change the values?

Hinge

Errors in the table of ordered pairs cascade directly into Node 3 — incorrectly generated pairs produce a graph that doesn't represent the function rule, meaning students cannot see or describe the relationship they were supposed to plot.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsSystematic generation of ordered pairs requires procedural care that students need to practise before plotting. Errors in the table cascade into errors in the graph.
