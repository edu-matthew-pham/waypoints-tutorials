Place value to 1000

AC9M2N01 n2 · waypoint 2 of 3 · Year 2 Maths · Number · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can read, write and represent three-digit numbers using materials grouped into hundreds, tens and ones, and explain the value of each digit.

Success criteria

  • Makes a given three-digit number using base-ten materials and states the value of each digit correctly
  • Writes the numeral for a set of grouped materials including at least one example with a zero digit

Prior knowledge

Waypoint 1: Counting into the hundreds.

Width

Minimum
Read, write and make a given three-digit number using base-ten materials; explain the value of each digit (e.g. the 3 in 345 means 3 hundreds = 300).
Typical
Read, write and represent a range of three-digit numbers including those with zeros in tens or ones position; explain each digit's value; match numerals to grouped materials and vice versa.
Wider
  • Collect and group a large quantity of objects (e.g. recycling items) into hundreds, tens and ones; record as a three-digit numeral and explain each group
  • Represent the same number in multiple ways using materials: e.g. 245 shown as 2 hundreds 4 tens 5 ones, and as 24 tens 5 ones — discuss why both are valid

Hinge

Students who drop or misread zero-placeholder digits (e.g. reading 305 as 35) will produce systematic ordering errors in Node 3 — they cannot correctly compare three-digit numbers if their digit-value interpretation is unreliable.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepThe meaning of each digit's positional value (especially zero as a placeholder) is a well-known misconception cluster. Representing numbers in multiple physical and symbolic forms helps students see that the digit's position — not just its face value — determines its meaning.
