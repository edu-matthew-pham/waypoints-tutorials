← AC9M6N07 Fractions, decimals and percentages

Finding a percentage of a quantity

AC9M6N07 n2 · waypoint 2 of 3 · Year 6 Maths · Number

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can find common percentages (10%, 25%, 50%, 75%, 20%) of a quantity using efficient strategies connecting percentages to fraction and decimal equivalents.

Success criteria

  • Student finds 50%, 25%, and 10% of a given quantity using a mental or written strategy.
  • Student explains the connection between the percentage and the calculation method used.

Prior knowledge

Waypoint 1: Finding a fraction of a quantity.

Width

Minimum
Find 50%, 25%, and 10% of given quantities using fraction equivalents or place value strategies; explain why 50% = ½ and 10% = divide by 10.
Typical
Find common percentages (10%, 20%, 25%, 50%, 75%, 5%, 1%) of quantities using efficient methods; build non-standard percentages from components (e.g. 15% = 10% + 5%); select digital tools for complex percentages.
Wider
  • Investigate building any percentage from 10% and 1% components — develop a mental strategy that works for any percentage
  • Compare multiple strategies for finding the same percentage and explain when each is most efficient

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents who learn percentages only as 'multiply by the decimal' often fail to recognise percentage problems in everyday contexts. Varied contexts — discounts, surveys, nutrition labels, sports statistics — build the recognition needed to identify percentage problems in unfamiliar situations.
