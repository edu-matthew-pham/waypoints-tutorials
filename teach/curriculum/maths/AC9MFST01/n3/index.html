Comparing organised data to answer a question

AC9MFST01 n3 · waypoint 3 of 3 · Foundation Maths · Statistics

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can compare organised data to answer an investigative question and explain what the data shows.

Lessons on this site

Success criteria

  • Student compares two or more categories of organised data and states which is larger or smaller
  • Student connects the comparison to the original investigative question — stating what the data shows about the question

Prior knowledge

Waypoint 2: Sorting and organising collected data.

Width

Minimum
Compare two groups of sorted data and state which is larger or smaller, connecting the comparison to the original investigative question.
Typical
Compare sorted and organised data to answer yes/no and comparison investigative questions; interpret classroom charts and simple representations; explain what the data shows in response to the question using comparative language.
Wider
  • Investigate statistical contexts from picture books (e.g. 'The Waterhole' by Graeme Base) — asking investigative questions, collecting data from the book, and comparing results to draw conclusions
  • Role-play being an industrial robot or AI system that uses sorted data to make decisions — connecting data comparison to real-world automated sorting contexts
  • Explore what First Nations Australians' environmental observations tell us — discussing how collected information can be used to answer questions about Country/Place

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkStudents commonly report what they see in the data (there are more shoes with laces) without connecting the observation back to the investigative question. The reasoning scaffold — 'the question was X; the data shows Y; so the answer is Z' — is the thinking move that makes data interpretation purposeful. This closure is the specific skill the descriptor demands.
Integration: a combining task at the wider tierAnswering an investigative question integrates question-to-data connection (node 1) and sorting/organising (node 2) into a complete statistical inquiry. The data has been collected and organised for a purpose — using it to answer the question is where those moves pay off. The full inquiry cycle (question → collect → organise → compare → answer) is the endpoint demand.
