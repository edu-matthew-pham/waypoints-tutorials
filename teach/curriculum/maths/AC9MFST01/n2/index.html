Sorting and organising collected data

AC9MFST01 n2 · waypoint 2 of 3 · Foundation Maths · Statistics · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can sort collected objects or images into categories that correspond to the investigative question.

Success criteria

  • Student sorts collected data into at least two named categories with each item in exactly one category
  • Student's organisation method makes it possible to compare the categories

Prior knowledge

Waypoint 1: Connecting a question to data collection.

Width

Minimum
Sort a collection of objects or images into two categories in response to an investigative question, naming each category.
Typical
Sort collected data (objects or images) into relevant categories; choose or use a given organising method (e.g. physical grouping, sticker chart, line of objects); create simple classroom charts or rosters using objects or stickers.
Wider
  • Sort data into more than two categories for investigative questions with multiple response options
  • Use one-to-one correspondence to line up or match objects from two categories — making the comparison visually clear
  • Explore how sorting and organising data from picture books (e.g. 'The Waterhole' by Graeme Base) can answer investigative questions

Hinge

Node 3 requires students to compare organised categories to answer the investigative question — but disorganised data (items in multiple categories, incomplete allocation) cannot be meaningfully compared. Students who cannot sort systematically produce data that is uninterpretable at node 3.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsThe physical process of sorting and organising data requires systematic allocation — each object goes in exactly one category. Students commonly create overlapping categories or re-sort mid-process. Repeated practice with the sorting process across varied investigative questions builds the systematic organisation habit.
