← AC9M5ST01 Nominal and ordinal data

Types of categorical data

AC9M5ST01 n1 · waypoint 1 of 4 · Year 5 Maths · Statistics · Hinge

Checkpoint

Students can distinguish nominal, ordinal and discrete numerical variables and explain the difference.

Success criteria

  • Student correctly classifies given variables by data type
  • Student explains the key difference between nominal and ordinal data

Prior knowledge

Students can analyse data distributions and identify patterns in many-to-one displays (AC9M4ST02). They have not yet distinguished nominal, ordinal and discrete numerical variables or calculated and interpreted mode.

Width

Minimum
Classify given variables as nominal, ordinal or discrete numerical with an explanation for each.
Typical
Classify a range of real-world variables; explain why ordinal data has order but not equal intervals; connect data type to appropriate display choices.
Wider
  • Survey how data type determines analysis choices in contexts like surveys and scientific research
  • Investigate what information is lost when ordinal data is treated as nominal

Hinge

Data type classification is required by Node 3 — students who cannot distinguish nominal from ordinal cannot select appropriate displays or justify their choices, collapsing the Mode B task.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepThe nominal/ordinal distinction is subtle and context-dependent. Multiple varied variables — some clearly nominal, some clearly ordinal, some ambiguous — help students develop the discrimination.
