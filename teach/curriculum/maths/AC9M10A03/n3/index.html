← AC9M10A03 Exponential functions

Connecting algebraic and graphical representations

AC9M10A03 n3 · waypoint 3 of 4 · Year 10 Maths · Algebra

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can move fluently between the algebraic equation and graphical representation of an exponential relation, reading key information from each form.

Success criteria

  • Student correctly identifies key graphical features (y-intercept, asymptote, growth/decay) from a given exponential equation
  • Student writes or identifies the exponential equation corresponding to a given graph

Prior knowledge

Waypoint 2: Graphical features of exponential functions.

Width

Minimum
Given an exponential equation, identify the key graphical features; given an exponential graph, write or identify the corresponding equation.
Typical
Translate between algebraic and graphical representations of exponential functions in multiple directions; use digital tools to verify connections; extract information from graphs to form equations; use equations to predict graphical features before plotting.
Wider
  • Investigate how digital tools with symbolic manipulation reveal that the same exponential relationship can be expressed in multiple equivalent algebraic forms
  • Explore the connection between the constant ratio in a table, the base in the equation, and the steepness of the graph — building a unified understanding across all three representations

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierMoving fluently between table, equation and graph is the integration goal — students who can work with each representation individually but cannot translate between them have compartmentalised rather than connected knowledge. This node is where the three representations become one coherent object.
