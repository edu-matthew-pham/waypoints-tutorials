Thousandths and beyond

AC9M5N01 n2 · waypoint 2 of 4 · Year 5 Maths · Number · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can read, write and name decimals with more than 2 decimal places, explaining the place value of each digit.

Success criteria

  • Student reads and writes a decimal to thousandths correctly
  • Student identifies the place value of each digit in a decimal with 3+ decimal places

Prior knowledge

Waypoint 1: Tenths and hundredths review.

Width

Minimum
Read, write and name a decimal to thousandths; identify the place value of each digit.
Typical
Extend the place value chart to thousandths and ten-thousandths; connect to metric contexts (e.g. kilometres, millimetres). Explain the pattern of powers of ten extending to the right.
Wider
  • Explore scientific measurement contexts requiring 4+ decimal places
  • Investigate how First Nations land measurement and navigation systems express precision differently

Hinge

The 'longer decimal = bigger number' misconception causes systematic errors in Node 3 — students who conflate decimal length with magnitude cannot compare or order decimals correctly.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepThousandths are abstract without grounding contexts. Students commonly confuse the length of a decimal with its magnitude — more decimal places perceived as bigger. Multiple concrete contexts (measurement, money, science) help resolve this.
