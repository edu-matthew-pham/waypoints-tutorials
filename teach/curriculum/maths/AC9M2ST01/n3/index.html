← AC9M2ST01 Acquire and sort categorical data

Displaying in lists and tables

AC9M2ST01 n3 · waypoint 3 of 3 · Year 2 Maths · Statistics

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can display sorted categorical data in a list or table and use it to answer questions about most/least popular categories.

Success criteria

  • Displays sorted data in a list or table
  • Correctly identifies the most and least common category from the table
  • States the total count for at least one category

Prior knowledge

Waypoint 2: Collecting and sorting into categories.

Width

Minimum
Transfer sorted data into a list or table; identify the most common and least common category.
Typical
Record data in well-organised lists and tables; use counting strategies to find totals per category; answer questions from the table (most popular, least popular, how many in a category, total respondents).
Wider
  • Compare different ways of recording the same data (list vs table vs tally); discuss which is easier to read and why
  • Investigate whether the question asked was clear enough; modify a survey question and discuss how the data collected might change
