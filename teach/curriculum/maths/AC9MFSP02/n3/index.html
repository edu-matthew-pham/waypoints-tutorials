Describing movement and location

AC9MFSP02 n3 · waypoint 3 of 3 · Foundation Maths · Space

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can describe where they have moved themselves or objects in a familiar space in relation to other objects, using positional language.

Success criteria

  • Student describes the new position of an object or themselves after movement, using positional language and a reference point
  • Student's description is specific enough for another person to identify the new location

Prior knowledge

Waypoint 2: Describing position in a familiar space.

Width

Minimum
Describe where they moved an object (or themselves) in a familiar space using at least one positional word and a reference point.
Typical
Describe movement of objects and themselves within a familiar space using positional language; give location descriptions that would allow someone else to retrace a path or find an object; connect movement descriptions to starting and ending positions.
Wider
  • Describe and follow simple positional instructions to navigate a familiar space (e.g. classroom or playground) — testing whether descriptions are sufficient for the listener
  • Explore First Nations Australians' games involving movement and spatial description within a space — describing position and movement relative to other participants and objects
  • Use positional language to describe and predict where a robotic toy will be after a movement instruction — connecting spatial reasoning to technology

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierDescribing movement integrates positional vocabulary (node 1) and static position description (node 2) into a dynamic context — students must track changing positions and describe the relationship after movement. The added complexity of movement (position is not fixed) is the integration challenge.
