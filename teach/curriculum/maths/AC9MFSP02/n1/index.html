Positional language vocabulary

AC9MFSP02 n1 · waypoint 1 of 3 · Foundation Maths · Space · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use a range of positional words correctly to describe where an object is in relation to a reference point.

Success criteria

  • Student correctly uses at least four different positional words to describe object positions in relation to a reference point
  • Student uses positional words that specify the relationship clearly enough for another person to identify the described location

Prior knowledge

Students have informal spatial vocabulary from everyday experience. They may use words like 'in', 'on' and 'next to' informally. They have not yet consistently and precisely described their own position or the position of objects in relation to a reference point.

Width

Minimum
Use at least three positional words correctly (e.g. 'in', 'on', 'under', 'next to', 'behind') to describe the position of an object.
Typical
Use a range of positional words (inside, outside, underneath, on top of, behind, in front of, next to, near, far, between) accurately to describe object positions in relation to reference points in a familiar space.
Wider
  • Explore positional language in First Nations Australians' instructive games — e.g. Thapumpan from the Wik-Mungkan Peoples — using spatial language to describe position relative to other participants
  • Use positional language to describe the position of a robotic toy in relation to classroom objects as it moves, connecting spatial vocabulary to technology contexts

Hinge

Nodes 2 and 3 require students to produce and interpret position descriptions — which are meaningless without precise positional vocabulary. Students who use vague terms ('there', 'over there') cannot give descriptions that allow a partner to locate an object, and cannot interpret descriptions given to them.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsPositional vocabulary needs to become fluent and automatic so students can use it in real-time spatial description. Students commonly confuse similar terms (in front of / behind; under / on top of) or use general words ('there', 'over there') instead of precise positional terms. Repeated use in varied, concrete placement activities builds the vocabulary precision needed.
