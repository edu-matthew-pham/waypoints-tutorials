← AC9MFSP02 Position and location

Describing position in a familiar space

AC9MFSP02 n2 · waypoint 2 of 3 · Foundation Maths · Space · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can describe the position of themselves and objects in relation to other people and objects within a familiar space.

Success criteria

  • Student describes the position of an object or themselves in a familiar space using at least one positional word and a named reference object
  • Student locates an object by following a position description given by another person

Prior knowledge

Waypoint 1: Positional language vocabulary.

Width

Minimum
Describe the position of one object in relation to another in a familiar space using positional language, and follow a position description given by someone else to find an object.
Typical
Describe the position of objects and themselves in a familiar space using multiple positional references; interpret position descriptions given by others; describe positions from different reference points (e.g. from own position, from another person's position).
Wider
  • Describe the position of objects in a familiar space well enough for a partner to find a hidden object — testing and refining the description
  • Explore First Nations Australians' instructive games involving position and movement descriptions within a space — e.g. Thapumpan from the Wik-Mungkan Peoples of Cape Bedford

Hinge

Node 3 (describing movement) requires students to describe a changing position — which depends on being able to describe a static position first. Students who cannot produce the three-component description (what / in relation to what / which word) cannot meaningfully extend to describing where something moved to.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkDescribing position requires students to identify a reference point, name the positional relationship, and specify what object is being located — three components that must be coordinated into a useful description. Students commonly omit the reference object or use vague references ('over there'). The reasoning scaffold here is: what is being located? in relation to what? using which positional word?
