← AC9M4N09 Algorithms with addition and multiplication

Represent algorithms as flowcharts

AC9M4N09 n2 · waypoint 2 of 3 · Year 4 Maths · Number · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can represent an algorithm as a flowchart using standard symbols for steps and decisions.

Success criteria

  • Students can create a basic flowchart representing an addition or multiplication algorithm
  • Students can trace a flowchart to generate the first several terms of a sequence

Prior knowledge

Waypoint 1: Follow a step-sequence algorithm.

Width

Minimum
Represent one algorithm as a basic flowchart with at least one step and one decision node; explain what each symbol represents.
Typical
Create flowcharts representing multiplication-based algorithms; use the flowchart to trace and verify sequence generation; explain how the decision node determines when to stop the sequence.
Wider
  • Represent the same algorithm in two forms (written steps and flowchart) and compare — discussing which is clearer for different purposes
  • Design a flowchart that generates multiples of a given number and test it with classmates — debugging the flowchart where the output is incorrect

Hinge

Students who cannot decompose an algorithm into sequential and conditional steps cannot meaningfully create their own algorithms in Node 3 — creation requires the same decomposition skill that following and representing flowcharts develops.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkFlowcharts require students to decompose an algorithm into explicit sequential and conditional steps. The reasoning scaffold — 'what happens at each step, and what decision is being made?' — must be made explicit before students can create their own flowcharts accurately.
