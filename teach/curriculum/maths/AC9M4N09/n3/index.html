← AC9M4N09 Algorithms with addition and multiplication

Create algorithms and identify patterns

AC9M4N09 n3 · waypoint 3 of 3 · Year 4 Maths · Number

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can create an algorithm using addition or multiplication and identify patterns in the generated sequence.

Lessons on this site

None yet.

Success criteria

  • Students can design an algorithm that generates a specified type of sequence (e.g. multiples of 4)
  • Students can identify and describe a pattern in a sequence they have generated and explain how the algorithm produces it

Prior knowledge

Waypoint 2: Represent algorithms as flowcharts.

Width

Minimum
Create one algorithm (specifying starting value and operation) to generate a number sequence; identify and describe an emerging pattern.
Typical
Create multiplication and addition algorithms; use digital tools (spreadsheets) to generate long sequences; identify patterns including multiples, geometric growth, and patterns in the ones digit; describe patterns in words and explain how the algorithm produces them.
Wider
  • Use a spreadsheet with a 'fill down' formula to generate 100 terms and investigate patterns that only become apparent over many terms (e.g. repeating units digits in multiples)
  • Create and compare algorithms that produce the same sequence through different rules, investigating whether the same pattern can have different generating algorithms
