Integers on a number line

AC9M6N01 n2 · waypoint 2 of 4 · Year 6 Maths · Number · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can locate and represent positive and negative integers on a number line, order integers including negative values, and describe the distance between integers.

Success criteria

  • Student correctly places positive and negative integers on a number line, including values between labelled intervals.
  • Student orders a set of integers including negative values from least to greatest and explains why a negative integer with larger absolute value is the lesser number.

Prior knowledge

Waypoint 1: Meaning of integers.

Width

Minimum
Place a set of positive and negative integers on a number line; identify which of two given integers is greater; state the integer that is a given number of steps from a reference point.
Typical
Order a mixed set of integers on a number line; calculate the distance between two integers (including across zero); identify the integer that sits halfway between two given integers; connect the number line representation to real-world contexts such as temperature change.
Wider
  • Represent and compare integers from multiple real-world contexts on the same number line (e.g. temperature and altitude on one line) and discuss what alignment reveals
  • Investigate open questions such as: 'Is there a largest or smallest integer?' and justify reasoning using number line structure

Hinge

The number line model is the conceptual foundation for Node 3 (Cartesian plane coordinates) and Node 4 (financial modelling). Students who cannot reliably order and place integers on a number line cannot extend to a two-axis system or interpret signed financial values.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkCrossing zero on a number line requires students to reason about direction and magnitude simultaneously. The logic of why -3 is less than -1 (further from zero in the negative direction) is not intuitive and benefits from explicit scaffold before procedural confidence develops.
Consolidation: more practise steps, short feedback loopsAccurate placement and ordering of integers on a number line requires precision — small placement errors propagate into calculation errors. Fluency with the number line representation is the foundation for all subsequent integer work.
