Comparing display types

AC9M4ST02 n1 · waypoint 1 of 2 · Year 4 Maths · Statistics

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can compare two or more data displays of the same data and identify differences in what each communicates effectively.

None yet.

Success criteria

  • Students can compare two displays of the same data and describe at least one advantage of each for a specific purpose
  • Students can suggest at least one question that can be answered by a given display

Prior knowledge

Students can create and compare different graphical representations (AC9M3ST02). They have not yet analysed the relative effectiveness of different displays or discussed distribution shape and variation.

Width

Minimum
Compare two different displays of the same dataset; identify one way each display is more or less useful for answering a particular question.
Typical
Compare student-generated and digital displays of the same data; describe similarities and differences; comment on usefulness for different questions; interpret representations from media where symbols represent one-to-many relationships.
Wider
  • Evaluate data representations from news sources or online media, asking 'what questions can this display answer?' and 'what information does it obscure or distort?'
  • Investigate how AI developers use data visualisation as a step in data preparation, connecting data analysis to real-world AI applications
