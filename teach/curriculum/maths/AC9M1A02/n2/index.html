← AC9M1A02 Repeating patterns

Abstract representation of the unit

AC9M1A02 n2 · waypoint 2 of 3 · Year 1 Maths · Algebra

Checkpoint

Students can represent the unit of repeat using letters or symbols, and connect abstract representation to the physical pattern.

Success criteria

  • Represents the unit of repeat using letters or symbols correctly.
  • Explains the connection between the letter code and the physical elements of the pattern.

Prior knowledge

Waypoint 1: Identify the unit of repeat.

Width

Minimum
Represent the unit of repeat in a given pattern using letters (e.g. SSCSC); connect the letters to the physical elements.
Typical
Represent units of repeat using letters, numbers or symbols across a variety of pattern types; explain the connection between the abstract representation and the physical pattern; use the representation to continue or predict the pattern; recognise that the same abstract pattern (e.g. ABCBA) can be realised in many physical forms.
Wider
  • Explore the abstract pattern structure of counting games from different cultures — including the repeating structure in First Nations oral and gestural number sequences — and represent the unit using letters.
  • Investigate how the same abstract pattern structure appears in different modalities (movement, sound, shape, colour) and create a pattern in one modality based on a pattern seen in another.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkAbstraction from a physical pattern to a letter-code requires students to see the pattern elements as instances of types rather than specific objects. This is an early algebraic move — scaffolding with the explicit labelling step (this is A, this is B, so the unit is AB) is the critical teaching act.
