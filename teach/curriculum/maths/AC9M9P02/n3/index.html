← AC9M9P02 Relative frequencies and compound probability

Estimating compound event probabilities from data

AC9M9P02 n3 · waypoint 3 of 3 · Year 9 Maths · Probability

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use relative frequencies from data to estimate probabilities of compound events ('and', 'or') and use these to make predictions.

Success criteria

  • Correctly calculates relative frequencies for both 'and' and 'or' compound events from the same data set
  • Uses a Venn diagram or two-way table to organise the data before calculating
  • Makes a reasonable prediction based on the estimated probability and explains the reasoning

Prior knowledge

Waypoint 2: Compound events: 'and', inclusive 'or', exclusive 'or'.

Width

Minimum
Use relative frequencies from a given data set to estimate the probability of one compound event involving 'and' and one involving 'or'.
Typical
Calculate relative frequencies for a range of compound events from given or collected data; use Venn diagrams or two-way tables as tools; use estimates to make predictions; compare estimates to theoretical probabilities where these can be calculated.
Wider
  • Design, test and refine an algorithm to calculate relative frequencies for compound events from a generated data set; evaluate reliability as the number of trials increases
  • Investigate a real survey data set with two categorical variables and calculate all four compound probabilities (A and B, A and not B, not A and B, not A and not B) — use a two-way table
  • Connect relative frequency estimates to decision-making contexts — discuss when a probability estimate is reliable enough to base a decision on

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierEstimating compound event probabilities from data integrates relative frequency calculation, compound event identification and Venn diagram/two-way table representation. Students who can do each step separately often make errors when they must identify the correct compound event region and then calculate the relative frequency for it.
