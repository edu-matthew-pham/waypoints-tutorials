← AC9M9ST02 Sampling methods and representation bias

How representation choices support a point of view

AC9M9ST02 n2 · waypoint 2 of 2 · Year 9 Maths · Statistics

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify how choices about data visualisation can be used to support a particular viewpoint and assess the strength and fairness of different representations.

Success criteria

  • Identifies at least one specific visualisation feature that could create a misleading impression
  • Explains how changing that feature would affect the viewer's interpretation
  • Assesses whether the representation fairly represents the data or is designed to support a predetermined conclusion

Prior knowledge

Waypoint 1: How sampling method affects results.

Width

Minimum
Identify one feature of a data visualisation (e.g. truncated axis, cherry-picked range) that makes the data appear to support a particular conclusion; explain how changing this feature would change the impression.
Typical
Analyse multiple data visualisations (including infographics) for features that could be used to mislead or emphasise a particular point of view; identify strengths, weaknesses and possible biases; discuss how the same data could be presented differently to support a different viewpoint.
Wider
  • Compare two visualisations presenting the same data with different design choices — evaluate which more accurately represents the data and why
  • Investigate how infographics in media selectively use data to support arguments — find a real example and critically analyse it
  • Explore how statistical visualisation choices affect public opinion on policy issues (e.g. climate data, health statistics) — discuss the ethical implications of misleading visualisation

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents commonly identify only the most obvious manipulation (truncated axis) but miss subtler choices (selective time range, inappropriate graph type, misleading scale). Analysing visualisations from multiple real media sources surfaces a range of techniques and builds genuine visual literacy.
