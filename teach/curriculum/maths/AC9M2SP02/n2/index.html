← AC9M2SP02 Locate positions in 2D space

Following directional pathways

AC9M2SP02 n2 · waypoint 2 of 3 · Year 2 Maths · Space

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can follow a set of directional instructions (including forward, backward, left, right, and fractional turns) to move through a grid or map.

None yet.

Success criteria

  • Follows a set of movement instructions to reach a target position on a grid
  • Identifies and corrects an error in a given set of instructions that leads to the wrong position

Prior knowledge

Waypoint 1: Interpreting 2D representations.

Width

Minimum
Follow at least three movement instructions to move from one position to another on a grid.
Typical
Follow movement instructions on a 4×4 grid or floor mat (forward, turns, backward) to reach a target; use a robotic toy to follow a path on a street scene mat; adjust instructions as needed.
Wider
  • Move through a 2D maze using directional language: clockwise, anticlockwise, quarter turn, take the path to the right
  • Follow and create instructions for a robotic toy on a floor map; verify the path and adjust instructions when the robot doesn't reach the target

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepConnecting directional language to 2D representation is a spatial reasoning challenge — students need to interpret their position relative to the map, not just their physical orientation. Multiple grid and map contexts (floor mat, screen, paper) help build this perspective-taking.
