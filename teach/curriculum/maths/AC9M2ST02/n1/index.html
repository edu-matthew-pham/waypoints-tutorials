← AC9M2ST02 Compare graphical representations

Creating a second representation

AC9M2ST02 n1 · waypoint 1 of 2 · Year 2 Maths · Statistics · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can represent the same dataset in two different ways (e.g. picture graph and column graph) and confirm both show the same data.

Success criteria

  • Creates two different representations of the same dataset
  • Confirms both representations show the same value for each category

Prior knowledge

Students represent and compare data using picture graphs and simple tables (AC9M1ST02). They have not yet created multiple different graphical representations of the same dataset or compared their common and distinctive features.

Width

Minimum
Create two different representations of the same small dataset; confirm both show the same totals for each category.
Typical
Create two different graphical representations (from: picture graph, column graph, dot plot, tally chart, list); use digital tools where appropriate; confirm both represent the same data; add appropriate titles and category labels.
Wider
  • Use digital tools including AI to create picture graphs with one-to-one correspondence; decide on appropriate title and whether categories suit the context
  • Represent country-of-birth data for the class using two different representations; compare and discuss

Hinge

Node 2 comparison is structurally impossible without two complete representations of the same dataset. Students who cannot produce the second representation cannot engage with the comparison at all.
