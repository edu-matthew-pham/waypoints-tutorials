Representing and solving

AC9M2N06 n2 · waypoint 2 of 3 · Year 2 Maths · Number

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can represent a practical problem using a diagram, number sentence or materials, choose a calculation strategy, and find the answer.

Success criteria

  • Represents a practical problem with a diagram or number sentence
  • Selects and applies a calculation strategy to find the answer

Prior knowledge

Waypoint 1: Identifying the operation.

Width

Minimum
Represent one practical problem with a diagram or number sentence; select a strategy; calculate the answer.
Typical
Represent a range of practical problems including money transactions using diagrams, number sentences and calculation strategies; select appropriate strategies for the numbers involved; record working.
Wider
  • Model simple money problems with whole dollar amounts using addition, subtraction, multiplication or division: e.g. class contribution problems, purchasing scenarios
  • Model equal grouping/sharing problems with real contexts: team sizes, food distribution; decide what to do with remainders and justify the decision
  • Model 'How many days left in this year?' by identifying days remaining in the current month and adding remaining full months using a calendar

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyStudents need exposure to a range of practical problem types — money, days, teams, food — to build a repertoire of contexts they can model. Each new context type strengthens transfer of the modelling process.
