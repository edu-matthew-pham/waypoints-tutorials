Classifying by number of sides

AC9M2SP01 n2 · waypoint 2 of 3 · Year 2 Maths · Space

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can sort and classify a collection of shapes by number of sides, including identifying and naming triangles, quadrilaterals, pentagons and hexagons.

Success criteria

  • Sorts a collection of shapes by number of sides correctly
  • Names triangles (3 sides) and quadrilaterals (4 sides) accurately

Prior knowledge

Waypoint 1: Spatial terms for shape features.

Width

Minimum
Sort a set of shapes into groups by number of sides; correctly count sides for each shape.
Typical
Sort and classify shapes by number of sides; name common polygons (triangle, quadrilateral, pentagon, hexagon); explain the classification rule; sort in different ways (e.g. by number of sides, by whether all sides are equal).
Wider
  • Sort triangles and other polygons into subgroups; discuss how a triangle can have different side lengths and angles but is always a triangle
  • Sort quadrilaterals by properties: some have all equal sides, some have parallel opposite sides — investigate which quadrilaterals have both
