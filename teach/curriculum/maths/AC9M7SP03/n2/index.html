← AC9M7SP03 Transformations on the Cartesian plane

Reflections on axes

AC9M7SP03 n2 · waypoint 2 of 3 · Year 7 Maths · Space

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students reflect a set of points on the x-axis and y-axis and describe the transformation using coordinate rules.

Success criteria

  • Correctly reflects a set of points across the x-axis and y-axis.
  • States the coordinate rule for each reflection.
  • Does not confuse which coordinate negates for each axis.

Prior knowledge

Waypoint 1: Translations using coordinates.

Width

Minimum
Reflect a simple shape on the x-axis and y-axis; record the new coordinates and state the coordinate rule.
Typical
Apply reflections on both axes; identify the coordinate rule for each; describe patterns in how coordinates change.
Wider
  • Investigate reflections on other lines of symmetry (e.g. y = x) and what happens to coordinates.
  • Create symmetric patterns by reflecting across both axes and explore rotational symmetry emerging from double reflection.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents often correctly apply the x-axis rule (negate y) but confuse it for y-axis (negate x). Seeing both reflections in close sequence across multiple figures consolidates the distinction.
