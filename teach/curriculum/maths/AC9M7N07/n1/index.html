Comparing and ordering integers

AC9M7N07 n1 · waypoint 1 of 2 · Year 7 Maths · Number · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students compare and order integers using less-than and greater-than notation, including negative integers.

Lessons on this site

  • Comparing integers

Success criteria

  • Correctly orders a set of integers including negatives.
  • Uses < and > notation correctly between integers.
  • Does not confuse the magnitude of a negative with its value (e.g. understands −10 < −1).

Prior knowledge

Students can locate integers on a number line and recognise negative integers in context (from AC9M6N01). Students understand magnitude and direction in simple contexts (above/below zero, gain/loss).

Width

Minimum
Order a given set of integers (including negatives) from least to greatest and use <, > notation to compare pairs.
Typical
Place a mixed set of integers on a number line; use inequality notation in expressions; explain why −7 < −2.
Wider
  • Investigate absolute value informally: distance from zero on a number line. Compare |−7| and |2| without formal notation.
  • Connect ordering to real contexts: temperature below zero, sea level, financial debt.

Hinge

The magnitude-vs-direction confusion (believing −7 > −2) produces systematic errors in Node 2 addition and subtraction — students who cannot correctly order integers cannot set up or check integer calculations.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents commonly believe −7 > −2 because 7 > 2. Multiple real-world contexts (temperature, floors below ground, financial loss) help resolve the magnitude vs direction confusion.
