Comparing distributions

AC9M10ST02 n3 · waypoint 3 of 3 · Year 10 Maths · Statistics

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can compare two or more distributions using boxplots, describing similarities and differences in centre, spread, shape and outliers in context.

Lessons on this site

  • Comparing with boxplots

Success criteria

  • Student compares two distributions using boxplots, commenting on centre, spread, shape and outliers with context-appropriate language
  • Student explains what the distributional difference reveals about the underlying context

Prior knowledge

Waypoint 2: Constructing and interpreting boxplots.

Width

Minimum
Compare two distributions using side-by-side boxplots; describe at least two differences in terms of centre and spread using context-appropriate language.
Typical
Compare multiple distributions using boxplots and other displays (histograms, dot plots, cumulative frequency graphs); describe shape (symmetry, skew, modality); discuss what the shape reveals about the data-generating process; use digital tools to explore different display types for the same data; evaluate which display best addresses a given question.
Wider
  • Compare the distribution shapes of the same variable across different subgroups (e.g. performance across different schools, biological measurements across different species) and discuss what the comparison reveals
  • Investigate how the same data appears very different on different display types (boxplot, histogram, dot plot) and evaluate which display answers a given statistical question most effectively

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepDescribing distribution shape (symmetric, skewed, bimodal) requires seeing these shapes in varied contexts — biological data is often right-skewed, social data often bimodal. Multiple data contexts build the shape-recognition vocabulary and connect shape to real-world phenomena.
Integration: a combining task at the wider tierDistribution comparison integrates five-number summary knowledge (node 1), boxplot construction and reading (node 2), and contextual interpretation into the full statistical comparison act. It is the endpoint of this descriptor's learning progression.
