Addition and subtraction as inverse operations

AC9M3A01 · Year 3 Maths · Algebra

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Descriptor

recognise and explain the connection between addition and subtraction as inverse operations, apply to partition numbers and find unknown values in number sentences

Prior knowledge

Students can recognise, describe and create additive patterns using numbers, shapes and objects; identify missing elements in sequences (AC9M2A01). They have not yet formally articulated the inverse relationship between addition and subtraction or applied it to find unknowns in number sentences.

By the end

Students recognise and explain that addition and subtraction are inverse operations, and apply this to partition numbers and find unknown values in number sentences.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • partitioning numbers using materials, part-part-whole diagrams or bar models and recording all related addition and subtraction facts
  • using the inverse relationship between addition and subtraction to find unknown values in number sentences
  • exploring First Nations Australians' stories and dances that show the connection between addition and subtraction, representing this as a number sentence

Waypoints

  • 1. Inverse relationshipHingeStudents can explain, using a part-part-whole model or bar model, why addition and subtraction are inverse operations.
  • 2. Partitioning using inverse operationsStudents can use the inverse relationship to partition numbers in multiple ways and record all related facts.
  • 3. Finding unknowns in number sentencesHingeStudents can find the unknown value in addition and subtraction number sentences using the inverse operation.
