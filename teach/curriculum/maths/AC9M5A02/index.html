Unknown values in multiplication equations

AC9M5A02 · Year 5 Maths · Algebra

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Descriptor

Find unknown values in numerical equations involving multiplication and division using the properties of numbers and operations

Prior knowledge

Students can find unknown values in equations involving addition and subtraction (AC9M4A02). They have not yet applied properties of multiplication and division (commutativity, associativity, equivalence) to find unknown values.

By the end

Students find unknown values in numerical equations involving multiplication and division using properties of numbers and operations.

Waypoints

  • 1. Properties of multiplicationStudents can demonstrate that multiplication is commutative and associative, and that division is neither.
  • 2. Equivalent number sentencesHingeStudents can use equivalence and number properties to determine whether multiplication/division equations are true and to find unknown values.
