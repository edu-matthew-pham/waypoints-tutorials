← AC9M5A02 Unknown values in multiplication equations

Equivalent number sentences

AC9M5A02 n2 · waypoint 2 of 3 · Year 5 Maths · Algebra · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use equivalence and number properties to determine whether multiplication/division equations are true and to find unknown values.

None yet.

Success criteria

  • Student determines whether an equation is true/false with correct reasoning
  • Student finds an unknown value in a multiplication/division equation using properties

Prior knowledge

Waypoint 1: Properties of multiplication.

Width

Minimum
Determine whether a given multiplication/division equation is true or false; explain the reasoning.
Typical
Apply relational thinking to find unknown values in equations like 3×5=30÷□; use equivalence reasoning across a range of structures.
Wider
  • Create equivalent number sentences using multiple operations
  • Use equations with unknowns in both sides: 4×□ = □×6

Hinge

Relational understanding of = is the prerequisite for Node 3 — students who treat = as 'write the answer' cannot formulate or verify equations arising from practical contexts.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkRelational thinking (understanding = as 'same value', not 'write the answer') requires an explicit scaffold. Students who have learned = as an answer prompt make systematic errors with balanced equations.
Context breadth: more contexts in the vary or modify stepThe variety of equation structures (unknown in different positions, multiple unknowns, cross-operation equivalence) exposes how relational thinking generalises. Breadth prevents students from learning the structure of one template.
