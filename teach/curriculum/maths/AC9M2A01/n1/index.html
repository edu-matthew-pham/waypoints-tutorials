← AC9M2A01 Additive patterns

Recognising the constant term

AC9M2A01 n1 · waypoint 1 of 3 · Year 2 Maths · Algebra · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify the constant amount being added or subtracted in a given additive pattern and describe it.

Success criteria

  • Identifies the constant term in an additive pattern (e.g. 'adds 2 each time')
  • Distinguishes between an increasing and a decreasing additive pattern

Prior knowledge

Students recognise, continue and create simple repeating patterns with shapes and objects, and skip count in sequences (AC9M1A01, AC9M1A02). They have not yet described the constant additive term in a growing/shrinking pattern or used it to find missing elements.

Width

Minimum
Examine a given additive number pattern; state the constant term (e.g. 'add 2 each time' or 'subtract 3 each time').
Typical
Identify the constant term in additive patterns presented as number sequences, shape sequences and object arrangements; describe the pattern in words; recognise patterns increasing and decreasing.
Wider
  • Recognise additive patterns in the built environment (windows per carriage, wheels per car); record results in a table and state the constant term
  • Recognise additive patterns in First Nations Australians' material culture on Country/Place; represent using drawings, counters and numbers and describe the constant term

Hinge

If students can only identify the constant term in number sequences but not in shape or object arrangements, Nodes 2 and 3 are brittle — creating patterns in non-numeric forms and finding missing elements in varied representations both depend on a generalised constant-term concept.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents may recognise the constant term in simple number sequences but fail to identify it in shape or object arrangements, or in decreasing patterns. Multiple context types are needed to build a generalised understanding of 'constant additive term' independent of representation.
