← AC9M10ST04 Two-way tables and categorical relationships

Using proportions to identify patterns

AC9M10ST04 n2 · waypoint 2 of 3 · Year 10 Maths · Statistics · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can calculate row or column proportions (or percentages) from a two-way table and use them to identify patterns across categories.

Lessons on this site

  • Row or column percentages

Success criteria

  • Student calculates row or column proportions correctly for a given two-way table
  • Student explains why proportions are more useful than raw counts for comparing categories of different sizes

Prior knowledge

Waypoint 1: Constructing two-way tables.

Width

Minimum
Calculate row or column percentages for a given two-way table; identify one pattern suggested by comparing proportions across categories.
Typical
Calculate and interpret row proportions and column proportions for a two-way table; explain why proportions are more informative than raw counts when row/column sizes differ; identify patterns and associations by comparing conditional distributions across categories.
Wider
  • Investigate survey responses using five-point Likert scales across two categories of respondents (e.g. junior vs senior students); use proportions to compare response patterns and discuss what the comparison reveals
  • Explore how two-way tables connect to conditional probability — P(response | group) is the conditional distribution, linking statistics to the probability work in AC9M10P01

Hinge

Using the wrong conditional direction (row vs column proportions) in N2 produces a fundamentally incorrect reading of the two-way table — N3 discussion of possible relationships is invalidated if the proportional comparison is pointed the wrong way.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkDeciding whether to use row or column proportions requires explicit reasoning about which variable is being conditioned on. Students frequently use the wrong conditional direction — a systematic process for deciding is needed.
