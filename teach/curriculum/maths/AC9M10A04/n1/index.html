Selecting the appropriate model

AC9M10A04 n1 · waypoint 1 of 3 · Year 10 Maths · Algebra · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can determine whether a given growth or decay situation is best modelled as linear, quadratic or exponential by analysing the pattern of change.

Lessons on this site

  • Which model?

Success criteria

  • Student correctly classifies a relationship from a table using the appropriate pattern (difference or ratio)
  • Student justifies the classification by showing the relevant constant pattern in the data

Prior knowledge

Students can connect algebraic and graphical representations of exponential relations and solve exponential equations (AC9M10A03). They have not yet chosen between linear, quadratic and exponential models for a given applied context, nor evaluated and modified models, nor reported assumptions and findings in a full modelling cycle.

Width

Minimum
Classify a relationship as linear, quadratic or exponential using a table of values (constant first difference, constant second difference, constant ratio); justify the classification.
Typical
Use first differences, second differences and ratios to classify relationships; connect the classification to the appropriate equation form; recognise when contextual descriptions (constant rate, constant percentage change) indicate a model type without needing a table.
Wider
  • Compare multiple representations of the same situation (table, graph, verbal description) and classify the model from each, checking for consistency
  • Investigate edge cases where the model type is not immediately clear (e.g. growth that starts linear but becomes exponential) and discuss the limitations of simple classification

Hinge

Incorrect model selection at N1 means the wrong equation is formulated in N2 — the entire modelling output is invalid if the model type is misidentified.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents who practise model selection on obvious cases (doubling = exponential, flat rate = linear) fail when the context is ambiguous or described verbally rather than in a table. Multiple context types — financial, biological, physical — build reliable classification.
