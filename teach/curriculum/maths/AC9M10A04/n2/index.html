← AC9M10A04 Model growth and decay

Formulating and applying the model

AC9M10A04 n2 · waypoint 2 of 3 · Year 10 Maths · Algebra

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can write an equation for a growth or decay model from a described context and use it to answer questions about the situation.

Success criteria

  • Student writes a correct exponential model equation identifying initial value and growth/decay factor from a described context
  • Student uses the equation to calculate a specified value and states it in context-appropriate units

Prior knowledge

Waypoint 1: Selecting the appropriate model.

Width

Minimum
Write an exponential growth or decay equation from a described context (stating initial value and growth/decay factor); use the equation to calculate a value at a specified time.
Typical
Formulate linear, quadratic and exponential models from contextual descriptions; calculate key values (e.g. population at a given time, balance after n periods); determine doubling time or half-life for exponential models; model compound interest using authentic rates.
Wider
  • Investigate and formulate exponential equations for population growth of native animals on Country/Place with varying reproductive behaviour, discussing what the model's parameters represent ecologically
  • Model compound interest scenarios using authentic Australian interest rate data; compare compound and simple interest growth over time

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkSetting up exponential models from verbal descriptions requires explicit scaffolding — students need a clear process for identifying initial value, growth factor (from percentage change), and time variable before they can write the equation reliably.
