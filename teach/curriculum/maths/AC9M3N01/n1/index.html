Place value to ten-thousands

AC9M3N01 n1 · waypoint 1 of 4 · Year 3 Maths · Number · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify the value of each digit in a five-digit number, naming the ten-thousands place.

Success criteria

  • Students can state the value of a specified digit in any five-digit number (e.g. the digit 4 in 24 381 is worth 4000).
  • Students can correctly partition a five-digit number into its place value components.

Prior knowledge

Students can recognise, represent and order numbers to at least 1000 using physical and virtual materials, numerals and number lines (AC9M2N01). They have not yet worked with numbers beyond the thousands range, or applied naming and writing conventions to numbers in the ten-thousands and beyond.

Width

Minimum
Identify place value of each digit in a given five-digit number using a place value chart.
Typical
Represent five-digit numbers using physical or virtual materials (MAB/base-ten blocks); identify and state the value of any digit in a five-digit number.
Wider
  • Explore numbers up to 100 000, extending place value understanding across six-digit numbers
  • Compare First Nations Australian counting and number systems with the Hindu-Arabic place value system, examining structural differences

Hinge

Place value understanding of five-digit numbers is the prerequisite for all downstream nodes — naming conventions (Node 2), number line placement (Node 3) and ordering (Node 4) all require students to correctly identify digit values. Students who have not resolved the extension pattern will produce systematic errors in every subsequent node.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents often over-rely on the ones/tens/hundreds pattern and struggle to extend the logic to ten-thousands. Encountering the pattern across multiple five-digit numbers — including those with internal zeros — helps resolve this rather than re-explaining the same example.
