← AC9M10ST05 Statistical investigations with bivariate data

Collecting, displaying and describing bivariate data

AC9M10ST05 n2 · waypoint 2 of 3 · Year 10 Maths · Statistics

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can collect or access bivariate data, display it using an appropriate graph, and describe the initial visual pattern.

Success criteria

  • Student produces an appropriate display for the bivariate data collected
  • Student describes the initial pattern using association vocabulary appropriate to the data type

Prior knowledge

Waypoint 1: Formulating bivariate investigation questions.

Width

Minimum
Collect or access a bivariate data set; display it in a scatterplot or two-way table as appropriate; describe the initial visual pattern using association vocabulary.
Typical
Collect bivariate data through observation, experiment or secondary sources; display using appropriate graphs (scatterplot for numerical, two-way table for categorical); describe association in terms of strength, direction and linearity; identify potential outliers or unusual features in the display.
Wider
  • Investigate biodiversity changes in Australia before and after colonisation by comparing relevant bivariate data sets; discuss data provenance and how the historical context affects interpretation
  • Access and use secondary data sets for a real bivariate investigation (e.g. climate data, health data, ecological data) and evaluate the quality and representativeness of the data

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepData collection for bivariate investigations varies substantially across methods — observational, experimental, and secondary source data each involve different quality considerations and display choices.
