← AC9M7A06 Manipulate formulas

Describing effects of variation across multiple variables

AC9M7A06 n2 · waypoint 2 of 2 · Year 7 Maths · Algebra

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students describe how changing each variable in a multi-variable formula affects the output, and identify which variables have the greatest effect.

Lessons on this site

  • Changing one thing at a time

Success criteria

  • Correctly describes the effect of changing each variable on the output.
  • Identifies which variable produces the largest change in output for an equal proportional variation.
  • Uses digital tool output systematically rather than performing isolated calculations.

Prior knowledge

Waypoint 1: Systematic variation of one variable.

Width

Minimum
Compare the effect of equal proportional changes in two different variables on the output of a formula.
Typical
Analyse a real formula (e.g. distance = speed × time; volume of a prism) and describe which variable has the most/least impact on the output for a given change.
Wider
  • Explore parameter variation in formulas used in machine learning or AI contexts (as described in elaborations) — model the concept of tuning parameters.
  • Investigate the formula for compound scenarios: if both speed and time double, what happens to distance? Connect to proportional reasoning.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepComparing the effect of variables requires varied formula contexts to develop generalised understanding. Students who only explore one formula see the pattern as context-specific rather than a feature of multi-variable relationships.
