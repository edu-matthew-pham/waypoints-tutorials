Systematic variation of one variable

AC9M7A06 n1 · waypoint 1 of 2 · Year 7 Maths · Algebra · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students vary one variable in a formula while holding others constant, and describe the effect on the output.

Lessons on this site

  • Changing one thing at a time

Success criteria

  • Correctly varies one variable while holding others constant.
  • Describes the effect of the variation on the output in words.
  • Uses a table or digital tool to organise the systematic variation.

Prior knowledge

Students can substitute values into formulas and generate tables of values (from AC9M7A01, AC9M7A05). Students have used digital tools for calculation.

Width

Minimum
Using a spreadsheet or table, vary one variable in a simple formula (e.g. V = l × w × h, vary h) and describe the effect on V.
Typical
Systematically vary each variable in turn in a multi-variable formula; describe the relationship between each variable and the output.
Wider
  • Investigate formulas where the output changes non-linearly with one variable (e.g. area of a square vs side length) — describe the difference.
  • Use spreadsheet formula functions to automate systematic variation across a range of values.

Hinge

Students who vary multiple variables simultaneously in Node 1 cannot describe the effect of any single variable — this blocks Node 2, where comparing the effect of different variables requires having isolated each one first.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkSystematic variation requires the explicit strategy of holding all variables constant except one. Students without this scaffold vary multiple things simultaneously and cannot isolate the effect of each variable.
