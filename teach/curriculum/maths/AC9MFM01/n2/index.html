← AC9MFM01 Measurement attributes

Direct comparison of a single attribute

AC9MFM01 n2 · waypoint 2 of 3 · Foundation Maths · Measurement · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can directly compare two objects or events on a single measurement attribute and state which has more or less of that attribute.

Success criteria

  • Student performs a direct comparison using an appropriate strategy for the attribute (e.g. lines up objects for length, hefts for mass)
  • Student states which object has more or less of the attribute and demonstrates or explains how they know

Prior knowledge

Waypoint 1: Naming measurement attributes.

Width

Minimum
Directly compare two objects on one attribute (length or mass), state which has more of that attribute, and demonstrate or explain how they know.
Typical
Directly compare pairs of objects on each of the four measurement attributes; use direct comparison strategies (lining up bases for length, hefting for mass, filling for capacity, starting at the same time for duration); justify comparisons using attribute language.
Wider
  • Compare the same pair of objects on two different attributes (e.g. which is longer AND which is heavier) and discuss how different attributes give different information about the same object
  • Compare objects from the kitchen pantry, classroom or natural environment — including objects found on Country/Place — on a chosen attribute, communicating reasoning

Hinge

Node 3 demands that students communicate reasoning about comparisons — but that reasoning can only be articulated if the comparison itself was performed correctly and on the right attribute. Students who habitually compare the wrong attribute, or who lack physical comparison technique, cannot produce valid reasoning at node 3.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepA common error is comparing the wrong attribute — e.g. comparing the colour or general size of an object rather than the specified attribute. Comparing across many pairs of objects, with the attribute named explicitly, helps students focus on the attribute rather than a general sense of 'bigger'. Different attribute types (length vs mass vs capacity) all require this focus shift.
Consolidation: more practise steps, short feedback loopsDirect comparison requires physical manipulation and careful alignment or measurement technique (e.g. lining up bases). Students need repeated practice with the physical comparison process before they can reliably demonstrate reasoning.
