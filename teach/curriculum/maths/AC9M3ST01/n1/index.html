Categorical and numerical variables

AC9M3ST01 n1 · waypoint 1 of 2 · Year 3 Maths · Statistics · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can distinguish between categorical and discrete numerical variables and identify each in a given investigation context.

Success criteria

  • Students can classify a variable as categorical or discrete numerical and justify the classification.
  • Students can give an example of each variable type from everyday contexts.

Prior knowledge

Students can create different graphical representations using software and compare representations of data (AC9M2ST02). They have not yet explicitly acquired data through observation and collection for named variable types, or used frequency tables as a systematic recording method.

Width

Minimum
Given two example investigations, identify whether the variable is categorical or discrete numerical and explain the difference.
Typical
Identify the variable type in a range of investigation contexts; explain what values the variable could take; propose questions of interest for each variable type.
Wider
  • Explore how the same real-world phenomenon can be measured as either categorical or numerical depending on the question asked (e.g. 'What colour is your hair?' vs 'How many siblings do you have?')
  • Investigate how variable type determines which graphical representations are appropriate

Hinge

Variable type identification is a prerequisite for Node 2 (appropriate recording method) and AC9M3ST02 (selecting appropriate graph types) — students who cannot classify variables will choose inappropriate recording and representation methods, undermining the entire investigation.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkThe categorical/numerical distinction requires a conceptual framework — it is not intuitively obvious. Explicit scaffolding of 'what type of values does this variable take?' provides the decision procedure students need.
