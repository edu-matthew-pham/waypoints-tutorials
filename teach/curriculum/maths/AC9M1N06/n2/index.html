← AC9M1N06 Model sharing and grouping

Represent with materials and diagrams

AC9M1N06 n2 · waypoint 2 of 3 · Year 1 Maths · Number · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can model an equal sharing or grouping situation using physical materials, a drawing and a number recording, explaining the connections between each.

Lessons on this site

None yet.

Success criteria

  • Produces a physical or drawn representation that correctly shows the equal groups.
  • Records the result as a number and confirms that all groups are equal.

Prior knowledge

Waypoint 1: Distinguish sharing from grouping.

Width

Minimum
Model one sharing or grouping problem using physical materials; draw a picture to represent the action; record the result as a number.
Typical
Model sharing and grouping situations using physical materials and diagrams; include money contexts (sharing coins equally between recipients); use subitising and counting to verify equal groups; draw representations showing the groups clearly; record results.
Wider
  • Represent the same sharing problem using three formats — physical objects, array diagram, number sentence — and explain which representation makes the equal-groups structure most visible.
  • Model sharing problems with coin collections, sorting by denomination and verifying equal amounts using counting and subitising.

Hinge

If students cannot represent a sharing or grouping action as a diagram or number record, they cannot apply a calculation strategy in Node 3 — the representation is the bridge between the concrete action and the symbolic solution.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkThe 'dealing' action students use to share physically does not automatically translate to a diagram or number recording. Explicitly scaffolding the move from action to picture to number is the key teaching investment at this node.
