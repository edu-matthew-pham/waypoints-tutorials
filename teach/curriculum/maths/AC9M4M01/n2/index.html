← AC9M4M01 Measure with scaled instruments

Measurement across multiple attributes

AC9M4M01 n2 · waypoint 2 of 2 · Year 4 Maths · Measurement

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can measure and compare across all five attributes using appropriate instruments and units, recording measures with decimal notation where appropriate.

Success criteria

  • Students can select and use an appropriate scaled instrument and unit for a given measurement task
  • Students can record a measurement in decimal notation where the value falls between whole units

Prior knowledge

Waypoint 1: Reading between the marks.

Width

Minimum
Measure one object or event using a scaled instrument for at least two different attributes; record with appropriate units.
Typical
Measure length, mass, capacity, temperature and duration using scaled instruments; select the appropriate instrument and unit for each attribute; record measures using decimal notation (e.g. 5.25 m, 2.5 kg, 28.5°C); compare measurements made with different instruments.
Wider
  • Investigate how First Nations Ranger Groups and other groups use scaled instruments to monitor and care for Country/Place — comparing traditional and contemporary measurement tools for environmental monitoring
  • Design and conduct a measurement investigation requiring at least three different attributes (e.g. measuring conditions for a plant growth experiment), explaining why each instrument and unit was selected
