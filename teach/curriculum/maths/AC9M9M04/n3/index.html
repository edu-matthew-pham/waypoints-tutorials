Percentage error

AC9M9M04 n3 · waypoint 3 of 3 · Year 9 Maths · Measurement

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Checkpoint

Students can calculate and interpret percentage error, using absolute value where appropriate.

  • Percentage error

Success criteria

  • Correctly calculates percentage error using the formula (|measured − exact| / exact) × 100
  • States the percentage error with % units and explains what it means
  • Identifies at least one context where using absolute value in the formula is important

Prior knowledge

Waypoint 2: Absolute and relative error.

Width

Minimum
Calculate the percentage error for one measurement; explain what the percentage error value means in the context of the problem.
Typical
Calculate percentage errors across a range of practical contexts (attendance estimates, budget variances, scientific measurements); apply the absolute value formula for percentage error; discuss when using absolute value is appropriate and when direction of error matters.
Wider
  • Investigate percentage error in budget or planning contexts — explore whether overestimating or underestimating has different consequences in specific situations
  • Connect percentage error to the concept of percentage change — identify the structural similarity and the key difference
  • Investigate how recommendation systems and regression models report percentage error (MAPE) and discuss what a given MAPE value means for prediction quality

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents often apply percentage error correctly in one context but fail to generalise — particularly around when absolute value is needed. Working across contexts where the direction of error matters differently resolves this and builds transferable application.
