Measurement error

AC9M9M04 · Year 9 Maths · Measurement

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Maths: treat it as a starting suggestion and check it before use.

Descriptor

calculate and interpret absolute, relative and percentage errors in measurements, recognising that all measurements are estimates

Prior knowledge

Students can represent and operate with very large and very small values in scientific notation (AC9M9M02). They have not yet formally distinguished between absolute error, relative error and percentage error, or applied these to interpret measurement accuracy.

By the end

Students calculate and interpret absolute, relative and percentage errors in measurements, recognising that all measurements are estimates.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • investigating error as a percentage of the exact value
  • using absolute value in a percentage error formula; considering when to use absolute value depending on context
  • calculating percentage errors in expected budgets versus actual expenditure
  • estimating the accuracy of measurements in practical contexts and giving suitable lower and upper bounds
  • investigating how absolute, relative and percentage errors relate to AI systems such as regression models and recommendation systems

Waypoints

  • 1. All measurements are estimatesHingeStudents can explain why all measurements are estimates and identify lower and upper bounds for a given measurement.
  • 2. Absolute and relative errorStudents can calculate and distinguish absolute error and relative error for a measurement.
  • 3. Percentage errorStudents can calculate and interpret percentage error, using absolute value where appropriate.
