Planning and selecting tools for a task

AC9TDI6P07 n1 · waypoint 1 of 3 · Years 5–6 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can plan achievable steps and timeframes for a task and identify which digital tools are needed at each step

Success criteria

  • Lists steps for the task with realistic timeframes
  • Identifies at least one appropriate digital tool for each step with a reason

Prior knowledge

Students can use the core features of common digital tools to create, locate and communicate content, following agreed conventions (AC9TDI4P06). They have used digital tools with provided guidance. They have not yet selected tools themselves — the shift is from using a nominated tool to choosing the appropriate one for a task.

Width

Minimum
For a given task, list the steps needed and identify at least one digital tool for each step
Typical
Create a plan with achievable steps and realistic timeframes for producing a digital solution; identify the specific tools needed for each stage (e.g. word processor for report, spreadsheet for data, presentation tool for communication); explain why each tool suits its step
Wider
  • Plan a school recycling report that requires multiple tools at different stages — search tools for data, a spreadsheet for analysis, a word processor for writing, and a presentation tool for sharing — identifying where the output of one tool becomes the input of the next
  • Develop a plan for a collaborative spreadsheet to cost a school celebration — identifying which features (shared editing, formulas, tagging) make it the appropriate tool for this task

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkTool selection is a reasoning task — students must work backwards from what the task requires to which tool's features match those requirements. Scaffolding the selection reasoning (what does this step produce? → what tool produces that format?) prevents students defaulting to the one tool they know.
