Applying data structures

AC9TDI10P09 n1 · waypoint 1 of 5 · Years 9–10 Digital Technologies (processes) · Processes and production skills · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can select and use appropriate data structures (arrays, dictionaries, objects) to model structured data in their programs.

Lessons on this site

No lesson is tagged to this waypoint. The standard is generally covered by some courses; see the standard's page for which are the main focus and which only touch it.

Success criteria

  • Program uses a data structure with more than one element
  • Student can explain why that data structure suits the data being stored

Prior knowledge

Students can implement, modify and debug programs involving control structures and functions (AC9TDI8P09). They have experience with iteration, selection, and basic functions. They have not yet implemented programs across multiple files or classes, applied data structures beyond simple lists, or written object-oriented code with custom classes.

Width

Minimum
Use at least one data structure beyond a simple variable (e.g. list/array or dictionary) to store and access structured data in a program.
Typical
Select appropriate data structures for different data needs — arrays for ordered sequential data, dictionaries/records for key-value data, objects for structured entities; justify the selection; access and manipulate stored data using the appropriate operations.
Wider
  • Apply the binary search algorithm from a library to search sorted data — explain why binary search is faster than linear search and what preconditions it requires
  • Use multiple data structures in the same program and explain what each is responsible for modelling
  • Investigate how choosing the wrong data structure (e.g. using a list when a dictionary is needed) affects program complexity and performance

Hinge

Data structure selection errors propagate through all subsequent nodes — a student who uses a list where a dictionary is needed produces a program at N5 that is structurally incorrect and cannot be cleanly extended or debugged.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepData structure selection requires students to reason about the shape of the data and how it will be accessed. Students default to lists for everything. Multiple varied scenarios — ordered lists, character stats in RPGs, temperature records — each foreground a different data structure choice.
