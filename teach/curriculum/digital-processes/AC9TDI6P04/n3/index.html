← AC9TDI6P04 Generate, modify and evaluate designs

Modifying a design to meet unmet criteria

AC9TDI6P04 n3 · waypoint 3 of 3 · Years 5–6 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify where a preferred design does not satisfy a criterion or user story and propose a modification to address it

Success criteria

  • Identifies at least one gap between the preferred design and the criteria
  • Describes a modification that would address the identified gap

Prior knowledge

Waypoint 2: Evaluating designs against criteria and user stories.

Width

Minimum
Identify at least one gap between the preferred design and the design criteria; describe a modification that would address the gap
Typical
Review the preferred design against all criteria and user stories; document which criteria are met and which are not; propose modifications for unmet criteria and explain how each modification addresses the gap
Wider
  • Modify a game or game controller design so it can be used by a wider range of players — documenting what the original design assumed about the user and how the modification removes that assumption
  • Prototype a modification and evaluate whether it resolves the gap — going through one iteration of the design-modify-evaluate cycle

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents tend to treat modification as correcting errors rather than genuinely extending the design to meet unmet criteria. Contexts where the unmet criterion is clear and consequential — a game that only some students can play, an interface that only English readers can navigate — make the modification purpose concrete.
