Using basic features to create content

AC9TDI2P04 n1 · waypoint 1 of 3 · Years 1–2 Digital Technologies (processes) · Processes and production skills · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can use the basic features of a common digital tool to create a piece of content

Lessons on this site

None yet.

Success criteria

  • Uses at least one basic feature of a digital tool to produce original content
  • The content produced is accessible — saved or stored so it can be found again

Prior knowledge

This is the first content creation descriptor (no Foundation predecessor). Students have used digital systems in familiar contexts and can recognise what they are used for. They have not yet deliberately used digital tools to create original content, locate specific content, or communicate content to others.

Width

Minimum
Use at least one basic feature of a digital tool (camera, drawing app, text input, presentation software) to create a piece of original content
Typical
Use basic features across different content types (take a photo, draw a picture, type a message, add text to a presentation) using appropriate tools; save or store the created content
Wider
  • Use presentation software to retell a story — apply features to combine text and pictures to communicate the story sequence
  • Create a card for a family member using a camera or drawing app — include a photo and a short typed message, combining two creation features

Hinge

Procedural fluency with creation features is prerequisite for Node 2 — students who stall on feature access during creation cannot redirect attention to locating and retrieving content.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsFeature use at this level requires motor accuracy and procedural memory — selecting the right icon, saving correctly, locating saved work. Students need repeated practice with the same features across multiple creation tasks before fluency develops. Consolidation here prevents stalling on procedural steps when communicating content.
