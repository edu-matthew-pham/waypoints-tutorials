Create and communicate content

AC9TDI2P04 · Years 1–2 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Descriptor

use the basic features of common digital tools to create, locate and communicate content

Prior knowledge

This is the first content creation descriptor (no Foundation predecessor). Students have used digital systems in familiar contexts and can recognise what they are used for. They have not yet deliberately used digital tools to create original content, locate specific content, or communicate content to others.

By the end

Students use basic features of common digital tools to create original content, locate relevant content, and communicate that content to others.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • using familiar digital systems to create content with others, for example using presentation software to retell a story
  • taking, storing safely and presenting photos of class work, for example locating photos they took of their work to show to parents or carers or for the teacher to upload to the class shared folder
  • finding images of (local) Australian flora and fauna or places for use in a story and including First Nations Australians' names for the items
  • using a camera or drawing app to create a picture, for example making a card for a family member that includes a photo and short message
  • creating individual pieces of work that contribute to a group task, for example each student contributes a recipe and photo of their favourite food to create a class recipe book

Waypoints

  • 1. Using basic features to create contentHingeStudents can use the basic features of a common digital tool to create a piece of content
  • 2. Using basic features to locate contentHingeStudents can use the basic features of a digital tool to locate specific content — including stored files and online images
  • 3. Using basic features to communicate contentStudents can use the basic features of a digital tool to communicate created or located content to others
