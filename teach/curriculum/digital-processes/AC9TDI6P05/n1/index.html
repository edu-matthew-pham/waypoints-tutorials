Using variables to store input

AC9TDI6P05 n1 · waypoint 1 of 3 · Years 5–6 Digital Technologies (processes) · Processes and production skills · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can write a program that takes input from the user or environment, stores it in a variable, and uses the variable in later steps

Lessons on this site

None yet.

Success criteria

  • Program stores a user input value in a named variable
  • The variable is used (not just stored) in a later step of the program

Prior knowledge

Students can implement simple algorithms as visual programs involving control structures and input (AC9TDI4P04). They have written programs with basic sequences, simple branching, and loops in a visual environment. They have not yet used variables to store and reuse values, or combined variables with control structures to respond to user input.

Width

Minimum
Write a program that asks the user for one value, stores it in a variable, and uses that variable at least once later in the program
Typical
Write programs that store user input in variables and use those variables in calculations, decisions, or output — e.g. ask how many shapes to draw, store in a variable, use that variable to control a loop count
Wider
  • Write a program that takes input from the environment (e.g. a sensor value or a simulated tracker reading) and stores it in a variable — explaining the difference between user input and environmental input
  • Write a program with multiple variables that each store different pieces of information and interact in the algorithm — e.g. a score variable and a lives variable in a quiz

Hinge

Variable handling in N1 is prerequisite for N2 — programs combining variables with branches and loops require students to track how variable values change across iterations and affect branch conditions. Students who cannot use variables reliably cannot build the combined programs in N2.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents commonly confuse the variable name with its value, or overwrite a variable unintentionally. Programs where the variable's stored value visibly affects output in a meaningful way (number of shapes, score, direction) help students trace the variable's lifecycle from assignment to use.
