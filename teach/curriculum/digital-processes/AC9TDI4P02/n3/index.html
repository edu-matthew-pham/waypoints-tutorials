← AC9TDI4P02 Algorithms with branching and iteration

Iteration as repeating steps

AC9TDI4P02 n3 · waypoint 3 of 4 · Years 3–4 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can describe an algorithm that repeats steps a fixed number of times and explain what changes with each repetition

Success criteria

  • Identifies that steps are repeated in an iterative algorithm
  • States what changes between repetitions (e.g. a count increases, a position moves)

Prior knowledge

Waypoint 2: Comparison operators as branching conditions.

Width

Minimum
Follow an algorithm that repeats a step a set number of times (e.g. add a number 5 times to compute a product); describe what the algorithm does and what changes in each repetition
Typical
Describe algorithms with iteration for different purposes — fixed-count repetition (multiply using repeated addition), and repetition until a condition is met; identify what is constant and what changes across iterations
Wider
  • Describe iteration in algorithms used for monitoring tasks — for example, an algorithm that counts sightings of a specific animal in a survey by repeating a tally step; discuss how the repetition connects to the data being collected
  • Explore an algorithm that combines iteration and branching — describe how repetition and decisions interact (e.g. 'check each item on a list; IF it matches THEN record it')

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents often understand iteration from one context (e.g. counting) but do not recognise it in others (processing a list, animating movement, repeating a procedure). Multiple contexts build a functional understanding of 'do this repeatedly' across varied algorithmic uses.
