Acquire, store and validate data

AC9TDI10P01 · Years 9–10 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Descriptor

develop techniques to acquire, store and validate data from a range of sources using software, including spreadsheets and databases

Prior knowledge

Students can acquire, store and validate data from a range of sources using spreadsheets and databases (AC9TDI8P01). They can identify data quality issues including relevance, correctness, currency and potential bias. They have not yet developed automated validation techniques, applied the Australian Privacy Principles to data collection, or considered training data issues for predictive models.

By the end

Students develop techniques — including automated validation, privacy-compliant acquisition, and bias-aware evaluation — to acquire, store and validate data from a range of sources using spreadsheets and databases.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • developing systems that store structured data, for example a movie or travel review website that collects Likert scale ratings and written reviews
  • developing systems that check data is correct and meaningful using automated techniques and manual analysis, for example, validating movie review data using rules and user interface elements, and detecting bias and fake reviews through simple statistical analysis
  • developing systems that acquire, use and protect data according to the Australian Privacy Principles, for example ensuring personally identifiable information is not publicly shared without consent and is protected from unauthorised access
  • accessing and storing data from the Australian Bureau of Statistics in a format that is useful for analysis, for example acquiring data on the population growth across age groups in Australia
  • identifying strengths and weaknesses of collecting data using different methods, for example online surveys, face-to-face interviews, phone interviews, observation, comments in response to a social media posting, phone logs, browser history and online webcam systems
  • considering how training data issues such as the zero problem dictate the output from predictive models; for example, a model with many examples of horses and no zebras in its training data is likely to classify all zebras as horses

Covered in these courses

Main focus: Data detective, SQL and databases

Touches on it: Web apps with Flask, Machine learning with Gradio

This is general coverage, not a lesson tagged to each waypoint. A course that only touches a standard meets it in passing; it may not be the course's main focus, and a teacher could extend it to cover the standard more fully.

Waypoints

  • 1. Designing systems that collect structured dataHingeStudents can design and develop a system that collects structured data from users, with appropriate fields and data types.
  • 2. Automated validation techniquesHingeStudents can develop automated validation techniques that check data is correct and meaningful using both rules and UI constraints.
  • 3. Privacy-compliant data acquisitionStudents can acquire and store data in accordance with the Australian Privacy Principles, protecting personally identifiable information from unauthorised access.
  • 4. Comparing and selecting data sourcesStudents can identify the strengths and weaknesses of different data collection methods and select sources appropriate to a given investigation.
