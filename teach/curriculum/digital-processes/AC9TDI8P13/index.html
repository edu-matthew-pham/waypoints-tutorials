Multi-factor auth and phishing

AC9TDI8P13 · Years 7–8 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Descriptor

Explain how multi-factor authentication protects an account when the password is compromised and identify phishing and other cyber security threats

Prior knowledge

Students can use unique passphrases across accounts and explain the risks of password re-use (AC9TDI6P09). They understand password-based security but have not yet explored what happens when passwords are compromised, how MFA adds a second layer of protection, or how phishing attacks exploit human behaviour.

By the end

Students explain how multi-factor authentication protects an account even when the password is compromised, and identify phishing and other cyber security threats by recognising the techniques attackers use to exploit users.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • explaining how multi-factor authentication prevents unauthorised access by prompting the account owner for a token or single-use password, for example demonstrating how a funds transfer from their bank account requires not only logging in, but provision of a one-time password received via SMS
  • identifying the common techniques used in phishing scams to identify and exploit susceptible users, for example using an email address from an unofficial domain when pretending to be an online retailer, or including grammatical errors to help filter out users who are more likely to detect the scam

Waypoints

  • 1. When passwords failHingeStudents can explain how a password can be compromised and why password-only security is insufficient
  • 2. How MFA protects accountsStudents can explain how multi-factor authentication adds a second layer of protection by requiring something beyond the password
  • 3. Identifying phishing and cyber threatsStudents can identify phishing and other cyber security threats by recognising the techniques used to exploit users
