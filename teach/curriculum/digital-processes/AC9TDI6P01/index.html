Define problems with user stories

AC9TDI6P01 · Years 5–6 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Descriptor

Define problems with given or co-developed design criteria and by creating user stories

Prior knowledge

Students can define problems with given design criteria and by co-creating user stories (AC9TDI4P01). They have worked with provided design criteria and contributed to user stories collaboratively. They have not yet developed design criteria with more agency (co-developed rather than given) or created user stories independently from stimulus.

By the end

Students define a problem by co-developing or applying design criteria and by creating user stories that identify an issue, the user, and their need.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • using provided stimulus to identify an issue and writing a user story in groups, for example using a newspaper article to develop a user story, such as: a family in a bushfire or flood-prone environment needs a way to ensure they are prepared in case of an emergency
  • discussing possible design criteria based on a stimulus, for example the cost, sustainability and timeliness for a roadside bushfire or flood risk rating system
  • investigating the impact that feral animals have on native flora and fauna and how this problem has led to economic development opportunities for groups such as the Arnhem Land Progress Aboriginal Corporation

Waypoints

  • 1. Identifying a problem from stimulusHingeStudents can identify an issue from a stimulus and frame it as a problem that a digital solution could address
  • 2. Writing a user storyHingeStudents can write a user story that identifies who the user is, what they need, and why
  • 3. Co-developing design criteriaStudents can contribute to co-developing design criteria that can be used to evaluate solutions
