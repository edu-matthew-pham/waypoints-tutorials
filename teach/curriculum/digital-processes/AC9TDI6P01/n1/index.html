Identifying a problem from stimulus

AC9TDI6P01 n1 · waypoint 1 of 3 · Years 5–6 Digital Technologies (processes) · Processes and production skills · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify an issue from a stimulus and frame it as a problem that a digital solution could address

Success criteria

  • Identifies a specific issue from the stimulus
  • States the problem in terms of a user need, not just a system gap

Prior knowledge

Students can define problems with given design criteria and by co-creating user stories (AC9TDI4P01). They have worked with provided design criteria and contributed to user stories collaboratively. They have not yet developed design criteria with more agency (co-developed rather than given) or created user stories independently from stimulus.

Width

Minimum
Given a stimulus (e.g. an article, scenario), identify an issue and state the problem a solution needs to address
Typical
Use stimulus material to identify an issue, name the affected users, and describe the problem in terms of what users need — not just what is wrong
Wider
  • Investigate how feral animals threaten native flora and fauna and identify the problem from the perspective of different stakeholders — rangers, farmers, ecologists — developing a problem statement that reflects one user group's needs
  • Examine how a community in a bushfire or flood-prone area needs an emergency preparedness solution — defining the problem from the perspective of the family user rather than the system designer

Hinge

Problem framing in N1 cascades into N2 (user story) and N3 (design criteria) — a student who frames the problem incorrectly will write user stories for the wrong user and criteria that cannot evaluate the actual need. All downstream design work inherits the N1 framing.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents tend to frame problems from a system-designer perspective ('we need an app') rather than a user perspective ('the family needs to know what to do'). Stimulus materials with emotionally real, socially meaningful contexts — emergencies, environmental threats — help students stay anchored to the user's actual experience and need.
