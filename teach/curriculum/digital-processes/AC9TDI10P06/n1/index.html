Tracing algorithms and identifying unexpected state

AC9TDI10P06 n1 · waypoint 1 of 4 · Years 9–10 Digital Technologies (processes) · Processes and production skills · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can trace an algorithm to identify when its state becomes unexpected, why this occurred, and what change is needed.

Lessons on this site

No lesson is tagged to this waypoint. The standard is generally covered by some courses; see the standard's page for which are the main focus and which only touch it.

Success criteria

  • Records the state of key variables at each step of the algorithm
  • Identifies the step where state becomes unexpected and explains why

Prior knowledge

Students can trace algorithms to predict output for a given input and identify errors (AC9TDI8P06). They can identify when a program's state is unexpected. They have not yet designed systematic test suites including boundary and invalid input cases, or applied a validation methodology beyond ad-hoc tracing.

Width

Minimum
Trace an algorithm step by step, record the state of each variable at each step, and identify one point where the state is unexpected.
Typical
Trace an algorithm with a bug; identify the exact step where the state diverges from expected; explain why the bug occurred (e.g. off-by-one, wrong condition, incorrect variable) and describe the fix needed.
Wider
  • Trace an algorithm involving nested loops or nested conditions, tracking the state of multiple variables simultaneously
  • Compare two algorithms that produce the same output for most inputs but differ at an edge case — explain what the difference is and which is correct

Hinge

Students who cannot systematically trace algorithm state cannot identify boundary conditions at N2 — boundary test design requires knowing what the algorithm does at each step to determine where its behaviour changes.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsAlgorithm tracing requires precision and discipline. Students who skip steps or guess at state values often fail to locate bugs correctly. Sufficient practice with varied algorithms — including those with intentional bugs — builds the systematic tracing habit.
