Implement programs with functions

AC9TDI8P09 · Years 7–8 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Descriptor

Implement, modify and debug programs involving control structures and functions in a general-purpose programming language

Prior knowledge

Students can implement algorithms as visual programs involving control structures, variables and input (AC9TDI6P05). They have programmed in visual/block-based environments but have not yet used a general-purpose text-based language, defined functions, or systematically debugged programs.

By the end

Students implement working programs in a general-purpose language (e.g. Python, JavaScript) using branching, iteration, variables and functions; read and modify existing code to change functionality; and debug programs by identifying and fixing errors.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • writing and editing programs to solve problems using branching, iteration, variables and functions in a general-purpose programming language, such as Python, JavaScript or C#
  • reading and interpreting an existing program and modifying the code to change functionality and fix errors, for example taking existing code for a weather forecasting app that includes temperatures and improving the output to include extra information such as rainfall, UV levels and air quality
  • writing a program that receives data from the environment to change the program behaviour, for example reading moisture level data from a soil sensor and switching on the watering system
  • writing a program that contains nested control structures to perform more complicated branching and decisions, for example using an IF statement inside a loop to count the warm days from an array containing temperature data only when the temperature for each day is more than 20 degrees Celsius
  • defining and using a function that produces different output based on the argument(s) it receives, for example a function that receives the name of an actor from user input, and searches a file or database to return a list of movies that actor appears in

Covered in these courses

Main focus: Python functions and events, micro:bit: talk and play, Arcade advanced skills

Touches on it: Python Foundations with Turtle, Console bridge: text in, text out, Drawing and animation with p5.js, The DOM and the browser console

This is general coverage, not a lesson tagged to each waypoint. A course that only touches a standard meets it in passing; it may not be the course's main focus, and a teacher could extend it to cover the standard more fully.

Waypoints

  • 1. Writing programs with control structuresHingeStudents can write programs in a general-purpose language using branching, iteration and variables to solve problems
  • 2. Defining and using functionsStudents can define functions that accept arguments and produce output, and use them to organise programs into reusable parts
  • 3. Reading and modifying existing codeStudents can read and interpret an existing program, explain what it does, and modify the code to change its functionality
  • 4. Debugging programsStudents can identify and fix errors in programs by testing, reading error messages, and tracing program execution
