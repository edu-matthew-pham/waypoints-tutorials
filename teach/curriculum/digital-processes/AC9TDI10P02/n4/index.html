← AC9TDI10P02 Analyse and visualise data

Machine learning as a form of data analysis

AC9TDI10P02 n4 · waypoint 4 of 4 · Years 9–10 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can explain how machine learning trains algorithms on data to identify patterns and classify inputs, and explore how adjusting model parameters affects outputs.

Success criteria

  • Correctly explains that ML algorithms learn patterns from training data
  • Demonstrates that changing training data or parameters changes model output
  • Can explain in plain language what changed and why

Prior knowledge

Waypoint 3: Developing interactive visualisations.

Width

Minimum
Describe what machine learning is and explain, using one example, how an algorithm is trained on data to classify new inputs.
Typical
Use a machine learning tool to train a model on a dataset and classify new inputs; adjust at least one parameter and observe how it changes the model's output; explain what the parameter controls.
Wider
  • Explore how adjusting the weighting of different input variables in a model changes its predictions — explain what this reveals about which variables have most influence
  • Investigate how training data composition affects model output — what happens when certain categories are underrepresented? Connect this to real-world bias in deployed AI systems
  • Use a visual ML tool (e.g. Teachable Machine) to train image classifiers and observe how classification accuracy changes as training data volume increases

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepMachine learning is conceptually opaque — students often treat it as a black box. Multiple hands-on experiments (image classification, parameter adjustment, training data variation) each make a different aspect of the process visible, building a more complete mental model than a single experiment.
