Analyse and visualise data

AC9TDI10P02 · Years 9–10 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Descriptor

analyse and visualise data interactively using a range of software, including spreadsheets and databases, to draw conclusions and make predictions by identifying trends and outliers

Prior knowledge

Students can analyse and visualise data using a range of software including spreadsheets and databases (AC9TDI8P02). They can identify trends and patterns in data and draw conclusions from visualisations. They have not yet developed interactive visualisations, applied machine learning as a form of analysis, or adjusted model parameters to observe effects on predictions.

By the end

Students analyse and visualise data interactively using spreadsheets and databases to draw conclusions and make predictions by identifying trends and outliers, including developing interactive visualisations and exploring how machine learning models analyse patterns in data.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • summarising data, its attributes and the relationships between data sets, identifying trends and outliers to draw conclusions and make predictions, for example summarising data about electorates and their demographics, historical swings and exceptions to predict an election outcome
  • developing interactive visualisations for exploring complex data, for example population, life expectancy and fertility rate in motion charts
  • using software to visualise and compare data to identify patterns, relationships and trends, for example investigating emerging trends in Australia's industries
  • exploring machine learning, a form of artificial intelligence where an algorithm is trained using a data set, for example to classify images into categories
  • adjusting parameters of an AI model to observe the impact of different factors on predicted outcomes; for example, changing the weighting of different input variables to see how much it changes the model's outputs

Covered in these courses

Main focus: Data detective

Touches on it: Web apps with Flask, Machine learning with Gradio

This is general coverage, not a lesson tagged to each waypoint. A course that only touches a standard meets it in passing; it may not be the course's main focus, and a teacher could extend it to cover the standard more fully.

Waypoints

  • 1. Summarising data and identifying trendsHingeStudents can summarise a dataset by identifying its attributes, relationships between variables, trends and outliers.
  • 2. Drawing conclusions and making predictionsHingeStudents can draw conclusions from data analysis and make predictions, including identifying the limits of the prediction.
  • 3. Developing interactive visualisationsStudents can develop interactive visualisations for exploring complex data, allowing users to control and view different aspects of a dataset.
  • 4. Machine learning as a form of data analysisStudents can explain how machine learning trains algorithms on data to identify patterns and classify inputs, and explore how adjusting model parameters affects outputs.
