Create content with conventions

AC9TDI4P06 · Years 3–4 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Descriptor

use the core features of common digital tools to create, locate and communicate content, following agreed conventions

Prior knowledge

Students can use basic features of digital tools to create, locate and communicate content (AC9TDI2P04). They have used digital tools for simple content creation. They have not yet worked with agreed conventions, information hierarchies, or search strategies for finding suitable sources.

By the end

Students use core features of common digital tools to create, locate and communicate content, following agreed conventions including safe search steps, file organisation and appropriate use of autocomplete features.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • discussing and creating as a class a set of steps they need to follow to safely find information online
  • using an online search engine to find suitable sources to create and communicate information, following agreed steps, for example creating a presentation on life cycles
  • grouping, naming and itemising objects using a logical hierarchy, for example creating a section of a virtual library or virtual supermarket using folders and files
  • using autocomplete features in text authoring tools; for example, using suggestions in a word processor to complete words or sentences, or using predictive text in SMS or messaging apps

Waypoints

  • 1. Finding information online safelyHingeStudents can follow agreed steps to find information online using a search engine
  • 2. Organising content with hierarchiesStudents can group, name and organise files and folders using a logical hierarchy
  • 3. Using core tool features to create and communicateStudents can use core features of a digital tool (including autocomplete) to create and communicate content following agreed conventions
