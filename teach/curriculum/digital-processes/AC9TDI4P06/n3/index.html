← AC9TDI4P06 Create content with conventions

Using core tool features to create and communicate

AC9TDI4P06 n3 · waypoint 3 of 3 · Years 3–4 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can use core features of a digital tool (including autocomplete) to create and communicate content following agreed conventions

Success criteria

  • Applies at least two agreed conventions in produced content
  • Content communicates the intended information clearly

Prior knowledge

Waypoint 2: Organising content with hierarchies.

Width

Minimum
Use a digital tool to create content for a purpose, applying at least one agreed convention (e.g. appropriate file name, correct folder, use of autocomplete)
Typical
Create and communicate content using core tool features across different formats (presentations, documents, messages); apply agreed conventions consistently; use autocomplete features in text authoring tools appropriately
Wider
  • Create content in a tool that is unfamiliar — apply the conventions learned in familiar tools and discuss which transferred and which required adjustment
  • Create content for a specific audience beyond the classroom (e.g. a presentation for parents or a guide for a younger class) — discuss how conventions change depending on the audience and purpose

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyCore tool features (file saving, naming conventions, autocomplete, folder use) need to be built across multiple tools and formats before they become transferable. Students who only practise in one tool often cannot apply conventions in a new one — repertoire across formats is the target.
