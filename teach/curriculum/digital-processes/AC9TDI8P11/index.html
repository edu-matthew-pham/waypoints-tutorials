Use digital tools efficiently

AC9TDI8P11 · Years 7–8 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Descriptor

Select and use a range of digital tools efficiently, including unfamiliar features, to create, locate and communicate content, consistently applying common conventions

Prior knowledge

Students can select and use appropriate digital tools to create, locate and communicate content, applying common conventions (AC9TDI6P07). They have used familiar tools but have not yet explored unfamiliar features to improve efficiency, used generative AI for content creation, or consistently applied conventions including heading hierarchy, captions and inclusive language.

By the end

Students select and use digital tools efficiently, including exploring unfamiliar features to improve their work; create, locate and communicate content while consistently applying common conventions including heading hierarchy, captions and inclusive language.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • locating relevant content from multiple sources, exploring advanced search functions and targeted criteria, for example using specific filters such as date range, image size, file type and usage licence
  • selecting and using appropriate digital tools, for example when participating in online lessons or planning sessions using a common video conferencing tool
  • applying common conventions consistently when creating content, for example organising content in paragraphs and within a heading hierarchy, writing captions to describe images and using gender-inclusive pronouns, where appropriate
  • creating logical storage locations for project assets and resources together with an outline to ensure collaborators are up to date, for example creating a logical storage area for a group to share content and ideas in a timely manner about the canteen issue they are solving
  • using effective prompts with generative AI models to create output that is better suited to the problem being solved; for example, specifying the voice, tone and brevity for a persuasive news article with a restrictive word limit
  • using a progressive series of prompts with generative models to refine output to improve its correctness; for example, performing translation from one language to another and instructing the model to correct errors in translation

Waypoints

  • 1. Selecting tools for purposeStudents can select appropriate digital tools for a specific communication task and explain why the chosen tool suits the purpose and audience
  • 2. Applying conventions consistentlyStudents can apply common conventions consistently when creating content, including heading hierarchy, captions, logical storage and inclusive language
  • 3. Exploring unfamiliar features and AI toolsStudents can explore unfamiliar features of digital tools to improve efficiency, including using generative AI with effective prompts
