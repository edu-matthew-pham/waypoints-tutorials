Selecting tools for purpose

AC9TDI8P11 n1 · waypoint 1 of 3 · Years 7–8 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can select appropriate digital tools for a specific communication task and explain why the chosen tool suits the purpose and audience

Success criteria

  • Selects a tool appropriate for the communication task
  • Explains why the tool suits the purpose or audience

Prior knowledge

Students can select and use appropriate digital tools to create, locate and communicate content, applying common conventions (AC9TDI6P07). They have used familiar tools but have not yet explored unfamiliar features to improve efficiency, used generative AI for content creation, or consistently applied conventions including heading hierarchy, captions and inclusive language.

Width

Minimum
Given a communication task, select an appropriate tool and explain why it suits the task
Typical
Compare tools for the same task; explain how tool selection affects audience reach, format and accessibility
Wider
  • Investigate how tool selection affects audience reach and accessibility — why a video might reach some audiences better than a document, or why accessibility features matter for inclusive communication
