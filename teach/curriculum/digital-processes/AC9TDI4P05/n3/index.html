Evaluating against user stories

AC9TDI4P05 n3 · waypoint 3 of 3 · Years 3–4 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can check a solution against a user story and discuss how well it meets the user's need and purpose

Success criteria

  • References both the user's need and purpose when evaluating
  • Identifies at least one thing the solution does well and one gap or limitation

Prior knowledge

Waypoint 2: Evaluating against design criteria.

Width

Minimum
Given a solution and one user story, discuss whether the solution meets the user's need and purpose
Typical
Evaluate existing and student solutions against user stories for different contexts; discuss how well the solution meets both the need and the purpose (the 'so that' part) of the user story; identify gaps between what was designed and what was needed
Wider
  • Evaluate a solution from the perspective of a user story you did not write — for example, evaluate a classmate's game against their user story and discuss whether the solution meets needs you might not have anticipated
  • Discuss a case where a solution meets the stated need but not the underlying purpose — for example, a tool that works technically but is too complex for the actual user to use

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents commonly evaluate whether the need is met but overlook the 'so that' purpose. Evaluating across different user stories — especially others' user stories — builds the habit of checking both what a solution does and whether it achieves the intended outcome.
Integration: a combining task at the wider tierThis node integrates the design criteria evaluation from node 2 with user story evaluation — applying both simultaneously to assess a solution from multiple lenses. The integration is the learning: criteria and user stories together give a more complete evaluation than either alone.
