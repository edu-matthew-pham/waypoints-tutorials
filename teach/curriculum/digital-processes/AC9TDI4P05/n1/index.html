Describing what a solution does for users

AC9TDI4P05 n1 · waypoint 1 of 3 · Years 3–4 Digital Technologies (processes) · Processes and production skills · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can describe what an existing digital solution does and who it helps

Success criteria

  • Names at least one task the solution helps users complete
  • Identifies the user group the solution is designed for

Prior knowledge

Students can discuss how existing digital systems satisfy identified needs for known users (AC9TDI2P03). They have discussed fit-for-purpose at a general level. They have not yet evaluated solutions explicitly against design criteria and user stories as structured evaluation tools.

Width

Minimum
Describe one existing digital solution and explain what task it helps users complete
Typical
Describe how familiar digital solutions (maps, online orders, interactive directories) allow users to complete specific tasks; identify who benefits and what need each solution addresses
Wider
  • Investigate how a digital solution used in a First Nations community context (e.g. GPS tools for ranger land management) helps specific users — describe what the tool does and who it helps in that context
  • Describe how library management systems help different users (librarians tracking loans, students finding books) — discuss how the same solution serves different user needs simultaneously

Hinge

Students who cannot describe what a solution does for users cannot perform criteria evaluation in N2 — evaluation requires knowing what the solution actually does before checking it against criteria.
