Querying data to answer questions

AC9TDI8P03 n3 · waypoint 3 of 3 · Years 7–8 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Checkpoint

Students can filter, sort and query structured data to answer specific questions, including using simple SQL

Success criteria

  • Filters or sorts data to produce a result that answers the given question
  • Explains what the query result shows in context

Prior knowledge

Waypoint 2: Storing structured data in tables.

Width

Minimum
Filter or sort a table to answer a given question; explain what the result shows
Typical
Write simple SQL queries using SELECT, WHERE and ORDER BY to answer questions from a database; compare the result of different queries on the same data
Wider
  • Investigate how query design affects what patterns are visible — compare two queries on the same dataset that reveal different insights
  • Explore how structured data modelling underpins a real application (e.g. a library catalogue, a booking system, a historical events database)

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkSQL query writing requires students to translate a question into a formal instruction with exact syntax. Scaffolding the translation (what do I want to find? → which column? → which condition? → what order?) prevents students from trial-and-erroring rather than reasoning about what the query should do.
