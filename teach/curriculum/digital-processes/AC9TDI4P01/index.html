Define problems with user stories

AC9TDI4P01 · Years 3–4 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Descriptor

define problems with given design criteria and by co-creating user stories

Prior knowledge

Students can investigate simple problems for known users that can be solved with digital systems (AC9TDI2P01). They have explored what makes a problem solvable. They have not yet worked with explicit design criteria or user story formats as structured tools for problem definition.

By the end

Students define problems using given design criteria and co-created user stories, capturing both what a solution must do and who it is for.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • recognising a range of familiar problems and defining achievable solutions using given design criteria, for example buying presents for family members within a specified budget
  • using responses to guiding questions to write a user story, for example a family member wants a way of entertaining their puppy when they are at school to stop it digging holes
  • co-creating a user story using a template such as 'A has so that ', for example 'a sports team wants to access league rankings online so that they can see their progress'
  • developing a problem statement for collecting and managing information, for example how First Nations Australians rangers could monitor animal populations, such as local marine turtles, using global positioning systems (GPS)
  • co-creating user stories about exploring hard-to-reach locations, for example a school student wants to explore neighbouring countries classified as remote to compare how people live

Waypoints

  • 1. What design criteria areHingeStudents can read a set of given design criteria and explain what a solution must do to meet them
  • 2. User story structureHingeStudents can write a user story using a template that identifies who the user is, what they need, and why
  • 3. Defining a problem using both toolsStudents can use design criteria and a user story together to define a problem — stating what the solution must do and who it is for
