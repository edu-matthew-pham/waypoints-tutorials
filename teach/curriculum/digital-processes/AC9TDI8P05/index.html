Design nested algorithms

AC9TDI8P05 · Years 7–8 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Descriptor

Design algorithms involving nested control structures and represent them using flowcharts and pseudocode

Prior knowledge

Students can design algorithms involving multiple branching alternatives and iteration (AC9TDI6P02). They can use sequence, branching and iteration as separate control structures. They have not yet nested control structures inside each other or represented algorithms in both flowcharts and pseudocode.

By the end

Students design algorithms involving nested control structures (IF inside IF, IF inside loops, loops inside loops), represent them precisely using both flowcharts and pseudocode, and explain the design decisions at each branching or iteration point.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • designing an algorithm or modifying an existing algorithm to fix an error or change functionality, for example calculating the coins and notes needed for an amount of money and changing the algorithm to handle new denominations
  • describing algorithms precisely in pseudocode (structured English) or with flowcharts for each part of the problem, for example using separate flowcharts to describe the purchase of an item and the giving of change during the purchase
  • describing algorithms with nested control structures, including a nested if, for example IF it is raining THEN [IF parents are home THEN drive to school]; or an IF inside a loop, for example REPEAT [select the largest coin smaller than the remaining total, and subtract it] UNTIL the remainder is zero

Covered in these courses

Touches on it: Python Foundations with Turtle, micro:bit Foundations, Arcade Foundations

This is general coverage, not a lesson tagged to each waypoint. A course that only touches a standard meets it in passing; it may not be the course's main focus, and a teacher could extend it to cover the standard more fully.

Waypoints

  • 1. Control structures as building blocksHingeStudents can identify sequence, branching and iteration as distinct control structures and explain what each does
  • 2. What nesting meansHingeStudents can explain what it means to nest one control structure inside another and why nesting is useful for more complex decisions
  • 3. Designing nested algorithmsStudents can design an algorithm with nested control structures to solve a problem, making deliberate choices about what to nest and why
  • 4. Representing in flowcharts and pseudocodeStudents can represent the same nested algorithm precisely in both flowchart and pseudocode notation, and translate between them
