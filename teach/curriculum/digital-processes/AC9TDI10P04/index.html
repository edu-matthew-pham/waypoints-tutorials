Define and decompose real-world problems

AC9TDI10P04 · Years 9–10 Digital Technologies (processes) · Processes and production skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (processes): treat it as a starting suggestion and check it before use.

Descriptor

define and decompose real-world problems with design criteria and by interviewing stakeholders to create user stories

Prior knowledge

Students can define and decompose real-world problems with design criteria and by considering the needs of users (AC9TDI8P04). They can identify constraints and requirements. They have not yet conducted stakeholder interviews, formulated user stories from primary research, or defined problems with explicit scope awareness.

By the end

Students define and decompose real-world problems by interviewing stakeholders to create user stories, establishing design criteria with precision and scope awareness.

Waypoints

  • 1. Eliciting stakeholder needs through interviewsHingeStudents can design and conduct an interview with a stakeholder to elicit their needs, capturing information relevant to defining the problem.
  • 2. Creating user storiesHingeStudents can create user stories from stakeholder interview data using the standard template format.
  • 3. Defining the problem with precision and scopeHingeStudents can write a precise problem definition that names the problem, identifies scope boundaries, and acknowledges what is and isn't solvable within the project.
  • 4. Establishing design criteriaStudents can establish design criteria derived from user stories and problem definition that will guide evaluation of solutions.
