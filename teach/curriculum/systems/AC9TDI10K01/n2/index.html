Network addressing and routing

AC9TDI10K01 n2 · waypoint 2 of 5 · Year 10 Digital Technologies (knowledge) · Networks and security · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (knowledge): treat it as a starting suggestion and check it before use.

Checkpoint

Students can explain how domain names and IP addresses allow data to be transmitted to specific devices on a network.

Lessons on this site

  • Names and addresses

Success criteria

  • Correctly distinguishes IP addresses from domain names
  • Explains the role of DNS in translating between the two
  • Describes how routing tables direct packets toward their destination

Prior knowledge

Waypoint 1: The OS as a hardware abstraction layer.

Width

Minimum
Explain the role of IP addresses in identifying devices on a network and describe how DNS translates domain names to IP addresses.
Typical
Explain how IP addresses, DNS and routing tables work together to direct data packets to the correct destination across a network; describe the difference between public and private IP addresses.
Wider
  • Trace a DNS lookup and packet routing path for a request to a website, identifying each step from browser to server
  • Investigate how the transition from IPv4 to IPv6 addresses the limitation of available addresses and what this means for networked device growth

Hinge

Confusion between IP addresses and domain names, or misunderstanding of how packets are routed, propagates into N4 and N5 — students cannot reason about where cryptographic protection applies or trace a complete data flow without correctly understanding how addressing and routing work.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents frequently conflate IP addresses with domain names, or assume routing is a single hop. Multiple tracing activities — DNS lookup, packet path, address types — resolve these conflations more effectively than repeating the same explanation.
