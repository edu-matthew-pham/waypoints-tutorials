Managing and securing networked systems

AC9TDI10K01 · Year 10 Digital Technologies (knowledge) · Networks and security

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (knowledge): treat it as a starting suggestion and check it before use.

Descriptor

investigate how hardware and software manage, control and secure access to data in networked digital systems

Prior knowledge

Students can investigate how data is transmitted and secured in wired and wireless networks, including the use of protocols (AC9TDI8K02). They can explain how hardware specifications affect performance (AC9TDI8K01). They have not yet examined the software layer (OS, access control, cryptography) that manages and secures data in networked systems.

By the end

Students investigate how hardware and software components — including operating systems, access control mechanisms, and cryptographic protocols — work together to manage, control and secure access to data in networked digital systems.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • explaining how the operating system hides the complexity of different hardware from applications, for example applications can treat input from a mouse and touch screen in the same way
  • exploring how public key cryptography, for example TLS, and hashing, such as SHA-1, secure the storage and transmission of data
  • configuring a simple network using real or simulated hardware and observing packets moving around the network, for example monitoring packets on simulated switches and networked devices
  • explaining how domain names and IP addresses allow data to be transmitted to specific networked devices, for example DNS and routing tables
  • describing elements of access control and explaining why they are necessary, for example authentication and permissions for restricting access to install software to administrators

Waypoints

  • 1. The OS as a hardware abstraction layerStudents can explain how the operating system hides the complexity of different hardware from applications, allowing software to treat different hardware uniformly.
  • 2. Network addressing and routingHingeStudents can explain how domain names and IP addresses allow data to be transmitted to specific devices on a network.
  • 3. Access control mechanismsHingeStudents can describe elements of access control — including authentication and permissions — and explain why they are necessary in networked systems.
  • 4. Cryptographic security mechanismsHingeStudents can explain how public key cryptography and hashing are used to secure the transmission and storage of data in networked systems.
  • 5. Integration — how hardware and software work together in secured networksStudents can investigate a networked digital system and explain how its hardware and software components — addressing, access control, and cryptography — work together to manage and secure data.
