← AC9TDI10K02 Content, structure and presentation separation

Representing documents with HTML and CSS

AC9TDI10K02 n2 · waypoint 2 of 3 · Year 10 Digital Technologies (knowledge) · Web documents · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (knowledge): treat it as a starting suggestion and check it before use.

Checkpoint

Students can write web pages using HTML for content and structure and CSS for styling, and explain how HTML tags separate content from structure.

Success criteria

  • HTML file uses structural tags correctly (headings, paragraphs, at minimum)
  • CSS rule targets an HTML element or class and changes its presentation
  • Student can explain what the HTML tag does versus what the CSS rule does

Prior knowledge

Waypoint 1: The three layers of a web document.

Width

Minimum
Write a simple web page with at least two structural HTML elements and one CSS rule applied to them; explain what the tag does versus what the CSS rule does.
Typical
Create a web page using HTML structural tags (headings, paragraphs, lists, divs) and CSS rules (colour, font, layout); explain how changing the CSS changes presentation without altering structure.
Wider
  • Apply CSS classes to demonstrate how the same structural element can have different presentations in different contexts on the same page
  • Use CSS to implement a responsive layout that changes presentation based on screen width, explaining how presentation changes while structure remains constant

Hinge

Syntactic fluency at N2 is prerequisite for N3 — students who cannot produce working HTML/CSS cannot demonstrate the separation principle in action; they can only describe it abstractly, which does not meet the descriptor's demand.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsHTML/CSS syntax requires precision — misplaced tags, missing closing elements, and selector errors are common. Students need sufficient practice with the syntax to develop fluency before the conceptual significance of separation is legible to them.
