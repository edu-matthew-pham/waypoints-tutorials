← AC9TDI10K02 Content, structure and presentation separation

Why separation matters

AC9TDI10K02 n3 · waypoint 3 of 3 · Year 10 Digital Technologies (knowledge) · Web documents

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (knowledge): treat it as a starting suggestion and check it before use.

Checkpoint

Students can explain why separating content, structure and presentation is important — specifically how it allows each to be designed, edited and stored independently.

Lessons on this site

  • Why keep them apart

Success criteria

  • Explains at least one concrete benefit of separation with a specific example
  • Connects the benefit to a real consequence (e.g. changing one CSS file updates many pages)

Prior knowledge

Waypoint 2: Representing documents with HTML and CSS.

Width

Minimum
Give at least one reason why separating content, structure and presentation is important — with a concrete example of the benefit.
Typical
Explain multiple benefits of separation: independent editing, consistent presentation across many pages via a single CSS file, accessibility (structure legible to screen readers), and easier maintenance.
Wider
  • Demonstrate the maintenance benefit by changing one CSS file to restyle an entire multi-page site, explaining why this would be impractical if styling were embedded in content
  • Investigate how major content management systems (e.g. WordPress themes) implement content/structure/presentation separation and explain the architectural choices
  • Examine how First Nations language preservation websites use structured content to support multiple language versions of the same page — explaining why structure separation makes this feasible

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents who have only produced a single small web page often struggle to appreciate why separation matters — the benefit is invisible at small scale. Multiple contexts (site-wide restyling, screen reader accessibility, multi-language content) each illuminate a different reason, making the principle concrete across scales.
