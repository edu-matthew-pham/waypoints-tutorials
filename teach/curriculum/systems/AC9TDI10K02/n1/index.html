The three layers of a web document

AC9TDI10K02 n1 · waypoint 1 of 3 · Year 10 Digital Technologies (knowledge) · Web documents · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (knowledge): treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify and distinguish the three layers of an online document: content, structure and presentation.

Lessons on this site

  • Tags label text

Success criteria

  • Correctly assigns specific examples (e.g. heading text, <h1> tag, font-size rule) to the correct layer
  • Does not confuse structural tags with visual appearance

Prior knowledge

Students can use a range of digital tools to create and communicate content (AC9TDI8P11, AC9TDI8P12). They have not yet formally encountered the three-layer model of web documents or the rationale for separating content, structure and presentation.

Width

Minimum
Given a web page, identify what is content (text), what is structure (markup that organises the document), and what is presentation (how it looks).
Typical
Describe what each layer contains and what role it plays; identify examples of HTML structural tags and CSS presentation rules in a web page.
Wider
  • Compare how the same HTML document renders with and without CSS — articulate specifically what changed and what did not
  • Investigate how a screen reader interprets an HTML document and explain how structure (not presentation) determines what is communicated to the user

Hinge

Misidentifying what belongs to content, structure, or presentation directly prevents N2 — students who conflate layers cannot correctly use HTML for structure and CSS for presentation.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsDistinguishing three layers is a precision task — students commonly assign CSS rules to 'structure' or treat HTML tags as presentation. Sufficient practice mapping specific examples (this text, this tag, this rule) to the correct layer builds the reliable discrimination needed before N2.
