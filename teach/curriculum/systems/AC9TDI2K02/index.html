Data as pictures, numbers and words

AC9TDI2K02 · Year 2 Digital Technologies (knowledge) · Digital systems

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (knowledge): treat it as a starting suggestion and check it before use.

Descriptor

represent data as pictures, symbols, numbers and words

Prior knowledge

Students can represent data using objects, pictures and symbols (AC9TDIFK02). They have matched physical objects and pictures to what they represent. They have not yet worked with multiple simultaneous representation forms (words, numbers, symbols, pictures) or reasoned about equivalence across forms.

By the end

Students represent the same data using different forms — pictures, symbols, numbers and words — and recognise that different forms can convey equivalent information.

Waypoints

  • 1. Recognising representation formsHingeStudents can identify data represented as pictures, symbols, numbers and words and name which form is being used
  • 2. Representing the same data in different formsHingeStudents can represent the same data using more than one form — for example representing a count as a tally, a number and a word
  • 3. Recognising equivalence across formsStudents can recognise that different representation forms — pictures, symbols, numbers and words — can convey the same data, and explain why different forms may be used
