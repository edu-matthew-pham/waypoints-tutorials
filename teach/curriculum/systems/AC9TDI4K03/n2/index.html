← AC9TDI4K03 Data types and representations

Multiple representations of the same data

AC9TDI4K03 n2 · waypoint 2 of 3 · Year 4 Digital Technologies (knowledge) · Digital systems · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (knowledge): treat it as a starting suggestion and check it before use.

Checkpoint

Students can give examples of the same data shown in different ways and explain that different representations exist for the same underlying information

Success criteria

  • Identifies two different representations of the same data
  • States that both representations carry the same underlying information

Prior knowledge

Waypoint 1: Types of data.

Width

Minimum
Give one example of the same data represented in two different ways (e.g. the number 4 as '4', 'four', and 'IV') and state that both represent the same value
Typical
Explain several examples of the same data in different representations (numerals vs words vs tally vs Roman numerals; 'stop' vs stop sign vs hand icon); recognise that representations can use different formats to convey the same information
Wider
  • Compare how the same geographic location data can be represented as coordinates, a street address, a place name and a map pin — investigate which representation suits which purpose
  • Explore how the Kimberley cave paintings encode ethnobotanical knowledge — compare how the same information about plant use might be represented in a modern classification system vs an image-based system

Hinge

Students who only know that representations exist but treat them as equivalent (no better/worse) cannot engage with N3's purpose-fitness reasoning — the N3 question ('why this representation?') is meaningless if students think all representations are interchangeable.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents easily understand one representation pair but often think the difference is about correctness rather than purpose-fitness. Multiple examples across different data types (numeric, symbolic, iconic) help students see that representation is a design choice, not a matter of right and wrong.
