How CPU, memory and I/O work together

AC9TDI6K01 n2 · waypoint 2 of 2 · Year 6 Digital Technologies (knowledge) · Digital systems

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (knowledge): treat it as a starting suggestion and check it before use.

Checkpoint

Students can explain how the CPU, memory and input/output components work together to perform a task

Lessons on this site

  • Working together

Success criteria

  • Correctly assigns at least three roles (input, process, memory, output) to the correct component in a given task
  • Explains what each component contributes without treating them as interchangeable

Prior knowledge

Waypoint 1: Digital systems are made of parts.

Width

Minimum
Trace through a simple calculation or task (e.g. entering numbers and getting a sum) and identify which component handles each step — input, processing, memory, output
Typical
Explain how CPU, RAM and input/output components each play a role in completing a simple task; describe what would happen if one component were missing or very slow
Wider
  • Investigate how video conferencing systems combine multiple input/output components (camera, microphone, screen, speaker) and explain how the CPU coordinates them simultaneously
  • Explore how a calculator app on a tablet uses each component differently from a web browser — which components are used most and why?

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkStudents need to reason about a process rather than just name components. The input → process → memory → output chain is a reasoning scaffold, not just a label set. Explicitly tracing a task step-by-step helps students build this as a thinking pattern rather than a memorised sequence.
Integration: a combining task at the wider tierThis node is where the individual component facts from Node 1 become a system understanding. Coordinating all four components in a single task trace is the learning — not any one component in isolation.
