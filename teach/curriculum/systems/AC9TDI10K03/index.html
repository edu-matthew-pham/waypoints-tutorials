Data compression techniques

AC9TDI10K03 · Year 10 Digital Technologies (knowledge) · Data representation

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Digital Technologies (knowledge): treat it as a starting suggestion and check it before use.

Descriptor

investigate simple data compression techniques

Prior knowledge

Students can explain how digital systems represent text, image and audio data using binary (AC9TDI8K03) and how integers are represented in binary (AC9TDI8K04). They understand that different data types require different amounts of storage. They have not yet investigated how data can be compressed to reduce storage and transmission requirements.

By the end

Students investigate simple data compression techniques, including lossless methods such as run-length encoding and lossy methods, and explain the difference between lossy and lossless compression and the consequences of each.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • using an algorithm to identify patterns in data and represent them in a compressed way, for example repeated pixels in an image with run-length encoding
  • exploring the difference between lossy and lossless compression and the consequences of each, for example exploring codecs for audiovisual compression such as MP3, MP4 and WAV formats, considering energy requirements of file sizes
  • examining an image and discussing whether the image quality would be compromised if all the blue pixels of the sky in one row were to be replaced by one token and the number of pixels it represents

Waypoints

  • 1. Why compression is neededStudents can explain why data compression is useful and identify contexts where it matters.
  • 2. Lossless compression — run-length encodingHingeStudents can use run-length encoding to represent patterns in data in a compressed form and explain how the algorithm works.
  • 3. Lossy vs lossless — trade-offs and consequencesStudents can explain the difference between lossy and lossless compression, identify contexts where each is appropriate, and describe the consequences of using each.
