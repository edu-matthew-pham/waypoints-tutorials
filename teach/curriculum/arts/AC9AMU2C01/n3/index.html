Selecting elements for a purpose

AC9AMU2C01 n3 · waypoint 3 of 4 · Years 1–2 The Arts · Music: creating and making

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in The Arts: treat it as a starting suggestion and check it before use.

Checkpoint

Students can make deliberate decisions about which elements to use in a composition or performance to achieve a specific communicative or expressive intention.

Lessons on this site

None yet.

Success criteria

  • Selects at least two elements for a composition or performance and states a reason for each
  • Can explain how the selected elements serve the intended communicative or expressive purpose

Prior knowledge

Waypoint 2: Combining elements to create effects.

Width

Minimum
Choose which elements to include in a composition or performance and state a reason connected to what they want the music to communicate.
Typical
Make and justify element selections across multiple composition and performance contexts — e.g. deciding to use a slow tempo for a lullaby, choosing to use loud dynamics for an exciting section, selecting particular instruments based on their tone colour; practise a repertoire of songs using elements such as tempo, dynamics or articulation for expressive effect.
Wider
  • Write lyrics for a chant/rap and select rhythmic patterns that match the mood or message of the lyrics — explain the connection
  • Use accessible technologies (recording device) to listen back to a composition and make decisions about which elements to change to better achieve the intended effect

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkSelection decisions require students to reason from intent to choice: 'What do you want this music to feel like? Which elements could help create that feeling?' Structured prompting — before composing — builds the habit of selecting with purpose rather than selecting by default.
