Exhibition materials and public sharing

AC9AVA6P01 n3 · waypoint 3 of 3 · Years 5–6 The Arts · Visual arts: presenting and performing

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in The Arts: treat it as a starting suggestion and check it before use.

Checkpoint

Students can create exhibition materials that support audience engagement — labels, introductions, advertising, reviews — and consider options for sharing work in public spaces.

Lessons on this site

None yet.

Success criteria

  • Creates at least one exhibition material (label, statement or introduction) for a class exhibition
  • The material provides relevant information about the artwork and the artist's intentions

Prior knowledge

Waypoint 2: Selecting documentation to communicate development.

Width

Minimum
Create at least one exhibition material (label, artist statement or introduction) for a class exhibition.
Typical
Create a set of exhibition materials for a class exhibition — labels with artist information, an exhibition introduction, advertising or review material; work collaboratively on an online exhibition; consider options for sharing in public or community spaces.
Wider
  • Develop a complete set of exhibition materials for a class show — labels, introduction, advertising and press statement — evaluate each element's effectiveness for the intended audience
  • Explore options for sharing work in public spaces (café galleries, community arts events) — plan what would need to change about the work and its presentation to suit a public audience

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierStudents bring together physical display skills, documentation selection and audience awareness to produce a complete exhibition — where every element (artwork, label, arrangement, statement) serves the audience's experience.
