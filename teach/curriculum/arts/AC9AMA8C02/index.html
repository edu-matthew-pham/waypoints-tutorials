Apply production processes and concepts

AC9AMA8C02 · Years 7–8 The Arts · Media arts: creating and making

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in The Arts: treat it as a starting suggestion and check it before use.

Descriptor

apply production processes and use media arts concepts to construct representations and produce media arts works that communicate ideas, perspectives and/or meaning for specific audiences using responsible media practice

Prior knowledge

Students can use production processes to create media arts works (AC9AMA6C02). They have not yet applied media arts concepts deliberately across the full production pipeline, nor maintained responsible media practice as a consistent production discipline.

By the end

Students apply production processes and media arts concepts to produce works that communicate intended meaning for specific audiences with responsible media practice throughout.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • using pre-production, production and post-production processes to produce a media arts work representing sustainable futures or social justice
  • combining established genre conventions such as framing in still and moving images, sounds in radio/podcasts, font in print
  • transferring established technical codes between media types
  • using Viewpoints to ask questions about forms, elements, genre, mood and setting
  • producing a media arts work about sustainable habits or social justice
  • creating a news story focusing on an event to communicate perspective, using Viewpoints to consider bias

Waypoints

  • 1. Applying production processes across the pipelineStudents can apply pre-production, production and post-production processes to produce a media arts work with deliberate intent at each stage
  • 2. Applying media arts concepts to construct representationsStudents can apply media arts concepts — genre conventions, technical codes, symbolic codes — to construct representations that communicate intended ideas for a specific audience
  • 3. Applying responsible media practice throughoutStudents can apply responsible media practice consistently throughout production — copyright, ICIP rights, ethical representation, safety and legality
