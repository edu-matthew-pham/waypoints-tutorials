Notating, documenting and recording compositions

AC9AMU6C01 n4 · waypoint 4 of 4 · Years 5–6 The Arts · Music: creating and making

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in The Arts: treat it as a starting suggestion and check it before use.

Checkpoint

Students can notate, document or record a composition in a format appropriate to the type of music and suitable for use in rehearsal and performance.

Success criteria

  • Documents a composition in a format matched to its type
  • Documentation is detailed enough to guide a rehearsal without relying entirely on memory

Prior knowledge

Waypoint 3: Composing within technical constraints.

Width

Minimum
Document a composition using a format matched to the music type (e.g. lead-sheet for a song, graphic/staff notation or recording for an instrumental piece) with sufficient detail to reconstruct it in rehearsal.
Typical
Use a combination of notation formats, audio recording and digital tools to document compositions; ensure documentation captures element manipulation decisions and structural devices; use documentation in rehearsal to maintain fidelity to compositional intent.
Wider
  • Create a combined graphic and staff notation document for a piece — use graphic notation for soundscape sections and staff notation for melodic sections; evaluate which format works better for each section
  • Use digital loop and notation tools to create a multi-track recorded and notated score — compare the information captured by each format

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyY5-6 students benefit from consolidating and extending their documentation repertoire. Different composition types require different documentation approaches — the goal is fluent selection of appropriate tools, not mastery of one format.
