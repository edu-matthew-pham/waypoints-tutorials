Performing and communicating with audiences

AC9ADA8P01 n3 · waypoint 3 of 3 · Years 7–8 The Arts · Dance: presenting and performing

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in The Arts: treat it as a starting suggestion and check it before use.

Checkpoint

Students can perform dance for an audience using technical and expressive skills appropriately, and communicate the choreographic intent through introduction and presentation

Success criteria

  • Performs dance with deliberate technical and expressive choices
  • Introduces the dance in a way that communicates choreographic intent to the audience
  • Performance is for the audience — not just an execution of choreography

Prior knowledge

Waypoint 2: Using production elements to communicate intent.

Width

Minimum
Perform a dance for an audience with at least one deliberate technical and expressive choice; introduce the dance with basic contextual information
Typical
Perform dance using technical and expressive skills that serve choreographic intent; introduce the dance using style-specific terminology that communicates the creative intention to the audience
Wider
  • Develop a program note or voice-over introduction using style-specific dance terminology that communicates choreographic intent to an audience unfamiliar with the dance context
  • Evaluate the performance experience from the audience's perspective — use peer feedback to assess whether the technical and expressive application communicated the intended ideas
  • Perform the same dance in two different performance contexts (e.g. studio showing vs formal stage) — evaluate how context changes performance choices and audience experience

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierThis node integrates rehearsal strategy (Node 1), production elements (Node 2), and technical and expressive skills from C02 into a complete performance event. The coordination of movement, production, and audience communication is the learning — students who can perform technically but cannot communicate with an audience have not met the standard's full demand.
