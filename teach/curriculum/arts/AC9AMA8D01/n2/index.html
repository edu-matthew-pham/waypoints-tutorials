← AC9AMA8D01 Develop media production skills

Using media languages to construct representations

AC9AMA8D01 n2 · waypoint 2 of 3 · Years 7–8 The Arts · Media arts: developing practices and skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in The Arts: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use media languages deliberately to construct representations of people, places or concepts with intended meaning

Success criteria

  • Uses at least one media language element with a clear representational purpose
  • Explains what meaning the choice produces — not just describes the choice
  • Representational choices are deliberate — not just genre conventions applied by default

Prior knowledge

Waypoint 1: Developing technical media production skills.

Width

Minimum
Use at least one media language element (framing, lighting, sound, colour, font) to construct a representation; explain what meaning the choice produces
Typical
Use a range of media language elements to construct representations across different genres or platforms; explain how each choice contributes to the intended meaning
Wider
  • Explore how media languages can perpetuate or challenge stereotyping, bias or identity issues — develop representations that deliberately challenge rather than reproduce dominant representations
  • Construct representations that explore social relationships, power dynamics or sustainability issues — evaluate how media language choices carry ideological weight
  • Investigate how to create representations of cultural or social groups that are safe, legal, ethical and responsible — develop criteria for evaluating own representational choices

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents commonly use media language elements by convention — familiar framing choices, default sound design — without reasoning about what each choice communicates. Working across different representational challenges (identity, power, social issues) forces students to develop deliberate media language selection rather than defaulting to genre conventions.
