Create geographical descriptions and explanations

AC9HG7S06 · Year 7 Geography · Skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Geography: treat it as a starting suggestion and check it before use.

Descriptor

create descriptions, explanations and responses, using geographical knowledge and methods, concepts, terms and reference sources

Prior knowledge

Students have prior communication skills from F–6 HASS (AC9HS6S07: present descriptions and explanations, drawing ideas, findings and viewpoints from sources, and using relevant terms and conventions). This standard raises the bar specifically for geographical communication — incorporating geographical methods (maps, graphs, data representations), geographical concepts, specialised terminology, and reference to sources as integrated elements of geographical writing and presentation.

By the end

Students create descriptions, explanations and responses using geographical knowledge and methods, concepts, terms and reference sources.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • creating a description that connects the audience to the topic and uses geographical concepts and terms to provide accurate information about a preferred strategy; for example, planning liveable streets and sustainable cities in Australia and Europe
  • constructing an explanation, using research findings to support ideas; for example, data on water usage over time and at different places; information about liveability indexes for different places in Australia and Europe
  • developing conclusions, using geographical methods to represent data and information; for example, a map showing water usage and a map indicating water scarcity in Australia; a map representing places where liveability is difficult and dangerous due to environmental factors

Waypoints

  • 1. Geographical descriptions with concepts and terminologyStudents can create geographical descriptions that use accurate terminology, reference geographical concepts, and connect the audience to the topic.
  • 2. Geographical explanations supported by research findingsHingeStudents can construct geographical explanations that use research findings (data, maps, statistics) to support ideas.
  • 3. Geographical representations as communication toolsStudents can develop geographical responses that use geographical methods — maps, data representations — to communicate conclusions and support arguments.
  • 4. Integration: create complete geographical responsesStudents create descriptions, explanations and responses that integrate geographical knowledge, methods, concepts, terminology and reference sources — producing coherent geographical communication.
