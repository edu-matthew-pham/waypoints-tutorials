← AC9HG9S01 Developing geographical inquiry questions

Planning a multi-scale investigation using digital tools

AC9HG9S01 n3 · waypoint 3 of 3 · Year 9 Geography · Skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Geography: treat it as a starting suggestion and check it before use.

Checkpoint

Students can plan an investigation of a geographical phenomenon using digital tools at a range of scales

Lessons on this site

None yet.

Success criteria

  • Identifies the phenomenon, scale(s) and digital tools in an investigation plan
  • Connects tool selection to the scale and question type
  • Explains how the plan addresses the sharpened questions from Node 2

Prior knowledge

Waypoint 2: Sharpening questions using concepts and scale.

Width

Minimum
Outline an investigation plan that identifies: the phenomenon, the scale(s) of study, at least two digital tools to be used, and what data or information will be collected
Typical
Plan a geographical investigation of a biome modification or place connection topic using digital tools; specify the scale(s) of investigation, the tools to be used (e.g. GIS, mapping platforms, digital data sources), and how the investigation will address the sharpened questions from Node 2
Wider
  • Develop an investigation plan that uses different digital tools for different scales — explain why each tool is appropriate for its scale
  • Anticipate methodological challenges in the plan — what data might be difficult to find, what scale transitions are problematic?
  • Evaluate two possible investigation plans for the same question — explain which is more feasible and would produce better geographical data

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierThe investigation plan integrates the sharpened questions from Nodes 1-2 with tool selection and scale decisions. Teaching investment should focus on the connection: the digital tools chosen should be appropriate for the scale and the question type, not selected arbitrarily. A plan where tool choice is disconnected from the question has not reached this checkpoint.
