Selecting appropriate representations

AC9S9I04 n1 · waypoint 1 of 3 · Years 9–10 Science · Inquiry · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Science: treat it as a starting suggestion and check it before use.

Checkpoint

Students can select the most appropriate representation for a given data type or investigation question and explain the rationale for their choice.

Success criteria

  • Can select an appropriate representation and explain the rationale — not just produce the representation.
  • Can identify when an alternative representation would be less appropriate and explain why.
  • Does not default to a single graph type for all data.

Prior knowledge

Students can select and construct tables, graphs and models to represent data (AC9S7I04). They have not yet selected among descriptive statistics as appropriate for a data type, used mathematical relationships to process data, or applied representations such as Sankey diagrams or Sankey-like proportional models.

Width

Minimum
Select an appropriate graph or table type for one described data set and explain why it is more appropriate than at least one alternative (e.g. why a line graph is more appropriate than a bar graph for continuous data showing a trend).
Typical
Select appropriate representations across multiple data scenarios — including when to use tables (raw data), line graphs (trends over continuous variables), bar graphs (category comparisons), scatter plots (relationships between variables) — and explain the selection rationale for each.
Wider
  • Examine when a mathematical relationship (formula) is more informative than a graph alone — e.g. calculating carbon storage using a formula rather than just graphing biomass data.
  • Compare the information provided by molecular models and balanced symbolic equations when examining conservation of mass — examining how different representations of the same data reveal different aspects (AC9S9U07 connection).

Hinge

Students who default to a single representation type (e.g. always bar graph) regardless of data type cannot process data effectively and will produce representations that obscure rather than reveal patterns. The ability to select an appropriate representation is the prerequisite for the pattern analysis at AC9S9I05.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkRepresentation selection requires explicit reasoning: 'What type of data is this? What question am I answering? What does this representation make visible or hide?' Students need this decision framework modelled before they can apply it independently.
