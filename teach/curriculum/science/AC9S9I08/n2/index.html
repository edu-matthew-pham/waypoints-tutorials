Writing a scientific investigation report

AC9S9I08 n2 · waypoint 2 of 3 · Years 9–10 Science · Inquiry

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Science: treat it as a starting suggestion and check it before use.

Checkpoint

Students can write a scientific investigation report that includes: a background paragraph referencing relevant scientific knowledge; an explanation of results using scientific knowledge; and a discussion that considers validity and reproducibility.

Success criteria

  • Can write a background paragraph that references relevant scientific knowledge — not just describes the procedure.
  • Can explain results using scientific knowledge — not just state what happened.
  • Can write a validity/reproducibility discussion that addresses specific features of the method — not just 'it could have been more accurate'.

Prior knowledge

Waypoint 1: Purpose, audience and communication choices.

Width

Minimum
Write one component of a scientific investigation report — background, results explanation or validity/reproducibility discussion — that meets the structural requirements of that component.
Typical
Write a complete scientific investigation report with all three components: background (introductory scientific context), results explanation (using scientific knowledge to explain what was found), and discussion (evaluating validity and reproducibility — connecting to AC9S9I02 and I06).
Wider
  • Develop an interactive presentation that shows feedback loops in human body systems — applying the investigation report skills in a multimodal format that adds visual communication of process alongside explanatory text.
  • Evaluate the discussion section of a sample report against validity and reproducibility criteria — identifying where the discussion is strong or where gaps in validity analysis undermine the scientific argument.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsScientific report writing has structural conventions that require practice for reliable execution — particularly the results-explanation distinction (what was found vs. why it happened) and the validity/reproducibility discussion (a genuine analysis, not a procedural postscript). Students need feedback-corrected practice across multiple reports before these conventions become habitual.
