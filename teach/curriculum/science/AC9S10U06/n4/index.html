← AC9S10U06 Periodic table and atomic structure

Using atomic structure to predict and explain element properties

AC9S10U06 n4 · waypoint 4 of 4 · Year 10 Science · Chemical

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Science: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use the position of an element in the periodic table to predict its electron configuration and properties, and explain those properties in terms of atomic structure.

Lessons on this site

  • Use the table to predict

Success criteria

  • Predicts the outer electron configuration and likely properties of an element from its table position
  • Explains at least two element properties in terms of atomic structure
  • Uses the periodic table as a predictive tool — not just a reference — for an unfamiliar element

Prior knowledge

Waypoint 3: Periodic trends — why properties repeat across periods.

Width

Minimum
Students predict the number of outer-shell electrons and describe the likely reactivity of an unnamed element given only its position in the periodic table.
Typical
Students predict whether an element is a metal or non-metal, its likely reactivity, and its likely bonding behaviour from table position; explain flame test results using electron energy transitions; evaluate how atomic structure knowledge enabled development of the modern periodic table; use the table as a predictive tool rather than a reference list.
Wider
  • Investigate Mendeleev's prediction of undiscovered elements — how did electron-configuration logic (before it was understood) allow gaps to be correctly identified?
  • Examine how the spectroscope's role in identifying elemental composition (flame tests, emission spectra) connected atomic structure evidence to table organisation

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierThis node is the descriptor's full demand — using atomic structure (electron configuration) to explain both properties and organisation. Students apply everything from N1–N3 to treat the table as a predictive model, not a lookup. The flame test and emission spectra elaborations are best placed here as application contexts.
