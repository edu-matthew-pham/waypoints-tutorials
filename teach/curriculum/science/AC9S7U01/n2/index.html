Taxonomy: major groups and kingdoms

AC9S7U01 n2 · waypoint 2 of 5 · Year 7 Science · Biological · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Science: treat it as a starting suggestion and check it before use.

Checkpoint

Students can place organisms into major taxonomic groups using observable features and justify their classification

Success criteria

  • Correctly places 5 familiar organisms into kingdoms with observable feature justification
  • Identifies at least one organism that is difficult to classify and explains why

Prior knowledge

Waypoint 1: Purpose of classification.

Width

Minimum
Name the major kingdoms; correctly place 5 familiar organisms into their kingdom with justification using observable features
Typical
Sort a set of 12 organisms into kingdoms; identify one organism that is difficult to classify and explain why
Wider
  • Name and classify species using Linnaean hierarchy (kingdom → species); explain what each level represents
  • Research a boundary case (e.g. Euglena, virus) — does it fit the kingdom model? What does this reveal about classification systems?
  • Observe and identify similarities and differences of particular features within and between groups of organisms using provided specimens or images

Hinge

Students who cannot reliably assign organisms to kingdoms using observable features cannot select discriminating features when constructing keys in Node 4 — the feature-selection skill that underpins both using and constructing keys depends on having a working taxonomy foundation.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyCorrectly placing organisms into kingdoms is a classification skill that improves through accumulated examples. Students need to build a repertoire of familiar organisms across kingdoms so the feature-based judgement becomes reliable — a single set of 5 organisms is not enough to generalise the skill. More varied organism sets, including boundary cases, build the pattern recognition needed for confident classification.
