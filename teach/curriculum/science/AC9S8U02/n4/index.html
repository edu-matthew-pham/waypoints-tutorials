Organ systems — coordinated organs enabling survival

AC9S8U02 n4 · waypoint 4 of 4 · Year 8 Science · Biological

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Science: treat it as a starting suggestion and check it before use.

Checkpoint

Students can describe how organs within a system coordinate to perform a survival function, applying this to one animal and one plant system.

  • Organ systems

Success criteria

  • Names the organs of one animal and one plant system and explains the function of each
  • Explains how the coordinated system enables a specific survival function
  • Compares one plant and one animal system as solutions to a shared survival problem

Prior knowledge

Waypoint 3: Organs — tissues working together for an integrated function.

Width

Minimum
Students describe the organs of one system and explain how the system as a whole enables a named survival function.
Typical
Students analyse one animal system (circulatory — heart, blood vessels, blood; or digestive — mouth, stomach, intestines, liver) and one plant system (vascular — xylem, phloem, roots, leaves); explain how each organ's structure contributes to the system's survival function; explain that the system fails if any organ fails; connect system function to individual survival (oxygen delivery, nutrient transport, water uptake).
Wider
  • Compare the vascular system of a plant to the circulatory system of an animal as analogous solutions to the same survival problem — what structural differences reflect different organism constraints?
  • Investigate how an artificial organ (dialysis machine, pacemaker) mimics or augments the function of a real organ — what structural principles does it replicate?

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepApplying the organ system analysis to both a plant and an animal system — and comparing them as analogous solutions — builds the generalised structure-function analytical capability the descriptor's 'analyse' demand requires.
