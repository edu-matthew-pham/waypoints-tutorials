Select equipment and record data

AC9S7I03 · Years 7–8 Science · Inquiry

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Science: treat it as a starting suggestion and check it before use.

Descriptor

select and use equipment to generate and record data with precision, using digital tools as appropriate

Prior knowledge

Students can follow safe procedures to investigate questions and use basic measurement tools (AC9S5I02). They have not yet selected equipment based on measurement range or precision requirements, or used digital tools to improve data quality.

By the end

Students select and use appropriate equipment to generate and record data with precision, using digital tools as appropriate.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • selecting and using equipment appropriate to the investigation, such as ensuring a selected thermometer can measure within the range of temperatures expected, or selecting an appropriate-capacity measuring cylinder for the volume of liquid needed
  • examining how the use of digital tools such as stopwatches and digital scales can enable the generation of more precise data
  • constructing tables, spreadsheets and graphic organisers to collect data and information
  • using appropriate standard units and performing simple unit conversions when recording data
  • using digital tools such as sensors to measure abiotic factors and apps that use image or call recognition to make field identifications

Waypoints

  • 1. Selecting appropriate equipmentStudents can select equipment appropriate to an investigation's measurement needs and justify the choice
  • 2. Recording data with precisionStudents can record data in organised formats using correct units and appropriate precision
  • 3. Using digital tools for data generationStudents can use digital tools to generate more precise or efficient data and explain the advantage over manual methods
