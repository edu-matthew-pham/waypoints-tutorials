Using digital tools for data generation

AC9S7I03 n3 · waypoint 3 of 3 · Years 7–8 Science · Inquiry

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Science: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use digital tools to generate more precise or efficient data and explain the advantage over manual methods

Success criteria

  • Identifies a digital tool appropriate for a given investigation
  • Explains the advantage of the digital tool over a manual alternative
  • Uses the tool to generate data with appropriate precision

Prior knowledge

Waypoint 2: Recording data with precision.

Width

Minimum
Identify one digital tool that improves data precision or efficiency in a given investigation; explain the advantage
Typical
Use digital tools such as sensors to measure abiotic factors and apps for field identification; compare precision of digital and analogue methods
Wider
  • Evaluate how digital tools such as stopwatches and digital scales improve data precision compared to analogue equivalents
  • Use field identification apps that use image or call recognition during ecosystem investigations
  • Design a comparison between digital and manual data collection for the same investigation and analyse which produces more reliable data

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyStudents need to encounter a range of digital tools — sensors, apps, spreadsheets, identification tools — across different investigation types to understand that 'digital tool' is a broad category with varied precision advantages. Each tool type adds a different dimension to the repertoire and prevents the overgeneralisation that digital is always more precise.
