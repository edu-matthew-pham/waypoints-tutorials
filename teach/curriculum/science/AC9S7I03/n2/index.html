Recording data with precision

AC9S7I03 n2 · waypoint 2 of 3 · Years 7–8 Science · Inquiry

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Science: treat it as a starting suggestion and check it before use.

Checkpoint

Students can record data in organised formats using correct units and appropriate precision

Success criteria

  • Records data using correct standard units
  • Precision is appropriate to the equipment used
  • Data table is organised with clear headings and units

Prior knowledge

Waypoint 1: Selecting appropriate equipment.

Width

Minimum
Record data in a provided table using correct units; use appropriate precision for the equipment used
Typical
Construct tables or spreadsheets to collect data; use standard units and perform simple unit conversions; record data to the precision of the equipment
Wider
  • Limited width — recording data with correct units and consistent precision is a mechanical skill that does not vary across investigation contexts. Designing tables and evaluating recording errors are practice volume on the same conventions, not genuinely broader contexts.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsRecording data with correct units and consistent precision is a mechanical skill where students commonly make careless errors — missing units, inconsistent decimal places, unlabelled columns. The skill does not vary across contexts; what helps is repeated practice with feedback on recording quality until correct habits are automatic.
