← AC9SFI03 Representing observations and identifying patterns

Observations are represented in provided formats

AC9SFI03 n1 · waypoint 1 of 2 · Foundation Science · Inquiry · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Science: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use a provided table or graphic organiser to record or sort observations, and contribute to a shared display.

Success criteria

  • Uses a provided template or graphic organiser to record or sort at least two observations
  • Contributes to a class display of sorted observations

Prior knowledge

No formal prior science learning assumed.

Width

Minimum
Students record observations in one provided format and contribute one observation to a shared class display.
Typical
Students use provided tables and graphic organisers to sort images of plants and animals by features; collaborate on floor or wall displays linking material images to object images; and represent observations through sorting, drawing and labelling in provided templates.
Wider
  • Collaborate to create a floor or wall display linking material samples to images of objects made from them
  • Sort images of plants and animals into groups using a provided graphic organiser
  • Identify common features of familiar animal groups (fish, birds, reptiles) using a provided template

Hinge

Node 2 requires students to identify patterns in sorted data — but if students cannot use a provided template to record or sort observations, they have no organised data in which to notice patterns. The pattern-identification task in Node 2 is only legible if Node 1 produces a usable representation.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyStudents at Foundation need exposure to multiple representation formats — tables, graphic organisers, floor/wall displays — before they can reliably select and use one. Building a repertoire of recording forms prepares them to represent data in the format that surfaces patterns most clearly.
