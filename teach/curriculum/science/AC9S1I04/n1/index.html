← AC9S1I04 Processing and representing data

Data is sorted and ordered to show patterns

AC9S1I04 n1 · waypoint 1 of 1 · Years 1–2 Science · Inquiry

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Science: treat it as a starting suggestion and check it before use.

Checkpoint

Students can sort and order data into provided categories, use a provided table or graphic organiser to organise their data, and identify one pattern from the organised data.

Success criteria

  • Sorts data into at least two categories using a provided organiser
  • Identifies one pattern from the organised or ordered data

Prior knowledge

Students can sort objects by observable features (F band). They now extend to sorting and ordering scientific data and identifying patterns in provided formats.

Width

Minimum
Students sort data into two categories using a provided organiser and identify one pattern from the sorted data.
Typical
Students use pictographs, tables and graphic organisers to sort data (plants vs animals, push vs pull objects, seasonal changes across the year); order data (sequential images of plant growth, seasonal changes); and identify patterns in organised data.
Wider
  • Use pictographs with drawings or digital photographs to document patterns of plant growth
  • Order images of seasonal changes across the year — examining time-ordered pattern representation
  • Use graphic organisers to sort objects that need a push vs pull force to work
