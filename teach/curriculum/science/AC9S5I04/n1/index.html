← AC9S5I04 Processing and representing data

Representations are selected and constructed for a given data type

AC9S5I04 n1 · waypoint 1 of 2 · Years 5–6 Science · Inquiry · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Science: treat it as a starting suggestion and check it before use.

Checkpoint

Students can select an appropriate representation type for a given data set or relationship and construct it accurately — with correct labels, conventions and structure.

Success criteria

  • Selects a representation type appropriate to the data or relationship and explains why it suits the purpose
  • Constructs the representation with correct labels, units and conventions for the chosen type

Prior knowledge

Students can construct tables and column graphs and use visual/physical models (AC9S3I04, 3-4 band). They now extend to selecting appropriate representations independently, constructing a wider range of types (ray diagrams, annotated field sketches, maps, physical landscape models), and using representations to identify and describe patterns, trends and relationships — not just to display data.

Width

Minimum
Students select and construct one appropriate representation for a given data set and explain why that representation type suits the data.
Typical
Students select and construct representations across Y5-6 science contexts — annotated field sketches for structural features, column graphs for simulation outcomes, physical landscape models for erosion, labelled ray diagrams for light behaviour, maps for erosion pattern distribution — and justify the representation type chosen in each case.
Wider
  • Compare two different representation types for the same data set and explain what each communicates that the other does not — examining representation as a deliberate choice
  • Construct labelled ray diagrams for light reflection and refraction scenarios — applying a new representation convention to Y5 physical science content
  • Use maps or aerial photographs to represent spatial data on erosion site locations — examining how spatial representation suits geographically distributed data

Hinge

Constructing a valid representation is the prerequisite for Node 2 interpretation — students cannot extract patterns from a malformed or wrong-type representation. A student who defaults to column graphs regardless of data type will be unable to use maps or ray diagrams to identify the patterns those representations are designed to reveal.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents at this band encounter a wider range of representation types than at 3-4 band — ray diagrams, annotated photographs, physical landscape models and maps are all new. Building fluency in selecting the right type for the data, and constructing each accurately, requires encountering varied representation types across different science contexts. Without breadth, students default to familiar formats (tables, column graphs) regardless of data type.
