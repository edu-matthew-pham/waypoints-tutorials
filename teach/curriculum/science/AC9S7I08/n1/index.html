Purpose, audience and text type

AC9S7I08 n1 · waypoint 1 of 3 · Years 7–8 Science · Inquiry

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Science: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify the purpose and audience of scientific texts and select an appropriate text type

Success criteria

  • Identifies the purpose and target audience of a scientific text
  • Explains how the text type suits the audience
  • Does not assume all scientific communication uses the same format

Prior knowledge

Students can write and create texts to communicate ideas and findings for specific purposes and audiences (AC9S5I06). They have not yet selected language and text features strategically for purpose and audience or produced multi-modal scientific communications.

Width

Minimum
Identify the purpose and target audience of a given scientific text; explain how the text type suits the audience
Typical
Examine a range of scientific texts; infer purpose and audience from language and text features; select appropriate text types for different communication purposes
Wider
  • Compare how the same scientific finding is communicated in a journal article, a news report and a social media post — explain what changes and why
  • Evaluate a scientific text that is poorly matched to its audience and explain what should change
  • Analyse how First Nations Australians scientists communicate science to diverse audiences and what text features they use

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents commonly write for a generic audience rather than making deliberate choices about language, detail level and text features for a specific reader. Examining multiple text types across different purposes — journal, news, social media, letter to editor, animation — helps students see that communication is a design decision, not a fixed format. Each new text type reveals different choices and trade-offs.
