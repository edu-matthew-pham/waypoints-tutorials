Organising data using appropriate formats

AC9HE7S02 n3 · waypoint 3 of 3 · Year 7 Economics and Business · Skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Economics and Business: treat it as a starting suggestion and check it before use.

Checkpoint

Students can organise information and data into appropriate formats — tables, graphs, visual displays — using digital tools.

Lessons on this site

  • Organise what you found

Success criteria

  • Organises selected information into an appropriate format using a digital tool
  • Explains why the chosen format suits the data type

Prior knowledge

Waypoint 2: Selecting relevant information.

Width

Minimum
Organise selected information into one appropriate format (table or graph) using a digital tool; explain why the format suits the data.
Typical
Organise data into appropriate formats using specialised digital tools — tables, graphs, visual displays; select the format that best suits the type and purpose of the data; apply to economics data (e.g. income data, business type counts, consumer trend data).
Wider
  • Organise multi-variable data (e.g. employment type by age group) into a format that makes the relevant relationship visible — comparing multiple format options before selecting
  • Curate a visual display combining data from multiple sources — practising how to integrate information from different formats into a coherent organised product
  • Use a digital tool to organise qualitative data (e.g. interview responses from an entrepreneur) into a structured format suitable for analysis

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsFormat selection requires practice with real data across multiple types. Students who default to one format (usually a table) need explicit experience with graphs and visual displays to build a repertoire of organisation strategies.
