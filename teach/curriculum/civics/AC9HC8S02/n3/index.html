Organising sources: identifying bias and selective information

AC9HC8S02 n3 · waypoint 3 of 3 · Year 8 Civics and Citizenship · Skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Civics and Citizenship: treat it as a starting suggestion and check it before use.

Checkpoint

Students can organise information from different sources by identifying bias, language choices and selective use of information — and explain how these features affect the value of the source for civic inquiry.

Success criteria

  • Can identify at least one example of bias, selective information or language choice in a civic source
  • Can explain how that feature affects what the source presents and what it leaves out

Prior knowledge

Waypoint 2: Selecting sources: accuracy and reliability.

Width

Minimum
Identify one example of bias, selective information use or language choice in a source about a civic issue and explain how it affects the source's usefulness.
Typical
Organise ideas from different sources — including opinion pieces, political party materials, government reports and independent organisation reports — by identifying bias, language choices and selective use of information, and explain how these features affect the picture each source presents of a civic issue.
Wider
  • Compare how a government report and an opposition party document present the same civic policy issue — systematically identifying differences in language, emphasis and what each source omits
  • Investigate how to construct a source matrix that maps multiple sources on a civic issue against dimensions of perspective, reliability and coverage — practising systematic source organisation
  • Examine how framing effects — the way an issue is named and contextualised — shape how different sources present the same civic facts

Response modes
