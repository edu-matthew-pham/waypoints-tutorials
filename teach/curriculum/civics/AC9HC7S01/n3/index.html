Using current events to generate civic questions

AC9HC7S01 n3 · waypoint 3 of 3 · Year 7 Civics and Citizenship · Skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Civics and Citizenship: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use current events to generate focused questions that apply to a wider civic investigation, connecting news events to the underlying political or legal concepts they illustrate.

Success criteria

  • Identify a current event related to a civic issue and develop a focused question connecting it to a broader civic concept
  • Explain what makes this question more useful for civic investigation than simply asking 'what happened'

Prior knowledge

Waypoint 2: Developing a key inquiry question.

Width

Minimum
Identify a current news event related to a civic issue and develop one question that connects the event to a broader political or legal concept.
Typical
Use current events to generate questions that apply to a wider investigation; for example, derive a question about freedom of expression protections from a news story about misinformation; explain how the current event illustrates an underlying civic issue.
Wider
  • Track a developing news story over several days and generate a sequence of questions that evolve as new information emerges, practising the dynamic nature of inquiry
  • Compare how the same current event generates different inquiry questions depending on whether the investigator is using a democratic, legal, or social cohesion lens
  • Investigate an international civic issue and develop questions that allow comparison with Australian systems — practising cross-contextual civic inquiry

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepDifferent current events surface different types of civic questions — using varied events (court decisions, election campaigns, government announcements, protest actions) builds the range of question types students can generate.
