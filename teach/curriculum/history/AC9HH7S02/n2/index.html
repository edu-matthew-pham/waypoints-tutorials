Locating sources — repositories and search strategies

AC9HH7S02 n2 · waypoint 2 of 3 · Year 7 History · Historical skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in History: treat it as a starting suggestion and check it before use.

Checkpoint

Students can locate primary and secondary sources using digital repositories, archives, and research databases, applying appropriate search strategies to find relevant evidence for a historical inquiry question.

Success criteria

  • Successfully locates at least one primary and one secondary source relevant to a given inquiry question.
  • Identifies the repository or database used and explains why it was appropriate for the source type sought.
  • Uses subject-specific search terms rather than general keyword searches.

Prior knowledge

Waypoint 1: Primary and secondary sources — the disciplinary distinction.

Width

Minimum
Use a digital repository or search tool to locate at least one primary and one secondary source relevant to a historical inquiry question.
Typical
Locate primary and secondary sources using digital repositories (e.g. museum collections, archival databases, library catalogues) and research databases, applying search strategies such as filtering by source type, using subject-specific keywords, and selecting search terms relevant to the inquiry question.
Wider
  • Investigate how different repositories specialise in different source types — museum collections for artefacts, national archives for government documents, digital humanities projects for ancient texts — and develop strategies for knowing where to look for different types of evidence.
  • Examine how digital repositories of archaeological sources and records can be searched using subject filters; for example, searching Rome ceramics + religion to find relevant artefacts, and what the search results reveal about the type and scope of available evidence.
  • Explore the difference between a Google search and a disciplinary repository search — examining why historians use specialised databases and what is lost when research is limited to general web searches.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsLocating sources across different repository types — museum collections, archival databases, library catalogues — requires practice with different interfaces, search filters, and keyword strategies. Students need repeated exposure to different repository types before they can independently identify which tool is appropriate for a given source type and apply effective search strategies.
