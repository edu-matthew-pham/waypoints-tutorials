Representativeness and broader societal values

AC9HH8S06 n2 · waypoint 2 of 3 · Year 8 History · Historical skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in History: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use additional sources to assess whether an individual account's values and attitudes are broadly representative of the society, or contrast with it — and explain the significance of this for the source's usefulness.

Success criteria

  • Uses at least one additional source to assess whether an individual account's values are broadly representative or contrasting
  • Explains the significance of this assessment for the source's usefulness in a historical inquiry

Prior knowledge

Waypoint 1: Values and attitudes in individual sources.

Width

Minimum
Use of at least one additional source to assess whether the values in the first source are representative of the broader society.
Typical
Corroboration across sources: using multiple sources to determine whether an individual account's values represent a majority position, a minority perspective, or an official view that masked dissent. Examples: comparing individual accounts of the Black Death (Villani, Boccaccio, Ibn Khaldun) to assess whether their values and attitudes are broadly shared; examining whether the monks' accounts of Viking raids reflect wider Christian society's values about the Vikings.
Wider
  • Compare the values revealed by sources from different social groups about the same event — e.g. aristocratic vs peasant accounts of the feudal system — to show how societal values are not uniform but contested across class and position
  • Examine how the values of different historians — shaped by their own national, cultural or political contexts — have led them to different interpretations of the same medieval sources

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepRepresentativeness assessment requires multiple sources from different positions within the same society. Varying the types of sources used (individual accounts, official records, visual sources, artefacts) builds a richer picture of whose values are represented and whose are not.
