← AC9HH9S02 Locate and identify primary and secondary sources

Comparing sources and using digital data

AC9HH9S02 n2 · waypoint 2 of 2 · Year 9 History · Historical skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in History: treat it as a starting suggestion and check it before use.

Checkpoint

Students can compare sources across repositories to analyse changes over time, including using digital data sources such as immigration records.

Success criteria

  • Compares at least two sources and identifies at least one difference in what they offer as historical evidence
  • Explains how at least one digital or data source differs from a qualitative primary source in what it reveals about the past

Prior knowledge

Waypoint 1: Locating sources across repositories.

Width

Minimum
Compare two sources on the same topic and identify at least one difference in what they offer as evidence.
Typical
Compare sources to analyse changes over time including data from online records such as immigration records; explain how quantitative data sources (immigration records, census data, ship manifests) differ from qualitative primary sources in what they reveal and conceal; locate and compare multiple sources on the same inquiry question to assess convergence and divergence in what sources show.
Wider
  • Use quantitative digital sources (e.g. immigration records, population census data from the period) alongside qualitative primary sources (diaries, newspapers) for the same inquiry question — practising the integration of different source types
  • Investigate a specific historical question using only digitised sources from one major repository, then assess what the inquiry is missing compared to a broader source search — developing critical awareness of how source selection shapes historical conclusions

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepUsing both quantitative digital sources and qualitative primary sources for the same inquiry question is a distinct task context — practising both develops a more complete repertoire of source-locating skill.
