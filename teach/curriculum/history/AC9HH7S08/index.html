Create historical arguments

AC9HH7S08 · Year 7 History · Historical skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in History: treat it as a starting suggestion and check it before use.

Descriptor

create descriptions, explanations and historical arguments, using historical knowledge, concepts and terms that reference evidence from sources

Prior knowledge

Students can explain historical interpretations about significant events, individuals, and groups, and develop reasoned arguments about why interpretations differ (AC9HH7S07). Students can identify and describe the accuracy and usefulness of sources, identify perspectives, and explain causes, effects, continuities, and changes (AC9HH7S03–S07). They have not yet produced formal historical descriptions, explanations, and arguments — texts that integrate historical knowledge, disciplinary concepts and terms, and source references into coherent historical communication.

By the end

Students create historical descriptions, explanations, and arguments that use historical knowledge, concepts, and terms, and that reference evidence from sources — producing texts that demonstrate command of historical communication conventions at Year 7 level.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • communicating a description or explanation using historical knowledge (for example, describing the social structure of the society) referring to evidence from sources (for example, reference to artwork)
  • developing a description or explanation using historical concepts and terms; for example, sources, evidence, continuity and change, perspective or interpretation
  • creating a presentation using different formats; for example, visual displays to recreate and show the specific features of an ancient battle, temple, pyramid complex or burial site supported by a timeline, annotations on a diagram or a summary
  • developing a historical argument; for example, explaining the significance of a past event, providing reasons for the event with reference to relevant evidence

Waypoints

  • 1. Historical description — communicating knowledge with evidenceHingeStudents can create a historical description that uses historical knowledge and subject-specific terms and refers to evidence from sources — a text that accurately describes a historical topic with appropriate disciplinary language.
  • 2. Historical explanation — reasoning with evidenceHingeStudents can create a historical explanation that uses historical knowledge, concepts, and terms to explain a causation, continuity/change, or significance question, with evidence from sources to support the reasoning.
  • 3. Historical argument — taking and supporting a position with evidenceStudents can create a historical argument about a historical topic — developing a position about significance, interpretation, or causation, supporting it with evidence from sources, and using historical knowledge, concepts, and terms throughout.
