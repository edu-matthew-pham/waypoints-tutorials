← AC9LCH8U03 Similarities and differences between target language and English using metalanguage

Extended metalanguage for text and grammar analysis

AC9LCH8U03 n1 · waypoint 1 of 3 · Years 7–8 Languages · Background speakers, F–10: understanding · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use extended metalanguage to describe and explain a range of text-level and grammatical features in both the target language and English.

Success criteria

  • Uses at least six metalanguage terms correctly across a text or grammar analysis
  • Includes at least one text-level and one grammatical metalanguage term used accurately

Prior knowledge

Students can compare language structures and features across the target language and English using metalanguage, and produce comparative analyses (AC9LCH6U03). They have compared text types, grammar and cohesive devices. They have not yet taught younger students using comparative frameworks, explored metaphorical versus literal meaning across languages, or applied comparative understanding to unlock unfamiliar content.

Width

Minimum
Use at least six metalanguage terms correctly across a text or grammar analysis that covers both languages, including at least one text-level term (e.g. paragraph, cohesion, point of view) and one grammatical term.
Typical
Use extended metalanguage for text features — paragraphing, conjunctions, sequencing, point of view, descriptive and emotive language; compare how these features work in target language and English texts; read formal texts such as reports and news articles and compare with own everyday speech.
Wider
  • Annotate a target language text fully using metalanguage for every grammatical and textual feature — compare the annotation with an English equivalent and identify all structural differences
  • Create a metalanguage comparison resource for a specific feature that differs across the two languages — designed to be used by another learner

Hinge

Extended metalanguage is the prerequisite for systematic language comparison and for supporting others' language learning. Students who cannot name and describe language features cannot explain similarities and differences, cannot apply comparative knowledge to unfamiliar content, and cannot teach others.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyMetalanguage is built through repeated deployment across varied analysis tasks — not through a single lesson. Students need to encounter and use each metalanguage term across multiple text types and comparison contexts before it becomes functional analytical vocabulary.
