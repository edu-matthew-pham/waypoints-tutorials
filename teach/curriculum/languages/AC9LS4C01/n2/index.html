← AC9LS4C01 Initiate exchanges and respond about self and environment

Describing environment, features and locations

AC9LS4C01 n2 · waypoint 2 of 3 · Years 3–4 Languages · Second language, F–10: communicating

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can describe the features, characteristics and locations of things and places in the classroom environment using location language and descriptive expressions.

Lessons on this site

None yet.

Success criteria

  • Uses at least two different location expressions correctly to describe the position of objects
  • Describes at least one characteristic or feature of a place or object using appropriate target language

Prior knowledge

Waypoint 1: Initiating and responding in personal exchanges.

Width

Minimum
Describe the location of at least two objects using location expressions; describe at least one feature or characteristic of a place or object.
Typical
Use a range of location expressions; describe characteristics, size and location of places and things; respond to questions about the classroom environment; use question-answer patterns about school life and surroundings.
Wider
  • Give and follow multi-step directions to locate an object or place — demonstrating command of spatial language beyond single-object description
  • Describe a space outside the immediate classroom using at least four different location or descriptive expressions

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepLocation and descriptive language develops through practice across varied physical environments and object sets. Students who only describe the immediate classroom develop narrow spatial language schemas.
