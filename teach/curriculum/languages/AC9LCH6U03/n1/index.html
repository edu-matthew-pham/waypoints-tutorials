Comparing grammatical features across languages

AC9LCH6U03 n1 · waypoint 1 of 3 · Years 5–6 Languages · Background speakers, F–10: understanding · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can compare specific grammatical features across the target language and English — including voice, tense encoding, comparative structures, and adjectival functions — using metalanguage.

Success criteria

  • Compares at least two grammatical features across target language and English using metalanguage
  • Explains for each feature where the two languages work similarly and where they differ

Prior knowledge

Students can compare text features, genre conventions and grammar patterns across target language and English using metalanguage (AC9LCH4U03). They can analyse cross-linguistic influence. They have not yet compared grammatical features systematically across different text types — active/passive voice, tense encoding, text cohesion, comparatives — or used metalanguage for text-level and grammatical analysis across multiple categories.

Width

Minimum
Compare at least two grammatical features across the target language and English using metalanguage, explaining where the features work similarly and where they differ.
Typical
Compare passive and active voice across target language and English; compare tense encoding (conjugation versus time expressions); compare comparative and superlative structures; explore adjectival verb constructions; use metalanguage from both languages to describe grammatical rules.
Wider
  • Investigate a grammatical feature that exists in the target language but not in English (or vice versa) — explain what communicative function it serves and how the other language handles the same communicative need
  • Create a bilingual grammar comparison resource — explaining a specific grammatical contrast to a student learning one of the two languages

Hinge

Grammatical comparison using metalanguage is the prerequisite for all analytical text work at this level. Students who cannot describe grammatical differences using metalanguage cannot analyse texts, explain language choices, or support their own writing decisions with linguistic reasoning.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkGrammatical comparison requires students to hold two systems in mind simultaneously and reason about structural differences. Explicit comparison frames and systematic category-by-category analysis build the analytical capacity before students can compare independently.
