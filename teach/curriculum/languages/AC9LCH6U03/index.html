Compare target language and English structures using metalanguage

AC9LCH6U03 · Years 5–6 Languages · Background speakers, F–10: understanding

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Descriptor

compare some target language structures and features with those of English, using some familiar metalanguage

Prior knowledge

Students can compare text features, genre conventions and grammar patterns across target language and English using metalanguage (AC9LCH4U03). They can analyse cross-linguistic influence. They have not yet compared grammatical features systematically across different text types — active/passive voice, tense encoding, text cohesion, comparatives — or used metalanguage for text-level and grammatical analysis across multiple categories.

By the end

Students compare structures and features of the target language and English across text types and grammatical categories, using metalanguage — including text organisation, grammar rules, voice, tense encoding, and cohesive devices.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • discussing aspects of grammar using metalanguage in Chinese or English
  • identifying and comparing language features of different text types in Chinese and English
  • comparing the use of passive voice and active voice in Chinese and English
  • comparing structural features of familiar personal, informative and imaginative texts
  • comparing different types of texts such as recipes, songs, stories and recounts
  • creating comparative lists of vocabulary used in different contexts
  • understanding how to create textual cohesion using adverbs of sequence and conjunctions
  • recognising grammatical features and how their use differs in Chinese and English
  • comparing the use of tenses in Chinese and English

Waypoints

  • 1. Comparing grammatical features across languagesHingeStudents can compare specific grammatical features across the target language and English — including voice, tense encoding, comparative structures, and adjectival functions — using metalanguage.
  • 2. Comparing text types and cohesive conventionsStudents can compare structural features, language conventions and cohesive devices across text types in the target language and English.
  • 3. Creating comparative analyses using metalanguageStudents can produce a structured language comparison — written or presented — using metalanguage to explain patterns of similarity and difference across the target language and English.
