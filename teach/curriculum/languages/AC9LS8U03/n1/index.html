← AC9LS8U03 Reflect on target language and English structures using metalanguage

Whole-text coherence and text-type conventions

AC9LS8U03 n1 · waypoint 1 of 2 · Years 7–8 Languages · Second language, F–10: understanding · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use metalanguage to compare whole-text coherence features and text-type conventions across the target language and English.

Success criteria

  • Identifies at least two whole-text coherence features in a target language text using metalanguage
  • Compares at least one text-type convention across the target language and English, explaining the difference

Prior knowledge

Students can compare target language and English structures using metalanguage across grammatical features, text types and persuasive language (AC9LS6U03). They have not yet used metalanguage to analyse whole-text coherence, or explored historical vocabulary influences.

Width

Minimum
Identify at least two whole-text coherence features in a target language text using metalanguage; compare at least one text-type convention across the target language and English.
Typical
Compare descriptive, reflective and persuasive language across text types in both languages; identify and analyse language features used to create effects in different text types; compare textual coherence elements — cohesive devices, introductions, summaries, linked paragraphs; compare text conventions across communication modes.
Wider
  • Analyse a target language and English text of the same type — use metalanguage to annotate every coherence feature and compare how each language achieves coherence
  • Compare advertising texts in the target language and English — annotate every persuasive feature in each and compare how each language constructs persuasion

Hinge

Whole-text metalinguistic analysis is the analytical tool for the text evaluation and synthesis work at subsequent bands. Students who only apply metalanguage at word or sentence level cannot engage with text-level evaluation.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkWhole-text coherence analysis requires students to hold the full text in view while applying metalanguage to structural and connective features. Structured annotation tasks scaffold this whole-text analytical attention.
