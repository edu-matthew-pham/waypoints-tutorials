Create texts using familiar language

AC9LS2C05 · Years 1–2 Languages · Second language, F–10: communicating

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Descriptor

use words, familiar phrases and modelled language to create spoken, written and multimodal texts

Prior knowledge

Students can communicate using modelled words and formulaic phrases (AC9LSF01) and respond to texts using gestures, images and words (AC9LS2C03). They have not yet created their own texts — they have only responded to or repeated modelled language.

By the end

Students use familiar words, phrases and modelled language to create spoken, written and multimodal texts about themselves, familiar topics and imaginative subjects.

Waypoints

  • 1. Creating texts about selfHingeStudents can create simple spoken and written texts about themselves — including profiles and descriptions — using familiar vocabulary and modelled sentence structures.
  • 2. Creating imaginative and informative multimodal textsStudents can create imaginative and informative multimodal texts — describing characters, places and familiar topics — using familiar vocabulary and adapted modelled language.
  • 3. Creating for real audiences and purposesStudents can create texts that serve real communicative purposes for genuine audiences — including cards, bilingual captions, event materials and labelled displays.
