← AC9LS2C05 Create texts using familiar language

Creating imaginative and informative multimodal texts

AC9LS2C05 n2 · waypoint 2 of 3 · Years 1–2 Languages · Second language, F–10: communicating

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can create imaginative and informative multimodal texts — describing characters, places and familiar topics — using familiar vocabulary and adapted modelled language.

None yet.

Success criteria

  • Creates at least one multimodal text combining visual and target language elements about an imaginative or informative topic
  • Uses adapted (not verbatim) modelled language in at least one creation — demonstrating flexibility beyond direct copying

Prior knowledge

Waypoint 1: Creating texts about self.

Width

Minimum
Create at least one multimodal text (spoken and visual, or written and visual) about a character, place or event using familiar target language.
Typical
Create character descriptions, story re-enactments, simple informative texts and bilingual captions using familiar vocabulary; add captions to displays; substitute words to create alternative versions of known stories or songs.
Wider
  • Substitute multiple elements to create a genuinely adapted version of a known story or song — changing character, setting and at least one action
  • Create a multimodal text across both imaginative and informative modes on the same topic — demonstrating flexible use of familiar language

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepText creation skills develop through varied text types and purposes. Creating across informative and imaginative modes — and across modalities — builds flexible production capacity.
