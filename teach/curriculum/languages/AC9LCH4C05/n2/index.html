Creating informative texts for a purpose and audience

AC9LCH4C05 n2 · waypoint 2 of 3 · Years 3–4 Languages · Background speakers, F–10: communicating

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can create informative texts in spoken, written or multimodal form using appropriate textual conventions, with supporting visual elements where relevant.

Success criteria

  • Creates an informative text using at least five target language sentences with appropriate format conventions
  • Uses at least one supporting visual element (image, chart, or diagram) appropriately in the text

Prior knowledge

Waypoint 1: Using a range of sentence structures.

Width

Minimum
Create at least one informative text (display, presentation, poster, or report) using at least five target language sentences with appropriate textual conventions.
Typical
Create informative texts — visual displays, presentations, annotated posters, digital storyboards — about topics of personal or community interest; use supporting images, charts and graphs; convey information about school, community and cultural topics; create descriptions for real-world contexts.
Wider
  • Create an informative text for a real external audience — for example, a travel brochure, a community newsletter, or a First Nations Country/Place description — with language and format selected for that audience
  • Compare the language features of two different informative text types — identify how audience and purpose shape vocabulary and structure choices

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepInformative text creation requires students to understand that different purposes and audiences call for different conventions. Varied creation tasks — presentation, poster, storyboard, digital text — build this contextual awareness before students can make independent text-type choices.
