← AC9LS8EC02 Develop language for classroom exchanges

Participating in collaborative tasks and activities

AC9LS8EC02 n4 · waypoint 4 of 4 · Years 7–8 Languages · Second language, from Year 7: communicating

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can participate in collaborative classroom tasks and games using target language for sharing, encouraging, taking turns and completing joint activities.

Lessons on this site

None yet.

Success criteria

  • Uses at least one functional target language phrase (instruction, asking, opinion) spontaneously during a collaborative task — not only in a scripted exchange
  • Can complete a paired or group activity with the target language as the primary medium of interaction

Prior knowledge

Waypoint 3: Expressing opinions and reactions.

Width

Minimum
Complete one collaborative classroom task using target language for at least one functional purpose (e.g. taking turns, asking a partner for information).
Typical
Participate in games, paired activities and group tasks using target language to share, praise, encourage and coordinate; use classroom instruction language to manage the activity.
Wider
  • Design and facilitate a simple classroom game that requires participants to use target language throughout (not just as a trigger for an English activity)
  • Facilitate a class routine (roll call, task distribution, instructions to peers) using only target language

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierCollaborative tasks are where instructions, asking strategies and opinion phrases from nodes 1–3 operate simultaneously. The teaching investment is in creating task structures where students must draw on multiple functional language sets at once.
