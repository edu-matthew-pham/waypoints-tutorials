Creating informative texts for presentation

AC9LS4C05 n1 · waypoint 1 of 3 · Years 3–4 Languages · Second language, F–10: communicating · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can create simple informative texts for presentation — reports, profiles, displays, captions — using familiar vocabulary and modelled sentence structures.

Success criteria

  • Creates an informative text with at least five target language elements appropriate to the topic
  • Presents the text to an audience using appropriate spoken support

Prior knowledge

Students can create spoken, written and multimodal texts using familiar words, phrases and modelled language (AC9LS2C05). They have not yet created informative texts for presentation purposes, used modelled textual conventions for specific text types, or created texts for external audiences.

Width

Minimum
Create at least one informative text for presentation using at least five target language elements with appropriate content.
Typical
Create class reports, visual and digital displays, self-profiles and informative presentations on familiar topics; use captioned photos and digital formats; add labels, captions and descriptions to images; create bilingual texts; describe locations and cultural contexts using modelled language.
Wider
  • Create an informative presentation that goes beyond copying facts — including personal selection of most interesting information and an explanation of why it was chosen
  • Create a bilingual informative text for a specified audience — making deliberate decisions about which language to use for which part

Hinge

Creating informative texts for presentation introduces the expectation that text creation serves an audience — not only personal expression. Students who cannot produce informative content for a defined purpose and audience cannot engage with the text-type and audience demands of subsequent bands.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepInformative text creation develops through varied topic and format conditions. Students who only create one type develop narrow production schemas. Varied text types — reports, profiles, displays, maps — build flexible informative production capacity.
