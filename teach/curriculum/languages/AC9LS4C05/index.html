Create informative and imaginative texts

AC9LS4C05 · Years 3–4 Languages · Second language, F–10: communicating

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Descriptor

create and present informative and imaginative spoken, written and multimodal texts using formulaic expressions, simple phrases and sentences and modelled textual conventions

Prior knowledge

Students can create spoken, written and multimodal texts using familiar words, phrases and modelled language (AC9LS2C05). They have not yet created informative texts for presentation purposes, used modelled textual conventions for specific text types, or created texts for external audiences.

By the end

Students create and present informative and imaginative spoken, written and multimodal texts using formulaic expressions, simple phrases, sentences and modelled textual conventions across a range of purposes and audiences.

Waypoints

  • 1. Creating informative texts for presentationHingeStudents can create simple informative texts for presentation — reports, profiles, displays, captions — using familiar vocabulary and modelled sentence structures.
  • 2. Creating imaginative texts using modelled conventionsStudents can create imaginative texts — stories, scripts, adapted performances, songs — using modelled textual conventions and familiar language.
  • 3. Presenting texts for genuine audiencesStudents can present informative and imaginative texts to genuine audiences — using appropriate delivery strategies for the audience and purpose.
