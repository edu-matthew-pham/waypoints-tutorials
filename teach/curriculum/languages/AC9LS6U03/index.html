Compare target language and English structures using metalanguage

AC9LS6U03 · Years 5–6 Languages · Second language, F–10: understanding

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Descriptor

compare some target language structures and features with those of English, using some familiar metalanguage

Prior knowledge

Students can recognise familiar target language features and compare with English using grammatical metalanguage (AC9LS4U03). They apply metalanguage to grammar comparison. They have not yet compared grammatical features in text production contexts, analysed persuasive language effects, or explored informal and youth language varieties.

By the end

Students compare target language and English language structures and features using metalanguage — including text-type conventions, persuasive language, informal variety and vocabulary pattern connections.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • comparing features of simple spoken and written texts in the target language with similar texts in English
  • comparing language use in advertisements and signs, noticing how different text types in each language create specific effects
  • using metalanguage in both the target language and English to discuss grammatical structures and features
  • recognising grammatical elements associated with particular texts in each language
  • exploring the use and popularity of abbreviations and phrases used by young people in target language communities and Australia
  • noticing similar word stems in the target language and English to identify meaning and extend vocabulary
  • compiling a graphic organiser to illustrate differences in grammar and textual conventions
  • comparing the use of diminutives to express affection and familiarity, with equivalents in English

Waypoints

  • 1. Comparing grammatical structures and text conventionsHingeStudents can compare grammatical structures and text conventions across the target language and English using metalanguage — identifying what each language does differently and explaining it.
  • 2. Persuasive language, informal varieties and vocabulary patternsStudents can identify and compare persuasive language in target language and English texts, and explore informal language varieties and vocabulary patterns.
