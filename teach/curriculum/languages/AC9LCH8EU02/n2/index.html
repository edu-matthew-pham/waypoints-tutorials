← AC9LCH8EU02 Characters, sentence structures and syntax

Writing system conventions and sentence construction

AC9LCH8EU02 n2 · waypoint 2 of 3 · Years 7–8 Languages · Background speakers, from Year 7: understanding

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can apply stroke order and direction rules, use punctuation correctly, and construct a range of sentence types — affirmative, negative, interrogative, imperative — using cohesive devices.

Success criteria

  • Writes at least five characters with correct stroke order
  • Produces at least three sentences using different sentence types with correct punctuation

Prior knowledge

Waypoint 1: Character analysis and morphological inference.

Width

Minimum
Write at least five characters with correct stroke order, and produce at least three sentences using different sentence types with correct punctuation.
Typical
Apply stroke order and direction when writing characters; use digital tools for unknown characters; use punctuation conventions; construct affirmative, negative, interrogative and imperative sentences; join, contrast and sequence using cohesive devices; use complement, extent and direction constructions.
Wider
  • Investigate running script or cursive forms of familiar characters — compare with standard printed forms and discuss the relationship between form and function
  • Create an annotated sentence analysis — label every grammatical component using metalanguage and explain the contribution of each to the overall meaning

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsWriting system conventions and sentence construction require repeated production practice. Regular writing tasks with attention to stroke order, punctuation and varied sentence types build the accurate productive competence needed.
