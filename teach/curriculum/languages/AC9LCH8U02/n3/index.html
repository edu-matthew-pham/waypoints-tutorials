← AC9LCH8U02 Character form and function, sentence structures and syntax

Full sentence-type range in composed texts

AC9LCH8U02 n3 · waypoint 3 of 3 · Years 7–8 Languages · Background speakers, F–10: understanding

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can compose texts using the full range of sentence types — affirmative, negative, interrogative, imperative — and apply full writing system and syntactic knowledge across a range of text types.

Lessons on this site

None yet.

Success criteria

  • Composes a text using at least three different sentence types with correct syntax
  • Applies appropriate punctuation and writing system conventions throughout the text

Prior knowledge

Waypoint 2: Modal, tense-expression and exclamatory structures.

Width

Minimum
Compose a text using at least three different sentence types correctly, with appropriate punctuation and writing system conventions throughout.
Typical
Construct and use affirmative, negative, interrogative and imperative sentences for different purposes; apply understanding of word order and sentence construction including target language-specific grammatical structures; compose texts across a range of types applying full grammatical knowledge.
Wider
  • Analyse a model text and annotate every sentence for type, modal/tense structure, and syntactic feature — then compose an equivalent text using the same full syntactic repertoire
  • Create a text that deliberately uses each sentence type for a different communicative function — explain how each type serves a purpose in the overall text

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierFull sentence-type range in composed texts integrates morphological production (node 1) and modal/tense structure knowledge (node 2) into complete compositional competence. The teaching investment is in extended writing tasks that require varied sentence types — not only narrative or only information tasks, but the full communicative range.
