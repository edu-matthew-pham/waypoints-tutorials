← AC9LCH10EU03 Analyse texts using metalanguage

Stylistic and linguistic analysis

AC9LCH10EU03 n1 · waypoint 1 of 3 · Years 9–10 Languages · Background speakers, from Year 7: understanding · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify and analyse grammatical differences between languages using metalanguage, and analyse language in a range of text types for purpose and audience.

Success criteria

  • Uses metalanguage to analyse at least three linguistic features in a target language text
  • Compares at least one feature with its English equivalent

Prior knowledge

Students can compare language structures and features across target language and English using metalanguage (AC9LCH8EU03). They have applied comparative metalanguage to text types and genre conventions. They have not yet conducted full stylistic analysis of target language texts, examined essay organisation conventions specific to the target language, analysed language in media contexts, or described genres unique to the target language literary tradition.

Width

Minimum
Use metalanguage to analyse at least three linguistic features in a target language text, and compare at least one feature with its English equivalent.
Typical
Use metalanguage to identify grammatical differences across languages — word order, verb mood, tense, possessive pronouns; analyse sequence of content in different text types; explain use of data and evidence in texts; analyse language in emails, blogs, news articles for purpose differences; identify linguistic terms in media reporting.
Wider
  • Produce a full linguistic and textual analysis of a target language text — annotating every feature with metalanguage and explaining its contribution to the text's purpose
  • Compare how the same linguistic feature operates across formal and informal registers in the target language — explain the difference and discuss the cultural logic behind it

Hinge

Linguistic and textual analysis using metalanguage is the prerequisite for all sophisticated text engagement at Y9-10. Students who cannot name and analyse language features cannot produce the analytical responses the descriptor requires.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyMetalanguage for analysis is built through repeated deployment across varied text types. Students need to encounter and apply each metalanguage term across multiple text analysis contexts before it becomes functional analytical vocabulary.
