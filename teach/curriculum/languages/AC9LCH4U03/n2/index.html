Metalanguage for grammar comparison

AC9LCH4U03 n2 · waypoint 2 of 3 · Years 3–4 Languages · Background speakers, F–10: understanding

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use metalanguage to describe grammar rules in the target language and compare grammatical conventions across the target language and English.

Lessons on this site

None yet.

Success criteria

  • Uses at least four metalanguage terms correctly in a grammar description or comparison
  • Explains at least one grammatical rule in the target language using metalanguage

Prior knowledge

Waypoint 1: Genre features and text purpose.

Width

Minimum
Use at least four metalanguage terms correctly in describing a grammar rule or comparison between the target language and English.
Typical
Use metalanguage to describe placement rules, word class functions and sentence-level patterns in the target language; compare grammatical conventions with English; identify where similar terms describe different grammatical functions across the two languages.
Wider
  • Annotate a short target language text using metalanguage labels — then compare the annotation with an equivalent English text annotation and identify structural differences
  • Investigate a grammatical feature that is named differently or functions differently in the target language metalanguage versus English metalanguage — explain the difference to a peer

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyMetalanguage for grammar is built through repeated use across different comparison tasks — not through a single lesson on terminology. Students need to encounter and deploy metalanguage across multiple text analysis and comparison contexts before it becomes functional vocabulary.
