← AC9LCH2U03 Target language features similar to and different from English

Text features and metalanguage for language types

AC9LCH2U03 n3 · waypoint 3 of 3 · Years 1–2 Languages · Background speakers, F–10: understanding

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in Languages: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify similarities and differences in text features across the target language and English, and use simple metalanguage to describe word types.

Success criteria

  • Identifies at least two text feature similarities or differences between a target language and English text
  • Correctly uses at least two metalanguage terms to describe language features

Prior knowledge

Waypoint 2: Vocabulary borrowing across languages.

Width

Minimum
Identify at least two similarities or differences in text features between a target language and English text, and correctly use at least two metalanguage terms (e.g. verb, noun, adjective) to describe language features.
Typical
Compare bilingual texts (picture books, songs, multimedia) and notice similarities and differences in punctuation, layout, and organisation; use simple metalanguage to describe word types in the target language and English; discuss grammatical categories that appear different across the two languages.
Wider
  • Compare two bilingual versions of the same text (e.g. a folk tale in target language and English) — identify all the structural and textual differences and compile a class comparison list
  • Explore a grammatical category that works differently in the target language from English — for example, where English uses one word type and the target language uses a different structure — and explain the difference in simple terms

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierText feature comparison and metalanguage use integrate structural comparison (node 1) and vocabulary knowledge (node 2) into a broader reading of how the two languages work as systems. The teaching investment is in making comparison explicit — naming what students notice — rather than leaving metalinguistic awareness implicit.
