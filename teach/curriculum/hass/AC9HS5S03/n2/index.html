← AC9HS5S03 Evaluate patterns and trends

Reading and analysing graphs and maps

AC9HS5S03 n2 · waypoint 2 of 4 · Year 5 HASS (Foundation to Year 6) · Skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in HASS (Foundation to Year 6): treat it as a starting suggestion and check it before use.

Checkpoint

Students can interpret data presented in line, bar, column and pie graphs, and extract patterns and trends relevant to HASS investigations.

Success criteria

  • Students correctly read and describe the pattern shown in at least one graph.
  • Students use specific data values or proportions to support their description of the pattern.

Prior knowledge

Waypoint 1: Patterns and trends vs isolated facts.

Width

Minimum
Read and describe the pattern shown in one type of graph (e.g. bar or line graph) using HASS data.
Typical
Interpret line, bar, column and pie graphs presenting HASS data (e.g. election results, colonial population growth, resource use, economic trends), describing patterns and trends and making simple comparisons between data sets.
Wider
  • Compare data from two different graph types showing the same information, and evaluate which representation makes the pattern more visible
  • Interpret graphs from First Nations Australians' language and Country/Place data to describe patterns in the diversity and distribution of First Nations peoples

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyFluency in reading multiple graph types is built through repeated practice — each graph type makes different features of data visible. Students need repertoire across types, not deep expertise in one.
