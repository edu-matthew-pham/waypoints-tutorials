← AC9HS6S02 Organise information and data

Evaluating sources and identifying key words

AC9HS6S02 n2 · waypoint 2 of 4 · Year 6 HASS (Foundation to Year 6) · Skills

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in HASS (Foundation to Year 6): treat it as a starting suggestion and check it before use.

Checkpoint

Students can use key words to search for relevant information and evaluate sources, recognising that domain names (com, edu, gov) indicate source provenance.

Success criteria

  • Students identify appropriate keywords for at least one HASS inquiry search.
  • Students correctly explain what edu, gov and com domain names indicate about a source.

Prior knowledge

Waypoint 1: Selecting appropriate methods for collecting information.

Width

Minimum
Identify appropriate search keywords for an inquiry and explain what domain names (com, edu, gov) indicate about source provenance.
Typical
Identify key words for effective information searches using search engines and library catalogues; evaluate sources using domain names as provenance indicators (com = commercial, edu = educational, gov = government); assess source relevance and reliability.
Wider
  • Develop and apply an advanced search strategy (including Boolean operators and domain filtering) to find high-quality sources for a specific HASS inquiry
  • Evaluate the difference between search results from edu/gov sources versus com sources on the same topic — and assess what each reveals about perspective and reliability

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsDigital search skills degrade without consistent practice — key word selection and domain-based provenance evaluation need to be applied regularly across inquiry tasks, not just taught once.
