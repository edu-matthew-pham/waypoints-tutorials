Plot, character and setting work together

AC9E1LE03 n4 · waypoint 4 of 4 · Year 1 English · Literature

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can discuss how plot, character and setting work together as features of a story — how each influences the others.

Success criteria

  • Student explains how at least one of plot, character or setting influences another element in a story
  • Student discusses all three features in relation to a given text

Prior knowledge

Waypoint 3: Stories have a plot.

Width

Minimum
Explain how the setting or a character quality influences an event in the plot of a given story.
Typical
Discuss how plot, character and setting interact in a story — how the setting shapes what events are possible, how character qualities drive plot events, and how these three elements together create the story.
Wider
  • Identify similar characters and settings in different story types (traditional tales, narrative poems, fables) and discuss how the three features function across these forms
  • Explore how changing one element — e.g. moving a traditional tale to a different setting — would affect the other elements

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierUnderstanding plot, character and setting as a system — not three separate checklists — is the endpoint of this descriptor. Students need to see how these features depend on each other to form a coherent story.
