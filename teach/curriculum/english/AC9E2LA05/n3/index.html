Choosing the right navigation tool

AC9E2LA05 n3 · waypoint 3 of 3 · Year 2 English · Language

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can select the appropriate navigation tool — print or digital — for a given information retrieval task and explain their choice.

Success criteria

  • Student can select an appropriate navigation tool for a given task and explain why they chose it.
  • Student can use both a print and a digital navigation feature to locate specific information.

Prior knowledge

Waypoint 2: How digital navigation features work.

Width

Minimum
Given a specific information-finding task, identify whether an index, table of contents or a website menu is the most efficient tool to use.
Typical
Compare print and digital navigation tools and discuss when each is more efficient; navigate both types to locate information for a purpose and reflect on the experience.
Wider
  • Compare information retrieval using a print index vs a website search bar for the same topic, and discuss the trade-offs
  • Explore how accessibility features (text-to-speech, screen-reader navigation) change how digital navigation works for different users

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierThis node integrates understanding of print and digital navigation tools and applies them to a purposeful retrieval task. Coordinating knowledge of both tool types to make an informed choice is the new cognitive demand.
