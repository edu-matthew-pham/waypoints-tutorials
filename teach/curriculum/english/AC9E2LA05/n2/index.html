How digital navigation features work

AC9E2LA05 n2 · waypoint 2 of 3 · Year 2 English · Language

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use website navigation tools — side-bar menus, drop-down menus and links — to locate information on a familiar website.

Success criteria

  • Student can use at least one digital navigation feature to locate specified information.
  • Student can name the navigation feature they used and explain what it does.

Prior knowledge

Waypoint 1: How print navigation features work.

Width

Minimum
Use a side-bar menu or navigation link on a familiar website to locate a specific piece of information.
Typical
Explore navigation tools on different websites — side-bar menus, drop-down menus, links, search bars — and explain how each tool helps users locate information.
Wider
  • Compare the navigation structures of two different websites with similar purposes (e.g. two library or museum sites) and discuss which is easier to use and why
  • Identify how navigation menus on mobile and desktop versions of the same site differ
