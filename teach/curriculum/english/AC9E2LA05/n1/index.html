← AC9E2LA05 Navigate print and screen texts

How print navigation features work

AC9E2LA05 n1 · waypoint 1 of 3 · Year 2 English · Language

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can explain how chapters, tables of contents and indexes are organised to support information access — numbering, alphabetical order, page reference — and use at least one to locate information.

Success criteria

  • Student can use a table of contents to locate a chapter and an index to locate a specific term.
  • Student can explain how the alphabetical order of an index speeds up information retrieval.

Prior knowledge

Students understand how print and screen texts are organised using navigation and structural features such as page numbers, headings and links (AC9E1LA05). They have not yet actively navigated these features to locate specific information — their prior knowledge is understanding how features work, not using them purposefully.

Width

Minimum
Use a table of contents to locate a specific chapter or section in a non-fiction book.
Typical
Use tables of contents, chapters and indexes across several non-fiction books; explain how numbered chapters and alphabetical indexes are organised to support access; use an index to locate a specific term.
Wider
  • Compare the organisation of indexes across two different non-fiction books and discuss why some terms are included and others are not
  • Create a simple table of contents for a class-made information text, making decisions about chapter sequence
