Print and screen text features

AC9E1LA05 · Year 1 English · Language

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Descriptor

understand how print and screen texts are organised using features such as page numbers, tables of content, headings and titles, navigation buttons, swipe screens, verbal commands, links and images

Prior knowledge

Students can understand conventions of print and screen including how books and simple digital texts are organised at Foundation level. They have not yet systematically compared the full range of navigational and organisational features specific to print versus screen texts.

By the end

Students understand how print and screen texts are organised using navigational and structural features including page numbers, tables of contents, headings, titles, navigation buttons, swipe screens, verbal commands, links and images.

ACARA elaborations

Examples from ACARA that illustrate this standard. They are examples, not a checklist, and belong to the standard as a whole.

  • comparing the layout of print and digital texts; for example, the layout of print and images in an information book and the layout of information in an online text

Waypoints

  • 1. Print texts use structural featuresStudents can identify structural features of print texts — page numbers, headings, titles, table of contents — and explain what each one does.
  • 2. Screen texts use navigation featuresStudents can identify navigation features of screen texts — navigation buttons, swipe screens, verbal commands, links — and explain how they are used to move through the text.
  • 3. Print and screen texts comparedStudents can compare how print and screen texts use different features to serve the same organisational purposes, and identify features unique to each.
