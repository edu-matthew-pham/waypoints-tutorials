← AC9E6LE05 Create and edit literary texts adapting from sources

Planning an adaptation

AC9E6LE05 n2 · waypoint 2 of 3 · Year 6 English · Literature

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can plan a literary text that adapts elements from a source text, making deliberate choices about which elements to keep, change or add.

Lessons on this site

None yet.

Success criteria

  • Produces a planning document that identifies at least two elements adapted from a source text
  • Identifies at least one literary device to be used and explains what effect it is intended to create

Prior knowledge

Waypoint 1: Adaptation as a literary strategy.

Width

Minimum
Plan an adaptation of one element (e.g. reimagining the hero) from a text experienced, noting which elements are kept and which are changed; identify at least one literary device to experiment with.
Typical
Plan a literary adaptation that adapts multiple elements (character, setting, plot structure, ideas) from a source text; identify and plan for literary devices (figurative language, narrative structure, dialogue) to be used in the text.
Wider
  • Plan an adaptation that deliberately shifts the cultural or social context of the source text (e.g. reimagining a Western adventure story in an Australian context)
  • Plan a character autobiography that requires deep reading of the source text to infer characterisation details not stated directly
