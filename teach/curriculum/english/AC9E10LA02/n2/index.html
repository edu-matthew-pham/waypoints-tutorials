← AC9E10LA02 Evaluative language reveals values

Implicit evaluation and hidden values

AC9E10LA02 n2 · waypoint 2 of 2 · Year 10 English · Language

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify subtle or implied evaluative language and explain the values it reveals, including how labelling and word choice communicate attitude without stating it explicitly.

Success criteria

  • Identifies an example of implicit or subtle evaluation in a text
  • Explains what value is implied by the language choice without the text stating it explicitly

Prior knowledge

Waypoint 1: Explicit evaluation and values.

Width

Minimum
Identify one example of implicit evaluation in a text (e.g. use of a label like ‘teenager’ rather than a person’s name) and explain the value it implies.
Typical
Analyse how implicit evaluation operates through labelling, word choice, and framing in a range of texts, explaining the values revealed without being stated.
Wider
  • Compare implicit evaluation in texts representing the same event or person from different perspectives — e.g. news reports from different outlets — to identify how different values shape the framing
  • Examine how political language uses implicit evaluation to position audiences without making values explicit
  • Analyse how implicit evaluation in texts about First Nations Australians has reflected and reinforced colonial values, and contrast with contemporary First Nations-authored texts

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepImplicit evaluation is harder to see in isolation; students need a range of examples — especially contrasting texts on the same topic — to develop the inference skill reliably.
Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkThe reasoning move from ‘what word was chosen’ to ‘what value that implies’ requires explicit scaffolding — students tend to notice explicit evaluation but miss how word choice silently signals attitude.
