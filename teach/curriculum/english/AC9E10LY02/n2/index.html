← AC9E10LY02 Spoken text analysis and opinion presentation

Presenting an opinion using interaction skills

AC9E10LY02 n2 · waypoint 2 of 2 · Year 10 English · Literacy

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can use interaction skills to discuss and present a developed opinion about a spoken text, drawing on their analysis of its features and effects.

Lessons on this site

None yet.

Success criteria

  • Presents a clear opinion about a spoken text connected to analysis of its features
  • Uses at least one interaction skill (turn-taking, building on others' contributions, supporting claims with evidence from the text)

Prior knowledge

Waypoint 1: Analysing spoken text structures and features.

Width

Minimum
Present an opinion about a spoken text using at least one interaction skill (e.g. structured turn-taking, referencing evidence from the text) and connect the opinion to analysis of the text's features.
Typical
Use interaction skills to discuss and present a well-developed opinion about a spoken text, drawing on analysis of its text structures and language features, including combination of words and sound.
Wider
  • Participate in a structured discussion where multiple opinions about a spoken text are presented and debated, using interaction skills to build on and respond to others
  • Present an opinion about a First Nations Australian media text in a class discussion, using interaction skills to engage with differing perspectives on the text
  • Compare two spoken texts presenting contrasting opinions on the same issue and present an opinion about which is more effective, using interaction skills in a seminar format

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsInteraction skills in formal discussion contexts require practice — students need repeated structured discussion opportunities to develop the fluency to present opinions clearly while also engaging responsively with others.
