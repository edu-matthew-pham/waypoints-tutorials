Evaluating use of sources and quotations

AC9E8LY03 n2 · waypoint 2 of 2 · Year 8 English · Literacy

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can evaluate how an author uses sources and quotations in a text — assessing whether sources are used effectively to support ideas — and form and express an opinion about the author's approach.

Success criteria

  • Evaluates whether a source or quotation in a text effectively supports the claim it is used to substantiate.
  • Forms a clear opinion about the author's use of sources and supports that opinion with reference to the text.

Prior knowledge

Waypoint 1: Evaluating language features for purpose and audience.

Width

Minimum
Evaluate how one source or quotation is used in a text — explain whether it effectively supports the idea it is meant to substantiate, and give a reasoned opinion about the author's approach.
Typical
Evaluate the use of sources and quotations across a text, forming and presenting opinions about how effectively the author has used evidence to support ideas; identify cases where source use is strong and cases where it is weak or misleading.
Wider
  • Investigate how the same source or quotation can be used to support opposing claims depending on what surrounding context and interpretation the author provides
  • Analyse how sources are selected and framed in a biased text — examining what the author's source choices reveal about their perspective and what sources are absent
  • Evaluate the source use in a student's own argumentative writing and revise for greater effectiveness

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyEvaluating source use effectively requires students to have encountered a range of approaches — strong integration, weak cherry-picking, selective quotation, absence of sources where sources are needed. Exposure to multiple examples of varying quality builds the comparative benchmark needed for genuine evaluation.
