Setting and mood

AC9E4LE03 n2 · waypoint 2 of 3 · Year 4 English · Literature

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can explain how an author's setting choices create mood, identifying specific language and visual features that produce the mood.

Lessons on this site

None yet.

Success criteria

  • Can name the mood created by a setting and identify at least one specific language feature (e.g. a specific adjective or sensory detail) that creates it
  • Does not just name the setting — connects specific features to the mood produced

Prior knowledge

Waypoint 1: Character development techniques.

Width

Minimum
Identify the mood created by a setting in a literary text and name one specific language or visual feature that creates it.
Typical
Analyse how setting choices — time of day, weather, landscape, sensory details, colour — create mood across a range of literary texts, explaining how the author's specific choices produce specific emotional atmospheres.
Wider
  • Compare how two authors create contrasting moods through setting description in texts in the same genre (e.g. two adventure stories with different settings)
  • Examine how Aboriginal and Torres Strait Islander authors portray Country as an active participant in setting mood, and discuss how this differs from Western landscape description
