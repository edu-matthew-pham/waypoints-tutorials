← AC9E10LA07 Features of still and moving images

Evaluating effects on representations

AC9E10LA07 n2 · waypoint 2 of 2 · Year 10 English · Language

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can evaluate how visual feature choices create nuance in representations, making supported judgements about the effect of those choices.

Success criteria

  • Makes a supported judgement about how at least one visual feature choice affects the representation of the subject
  • Uses specific visual evidence to support the evaluation

Prior knowledge

Waypoint 1: Visual feature identification and analysis.

Width

Minimum
Evaluate how at least one visual feature choice (e.g. use of light and dark) creates nuance in a representation, making a supported judgement.
Typical
Evaluate how a range of visual feature choices work together to create complex or nuanced representations in still and moving images, making supported judgements with visual evidence.
Wider
  • Evaluate how visual feature choices in political imagery have shaped representations of power or vulnerability across different historical periods
  • Compare the representation of the same subject in different media (e.g. film still, news photograph, artwork) and evaluate how different visual choices construct different meanings
  • Evaluate how documentary filmmakers use visual features to position audiences in relation to their subjects, examining ethical dimensions of those choices

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents often evaluate visual features as if they have fixed meanings (e.g. ‘darkness = evil’); encountering the same feature used to different effect in different contexts resolves this misconception and builds genuine evaluative flexibility.
