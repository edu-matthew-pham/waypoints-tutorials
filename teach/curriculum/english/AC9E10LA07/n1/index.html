← AC9E10LA07 Features of still and moving images

Visual feature identification and analysis

AC9E10LA07 n1 · waypoint 1 of 2 · Year 10 English · Language · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify specific visual features of still and moving images (e.g. lighting, angle, colour, framing) and analyse their effect on meaning.

Success criteria

  • Identifies at least two specific visual features in a still or moving image
  • Explains the effect of each feature on how the subject is represented

Prior knowledge

Students analyse how symbols in still and moving images augment meaning (AC9E9LA07). They have not yet evaluated the features of still and moving images and the effects of those choices on representations.

Width

Minimum
Identify at least two visual features in a still or moving image and analyse the effect of each on how a subject is represented.
Typical
Analyse a range of visual features in still and moving images across different media contexts, explaining how each feature contributes to the representation of the subject.
Wider
  • Compare how the same visual features (e.g. high angle shot, low-key lighting) function differently in film noir, documentary and advertising contexts
  • Examine how visual features in news photography construct representations of events and people
  • Analyse how First Nations Australian visual artists use features such as light, colour and framing to create representations that challenge dominant visual conventions

Hinge

Node 2 requires students to evaluate the effects of visual feature choices on representations — a judgement that depends on having a working vocabulary of visual features. Without this, evaluation cannot be grounded in specific technical choices.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyStudents need to build a repertoire of visual feature vocabulary (shot type, angle, lighting, colour temperature, framing) before they can analyse novel images effectively — accumulating cases across image types is the pedagogical work here.
