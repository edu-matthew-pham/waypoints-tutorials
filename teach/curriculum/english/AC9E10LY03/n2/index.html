← AC9E10LY03 Language features represent values, beliefs and attitudes

Evaluating how language represents values

AC9E10LY03 n2 · waypoint 2 of 2 · Year 10 English · Literacy

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can evaluate how language features are used to represent values, beliefs and attitudes, making supported judgements about the effectiveness or significance of the choices.

Success criteria

  • Makes a supported judgement about how a language feature represents a value, belief or attitude
  • Explains the significance of that representation for the text's purpose or audience

Prior knowledge

Waypoint 1: Explicit and implicit representation of values.

Width

Minimum
Evaluate how at least one language feature is used to represent a value or attitude in a text, making a supported judgement.
Typical
Evaluate how language features across a text represent values, beliefs and attitudes, making supported judgements about the significance of those choices for the text's purpose and audience.
Wider
  • Evaluate how the representation of values in political texts (e.g. election advertisements, parliamentary speeches) shapes audience understanding of what is at stake
  • Evaluate how values represented in media texts about First Nations Australian communities have changed over time, and assess the significance of those changes
  • Compare how different texts covering the same event evaluate values differently and assess what that reveals about the values of the text producers

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkEvaluation of how language represents values requires students to reason from specific language choices through their implicit assumptions to broader value positions — this multi-step inference needs explicit scaffolding.
