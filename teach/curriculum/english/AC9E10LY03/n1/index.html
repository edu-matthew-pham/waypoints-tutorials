← AC9E10LY03 Language features represent values, beliefs and attitudes

Explicit and implicit representation of values

AC9E10LY03 n1 · waypoint 1 of 2 · Year 10 English · Literacy · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify language features that explicitly or implicitly represent values, beliefs or attitudes and analyse how they do so.

Success criteria

  • Identifies at least one language feature that represents a value, belief or attitude
  • Distinguishes whether the representation is explicit or implicit and explains how the feature achieves it

Prior knowledge

Students analyse and evaluate how language features represent perspectives of issues, events and groups (AC9E9LY03). They have not yet analysed how language features implicitly or explicitly represent values, beliefs and attitudes.

Width

Minimum
Identify one language feature in a text that explicitly or implicitly represents a value, belief or attitude, and analyse how it does so.
Typical
Analyse how a range of language features across a text represent values, beliefs and attitudes both explicitly and implicitly, distinguishing between the two modes of representation.
Wider
  • Analyse social or political cartoons to identify the implicit and explicit values, beliefs and attitudes expressed through visual and language features
  • Compare how the same value is represented explicitly in one text and implicitly in another, examining what the different strategies achieve
  • Examine how language features in First Nations Australian activist texts explicitly assert values that mainstream texts represent only implicitly or not at all

Hinge

Node 2 requires students to evaluate how language features represent values — a judgement that depends on the ability to identify and distinguish between explicit and implicit representation. Without this distinction, evaluation collapses into surface-level comment.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepThe distinction between explicit and implicit representation is context-dependent — what is explicit in one cultural context may be implicit or absent in another; students need contrasting text contexts to see this clearly.
