Features serve purpose

AC9E5LY03 n1 · waypoint 1 of 3 · Year 5 English · Literacy · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify a characteristic feature of a text type and explain how it serves the text's purpose — not just that it is present.

  • Features that fit the job

Success criteria

  • Identifies a characteristic feature and explains how it serves the text's purpose — explains the relationship, not just names the feature.
  • Applies the explanation to at least two different text types or two different features within a text type.

Prior knowledge

Students can identify the characteristic features used in imaginative, informative and persuasive texts (AC9E4LY03). They have not yet explained how those features meet the purpose of the text — moving from identification to purposive explanation.

Width

Minimum
Identify at least two characteristic features of a text type and explain, for each, how it helps the text achieve its purpose.
Typical
Explain how characteristic features across imaginative, informative and persuasive texts work to meet their respective purposes — examining how features such as character, dialogue, topic sentence, thesis statement, emotive language, and modal verbs are purposively chosen.
Wider
  • Examine how the same feature (e.g. an emotive vocabulary choice) can serve different purposes in different text types — discussing how purpose shapes the use of the feature, not just the feature itself
  • Analyse a persuasive text about a local community issue and explain how its features work to achieve action — connecting the elaboration example to the broader principle

Hinge

The feature-serves-purpose reasoning move is the foundation on which Node 2's character analysis and Node 3's multi-feature integration both depend. Students who can only identify features without explaining their function cannot engage with the purposive reasoning that Node 2 and Node 3 require.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepStudents who have only explained features in narrative texts may apply narrative reasoning to persuasive or informative texts inappropriately. Encountering feature explanation across all three text-type categories builds the understanding that purpose determines feature function, not text type name alone.
