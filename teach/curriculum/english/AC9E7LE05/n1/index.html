How each narrative element creates meaning

AC9E7LE05 n1 · waypoint 1 of 2 · Year 7 English · Literature · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify how characters, settings and events each contribute to meaning in a narrative

Success criteria

  • Identifies how a character, setting and event each contribute to meaning in a given narrative
  • Explains what each element contributes — not just that it is present

Prior knowledge

Students can identify and explain how images, figures and visual elements contribute to meaning (AC9E6LA07) and identify characteristics of an author's individual style (AC9E6LE03). They have not yet examined how narrative elements — characters, settings and events — combine to create meaning, rather than each contributing independently.

Width

Minimum
In a given narrative, identify one example of how a character, one of how a setting, and one of how an event contributes to meaning; explain each
Typical
Examine how character construction, setting description and event sequencing each create specific meanings in a narrative — what does each element make possible for the story's meaning that the others cannot?
Wider
  • Analyse and explain the structure and features of short stories, discussing how authorial choices about character, setting and event sequence serve the story's purpose and affect its appeal
  • Explore traditional stories from Asia and discuss how oral mode, visual elements and verse are used alongside character, setting and event to create meaning

Hinge

If students cannot identify what each element individually contributes, Node 2's work on how they combine is inaccessible — combination analysis requires first knowing what each element contributes in isolation.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyStudents need to build a repertoire of narrative examples — stories where character construction, setting and event sequencing each do distinct work — before they can understand how the elements combine. Building the repertoire across short stories, traditional stories and different narrative forms gives students the comparative material needed for the next node.
