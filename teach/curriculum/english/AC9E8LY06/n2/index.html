← AC9E8LY06 Plan, create, edit and publish written and multimodal texts

Creating with deliberate language and feature selection

AC9E8LY06 n2 · waypoint 2 of 3 · Year 8 English · Literacy · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can create written or multimodal texts that make deliberate selections from text structures, language features, literary devices and visual features to serve their purposes and audiences.

Lessons on this site

None yet.

Success criteria

  • Creates a text for a named purpose and audience.
  • Can identify and explain at least two deliberate structural or language choices made in the text and how they serve the purpose.

Prior knowledge

Waypoint 1: Planning and organising ideas.

Width

Minimum
Create a text for a specified purpose and audience that demonstrates at least two deliberate selection choices (e.g. a specific text structure, a vocabulary choice to position the reader, or a literary device for effect) and can explain each choice.
Typical
Create written and multimodal texts for a range of purposes (imaginative, reflective, informative, persuasive, analytical) and audiences, making deliberate and explainable selections from text structures, language features, literary devices and visual features; select vocabulary to position and persuade the reader where appropriate.
Wider
  • Create a text that deliberately exploits the conventions of a specific genre for persuasive or satirical effect — using the reader's genre expectations as a rhetorical tool
  • Create a multimodal text in which visual features and written text work interdependently, and reflect on how each modality contributes differently to the overall purpose
  • Create a text for an unfamiliar audience (e.g. a First Nations community audience, an academic audience, an international audience) and reflect on what structural and language choices the unfamiliar audience requires

Hinge

Node 3 is editing for accuracy and meaning. Effective editing requires a text that was created with deliberate choices — something to evaluate and refine. Students who created without repertoire at Node 2 have only mechanical errors to correct at Node 3, not purposeful revision decisions to make. The editing task collapses to proofreading.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyCreating across the range of text purposes (imaginative, informative, persuasive, analytical) requires a repertoire of structural and language strategies associated with each purpose. Students who have only created in one mode cannot transfer confidently to others. Multiple creation tasks across purposes build this repertoire.
