Language features as perspective devices

AC9E9LY03 n1 · waypoint 1 of 2 · Year 9 English · Literacy · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can analyse how specific language features represent a perspective — identifying the choices and explaining the perspective they embed.

Success criteria

  • Student identifies a language feature and names the perspective it represents
  • Student explains how the feature represents the perspective — not just that it 'shows the author's opinion'

Prior knowledge

Students analyse how language features shape meaning and vary according to audience and purpose (AC9E7LY03). They have not yet evaluated language features as perspective-representing devices — moving from describing what features do to evaluating how effectively they represent a perspective.

Width

Minimum
Identify at least two language features in a text and analyse how each represents a particular perspective on the text's subject.
Typical
Analyse how language features across a text work together to represent a perspective — examining how language in news and social media coverage of a contentious issue is used to convey opinions and represent ideas.
Wider
  • Compare language features across coverage of the same contentious issue in two media contexts with different editorial positions
  • Examine how language features in inspirational or advocacy speeches position the audience toward a perspective — identifying techniques that influence listener response

Hinge

Evaluating representation at N2 requires being able to identify which language features represent a perspective and how — students who haven't built this analytical move have no basis for evaluative judgement beyond personal agreement or disagreement.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Context breadth: more contexts in the vary or modify stepPerspective representation is easiest to see in obviously biased texts. Students need to encounter subtler uses — in news reporting, in ostensibly neutral descriptions — to understand that all language represents perspective, not just intentionally persuasive texts.
