← AC9E2LA03 Texts organised by purpose

Same purpose, different forms

AC9E2LA03 n3 · waypoint 3 of 3 · Year 2 English · Language

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify that a single purpose (e.g. expressing an opinion) can be expressed through different text forms — poster, email, brochure — and that the form shapes the language features used.

Success criteria

  • Student can identify that the same purpose can take different forms.
  • Student can name at least one way language features or organisation changes when the form changes, even if the purpose stays the same.

Prior knowledge

Waypoint 2: Language features signal text type.

Width

Minimum
Identify two different forms that serve the same purpose and name one way the language or organisation differs between them.
Typical
Discuss how opinion, information or recount purposes can each be realised across multiple forms, and identify how the chosen form shapes language features, layout and audience expectations.
Wider
  • Create or compare two versions of the same message in different forms (e.g. a recount as a letter and as a multimodal presentation) and discuss how the form changes the language
  • Identify texts in digital formats (website, infographic, ebook) and compare their organisation to print equivalents

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierThis node integrates the two prior understandings — purpose drives organisation AND language features signal text type — and adds the insight that form is a third variable. Coordinating all three is the learning challenge here.
