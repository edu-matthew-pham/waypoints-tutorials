Language features by text type

AC9E4LA03 n2 · waypoint 2 of 4 · Year 4 English · Language · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify specific language features associated with particular text types and explain how these features serve the text's purpose.

None yet.

Success criteria

  • Can name a language feature in a text and connect it to what the text is trying to do at that point
  • Can identify at least two different language features, not just one repeated example

Prior knowledge

Waypoint 1: Stages and purpose.

Width

Minimum
Identify at least two language features in a provided text and explain why those features suit that text type (e.g. action verbs in a recount, timeless present tense in a report).
Typical
Identify language features across a range of text types — including verb choices, tense, noun group structure, connectives — and explain how each feature contributes to the text's purpose and stage structure.
Wider
  • Compare language features across texts on the same topic but in different text types (e.g. an explanation and a report about the water cycle)
  • Examine how multimodal texts combine language features with visual features to serve the text's purpose

Hinge

Distinguishing explanation from report structure in N3 requires students to recognise their different language features — without the feature repertoire from N2, students can only compare surface structure, not the linguistic choices that produce it.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Repertoire building: more cases to sort or classifyLanguage features vary across text types — students need to accumulate examples across multiple types before the distinctions between them stabilise and become reliably distinguishable.
