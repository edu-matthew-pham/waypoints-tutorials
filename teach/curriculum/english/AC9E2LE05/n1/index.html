Identifying features to use

AC9E2LE05 n1 · waypoint 1 of 3 · Year 2 English · Literature · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify key literary features in a model text and articulate how they will use those features in their own creation.

Success criteria

  • Student can name at least two literary features from a model text.
  • Student can articulate how they will use each feature in their own creation before drafting.

Prior knowledge

Students retell or adapt familiar stories using plot, characters, language features and structure (AC9E1LE05). They have not yet independently created imaginative texts or adaptations that deliberately apply key literary features as design choices.

Width

Minimum
Identify at least two literary features in a model text and state which they will use in their own creation.
Typical
Analyse a model text for literary features — character type, setting, structural pattern, language choices — and make deliberate decisions about which to use and how to adapt them for their own text.
Wider
  • Compare features across two model texts with different tones or purposes and discuss which features would suit their intended creation
  • Use a planning frame to map their intended character, setting and narrative structure before drafting

Hinge

Shallow feature identification at this node cascades directly into Nodes 2 and 3 — students who have not clearly identified which features they will use produce character and setting descriptions that lack deliberate design, and narratives with no coherent structural basis.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkIn Mode B, the planning phase is a hinge — shallow analysis of the model text cascades into an underdeveloped creation. Making the feature-identification and feature-selection reasoning explicit before drafting begins prevents downstream phase collapse.
