← AC9E4LE02 Effects of text structure

Sharing opinions using evidence

AC9E4LE02 n3 · waypoint 3 of 3 · Year 4 English · Literature

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can share an opinion about a text and support it with reference to specific text structures and language features.

Lessons on this site

None yet.

Success criteria

  • Can state a clear opinion about a text and support it with at least one specific textual reference
  • Does not offer only plot summary — the response engages with how the text is constructed, not just what happens

Prior knowledge

Waypoint 2: Describing effects on reader response.

Width

Minimum
State an opinion about a text and support it with at least one reference to a specific text structure or language feature.
Typical
Share a reasoned opinion about a literary text in a discussion or written response, supporting the opinion with multiple references to specific structural and language features and explaining how these features support the view.
Wider
  • Compare personal responses to a text with a peer's, identifying where opinions differ and examining whether different textual features are being prioritised
  • Respond to a First Nations Australian literary text using metalanguage to describe structural and language features, with attention to how cultural context shapes interpretive choices

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Integration: a combining task at the wider tierSharing a supported opinion integrates identification (node 1) and effect description (node 2) into a coherent reader-response — the full capability the descriptor demands.
