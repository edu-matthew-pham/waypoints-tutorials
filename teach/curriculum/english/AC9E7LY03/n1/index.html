Language features shape meaning

AC9E7LY03 n1 · waypoint 1 of 2 · Year 7 English · Literacy · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify specific language features in a text and explain how each shapes meaning

Lessons on this site

  • Features that shape meaning

Success criteria

  • Identifies at least two language features in a given text
  • Explains how each feature shapes the meaning a reader constructs

Prior knowledge

Students can analyse how text structures and language features work together to meet the purpose of a text and engage and influence audiences (AC9E6LY03). They have not yet worked at the level of analysing how specific language features shape meaning, or explicitly examining how features vary with audience and purpose.

Width

Minimum
In a given text, identify at least two language features (e.g. word choice, modality, tense, sentence type, figurative language) and explain how each shapes the meaning a reader constructs
Typical
Analyse how a range of language features work together to shape meaning in a text — examining word choice, sentence structure, modality and figurative language and explaining how each contributes to the overall meaning
Wider
  • Explain the relationship between language features and audience and purpose — identify the most likely target audience for an advertisement and justify why by tracing specific language features
  • Examine depictions of histories and cultures of First Nations Australians in texts and discuss how language features shape the meaning constructed about those histories and cultures

Hinge

If students cannot explain how a language feature shapes meaning, Node 2's comparative audience-purpose work collapses — explaining why features vary requires first being able to explain what features do.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Structured reasoning: a worked chain of reasons, then a write-and-compare (reasoning) checkStudents commonly identify language features without explaining their effect on meaning — listing that a text uses metaphor without explaining what the metaphor makes the reader think or feel. The reasoning scaffold — feature → effect on reader → contribution to meaning — is the core analytical move this descriptor develops.

Related standards
