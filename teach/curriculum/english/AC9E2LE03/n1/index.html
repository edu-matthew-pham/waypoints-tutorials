Language that describes character

AC9E2LE03 n1 · waypoint 1 of 3 · Year 2 English · Literature

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can identify language — specific nouns and adjectives — used to describe a character's appearance and personality, and explain what impression that language creates.

Success criteria

  • Student can identify specific language used to describe a character and explain the impression it creates.
  • Student can name at least one noun and one adjective from the character description and explain how each contributes.

Prior knowledge

Students discuss plot, character and setting as features of stories (AC9E1LE03). They have not yet examined how specific language choices present characters and settings differently across texts.

Width

Minimum
Identify two language features — at least one noun and one adjective — used to describe a character and explain the impression each creates.
Typical
Identify and compare the language used to describe characters across multiple texts, noticing how different word choices create different impressions of similar character types.
Wider
  • Compare how a hero and a villain in the same text are described using contrasting language choices, and discuss how the author uses language to position the reader
  • Examine how a character is described at the start vs the end of a narrative and identify how language reflects character change
