← AC9EFLA04 Conventions of print and screen

Print is directional

AC9EFLA04 n1 · waypoint 1 of 3 · Foundation English · Language · Hinge

Draft, from Waypoints Kit v0.2. Generated from Kit's node data and not yet reviewed by a specialist in English: treat it as a starting suggestion and check it before use.

Checkpoint

Students can demonstrate that written English is read left to right and top to bottom, and can apply this when approaching a new text.

Lessons on this site

None yet.

Success criteria

  • Student tracks print from left to right without prompting.
  • Student correctly returns to the start of the next line when text wraps.

Prior knowledge

Students have been handled books and interacted with digital devices at home and in early childhood settings. They have not yet been explicitly taught or asked to name the conventions that organise print and screen texts.

Width

Minimum
Demonstrate left-to-right, top-to-bottom reading direction when approaching a familiar book or text.
Typical
Understand and apply print conventions for directionality; indicate where to start reading on a page; return correctly to the next line when reading.
Wider
  • Compare English print direction with texts written in other directions — right-to-left or vertical scripts — and discuss why conventions differ
  • Explore how directionality affects the layout of a page — where images appear, how text is positioned

Hinge

Print directionality is a prerequisite for both Node 2 (identifying title and starting point requires knowing where reading begins) and LY04 (reading connected text requires correct directional tracking) — without it, all print-based literacy tasks collapse.

Response modes

Where extra effort goes at this waypoint (width), not what kind of lesson it is.

Consolidation: more practise steps, short feedback loopsDirectionality is a mechanical habit — it must become automatic. Students need to practise the correct left-to-right, return sweep movement until it is habituated. Width is thin here; accuracy and fluency are what matter.
