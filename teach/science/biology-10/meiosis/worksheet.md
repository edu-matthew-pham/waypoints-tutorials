# Why is every sperm and egg different?

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** You and your brother or sister came from the same two parents. The chance that two of their sperm or eggs carry exactly the same chromosomes is tiny.


:::teacher-note

**In one sentence:** Students model meiosis, explain how it halves the chromosome number and produces genetically different gametes, and contrast it with mitosis (AC9S10U01, node 3, a hinge node).

**Students should be able to say:** I can explain that each gamete gets one chromosome from each pair. I can calculate the number of possible gametes for a small number of pairs. I can distinguish meiosis from mitosis.

**Width:** the unmarked parts are the floor every student does (Engage, Explore, Explain, Evaluate). Typical and Wider sections add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Explain: meiosis


:::keep-together

### One of each pair

**On the board, every gamete had three chromosomes. Which is true?**

☐ Each gamete gets the whole pair from one chromosome

☐ Each gamete gets exactly one chromosome from each pair

☐ Each gamete gets all the red ones or all the blue ones

☐ Each gamete gets any three chromosomes

:::


:::teacher-note

**Answer:** Each gamete gets exactly one chromosome from each pair

:::


:::keep-together

### Three pairs

**With 3 pairs, each with 2 choices, how many different gametes are possible?**

Answer: {{field-15}}

:::


:::teacher-note

**Answer:** 8

2 × 2 × 2 = 8.

:::


:::keep-together

### 23 pairs

**Humans have 23 pairs. About how many different combinations are possible?**

☐ 2 × 23 = 46: two choices for each of 23 pairs

☐ 23: one new combination for each pair

☐ 23 × 23 = 529

☐ 2 to the power 23: over 8 million

:::


:::teacher-note

**Answer:** 2 to the power 23: over 8 million

:::

## Elaborate: even more variety


:::keep-together

**Each parent can make over 8 million different gametes. Ignoring crossing over, roughly how many different children could two parents have?**

☐ About 8 million × 8 million: around 70 trillion

☐ About 16 million

☐ 46

☐ About 8 million

:::


:::teacher-note

**Answer:** About 8 million × 8 million: around 70 trillion

Crossing over (pairs swapping pieces during meiosis) adds far more variety still.

## Evaluate: look back

Write one sentence: "At first I thought… Now I think… because…"

**Revision summary**

- **Meiosis** makes gametes: chromosome pairs separate; each gamete gets **one from each pair**, so it has **half** the number.
- Which of each pair goes into a gamete is **random**: 2 × 2 × 2 … for 23 pairs, over **8 million** combinations.
- Random fertilisation (and crossing over) multiply the variety.
