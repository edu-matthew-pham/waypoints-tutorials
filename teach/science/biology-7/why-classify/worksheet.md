# Why sort living things?

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** There are about 2 million named species of living things, and millions more not yet named. Without a system, how would anyone find their way around them?


:::teacher-note

**In one sentence:** Students explain why living things are classified (identifying, communicating, showing relationships), tell classification from a plain list, and give an everyday example (AC9S7U01, node 1).

**Students should be able to say:** I can give two reasons why living things are classified. I can tell classification from a simple list. I can give an everyday example of classification.

**Width:** the unmarked parts are the floor every student does (Engage, Explore, Explain, Evaluate). Typical and Wider sections add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Explain: what classification is for


:::keep-together

### Reasons

**Is it a reason scientists classify living things?**

Groups: A reason to classify, Not a reason

- To identify an organism they don't know: {{field-15}}
- To use names every scientist understands: {{field-15}}
- To see which organisms are related: {{field-15}}
- To make the living world look neat: {{field-15}}
- To decide which organisms are better: {{field-15}}

:::


:::teacher-note

**Answer:** To identify an organism they don't know → A reason to classify; To use names every scientist understands → A reason to classify; To see which organisms are related → A reason to classify; To make the living world look neat → Not a reason; To decide which organisms are better → Not a reason

:::


:::keep-together

### Classification or a list

**Which is classification, not just a list?**

☐ Grouping animals by shared features

☐ Writing animals in alphabetical order

☐ Numbering animals in the order you saw them

:::


:::teacher-note

**Answer:** Grouping animals by shared features

Classification groups things by what they share (such as backbone or no backbone, then smaller groups inside), so the group tells you something about each member.

:::


:::keep-together

### Everyday classification

**A supermarket groups food by aisle: dairy, bakery, fruit. How is that like scientific classification?**

☐ Both put things in alphabetical order

☐ It isn't: only scientists classify

☐ Both group things to help people find them

:::


:::teacher-note

**Answer:** Both group things to help people find them

Groups by shared features help people find things and talk about them. Libraries, supermarkets and phone contacts all classify for a purpose, and scientific classification's purposes are identifying, communicating and showing relationships.

:::


:::typical

## Elaborate: two ways to group


:::keep-together

### Which system

**You could group these animals by where they live (land, water, air) or by body features (backbone, feathers, fur). Which is more useful for showing how they are related?**

☐ Body features: a platypus and a kangaroo share fur and milk, though one swims

☐ Both are equally useful for every purpose

☐ Where they live: animals in the same place are related

:::


:::teacher-note

**Answer:** Body features: a platypus and a kangaroo share fur and milk, though one swims

Grouping by habitat suits some jobs (planning a reserve), while grouping by shared features suits others (showing relationships), so the purpose decides the system.

:::

## Evaluate: look back

Write one sentence: "At first I thought… Now I think… because…"

**Revision summary**

- Scientists classify living things to **identify** them, to **communicate** clearly (one name everyone understands) and to show how they are **related**.
- Classification groups by shared features; a list (alphabetical, by date) does not.
- Every classification is built for a purpose; different purposes can suit different systems.
