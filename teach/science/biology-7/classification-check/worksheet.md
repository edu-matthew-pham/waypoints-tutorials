## Building a key


:::keep-together

### Good key questions

**Would this make a good question in a key?**

Groups: Good question, Poor question

- Does it have six legs?: {{field-15}}
- Does it have feathers?: {{field-15}}
- Is it large?: {{field-15}}
- Is it scary?: {{field-15}}
- Does it have a shell?: {{field-15}}

:::


:::teacher-note

**Answer:** Does it have six legs? → Good question; Does it have feathers? → Good question; Is it large? → Poor question; Is it scary? → Poor question; Does it have a shell? → Good question

:::


:::keep-together

### How many questions?

**You build a key to identify 6 different organisms. About how many questions does it need?**

☐ 6: one per organism

☐ 12: two per organism

☐ 3: half the number of organisms

☐ 5: each question splits one group into two

:::


:::teacher-note

**Answer:** 5: each question splits one group into two

Each question splits one group into two, so to end with 6 separate organisms you make 5 splits.

:::


:::keep-together

### A peer tests your key

**A classmate follows your key and names a specimen wrongly. What does that tell you?**

☐ Your key has a fault to find and fix

☐ The classmate is not good at science

☐ The specimen is not in the key

☐ Keys cannot be made accurate

:::


:::teacher-note

**Answer:** Your key has a fault to find and fix

The fault could be an unclear question or a wrong branch. Testing with another person shows up unclear questions that you couldn't see yourself.

:::


:::keep-together

### A question that doesn't split

**A key ends with the question "Does it have four legs?" to separate a dog from a cat. What is wrong with it?**

☐ Both answer yes, so it doesn't split them

☐ The key needs more animals in it

☐ Nothing: both animals reaching the same end is fine

☐ Legs are not an observable feature

:::


:::teacher-note

**Answer:** Both answer yes, so it doesn't split them

Every question must split the group into two, so pick a feature one animal has and the other doesn't, such as "Does it have retractable claws?"

:::


## Classification changes


:::keep-together

### A reclassification

**Which is a real example of classification changing because of new evidence?**

☐ An animal changed its features during its life, so it was moved to a new group

☐ DNA comparisons showed that archaea are not bacteria, so a third domain of life was recognised

☐ A scientist preferred a different name, so the group was renamed

☐ Two groups looked alike, so they were merged without any new evidence

:::


:::teacher-note

**Answer:** DNA comparisons showed that archaea are not bacteria, so a third domain of life was recognised

Comparing DNA (and other molecules) showed that archaea are a separate line of life, not part of the bacteria. Fungi were also moved: DNA shows they are closer relatives of animals than of plants.

:::


:::keep-together

### What can change it?

**Could this lead scientists to change a classification?**

Groups: Can change it, Cannot change it

- New DNA evidence: {{field-15}}
- A better microscope showing new structures: {{field-15}}
- A newly discovered species that does not fit: {{field-15}}
- An opinion with no evidence: {{field-15}}
- Wanting the groups to look neat: {{field-15}}

:::


:::teacher-note

**Answer:** New DNA evidence → Can change it; A better microscope showing new structures → Can change it; A newly discovered species that does not fit → Can change it; An opinion with no evidence → Cannot change it; Wanting the groups to look neat → Cannot change it

:::


:::keep-together

### Weaker or stronger?

**Scientists reclassified some organisms. Does that make science less trustworthy?**

☐ Yes: classification should never change

☐ No: updating ideas with new evidence makes them more reliable

☐ It makes no difference to how reliable it is

☐ Yes: it shows scientists were wrong about everything

:::


:::teacher-note

**Answer:** No: updating ideas with new evidence makes them more reliable

Updating ideas when new evidence appears is how science works. Science corrects itself, and because ideas are tested against new evidence, the ones that survive can be trusted more.

:::
