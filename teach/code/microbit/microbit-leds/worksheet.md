# Pictures in order

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A shop sign scrolls its name, then shows a picture. It is a short list of instructions, done in order.


:::teacher-note

**In one sentence:** Students see that blocks in on start run once, from the top, so the order of the blocks is the order of the pictures, and the last one stays.

**Students should be able to say:** I can say what the micro:bit will show, in order. I can say why the last picture stays on. I can make a name badge from words and a picture I draw.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

### Lily's sign

**Lily's sign has three blocks in on start: show string HI, show icon happy face, show icon tick. What do you see?**

☐ Only the tick

☐ HI scrolls, then the happy face, then the tick, which stays

☐ Only HI

☐ HI, the face and the tick all at once

:::


:::teacher-note

**Answer:** HI scrolls, then the happy face, then the tick, which stays

The micro:bit does one block at a time, from the top. Each picture replaces the one before, and the tick is last, so it stays.

:::


:::keep-together

### Ten seconds later

**Ten seconds after the program starts, which picture is on the screen?**

☐ HI: the first block

☐ The tick: the last block

☐ All three, taking turns

☐ Nothing: the program has finished

:::


:::teacher-note

**Answer:** The tick: the last block

When the last block has run, the program is finished, and the last picture is still on the LEDs.
