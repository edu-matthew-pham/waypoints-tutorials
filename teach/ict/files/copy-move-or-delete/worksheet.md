# Copy, move or delete

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A student drags her homework from the Documents folder onto a USB stick, hands it in, and then cannot find the file at home. What did she do?


:::teacher-note

**In one sentence:** Students learn that copy leaves the original and makes two files, move leaves one in a new place, delete sends a file to a bin that may not exist on every device, and a shortcut only points. They sort actions, find a mistake in a drag to a USB stick, and plan how to take work home safely.

**Students should be able to say:** I can say whether an action copies, moves or deletes. I can check where a file is after I act. I can say that a USB stick or shared drive may have no bin.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Worked example: the missing homework


:::keep-together

### Say which one you are doing

1. $\text{Decide}$ — Copy (two files), move (one file, new place) or delete (to the bin).
2. $\text{Do it}$ — Use the menu or keys you know: Copy, Cut, Paste. Dragging can do either.
3. $\text{Look}$ — Open both folders. Is the file where you expect, and gone or still there where you expect?
4. $\text{Only then}$ — Delete the old one, if you meant to.

Now: which action leaves two files?

**You want your homework in two places, the Maths folder and a USB stick. Which action?**

☐ Delete it from Maths

☐ Make a shortcut to it on the USB stick

☐ Copy it to the USB stick

☐ Move it to the USB stick

:::


:::teacher-note

**Answer:** Copy it to the USB stick

Copy leaves the file in Maths and puts a second one on the USB stick.

:::


:::keep-together

### Find the mistake

**Dev cannot find his poster at home. Click the line where Dev first goes wrong.**

```
 1  Dev finishes his poster on a school computer.
 2  He drags it onto his USB stick and pulls the stick out.
 3  He does not look at the school folder or the stick to see where the poster is now.
 4  At home the stick has the poster but at school it is gone from his folder.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: Dev dragged the poster to the USB stick and did not check where it was now. He thought the drag copied it, but he did not look, and the file was moved from the school drive.

:::


:::keep-together

### What to check

**What should Dev have done after dragging?**

☐ Nothing, drag always copies

☐ Looked in both places to see where the file is

☐ Emptied the bin

☐ Renamed the file

:::


:::teacher-note

**Answer:** Looked in both places to see where the file is

Look in both places. That one check tells you whether it was a copy or a move.
