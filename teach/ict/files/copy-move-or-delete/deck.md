# Copy, move or delete

Files and systems · Copy

<!-- Speaker note: Students learn that copy leaves the original and makes two files, move leaves one in a new place, delete sends a file to a bin that may not exist on every device, and a shortcut only points. They sort actions, find a mistake in a drag to a USB stick, and plan how to take work home safely. About 40 minutes (Predict and Try 8 min · Worked example 10 min · Vary 7 min · Practise 6 min · Make and own storage 9 min). -->

## Why it matters

> A student drags her homework from the Documents folder onto a USB stick, hands it in, and then cannot find the file at home. What did she do?

<!-- Speaker note: Four things look alike and are not: - **Copy**: a second file. The first stays where it is. Now there are two. - **Move**: the file goes from one folder to another. There is still one. - **Delete**: the file goes to the **bin** (or trash). It is gone from its folder and can usually be put back until the bin is emptied. - **Shortcut**: a small file that points to another file. If the original goes, the shortcut stops working. Dragging a file does different things depending on where you drop it. On the same drive it usually **moves** it. To a different drive or a USB stick it usually **copies** it. The safe habit is to say which one you mean, then check that the file is where you expect, in both places. -->

## Say which one you are doing

Now: which action leaves two files?

$$\text{Decide}$$

1) $\text{Do it}$ — Use the menu or keys you know: Copy, Cut, Paste. Dragging can do either.
2) $\text{Look}$ — Open both folders. Is the file where you expect, and gone or still there where you expect?
3) $\text{Only then}$ — Delete the old one, if you meant to.

## Find the mistake

**Dev cannot find his poster at home. Click the line where Dev first goes wrong.**

```
 1  Dev finishes his poster on a school computer.
 2  He drags it onto his USB stick and pulls the stick out.
 3  He does not look at the school folder or the stick to see where the poster is now.
 4  At home the stick has the poster but at school it is gone from his folder.
```

* Answer: line 3

<!-- Speaker note: Line 3: Dev dragged the poster to the USB stick and did not check where it was now. He thought the drag copied it, but he did not look, and the file was moved from the school drive. -->

## Exit ticket

**How can you tell if you copied or moved a file?**

* Look in the first folder. If the file is still there it was a copy; if it is gone it was a move.
