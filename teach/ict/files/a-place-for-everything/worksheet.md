# A place for everything

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** Two students save the same bean results. One finds them in ten seconds and the other in ten minutes. What did the first one do?


:::teacher-note

**In one sentence:** Students learn that a folder holds files and sits inside another folder, that a path is the address of a file read from the outside in, and that a good name says what the file is and has the date as year-month-day. They sort files into folders, name files, and plan folders for their own subjects.

**Students should be able to say:** I can read a path and say which folder a file is in. I can give a file a name that says what it is and when. I can plan folders for my own subjects.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Worked example: names that work


:::keep-together

### A name that says what it is

1. $\text{What is it?}$ — Start with the thing: bean-results, fractions-homework.
2. $\text{Which one?}$ — Add the date as year-month-day, so a list sorts into order.
3. $\text{No spaces or odd signs}$ — Use hyphens. Spaces and signs such as # or / can cause trouble.
4. $\text{Keep the ending}$ — .txt, .docx, .png say what kind of file it is. Do not change it by typing.

Now: which name says what the file is?

**Which name is best for a file with the bean results from 12 October 2026?**

☐ results.txt

☐ 12-10-26 NEW results FINAL.txt

☐ bean results (2).txt

☐ bean-results-2026-10-12.txt

:::


:::teacher-note

**Answer:** bean-results-2026-10-12.txt

It says what it is (bean results) and has the date as year-month-day, so a sorted list puts the files in date order.

:::


:::keep-together

### Find the mistake

**Ana cannot find her bean results. Click the line where Ana first goes wrong.**

```
 1  Ana saves her bean results as results.txt.
 2  She changes the numbers and saves again as results-final.txt.
 3  She changes them once more and saves it as results-final-final-2.txt, so the name says nothing about what is inside.
 4  The next week she cannot tell which file is newest.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: Ana named the file results-final-final-2 instead of saying what is in it. Words like final stop being true when she saves another one, and nobody can tell which is newest.

:::


:::keep-together

### Why year first

**Why write the date as 2026-10-12 and not 12-10-26?**

☐ It looks nicer

☐ Computers cannot read the other way

☐ A list sorted by name puts the files in date order

☐ It is shorter

:::


:::teacher-note

**Answer:** A list sorted by name puts the files in date order

Year first, then month, then day, so sorting by name also sorts by date.

:::
