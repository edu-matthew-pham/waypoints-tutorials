# A place for everything

Files and systems · Find it

<!-- Speaker note: Students learn that a folder holds files and sits inside another folder, that a path is the address of a file read from the outside in, and that a good name says what the file is and has the date as year-month-day. ## Why it matters

> Two students save the same bean results. One finds them in ten seconds and the other in ten minutes. What did the first one do?

<!-- Speaker note: A **folder** holds files and other folders. A **path** is the address of a file: the folders you go through, in order, then the file. Here the path is `Science/Beans/results-2026-10-12.txt`: ```text Documents Science Beans results-2026-10-12.txt Maths homework-2026-10-14.docx ``` A good **name** says what the file is, and it still makes sense in a long list. The ending after the dot, such as `.txt` or `.docx`, says what kind of file it is. -->

## A name that says what it is

Now: which name says what the file is?

$$\text{What is it?}$$

1) $\text{Which one?}$ — Add the date as year-month-day, so a list sorts into order.
2) $\text{No spaces or odd signs}$ — Use hyphens. Spaces and signs such as # or / can cause trouble.
3) $\text{Keep the ending}$ — .txt, .docx, .png say what kind of file it is. Do not change it by typing.

## Find the mistake

**Ana cannot find her bean results. Click the line where Ana first goes wrong.**

```
 1  Ana saves her bean results as results.txt.
 2  She changes the numbers and saves again as results-final.txt.
 3  She changes them once more and saves it as results-final-final-2.txt, so the name says nothing about what is inside.
 4  The next week she cannot tell which file is newest.
```

* Answer: line 3

<!-- Speaker note: Line 3: Ana named the file results-final-final-2 instead of saying what is in it. Words like final stop being true when she saves another one, and nobody can tell which is newest. -->

## Why year first

**Why write the date as 2026-10-12 and not 12-10-26?**

- It looks nicer
- Computers cannot read the other way
- A list sorted by name puts the files in date order
- It is shorter

* Answer: A list sorted by name puts the files in date order

<!-- Speaker note: Year first, then month, then day, so sorting by name also sorts by date. -->
