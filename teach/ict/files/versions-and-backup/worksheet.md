# Versions and backup

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A student spends a week on a report, then saves a bad edit over the top and closes it. Is the good version gone?


:::teacher-note

**In one sentence:** Students learn that saving over a file replaces the old one, that a version is an earlier state of a file and a backup is a copy in a different place, and that sync is not a backup on its own because it copies deletions and mistakes. They sort versions and backups, find a mistake about a single copy, and plan how to protect a project.

**Students should be able to say:** I can say what a version is and what a backup is. I can explain that sync copies mistakes and deletions. I can plan how to protect my project.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Worked example: the lost week


:::keep-together

### Two ways to be safe

1. $\text{Before a big change}$ — Save a copy with the date in its name, or check that version history is on.
2. $\text{After the work}$ — Save a copy in a second place that is approved by the school.
3. $\text{Check}$ — Open the second copy. Does it open, and is it the one you expect?
4. $\text{Often}$ — Little and often. The newest work is the work you lose.

Now: what protects against a broken laptop?

**Your laptop falls and breaks. Which would have protected your work?**

☐ A backup in a different place

☐ A shortcut

☐ A version in the same folder

☐ A new file name

:::


:::teacher-note

**Answer:** A backup in a different place

A backup in a different place, so the laptop breaking does not take the work.

:::


:::keep-together

### Find the mistake

**Lin lost her whole project. Click the line where Lin first goes wrong.**

```
 1  Lin works on her science project for a week.
 2  She saves it on her laptop each day.
 3  She keeps only that one copy, on the laptop, and does not put it anywhere else.
 4  Her laptop breaks, and the project is gone.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: Lin kept her only copy on the laptop, and had no second place. When the laptop failed, there was nothing else. A backup in another approved place would have saved the week.

:::


:::keep-together

### Sync

**A friend says her cloud folder is her backup. She deletes a file from her laptop by mistake. What happens in the cloud folder?**

☐ Nothing, the cloud is separate

☐ The file comes back on its own

☐ The deletion usually syncs, and the file goes from the cloud copy too

☐ The cloud keeps it for ever

:::


:::teacher-note

**Answer:** The deletion usually syncs, and the file goes from the cloud copy too

Sync copies deletions and mistakes as well. Find out whether your service keeps old versions or deleted files, and for how long.
