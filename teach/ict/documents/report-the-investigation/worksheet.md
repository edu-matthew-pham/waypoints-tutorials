# Report the investigation

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** The class has the bean results from the Working with data course, and a teacher who wants a one-page report and a three-slide talk by Friday. What do you do first?


:::teacher-note

**In one sentence:** A challenge that uses the whole course. Students turn a class bean investigation into a one-page report (real headings, a numbered method, a table with a header row, a look set through styles, room to read) and a three-slide talk (one idea per slide, a picture with alt text and a credit, readable size and contrast), then repeat it with their own class's results in the school's apps.

**Students should be able to say:** I can make a report with real headings, a list and a table. I can make three slides that carry one idea each and can be read from the back. I can credit a picture and say what it shows.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::
