# Room to read

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A report is a page and a bit long. A student squeezes it onto one page. Her teacher says it is now harder to read. How can less paper be worse?


:::teacher-note

**In one sentence:** Students learn that layout is for the reader: space between parts, margins that keep lines short enough to follow, and a left edge for paragraphs. They open up a crowded page and repeat it in the word processor the school uses.

**Students should be able to say:** I can use space, margins and alignment to make a page easier to read. I can say why squeezing a page to save room can make it worse. I can find these settings in my own word processor.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Worked example: why more room


:::keep-together

### Opening up the page

1. $\text{Space between parts}$ — Open it, so each part is easy to find and the page can be scanned.
2. $\text{Margins}$ — Keep them wide enough that lines are not too long to follow.
3. $\text{Alignment}$ — Align body text to the left, so each line starts at the same edge.
4. $\text{The look is for the reader}$ — Fewer pages is not the goal. Use more room if the reader needs it.

Now: why does a left edge help?

**Why is a paragraph that starts at the same left edge on every line easier to read than a centred one?**

☐ It uses less paper

☐ It looks fancier

☐ It is shorter

☐ The eye knows where each new line starts

:::


:::teacher-note

**Answer:** The eye knows where each new line starts

With a left edge the eye jumps straight back to the same place. With centred lines it has to hunt for the start of each one.

:::


:::keep-together

### Find the mistake

**Jay's teacher says the report is hard to read. Click the line where Jay first goes wrong.**

```
 1  Jay's report is one page and a bit long, and the limit is one page.
 2  Jay sets the margins to narrow and the space between parts to tight so it fits.
 3  It now fits on one page.
 4  His teacher says it is hard to read.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: Jay narrowed the margins and tightened the space to save paper. That made the page crowded. White space is part of the layout, not wasted paper.

:::


:::keep-together
