# Lists and tables

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A report gives each condition and its height as three sentences. A reader wants to compare them. What would make that quick?


:::teacher-note

**In one sentence:** Students choose between a bulleted list, a numbered list and a table by looking at the shape of the facts: no order, an order, or several facts for each item. They give a table a header row so its columns are named, and repeat it in the word processor the school uses.

**Students should be able to say:** I can choose a bulleted list, a numbered list or a table to fit the facts. I can say what a table's header row is for. I can make each of them in my own word processor.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Worked example: list or table


:::keep-together

### Choosing the shape

1. $\text{Steps in order}$ — Use a numbered list. The numbers show the order.
2. $\text{Items with no order}$ — Use a bulleted list, such as the equipment you need.
3. $\text{Items with several facts}$ — Use a table, so a reader can compare down a column.
4. $\text{Name the columns}$ — Make the first row a header row, so each column is named.

Now: which fits three beans with a colour and a height?

**Three beans each have a colour and a height. A reader wants to compare the heights. What fits best?**

☐ A bulleted list of sentences

☐ A table with a column for height

☐ One long paragraph

☐ A numbered list

:::


:::teacher-note

**Answer:** A table with a column for height

Each bean has several facts, so a table lines the heights up in a column.

:::


:::keep-together

**Answer:** line 2

Line 2: the steps have an order, but Ravi used bullets. Bullets say 'these are all here', not 'do this first'. A numbered list shows the order.

### What is a header row?

**What does the header row of a table do?**

☐ Sorts the rows

☐ Adds up the numbers below

☐ Names what each column holds

☐ Makes the table bigger

:::


:::teacher-note

**Answer:** Names what each column holds

The header row names the columns, and the app can tell the header from the data (for a screen reader, too).

## Make: In your own app

Bulleted and numbered lists are buttons near the styles list in every word processor. Tables are under Insert. Most apps have a Header row option in the table's settings, and it is what screen readers use to read column names.

Work in the tutorial. Plan first: what will you change, and how will you test it?
