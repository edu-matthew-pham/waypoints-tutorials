# Change the style, not every line

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** A student makes six headings bigger, one click at a time. Next week she adds a seventh part. Will its heading match the others?


:::teacher-note

**In one sentence:** Students learn that a style is one definition used by every part that has it, so changing the style once changes them all and any added later, while changes made by hand stay on top of the style. They set the look of a report through its styles and repeat it in the word processor the school uses.

**Students should be able to say:** I can change a style once so every part with it changes. I can say why changing each part by hand goes wrong. I can tell when formatting by hand is the right choice.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Worked example: change it once


:::keep-together

### Change a style once

1. $\text{Open the style}$ — Pick Heading 1 in the styles panel, not one heading on the page.
2. $\text{Change the look}$ — Make it bigger, change the font or turn bold on or off.
3. $\text{Every part follows}$ — All the Heading 1 parts change together, and any you add later start with the new look.
4. $\text{By hand only for one}$ — Use Bold on a selected part only for a single exception, such as one word that needs to stand out.

Now: why change the style?

**Why change the style instead of each heading?**

☐ It saves the document

☐ One change reaches every part with that style

☐ It makes the headings bold

☐ It checks the spelling

:::


:::teacher-note

**Answer:** One change reaches every part with that style

A style is one definition, so one change reaches every part that uses it, now and later.

:::


:::keep-together

### Find the mistake

**Sam's seventh heading does not match the other six. Click the line where Sam first goes wrong.**

```
 1  Sam's report has six parts, and each has a Heading 1 heading.
 2  Sam wants every heading bigger, so she clicks each heading and makes it bigger by hand.
 3  The six headings now look the same.
 4  A week later she adds a seventh part and gives it Heading 1.
 5  The seventh heading is smaller than the other six.
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 2

Line 2: Sam changed each heading by hand. The style itself did not change, so the seventh heading, which uses the style, still has the old look.

:::


:::keep-together

### What stays on top?

**Sam makes one heading bold by hand, then you remove bold from the Heading 1 style. What happens to Sam's heading?**

☐ It turns into body text

☐ It stays bold

☐ It disappears from the headings panel

☐ It stops being bold

:::


:::teacher-note

**Answer:** It stays bold

Formatting by hand stays on top of the style. That is why mixing the two goes wrong.
