# What did he do, and how did it change things?

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** An order from the emperor says: from now on, everyone measures grain the same way. How does one sentence written in the capital change what a farmer does a thousand kilometres away?


:::teacher-note

**In one sentence:** Describe the First Emperor's achievements (standard script, weights, measures and coins; roads, canals and walls; one system of laws run by officials) and explain each as action, how it worked and what changed, using more than one kind of evidence.

**Students should be able to say:** I can describe two of the First Emperor's achievements with evidence. I can explain how an achievement changed things, not just that it did. I can name the other people who made the changes happen.

**Width:** the unmarked parts are the floor every student does (predict, run, investigate and make). Typical adds the modify practice; wider adds the real-world contexts. They add contexts, not difficulty. Students work in the online tutorial alongside this sheet.

:::

## Worked example: explaining how


:::keep-together

### Explain how

**Which sentence explains how the single script changed the empire, not just that it did?**

☐ The single script was a very important achievement that changed China a great deal

☐ Officials everywhere used the same characters, so orders were read the same way everywhere

☐ The single script made the emperor famous across the whole world, then and now

☐ The emperor liked one script best, so he chose it for everyone in the whole land

:::


:::teacher-note

**Answer:** Officials everywhere used the same characters, so orders were read the same way everywhere

An explanation names the action, how it worked (officials using the same characters) and what changed.

:::


:::keep-together

### Find Nib's mistake

**Nib is explaining how the First Emperor united China (Nib's notes are made up for this lesson). Click the first line where Nib's thinking goes wrong.**

```
 1  Qin defeated the last six rival kingdoms by 221 BCE.
 2  After that the empire had one script, one set of measures and one set of laws.
 3  Nib says: "The First Emperor did all of this by himself."
 4  Nib says: "So the officials and workers don't matter to the story."
```

Line: {{field-15}}

Why is it wrong?

{{lines-2}}

:::


:::teacher-note

**Answer:** line 3

Line 3: Nib says he did it all by himself. He gave the orders, but generals led the armies, advisers like Li Si planned the changes, officials ran the commanderies and labourers built the roads and walls. Qin had also been growing stronger for generations before him.

:::


:::keep-together

### According to whom?

**Why does the lesson say 'according to Sima Qian' about the burning of books and the killing of scholars?**

☐ He wrote a century later for the Han, so details may have grown

☐ Because Sima Qian was there and saw it happen with his own eyes

☐ Because historians are sure the Qin never burned any books

☐ Because the First Emperor wrote the story himself on a stone inscription

:::


:::teacher-note

**Answer:** He wrote a century later for the Han, so details may have grown

Sima Qian wrote about a century later for the Han, who replaced the Qin. Naming the source shows whose account it is, and helps you judge how far to trust it.
