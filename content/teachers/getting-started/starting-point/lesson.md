Learning Waypoints helps you work out what students need to understand, what to teach first and how to check their thinking. You can use it to plan a topic, prepare teaching resources or try an activity with your class.

A **waypoint** is an idea students need to understand to meet a curriculum expectation. In our Geography example, one waypoint is understanding that a renewable resource can still be used up. That matters when students explain why a river can run low.

The waypoints draw on ACARA descriptors. Their sequence, examples and teaching suggestions reflect professional judgement; ACARA does not prescribe them. You can use them alongside your learning intentions and success criteria to think through what students already know and where they might need help.

The teacher situations in this lesson are made up.

## Think first: tomorrow's lesson

```step
stage: predict
insight: "Start with the part that helps with the lesson you are planning."
check:
  type: predict
  q: "You already know the concept and need slides for tomorrow. Where would you look first?"
  options: ["Unpack", "Prepare", "Tutorials"]
  actual: "Start in Prepare for slides. You can also use Unpack to revisit the idea or Tutorials to find a check, whenever those would help."
```

## The idea: three ways in

```step
stage: investigate
insight: "The three tools serve different needs and can be used independently."
```

- [**Curriculum: Unpack**](https://acara.learningwaypoints.com/): see how ideas build on each other and what students need to understand first.
- [**Planning and preparation: Prepare**](https://prepare.learningwaypoints.com/): work with slide decks and printable teaching resources.
- [**Tutorials**](https://tutorials.learningwaypoints.com/geography/water-7/resource-types/): use activities, checks and feedback to explore what students understand, on their own or as a class.

Open each tool and have a look. Use whichever part helps with your planning; you do not have to use all three or follow a set order. The Geography example is a preview, not yet tried with classes.

## Check: match the need

```step
stage: practise
insight: "Match an immediate need to what the tool actually offers."
check:
  type: match
  q: "Where would you start in each of these situations?"
  pairs:
    - ["Find out what students need to understand before a Year 7 Geography topic", "Unpack"]
    - ["Prepare slides for tomorrow's lesson", "Prepare"]
    - ["Find a check to explore why students confuse renewable and continuous resources", "Tutorials"]
  explain: "Unpack helps you understand how the ideas build. Prepare helps you make teaching resources. Tutorials offers activities, checks and feedback. Choose the part that helps you now."
hint:
  - "Does the teacher need help with the ideas, a teaching resource or a check to try?"
```

## Check: is there a required order?

```step
stage: practise
insight: "You can use one tool without working through the others."
check:
  type: question
  q: "A colleague already has a unit plan and wants one misconception check. Which advice fits?"
  options:
    - "Use the relevant Tutorials check alongside the unit."
    - "Complete Unpack and Prepare before opening Tutorials."
    - "Use Unpack because its curriculum map is a ready-made slide deck."
    - "Use Tutorials only for homework; classroom teaching needs another tool."
  answer: 0
  feedback:
    - null
    - "Your colleague can go straight to the check they need."
    - "Unpack shows how ideas build on each other. Look in Prepare for slides."
    - "A tutorial check can also support a whole-class prediction or discussion."
  explain: "Use the check where it fits the unit you already teach."
```

## Apply: your next starting point

```step
stage: make
insight: "Teachers choose a starting point and can explain when another tool might help."
check:
  type: reflect
  text: "I chose one tool for a lesson I am planning and explained, in my own notes or to a colleague, when a second tool might also help."
```

Choose one tool for a lesson you are planning. Explain in your own notes or to a colleague when a second tool might help. No response is sent or automatically assessed. The next lesson takes you through a Geography example.

```teacher
summary: "Teachers compare three invented planning needs and choose a starting point for their own work."
time: 5
timing: "Think first 1 min · Three tools 1 min · Checks 2 min · Apply 1 min"
goals:
  - "I can choose a Waypoints tool for a teaching need."
before: "For a facilitator: invite one current planning need. The course is optional; teachers can use it independently. All teacher scenarios are invented."
running:
  - "Ask for a prediction before naming the three tool roles."
  - "Open each real tool. Discuss a case where two tools would both help."
  - "Let teachers choose their own starting point without collecting their notes."
struggle: "If teachers expect to complete all three tools in order, ask what they need for tomorrow and start there."
stuck:
  - { see: "Everyone must do all three in order.", ask: "What do you need for tomorrow?", fix: "Start with the tool that serves that need." }
support: "Read the three needs aloud and compare one pair at a time."
stretch: "Describe two different starting points for the same topic."
exit: { q: "Must you start in Unpack?", a: "No. You can start with whichever part helps you." }
class:
  activities:
    - { at: end, kind: discussion, title: Your starting point, minutes: 1, do: "Name a lesson you are planning and the tool you would open first.", notes: "Accept different choices when the teaching need supports them." }
```
