## The idea in plain words

**Encoding** writes data in another form by a public rule: binary, hex and base64 look scrambled, but anyone can turn them back, so they hide nothing. **Encryption** needs a secret key as well; without the key, the data can't be read. (Hashing, in Security and privacy, is one-way: for checking passwords, not for reading them back.)

A web page is sent **whole** to every visitor's browser. Comments, hidden fields, scripts and a photo's details (often the place it was taken) aren't shown on the page, but anyone can read them with View source or by saving the file. And a check that runs in the browser can be skipped by its visitor, so real checks happen on the server.

## The mission

Students check the Coding Club's own pages and messages before anyone else does, then fix what they find. Everything is made up; addresses use the `example` domains.

## Rules of the game

Only test what you own or have been given permission to test, as here. Every finding is fixed and reported.
