## The idea in plain words

Every web page is three layers. **Content** is what it says: the words, pictures and links. **Structure** is what each part *is*: HTML tags mark a heading, a paragraph, a list, the menu (nav), the main part. **Presentation** is how it looks: CSS rules set colours, fonts, sizes and layout.

Kept apart, each layer can change on its own. Swap the style sheet and the page looks completely different, but its structure and words are untouched. One style sheet can style every page of a site, so one change restyles them all. A screen reader ignores the look and reads the structure ("Heading level 2: This week"; "List, 3 items"), so a page that fakes a heading with big bold text sounds like plain text to a blind reader. The same structure can be laid out for a phone or a laptop.

## What students get wrong

- **How it looks is what it is.** Big bold text is not a heading unless the structure says so.
- **If it looks the same, it is the same.** A screen reader, a search engine and a phone layout read the structure, not the look.
