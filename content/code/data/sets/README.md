# Data sets for Data detective

Every lesson reads one table shape: a name, a category, a year or level, and a number. A class can swap in its own CSV with the same idea (the Files tab in the Python playground can add a file from the computer).

- **music.csv** (49 well-known songs: title, artist, year, genre, minutes). Compiled by hand for these lessons from widely published facts. Lengths are rounded and approximate (album or single versions differ), and each song has one simple genre label, which is a choice rather than a fact. Free to use (CC0). To use checked data instead, export a CSV with the same columns (title, artist, year, genre, minutes), for example from the Wikidata Query Service, and put it in the course in place of this file (or students add it in the Files tab).
- **survey.csv** (20 rows, made up for these lessons, no real students). A class survey with deliberate mess for the cleaning lesson: mixed capitals and spaces, a blank genre, a blank number, a number in words, a negative and an impossible number of hours, and a repeated row. Free to use (CC0).
