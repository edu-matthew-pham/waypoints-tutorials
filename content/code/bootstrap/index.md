**Bootstrap** is a big stylesheet someone else wrote. You link it, then add its class names to your tags: `class="btn btn-primary"` makes a styled button with no CSS of your own. You built every part of the club page by hand in HTML & CSS; here you rebuild them with Bootstrap and decide when each way is better.
