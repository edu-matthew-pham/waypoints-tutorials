A place for everything

A folder holds files and sits inside another folder, so every file has an address called a path, such as Science/Beans/results-2026-10-12.txt. A name should say what the file is and still sort well: a clear word first, the date as year-month-day, and no final-final-2. The ending (.txt, .docx, .png) says what kind of file it is.

Two students save the same bean results. One finds them in ten seconds and the other in ten minutes. What did the first one do?

How this lesson works: Predict, Try, Investigate, Modify, Practise, Make

In your school's storage

Use only the storage your school has approved. File Explorer, Finder, Google Drive and OneDrive all have New folder and Rename. The path is usually shown at the top of the window, or in the file's details.

For teachers

Students learn that a folder holds files and sits inside another folder, that a path is the address of a file read from the outside in, and that a good name says what the file is and has the date as year-month-day. They sort files into folders, name files, and plan folders for their own subjects. About 40 minutes.

Open the teacher guide: answers, solutions, slides and a worksheet.

Students will be able to

  • I can read a path and say which folder a file is in.
  • I can give a file a name that says what it is and when.
  • I can plan folders for my own subjects.

Before class

Check your school's approved storage first and fit the last step to it: a shared drive, OneDrive, Google Drive or the local device.

The one idea: a folder says what it is for, a name says what is in the file, and the path joins them into an address. The folders and files here are made up.

Running the lesson

  1. Predict: students who pick the file name have the path the wrong way round. Say it aloud from the outside in.
  2. Try: ask what a stranger would need to know to find the file.
  3. Worked example: ask Ana what the name will mean next week.
  4. Practise: ask which name they could find by sorting.
  5. Own storage: check the name before they save. Does it say what and when?

The hard part (on purpose)

Students save everything on the desktop or in Downloads and rely on search. Ask them to find a file from three weeks ago without searching.

When students get stuck

  • A student cannot say what the path means. Ask: Which folder do you open first? Fix: Read it from the left: open the first folder, then the next, and the file is last.
  • A student names everything final. Ask: What will it be called when you save another one? Fix: Put the date in the name, not the word final. The newest sorts last.
  • A student changes the ending to change the type. Ask: What is inside the file? Fix: Use Save as or Export to change the type. Renaming only changes the label.

Stretch and support

Stretch: Plan the folders for a whole term in all your subjects. Which folders would you open most? Could a friend find a file from your plan?

Support: A card with three words: what it is, when, where. Say all three before you save.

What each step is for

  • which folder?: Committing to an answer tests the move: a path is read from the outside in.
  • Try: put the files where they belong: Sorting files into folders settles the prediction: every file has one place, and the folder says what it is for.
  • Worked example: names that work: Choosing a name models the method. Ana saves over her good file, the mistake planted after it.
  • Vary: good name or poor name?: Each task changes what is being named: good names, an unclear name and a path.
  • where would you look?: Reading paths and naming new files, so the habit is repeated on new examples.
  • plan your own folders: Planning a folder for a real set of work has students use the move on their own subjects.
  • In your school's storage: Making the folders in the school's own storage shows the idea is the same everywhere.

Next lesson2. Copy, move or deleteCopy makes a second file and leaves the first where it is. Move takes the file out of one folder and puts it in another, so there is still one. Delete sends a file to a bin where you can usually get it back until the bin is emptied, and a file on a USB stick or a shared drive may have no bin at all. A shortcut points to a file and is not a copy. Before you act, say which one you are doing.
